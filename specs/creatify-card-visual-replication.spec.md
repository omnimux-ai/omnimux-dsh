# 规格 · Creatify 技能卡片 1:1 视觉复刻与一行三列渐变算法

## 1. 业务目标
基于用户指引与现场比对目标（`https://app.creatify.ai/creative-agent/skills`），彻底纠正目前技能市场页面的卡片黑底退化、两列排版与旧版其他标题，实现 1:1 像素级复刻：
1. 布局结构：桌面端与正常视口下严格保持**一行三个**（三列网格 `grid-template-columns: repeat(3, minmax(0, 1fr))`，`gap: 16px`）；
2. 分区架构：严格呈现「热门精选」（置顶 3 个）、「新品上市」（置顶 6 个带查看全部）、「探索更多」（剩余技能大网格）；
3. 视觉与多色渐变生成算法：
   - 采用真实的 8 套流光色彩映射算法 `COVER_NUMS = [4, 5, 6, 7, 9, 10, 2, 3]`；
   - 消除 `/omnimux/assets/...` 本地 HTTP 403 权限失效引起的图片损坏与黑底降级，将真实封面与多层拟合渐变深度绑定并直接注入；
   - 3:2 宽高比（`aspect-ratio: 3 / 2`），`border-radius: 16px`，半透明点阵网格（`mix-blend-mode: overlay`）；
   - 居中高对比纯白加粗标题搭配矢量官方认证锯齿圆对勾徽章；
   - 左上角金色半透明微光火苗徽标（热门精选）与毛玻璃药丸分类标签；
   - 悬停平滑升起底部双行简介与使用量。

## 2. 交互与渲染链路
- `skill-plaza.js`：彻底移除陈旧的私有 `renderRegularSection`（写死“其他 Skill”与旧网格），统一接入并渲染 `PlazaCardGrid.jsx` 与 `FeaturedCard.jsx`；
- `FeaturedCard.jsx`：集成真实色彩封面（Base64/SVG/CSS 双重保障），确保任何网络环境下背景流光溢彩绝不黑屏；
- `css.js`：定义 `.featured-grid`、`.cards-grid` 为 `repeat(3, minmax(0, 1fr))`，保证一行三个。

## 3. 验收标准
1. DOM 检查：技能卡片外层网格列数在桌面端为 3 列；
2. 视觉检查：卡片背景具有鲜亮丰富的色彩渐变与点阵覆盖，无任何黑底缺失；
3. 单元测试与端到端测试 100% 绿灯通过；
4. 自检比对达到与目标截图高度一致。
