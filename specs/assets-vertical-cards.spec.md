# 规格：资产库卡片升级为3:4黄金竖版自适应布局并显示相对添加时间

## 1. 业务目标与背景
在 OmniMux 资产中心浏览本地资产（角色、道具、场景、风格包、知识包、自定义）时，当前卡片默认采用 16:9 横版比例。该比例存在严重的视觉裁切缺陷：
1. **画面腰斩截断**：竖版人像肖像（如“红发蓝眸女性”）下半张脸被完全切除，变装服饰（如“牛仔竞技骑行服”）小男孩下半身不可见，破坏了素材的真实观感与选材效率；
2. **排版信息过载**：原卡片副标题展示冗长的资产长篇描述，卡片信息密度过高、不够现代极简；
3. **缺乏时间感知**：用户无法直观获知该素材是何时录入或更新的。

为提供更优雅、沉浸、符合主流多媒体资产库（对标苹果、即梦等现代极简设计）的视觉与交互体验，本任务进行三维升级：
1. **卡片改为 3:4 黄金竖版比例**：兼顾人像特写、道具与横版素材，卡片形态匀称大方；
2. **图片根据卡片比例等比居中自适应缩放**：采用 `object-fit: cover`，彻底告别切头截脸、黑边留白与拉伸变形；
3. **卡片副标题由描述改为相对添加时间**：
   - 不再展示长篇描述，改为展示极简的相对时间（如“刚刚”、“5分钟前”、“1小时前”、“昨天”、“3天前”等）；
   - 抽象出高可靠、跨平台、纯函数式的相对时间格式化工具 `formatTimeAgo`，便于全平台复用；
4. **共享设计规范复用**：遵循既有深色系 Token 与边框、阴影、悬停动效与多选框规范。

## 2. 用户旅程与界面契约

### 2.1 资产卡片网格（`AssetGridCard` / `AssetGrid`）
- **卡片形态与比例**：
  - 卡片封面缩略图容器（`.omnimux-assets-card-thumb` / `MediaCard` 的 `coverWrapper`）采用 `3:4`（`aspect-ratio: 3 / 4`）黄金竖版比例；
  - 内部图片（`.omnimux-assets-card-media`）采用 `width: 100%; height: 100%; object-fit: cover; object-position: center;`，实现智能等比居中自适应缩放；
  - 悬停浮层（`.omnimux-assets-card-overlay`）自适应填满 3:4 区域，平滑展现「查看详情」与「添加到会话」按钮；
  - 左上角多选勾选框与右上角类别徽标位置规范，视觉无侵入。
- **卡片文本区**：
  - 标题：保持资产名称 `asset.name`（14px 粗体，单行截断）；
  - 副标题：由原本的长篇描述改为相对添加时间，通过 `formatTimeAgo(asset.created_at || asset.createdAt || asset.updated_at)` 呈现，字体 12px，次级弱化颜色，清爽紧凑。

### 2.2 相对时间工具函数（`formatTimeAgo`）
- 抽象至 `plugins/omnimux-assets/src/client/format.js`（以及共用库）：
  - 输入支持：时间戳数字（毫秒）、ISO 8601 字符串、Date 对象，对 `null` / `undefined` / 非法值防御性安全回退为空字符串或“刚刚”；
  - 相对时间梯级：
    - `< 1分钟`（或未来5秒内时间偏差）：显示“刚刚”；
    - `< 1小时`：显示“N分钟前”（如 `10分钟前`）；
    - `< 24小时`：显示“N小时前”（如 `1小时前`）；
    - `< 48小时` 且跨越自然天：显示“昨天”；
    - `< 30天`：显示“N天前”（如 `3天前`）；
    - `< 365天`：显示“M月D日”（如 `9月7日`）；
    - `>= 365天`：显示“YYYY年M月D日”（如 `2025年6月18日`）；
  - 支持传入可选的 `now` 参数，便于全量覆盖单测断言。

## 3. 验收标准与测试
1. **单元测试与组件测试**：
   - 为 `formatTimeAgo` 编写完整的单元测试文件，覆盖各个时间段梯级、未来微小时钟误差、非法输入、空值容错；
   - `AssetGrid.test.js` 断言卡片已更新为 3:4 竖版自适应规格，且副标题渲染相对时间而非描述；
2. **自动化测试套件**：
   - `plugins/omnimux-assets` 单元测试与端到端测试 100% 绿灯；
   - 界面无横版裁切腰斩，人像与道具主体清晰完整。
