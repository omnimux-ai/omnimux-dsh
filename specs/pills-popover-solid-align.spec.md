# 快捷菜单面板紧贴依附输入框下方且保持既有UI样式规范

## 目标与验收
1. 用户明确需求：
   - 默认状态：列表面板完全隐藏不显示，输入框下方仅呈现 4 个居中快捷胶囊按钮；
   - 点击交互状态：点击任一快捷按钮后，按钮平滑隐退，列表面板直接切换呈现并紧贴依附在输入框正下方（顶部间距约 4.7px）；
   - 对齐与材质：面板宽度左右两端严格等宽对齐输入框（误差 0px），背景采用纯深色实底遮罩，完全不透底；
   - UI 规范遵从：全量复用现有设计系统变量（`--dsw-alias-*` 等），严禁随意新增外来样式或非标配置。
2. 背景不透明度验收：面板背景使用 `--dsw-alias-bg-elevated` 或 `--dsw-alias-bg-layer-2`，实色遮罩，彻底杜绝透底。
3. 宽度与几何对齐验收：面板宽度与输入框等宽（误差 0px），实测间距紧贴（约 4.7px）。
4. 交付门禁：先高保真交互演示并实机测量几何数据，待用户确认后合入。
