# 规格 · 设置面板行标签与说明句的窄宽度布局（Issue #3796）

## 背景

侧栏设置面板每行是 `<label>` 里的一对「标签 + 说明句」，下面挂控件。`src/panel/styles.css` 的
`.settings label` 用 `grid-template-columns: 1fr auto`：标签在 `1fr` 列，说明句在 `auto` 列。
说明句是长中文且没有换行约束，`auto` 列按内容撑到接近整行宽，`1fr` 列被压到不足一个汉字宽。
中文在极窄容器里逐字断行，于是「文本生成模型」竖着叠成 5 行；两行说明句长短不同，行高也不齐。

## 目标

- 标签永远单行完整显示，不逐字竖排。
- 说明句让出列宽：宽面板下与标签同排右对齐并允许换行；窄面板下落到标签下方、左对齐。
- 控件（模型选择器）整行满宽，与说明句之间不留异常空白。
- 只改 `.settings label` 行的排版规则，不动任何设置键、持久化、文案与控件实现。

## 假设

- 竖排的直接成因是网格 `1fr` 列被 `auto` 列挤到不足一字宽，而不是字体、`word-break` 或缩放变量；
  因此把标签列改为按内容取宽、说明句列改为可收缩可换行，就能在不改文案的前提下恢复单行。
- 设置面板所有 `label` 行共用同一套网格，修好模型两行不会连带破坏其它行，因为其它行控件本就
  `grid-column: 1 / -1` 满宽跨两列，列宽变化只影响标签与说明句的相对位置。

## 证伪方式

- 若真实浏览器（未打包扩展，≤420px 面板宽）截图里标签仍出现竖排或说明句仍占满整行，则本改动未生效。
- 若其它设置行（连接实例、桥地址、Token、主题、语言、字号）出现标签被裁切、说明句压住控件或
  横向溢出，则说明网格改法误伤了共用行，判为证伪。

## 验收用例

1. 真实浏览器、面板宽 420px：两行标签各占一行、完整可读；选择器满宽。
2. 真实浏览器、面板宽 420px 与 1280px 两种宽度：说明句不覆盖控件，不产生横向滚动。
3. `panel-styles` 与 `panel-text-model-isolation` 定向单测通过。

## 旧标准变更

无。本任务不改写任何既有具名用例的断言；`panel-styles.spec.ts` 对 `.settings` 与 `.settings > *`
的断言保持原样（本改动不触及这两条规则）。
