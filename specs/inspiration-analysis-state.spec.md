# 灵感详情分析实时状态（#3400）

## 目标与验收
- 点击分析后立即禁用提交按钮，按钮文字严格显示“解析中...”。
- 关闭并重新打开同一帖子，仍从已保存状态显示进行中；完成与失败可实时刷新，恢复操作。
- 不同帖子与分析对象不串状态；关闭窗口不取消后台分析，不重复提交。
- 后台异常重启后，失去执行者的分析记录转为中断失败，可重新分析，不能永远锁住按钮。

## 范围与实现约束
复用已有分对象分析记录与详情获取能力；不引入平行任务存储或模型调用。仅修改灵感插件及必要测试。

## 新用户基线
依赖已安装插件、登录及已配置可分析渠道；状态读取使用现有服务。缺能力继续显示现有明确失败信息。测试使用合成后台，不读取开发机凭据或业务数据。

## 文档影响
本规格记录行为变更；不改变公开能力、模型、工具与配置契约，无其它文档改动。
