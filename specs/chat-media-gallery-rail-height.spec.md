# 助手回复多素材画廊 · 缩略图栏高度锁在主图内

## 1. 目标（Objective）

对话里一次生成多张图时，结果卡片是「左侧主图 + 右侧缩略图」。缩略图张数变多时，右侧栏不得把整张卡片和下面的对话往下撑开。可见高度必须等于当前主图高度；多出来的缩略图只在右侧栏里上下滚动，点击仍可切换主图。

用户：看对话结果的人。成功：8 张及以上缩略图时，卡片底边与主图底边对齐，下方对话不被遮挡。

## 2. 问题与根因

| 现场 | 根因 |
| --- | --- |
| 右侧缩略图无限往下堆，盖住下方对话 | 画廊容器高度随内容撑开；右侧栏 `height: 100%` 在父级 `height: auto` 下无法解析，栏高被全部缩略图内容决定 |
| 容器虽有最大高度，仍往下溢出 | 默认不裁切子元素，最大高度未限制右侧栏 |

## 3. 布局规则

1. 画廊高度只由左侧主图决定（主图自身仍受最大高度约束）。
2. 右侧缩略图栏贴齐主图上、下边，栏内纵向滚动。
3. 缩略图总高不超过主图时，不出现无意义滚动条。
4. 点选、键盘切换、渐隐提示、单张卡片布局均保持原语义。

## 4. 命令（Commands）

- 单测：在工作树 `plugins/omnimux` 内跑媒体画廊相关测试
- 静态：`git diff --check`
- 验收：隔离工作树内真实浏览器打开演示页，截图保留

## 5. 项目结构

- `plugins/omnimux/src/client/media-viewer/styles.js`：画廊与缩略图栏几何
- `plugins/omnimux/src/client/attachments/assistantMessageMediaEnhancer.test.ts`：结构与交互回归
- 本规格：`specs/chat-media-gallery-rail-height.spec.md`

## 6. 代码风格

沿用现有画廊样式块；高度约束用定位贴边或等效「栏不参与撑开父级高度」的写法，不引入新组件、不改令牌体系。

## 7. 测试策略

- 契约测试锁定：画廊高度由主图决定、缩略图栏裁切并内部滚动、栏不把父级撑高。
- 既有多素材点选 / 键盘切换用例保持全绿。
- 真实浏览器演示页：8 张以上缩略图时，栏高度等于主图高度。

## 8. 边界（Boundaries）

- 总是：只改对话气泡内多图结果卡片的高度约束；颜色与圆角继续用官方令牌。
- 先问：若要改单张结果卡片或右侧大图工作台。
- 绝不：改生成逻辑、改缩略图点选语义、把规格草稿写进主检出。

## 9. 成功标准（Acceptance Criteria）

- **AC-1**：多张结果时，缩略图栏的可见高度等于主图可见高度（允许 1px 舍入误差）。
- **AC-2**：缩略图总高超出主图时，只在栏内上下滚动；画廊容器高度不随缩略图张数增加。
- **AC-3**：点击被卷出的缩略图，主图切换为对应内容。
- **AC-4**：仅 1 张结果时，布局不变（无右侧栏）。
- **AC-5**：既有点选、键盘、视频封面用例全绿。

## 10. 假设

1. 只修对话气泡内的多图结果卡片，不修右侧大图工作台。
2. 主图最大高度维持现有上限，不在本任务放宽或收紧。
3. 界面改动先演示、用户确认后再合入主干。
