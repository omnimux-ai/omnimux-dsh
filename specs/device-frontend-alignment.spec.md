# feat(device): 参考 tame.so 全量对齐手机管理前端（Issue #2434）

## 背景
竞品 tame.so 研究后用户拍板「全量对齐（6 条全做）」。当前工作台 5 个标签页除集群外壳外均为静态演示内容，且组件全部内联样式（过不了 UI02 门禁）。

## 用户操作旅程与验收用例
1. **全局**：打开工作台，头部下方看到连接状态条（未连接 Mac 的警示点 + 引导语）；右侧「AI 权限」按钮打开白名单弹层（能做/永远不能两栏，高危操作人工确认）。
2. **接入向导**：点击「接入设备」打开向导弹层：4 步流程（连数据线并信任→选签名方案【推荐 付费开发者自动签 ≤100台/年｜免费账号 ≤3台】→自动构建签名安装→设备上线）+ 接入要求清单（专用无密码设备/数据线/完整 Xcode/macOS 14+/Apple silicon）+ AI 权限白名单卡。原「证书」页折叠进向导（竞品无独立证书页）。
3. **排期**：日历/列表切换；周日历每天一个「＋ 新建」；内联新建任务表单五字段（平台/账号/动作/细节/时间），创建出 toast 确认；列表视图展示示例任务行。
4. **素材**：工具行（添加默认文案/添加照片或视频）+ 搜索框 + 计数（0 项 · 0KB）；空状态写明下一步并给「去排期」跳转按钮。
5. **账号**：空状态写明「先接入设备再添加账号」+「打开接入向导」按钮；说明绑定关系与两分钟下发语义。
6. **审计**（原「诊断」页升级）：空状态「暂无已完成的执行会话」+ 两分钟同步说明 +「查看集群」按钮。
7. **养号**：保留三张策略卡，新增「暂无可用设备」引导 +「去账号页」按钮。
8. 标签页变为：集群 / 排期 / 素材 / 账号 / 审计 / 养号（诊断、证书移除）。

## 技术约束
- 组件与样式全量重写：零内联业务样式（UI02），全部类化；色彩仅官方 --dsw-* Token（var 封装或 color-mix 派生），仅手机硬件质感保留既有 exempt-ui03。
- Stage 保活契约（everOpened，#2433 已落地，保持）；iPhone 真机卡片结构沿用 #2433。
- 全部为演示态：不接真机数据，空状态诚实标注下一步。

## 验收标准
1. 真实浏览器渲染：6 标签页 + 状态条 + 向导弹层 + 白名单弹层全部可见可交互（截图证据），先演示给用户确认再合入。
2. `pnpm --filter omnimux-device test` 通过：E2E 增补新标签集合、向导结构件、白名单、空状态、排期表单断言；证书/诊断标记不存在。
3. CI 设计契约全绿。

## 新用户基线
纯前端演示态，无开发机私有路径与运行时依赖。

## 文档影响
标签页与页面语义变化，合并后在 PR 描述中说明；PRD/ARCHITECTURE 的页面清单属产品蓝图不随本次改。

## 风险
中：整页重写，但无运行时行为依赖（纯展示层），浏览器全页证据兜底。
