# 规格：侧边栏分栏与全屏机制回归原生并纯粹化视窗独立偏好记忆

- 任务单号：Issue #2037
- 目标模块：`plugins/omnimux`
- 实施分支：`agent/omnimux-tab-viewport-native-reconciler-issue-2037`

## 一、背景与问题根因分析

在之前的版本演进中，系统引入了 `data-omnimux-conversation-collapsed` 属性，并在 CSS 中强制把中间网格列设置为 `0px`（`grid-template-columns: 280px 0px 1fr !important;`）。
其初衷是为了在全屏时让右侧工作台铺满屏幕，但原生 DSH 侧边栏本身在全屏模式下（`[data-sidebar-right-panel="fullscreen"]`）是通过 `position: fixed; inset: 0` 自然顶层铺满的，底层的会话栏并不需要被强制收缩为 0 像素。

由于引入了外部 0 像素压制机制与快照同步器（`fullscreen-collapse-sync.js`）：
1. **快照死锁**：在项目、资产库等默认全屏页面中，同步器把全屏时的临时折叠误记录为进入前快照；
2. **退出全屏失效**：用户点击原生退出全屏按钮时，原生右侧栏已切为分栏（`push` 模式），但外部 CSS 依然死死将中间会话栏锁定在 0 像素，导致视觉呈现依然占满屏幕、会话栏无法呼出的死锁。

## 二、架构收敛与重构设计

1. **卸载外层 0 像素强制压制（回归原生理性）**：
   - 彻底废除在右侧面板打开时将会话列强制写死为 0px 的全局规则；
   - 让右栏全屏与分栏完全由官方底座原生的 `position: fixed; inset: 0`（全屏覆盖）与 `push`（并排分栏）接管；
   - 移除 `fullscreen-collapse-sync.js` 中的快照污染死锁，确保退出全屏时中间会话栏天然完整舒展呈现。

2. **纯粹化页面独立全屏记忆调和器（保留核心业务诉求）**：
   - 保留产品核心诉求：一级工作台页面（项目、资产库、灵感社区等）默认全屏；
   - 纯粹通过原生 `enterHostRightSidebarFullscreen` 与 `exitHostRightSidebarFullscreen` 调度宿主模式；
   - 严格记录用户在每个页面的独立视窗模式选择，并在切回该页面时忠实还原；
   - 会话优先守卫：当用户点击左侧会话记录时，会话栏拥有最高展开优先级。

## 三、验收标准（Acceptance Criteria）

- **AC-1**：用户打开「项目」、「资产库」、「灵感社区」等工作台页面，默认以全屏模式呈现（`data-sidebar-right-panel="fullscreen"`）。
- **AC-2**：在任意全屏工作台页面，用户点击右上角退出全屏（分栏）按钮，右侧栏缩为伴随分栏，中间会话栏立即恢复可见且具有有效正向宽度（`convWidth > 0`），最外层无残留的 0 像素锁死属性。
- **AC-3**：在退出全屏为分栏状态后，系统持久化记住该页面的分栏偏好；当切换至其他页面再返回该页面时，该页面维持分栏模式，不会异常回弹为全屏。
- **AC-4**：点击左侧会话列表中的任意会话项，无论当前处于何种页面或何种全屏状态，一律平滑退出全屏、居中展开会话栏。
- **AC-5**：全量单元测试与 E2E 回归测试 100% 通过。
