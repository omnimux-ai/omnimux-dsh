# 中枢模型检索面板 · 模型分组在线测试与最小样本规格 (Model Console Test Feature Spec)

- 日期：2026-09-18
- 目标页面：`http://127.0.0.1:45130/`（中枢模型检索面板）
- 需求来源：用户要求「增加给每个模型分组增加测试按钮，每个模型预设一个最小测试样本，来验证模型是否可用。例如生图模型，预设 prompt 和参数，点击测试后切换运行中，完成后显示测试结果：成功或失败，失败错误原因：xxxx。如果是必须提供参考素材的预设一个素材，要根据契约格式来预设测试提交的参数」

## 1. 核心目标与范围

1. **自动生成契约最小测试样本**：
   - 遍历各模态（文本、生图、视频、音频、网页提取）契约规范，根据模型支持的生成操作与线路分组参数约束，自动组装符合契约规范的最小合法请求参数（prompt、resolution、aspectRatio、duration、voice 等）。
   - 对于必须提供参考素材的场景（如垫图生图、首帧生视频、语音转写等需素材槽位 `min >= 1` 的操作），严格按照契约槽位的角色（`role`）、类型（`type`）、MIME 允许列表（`allowedMimes`）及大小上限（`maxSizeMb`）预设合规测试素材。
2. **分组测试卡片交互**：
   - 在每个模型的线路分组卡片（包含未配专用分组的默认候选卡片）中增加「契约测试样本」摘要展示与「测试分组」按钮。
   - 点击测试后，按钮无缝切换为「运行中…」状态（搭配原生 SVG 加载动效，禁用重复点击），卡片下方呈现加载进度指示。
3. **真实调用与结果展示**：
   - 本地服务 `POST /api/test-model` 处理测试请求，优先通过 SubmitGuard 执行契约校验门禁，随后向中枢真实网关端点发送连通性请求。
   - 测试完成后，状态转为「测试成功」或「测试失败」：
     - 成功：绿色高亮展示响应耗时及调用结果摘要（如任务编号）；
     - 失败：红色警示框清晰展示大白话格式的「失败错误原因：xxxx」（如上游 401 凭证无效、402 余额不足、429 限流、网络超时或契约未声明适配实现）。
   - 按钮转换为「重新测试」，支持随时复测。

## 2. 验收标准（可测试）

- **AC-1（全模态样本预设）**：42 款模型及其线路分组均能自动生成结构完整的最小测试样本；当操作需要素材时，预设符合契约槽位约束（mime、sizeBytes、role）的素材对象。
- **AC-2（SubmitGuard 兼容性）**：已声明 profileId 的就绪模型样本必须 100% 通过 SubmitGuard 参数门禁校验。
- **AC-3（交互三态）**：
  - 初始态：展示测试按钮与预设样本详情折叠开关；
  - 运行态：按钮显示「运行中…」，附带 SVG 旋转动效，处于禁用状态；
  - 终态：呈现明确的成功（绿色）或失败（红色）标签与详情卡片，失败时必定展示「失败错误原因：xxxx」。
- **AC-4（服务接口稳定）**：`POST /api/test-model` 接口返回标准 JSON 结构 `{ ok: boolean, durationMs: number, message?: string, error?: string, details?: object }`。
- **AC-5（视觉规范对齐）**：遵循 design.md 单色墨水质感，32px 控件高基准，8px 圆角，严禁 Emoji 图标（UI04）。
