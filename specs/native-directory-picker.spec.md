## 一、产品概况与业务目标（PRD Overview）

### 1.1 背景与用户痛点根因分析
在历史实现（Issue #2515 / PR #2518 及 Issue #2630）中，「创建项目」与「创建应用副本」曾尝试采用**“在弹窗内自定义内嵌子目录列表（In-Dialog Tree Browsing）”**的方案。该方案在实际交付与用户实测中暴露了致命缺陷：
1. **macOS TCC 权限与应用沙箱致命拦截**：macOS 严格受控于 TCC（Transparency, Consent, and Control）隐私权限与沙箱隔离。当前端通过内部 Node/RPC（`/api/browse-directory`）枚举遍历宿主本地敏感目录（如 `Desktop`、`Documents`、`Downloads` 或外置卷）时，由于缺乏原生权限凭据，系统直接硬性拦截拒绝，导致前端频繁报出刺眼的红字错误：`无法打开该文件夹` / `浏览目录失败，请重试`。
2. **交互原始且体验割裂**：自研内嵌文件树体验简陋，缺少系统 Finder / 资源管理器的侧栏书签、快捷搜索、排序、权限即时授权（Powerbox / Security-Scoped Bookmark）等基础操作系统级能力，且在弹窗内层叠展开造成信息严重过载。
3. **过度设计与文案冗余**：界面内充斥着大量喋喋不休的自言自语（如 `(不会在电脑硬盘中新建或重命名物理文件夹)`、`留空则写入默认项目库...`、`(推荐)` 胶囊等），严重背离现代高级 SaaS 极简质感。

### 1.2 核心业务目标（用户最高指令响应）
针对用户明确提出的最高要求：**“禁止使用没之前文件夹方式，只能用系统内置的打开窗口”**，本期重构目标如下：
1. **彻底废除弹窗内自定义内嵌文件树**：全面移除弹窗内的子目录列举、路径面包屑、进入/返回上一层、内嵌“选择此文件夹”等所有低可用、易报错代码，杜绝 macOS TCC 权限报错。
2. **全面恢复并统一使用系统内置原生打开窗口（Native Directory Picker）**：点击添加/更改文件夹时，直接且唯一地唤起操作系统原生对话框（macOS Finder Open Panel / Windows Explorer）。用户确认选择后，进程自动获得系统赋予的该目录访问许可，前端直接接收返回的真实绝对路径并呈现为干净卡片。
3. **落地现代 SaaS 科技极简规范（Linear / Vercel 体验对齐）**：
   - **零冗余标签**：砍掉一切主观评价胶囊（严禁 `推荐`、`极速`、`高画质` 等）。
   - **零括号废话**：标签采用纯粹实体名词，严禁拖带括号解释长句。
   - **实体名词与动词纯粹律**：标题与标签纯名词化，按钮仅使用高确定性动词（`取消`、`创建`、`选择`、`更改`、`移除`）。

### 1.3 明确不做的范围（Non-Goals）
- **绝不在弹窗内部再造文件系统浏览器**：任何形式的弹窗内目录展开、异步折叠树、内嵌滚动条一律禁止。
- **绝不在空态/已选态渲染长段解释性文字**：用户不需要理解 project.json 种子的实现细节，去除所有说明式小字。
- **绝不使用非标准字符图标**：弹窗关闭按钮必须使用标准矢量图标，严禁出现字符 `×` 或 emoji 装饰符（`💎`、`🔥`、`✨`）。

## 三、UI 元素与 SaaS 极简文案锁定规格表（UI & Copy Spec — 唯一真源）

### 3.1 弹窗 A：「创建项目」元素与文案白名单

| 组件/元素 ID | 元素类型 | 中文精确文案（逐字锁定） | 英文精确文案（en-US） | 显隐与交互规则 | 严禁附加项（显式红线） |
|---|---|---|---|---|---|
| `project.dialog.modal` | Modal 容器 | - | - | 宽度固定 440px，居中浮层，深浅色自适应 | 禁加多余内边框装饰 |
| `project.dialog.title` | 模态标题 | `创建项目` | `Create Project` | 顶栏常驻，字号 16px，600 字重 | 禁加副标题、禁加图标 |
| `project.dialog.close` | 图标按钮 | - | - | 右上角矢量关闭图标，点击关闭弹窗 | 严禁用字符 `×` 代替矢量图标 |
| `project.name.icon` | 辅助图标 | - | - | 输入框左侧前置文件夹标准图标（16×16） | 禁加其它装饰图 |
| `project.name.input` | 文本输入框 | 占位符：`项目名称` | Placeholder: `Project name` | 首屏自动聚焦；回车触发提交；字数限制 64 字符 | 严禁显示任何外置解释长句 |
| `project.source.label`| 分组标签 | `存放位置` | `Location` | 字段上方小标，纯实体名词 | 严禁写 `源文件夹(可选)`、禁带括号 |
| `project.picker.empty`| 触发按钮 | `选择文件夹` | `Choose Folder` | 空态显示。点击直接调用系统原生文件夹选择器 | 严禁出现“在此电脑上添加”、严禁加“浏览”胶囊 Badge |
| `project.picker.card` | 已选卡片 | 展示选中文件夹名，Tooltip 展示完整物理路径 | 显示选中文件夹名 | 选中后显示，高度 36px，左侧文件夹图标，右侧操作组 | 严禁显示电脑硬件图标/“本机电脑”废话标签 |
| `project.picker.change`| 行内按钮 | `更改` | `Change` | 点击再次唤起系统原生选择窗口 | 禁加多余图标 |
| `project.picker.remove`| 图标按钮 | - (Aria: `移除文件夹`) | (Aria: `Remove folder`) | 点击清空已选路径，立即平滑回退到空态 | 禁带文字标签 |
| `project.btn.cancel`  | 次要按钮 | `取消` | `Cancel` | 底栏居右排布第一位，点击直接销毁弹窗 | 禁加图标 |
| `project.btn.submit`  | 主要按钮 | `创建项目` | `Create Project` | 名称非空且合规时激活；提交中展示 loading | 严禁写 `立即创建`、`确认创建` |
| `project.error.text`  | 校验报错行 | `操作失败，请重试。` / `当前工作区已有项目` | `Operation failed, please try again.` / `Project already exists` | 仅在提交发生异常时以红色文本展示在底栏上方 | 严禁输出原始底层堆栈或英文报错码 |
