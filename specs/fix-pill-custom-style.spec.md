# 技能市场分类胶囊对齐业务决策规格（暗灰底白字加粗方案）

## 1. 背景与业务判定
业务负责人在样式仲裁看板中明确选定：
- 针对分类筛选胶囊，**采纳业务手写自定义方案（方案 B）**：即暗灰低饱和半透明底色 + 纯白高对比文字 + 字体加粗（font-weight: 700）。
- 杜绝在暗黑模式下呈现刺眼、割裂的纯白实心大底色药丸胶囊。

## 2. 规范定义
- `.cat-btn.active, .sh-mkt .cat-btn.active`：
  - 背景底色：`var(--dsw-alias-interactive-bg-active, rgba(255,255,255,.16))`
  - 文字颜色：`var(--dsw-alias-label-primary, #ffffff)`
  - 边框描边：`1px solid var(--dsw-alias-border-l3, rgba(255,255,255,.28))`
  - 字重属性：`font-weight: 700`（强对比加粗）
  - 几何形态：`border-radius: 999px; height: 28px; padding: 0 14px;`

## 3. 验收标准
- **AC-1**：技能市场分类药丸在选中时呈现低调高级的半透明暗灰底色（`rgba(255,255,255,.16)`），文字为纯白加粗。
- **AC-2**：彻底消除刺眼的纯白实心底反相黑字块，在暗黑背景下舒适沉浸。
- **AC-3**：全量测试与静态设计门禁（UI01~UI10）全部通过。
