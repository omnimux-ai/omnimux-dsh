# 规范：恢复灵感社区在左侧侧边栏展示与使用

## 1. 业务目标与背景
用户明确指示：把「灵感社区」插件在左侧侧边栏显示出来。
灵感社区是创作者发现对标素材、复刻爆款视频、解析优秀脚本与提示词的重要灵感来源。为了满足用户在创作流程中快速浏览、搜索和使用优质灵感素材的需求，将「灵感社区」从内测名单移出，正式恢复为一级功能导航项并稳定挂入左侧侧边栏。

## 2. 关键用户旅程与验收标准
1. **左侧侧边栏入口恢复展示（AC-1）**：
   - 用户打开主界面，在左侧侧边栏的插件导航区域中，能够清晰看到并直接点击「灵感社区」导航项；
   - 「灵感社区」与其他一级导航项（工作流、资产中心、产品库等）层级规范、排版与对齐保持一致。
2. **生命周期名单移除内测拦截（AC-2）**：
   - 从中枢插件生命周期配置名单中移除 `omnimux-inspiration` 的 `alpha` 限制；
   - 侧边栏协调器在排布插件入口时，不再拦截 `omnimux-inspiration`，正常渲染并挂入界面。
3. **工作台关联与激活交互正常（AC-3）**：
   - 用户点击左侧侧边栏中的「灵感社区」，右侧工作台能够平滑切换并展示灵感社区页面（`omnimux-inspiration:library`）；
   - 侧边栏中的「灵感社区」保持选中高亮激活状态。
4. **测试防护与回归全绿（AC-4）**：
   - 侧边栏协调器测试用例覆盖并验证灵感社区正常挂载；
   - 全链路回归与端到端测试均保持 100% 通过。
