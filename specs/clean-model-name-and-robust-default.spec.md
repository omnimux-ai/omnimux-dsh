# 移除模型下拉后缀提示并增强工程默认模型推导 · 规格说明书 (Issue #2647)

## 1. 业务目标与背景
1. **彻底移除赘余后缀文本**：
   - 用户明确要求：表单首部的模型选择器**不要显示 `(工程默认 · 作者推荐)` 这个文本提示**；
   - 无论在下拉框的收起按钮文本，还是下拉浮层的默认选项标题中，均直接展示干净、专业的纯模型名称（例如 `Seedance 2.0`），让界面彻底回归极简；
2. **多层级推导默认模型（杜绝误退回「智能推荐」）**：
   - 在开发版应用实测发现：部分应用历史缓存或预设中未内联完整的 `snapshot.nodes`，导致之前的代码因找不到节点而误回退为「智能推荐 (默认)」；
   - 增加多层级健壮推导：
     1. 优先读取 `manifest.defaultModel` / `manifest.metadata.defaultModel`；
     2. 其次读取 `manifest.workflowBinding.snapshot.nodes` 中的主生成节点模型；
     3. 再次根据应用分类与已知预设（`app-creatify-*` 默认 `seedance-2.0`，视频类应用默认 `seedance-2.0`，图像类应用默认 `gpt-image-2.5`）；
   - 确保默认模型 100% 能解析出具体的模型名称（如 `Seedance 2.0`），彻底消灭未更新感。

## 2. 界面与交互规范
- **下拉框收起态**：
  - 未手动选择时，直接展示 `${defaultModelName}`（如 `Seedance 2.0`），无任何括号后缀；
  - 手动选择模型后，展示当前选中的模型名称（如 `MiniMax H3`）；
- **下拉菜单首项（默认项）**：
  - 标题：纯净模型名称 `${defaultModelName}`；
  - 徽标/标签：右侧配浅灰色微徽标 `[工程默认]` 或精简副标题 `工程预设推荐模型`，主标题绝无冗长后缀括号；
- **各主流模型选项**：保持原样，展示模型名称及规格副标题。

## 3. 验收标准
1. 表单首行「生成模型」下拉框在未选择时，直接显示纯净的模型名字（如 `Seedance 2.0`），绝不包含 `(工程默认 · 作者推荐)` 文本；
2. 下拉菜单展开后，首项标题为纯净模型名称，杜绝括号后缀；
3. 打开「巨型商品撞屏与荒诞追逐」、「手机与网页交互实机演示」等任意旧工程时，即便本地缓存缺少 nodes，依然准确显示对应默认模型；
4. 全量自动化测试通过，两轮开源 OCR 代码审查 0 阻断。
