# 规格说明：应用编辑副本弹窗显式标签与行为意图标注 (Issue #2639)

## 1. 业务痛点与用户心智对齐
- **用户困惑点**：
  在点击「编辑应用」呼出的弹窗中，输入框内预填了长文本应用名称（如 `海外达人自拍第一视角口播评测 (副本)`），下方展示当前工作区目录（如 `omnimux-dsh`）。
  用户容易产生顾虑：
  1. “项目名称与工作区不一样，是不是会在电脑硬盘里新建一个物理文件夹？”
  2. “如果工作区已有项目，会不会直接冲掉我原来的项目名字？”
- **解决核心**：
  彻底消除用户关于“是否会新建文件夹或篡改工作区”的疑虑，在弹窗中增加显式字段 Label 与精准的大白话行为说明。

## 2. 交互规格与文案标准
1. **未建项模式（mode === 'project'，即当前工作区尚未作为视频项目初始化时）**：
   - 输入框上方显示显式标题：**「项目显示名称」**；
   - 输入框下方显示辅助说明：**「仅作为软件内的项目名称，不会在电脑硬盘中新建或重命名物理文件夹」**；
   - 工作区位置标题显示：**「存放工作区目录」**（清楚表明这是物理文件的安放目录）。
2. **已有项目模式（mode === 'page'，即当前已有绑定项目时）**：
   - 输入框上方显示显式标题：**「新创作页名称」**；
   - 输入框下方显示辅助说明：**「原项目名称保持不变，仅在当前项目中追加一张新画布」**。

## 3. 质量与验收标准
- 遵循极简设计规范（Token 引用，0 内联业务样式）；
- 单测与 E2E 测试断言新增标签与辅助说明文字；
- 实机预演截图并落盘证据。
