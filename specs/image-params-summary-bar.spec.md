# 规格说明书：生图输入框参数胶囊核心数据回显与自适应折叠修复

## 一、背景与问题陈述
用户在创作工作台使用图像生成节点时，输入框底部的参数触发条出现严重展示缺陷：
1. **核心数据项全部丢失**：当前按钮仅渲染为一个空框图标与下拉箭头（`[ ⬚ ∨ ]`），所有选中的参数（如 1:1 比例、1K 清晰度、高画质、模式）均不可见。
2. **根因一：折叠测量算法陷入自锁死循环（Death Spiral）**：`CfgSummaryBar` 将自身当前的 `clientWidth` 作为可用宽度进行判定。当内容因预估超宽被初步折叠后，按钮自身宽度收缩，导致 `ResizeObserver` 计算出的可用宽度更小，将按钮彻底死锁在仅剩图标的最小折叠态。
3. **根因二：数据链路缺失画质（quality）**：`formatImageSummary` 与 `ImageTriggerBar` 未接入模型契约中的 `quality` 字段，导致即使展开也无法呈现画质选项。
4. **根因三：参数排版与分隔规范未对齐**：图 2 明确要求按「比例（带图标）· 清晰度 · 画质 · 生成方式/自适应」顺序并以中点符号连接展示，当前逻辑存在倒置且单一模式下直接隐去。

## 二、验收标准（Acceptance Criteria）
- [ ] **AC-1（折叠死锁解除）**：在底栏宽度充裕时，图像参数胶囊完整展开显示文字，杜绝异常缩回仅剩图标。
- [ ] **AC-2（画质参数接入）**：`formatImageSummary` 与 `ImageTriggerBar` 完整接入 `quality`（如「高」/「标准」），当模型 schema 支持质量项时正常提取并显示。
- [ ] **AC-3（图 2 排布格式对齐）**：
  - 槽位顺序规范：`ratio`（含比例几何图标）→ `resolution`（清晰度，如 1k/2k/4k）→ `quality`（画质，如 高/标准）→ `mode`（生成方式/自适应）；
  - 文本各数据项之间使用统一的点号符号 `·`（或语义化等效视觉）清晰分隔；
  - 比例为 auto 时诚实回显为「自适应」。
- [ ] **AC-4（响应式弹性保护）**：在视口极度狭窄的极限场景下，按优雅降级顺序折叠（模式 → 质量 → 清晰度 → 比例文字），比例图标与下拉箭头永不丢失。
- [ ] **AC-5（回归与自动化门禁全绿）**：更新并补充单元测试与集成测试，覆盖图像参数多态解析、画质槽位装配及折叠协议判定。
