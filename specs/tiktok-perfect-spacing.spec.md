# TikTok 场景图标完整留白与作品识别彻底修复规格 (Issue #2035)

## 1. 业务痛点与目标
1. **真实竞品 (CreatOK) 复合结构遮挡**：CreatOK 插件包含「圆形图标」与下方「CreatOK」文本标签两部分。此前算法按纯图标高度计算，导致幽灵图标紧贴/遮挡了文字底部。必须确保将包含文本在内的整个竞品容器推升，并保持至少 14px 的安全大留白。
2. **消灭「这一页没有可操作的作品」误报**：用户在个人主页视频弹窗或推荐流浏览时，地址栏可能未及时更新带具体视频编号。只要视口存在活跃操作栏（用户正在看片），必须从当前视频容器中精准提取作品地址，杜绝红字报错。

## 2. 验收标准
- **AC-1 (复合组件完整推升)**：识别竞品图标与其附属文本标签（或其最近的父级 Item 容器），以最外层边界计算，将对手整体推升至幽灵图标上方至少 14px，确保文字下沿与幽灵图标上沿有清晰留白。
- **AC-2 (全场景活跃作品自愈捕获)**：当用户在包含活跃操作栏的任何页面（包括推荐流与博主主页视频弹窗）点击操作时，只要当前视口有正在播放的视频卡片或关联链接，直接提取为目标作品，彻底杜绝 `noTarget` 报错。
