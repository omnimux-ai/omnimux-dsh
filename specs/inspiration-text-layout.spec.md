# 灵感社区内容解构排版（Issue #1758）

## 目标与获批设计
用户已在对话中确认推荐方案：保留弹窗三栏、主题配色与全部原始内容；标题独占一行，正文左对齐；分镜表格逐条纵向展示。对话内排版示意已演示并获批。无需新增折叠功能。

## 成功标准
- 长中英文标签自然换行，正文在标签下方占满可用宽度，不向右挤压。
- 合法 Markdown 表格显示为逐条记录，各单元格保留完整文字，分隔符不作为正文显示。
- 普通段落、链接、提示词及无法识别的文本不丢失；复制使用原始文本，保持现有语义。
- 打开真实预览弹窗，在桌面及窄屏检查正文尺寸为正、无横向溢出；滚动后仍能使用复制及关闭。
- 保留已有章节、复制、视频及立即复刻交互，不调整页面其他区域。

## 项目结构与代码风格
生产修改仅限 plugins/omnimux-inspiration/src/client 下解析、InspirationPreviewModal.jsx、styles.js 与对应测试；真实走查后在 tests/e2e/inspiration-text-layout.* 固化正式回归及测试夹具。复用 parseDocAnalysis 及现有文档样式。不增加依赖；沿用具名导出、两空格缩进与宿主语义色彩。

## 实现计划
1. 先补解析单元失败用例：多行表格、转义竖线、普通文本保留。
2. 最小扩展已有解析与展示，标签正文纵向排列，长文本安全换行。
3. 在独立工作树真实浏览器走查并保留截图，再固化适用界面回归测试。
4. 运行相关全量测试、构建和静态校验，独立审查；通过后按仓库流程交付。

## 边界
总是：保留源内容、隔离修改、真实浏览器验证、独立评审。
先问：新增依赖、改变分析数据合同、扩大弹窗交互范围。
绝不：修改正式 DSH、生产配置、其他工作区、清理他人改动或伪造验证。
