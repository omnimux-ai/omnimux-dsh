# 生成面板收敛为紧凑卡片（收起/展开）— 任务规格

## 背景与问题
上一版把生成能力并入剪辑窗口左列后，左列被"塞满"：标题行 + 生成记录卡片 + 四个模式标签 + 模式说明行 + 大输入框 + 独立成行的时长/分辨率/画面比例三行 + 提示文案 + 大号生成按钮，垂直空间几乎占满，观感臃肿。

## 目标（用户口径）
把生成面板收敛成一张紧凑卡片，1:1 对齐参考图（Google Vids 风格合成器）：
- 一行模式芯片：创建 / 修改 / 添加动画 / 延续，右侧一个展开箭头
- 提示词输入区
- 附件缩略图 + 虚线「添加」块
- 底部一颗参数胶囊「模型 · 分辨率 · 比例 · 时长」+「清除」+ 圆形发送键

## 交互契约
1. **默认收起**：进入剪辑窗口时只显示紧凑一行（模式芯片行 + 展开箭头），输入区不铺开。
2. **展开触发**：点击输入框、或点击展开箭头 → 展开。
3. **展开效果**：展开后才显示完整输入区与更多设置（提示词输入、附件添加、参数胶囊、清除/发送）。
4. **再次点击箭头** → 收起（保持已填内容不丢）。

## 移除项（非必要元素）
- 模式说明行（如「创建 用文字生成一段新视频」）
- 独立成行的时长 / 分辨率 / 画面比例选择行（改为收进底部参数胶囊）
- 「请先填写提示词」这类常驻提示行（改为发送键禁用态表达）
- 大号「生成」按钮（改为圆形发送键）

## 不可移除（功能不缩水）
- 四模式与映射不变：`text_to_video` / `first_frame` / `video_edit` / `video_extend`
- 时长 / 分辨率 / 比例逐项透传不变
- 附件选择、生成记录入口仍可达（可收进展开态或折叠区）
- 仍走「面板 → 插件接口 → 中枢生成缝 → 本机通道」

## 可测验收标准
- AC1 收起态：进入剪辑窗口后，生成面板的输入区不可见，芯片行可见，面板高度显著小于展开态。
- AC2 点击展开箭头 → 输入区出现。
- AC3 收起后再点击输入框 → 输入区出现。
- AC4 展开态存在：提示词输入、附件「添加」块、参数胶囊（含模型/分辨率/比例/时长四项）、清除、发送键。
- AC5 移除项不存在：模式说明行、独立的三行选择器、常驻提示行、大号生成按钮。
- AC6 四模式芯片齐全且可切换；切换后模式映射与上一版一致。
- AC7 真机截图两张（收起态、展开态）人眼复检无破版、无留白黑洞。

## 验证方式
工作树内真实浏览器：`node scripts/worktree-app-qa.mjs --journey=scripts/qa/vids-composer-compact.mjs`（新增验收旅程），断言覆盖 AC1–AC6，截图覆盖 AC7；另跑 clip/video 套件与 `verify:stages`、`verify:anti-slop`、`check:boundaries`、`verify:product-baseline`。
