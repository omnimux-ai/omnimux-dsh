# 规格文档：产品库实物产品与数字产品独立治理与悬停分流交互

**文件：** `specs/product-independent-forms.spec.md` ｜ **优先级：** P0 ｜ **模块：** `plugins/omnimux-products`
**关联 Issue：** #1695
**变更面：** Client / Stage / 页面路由 / 链接提取服务

---

## 1. 业务目标与问题定义

### 1.1 核心痛点与缺陷根因
1. **实物与数字形态混杂**：实物电商产品与数字化 SaaS 混用同一张表单，导致实物商品被强制赋予无意义的双端整屏截图容器，数字产品又暴露出不相关的价格/SKU/促销输入项。
2. **实物链接提取偏离场景**：实物商品提取时耗费数十秒调用无头浏览器捕获整屏截屏，却未将电商详情页真正核心的商品主图、轮播图沉淀为首屏封面素材。
3. **入口缺乏分流引导**：单一的「添加产品」按钮无法让用户在录入前明确其治理形态，表单内的类型切换按钮又容易造成脏数据与表单状态紊乱。
4. **详情查看缺乏类型自适应**：列表卡片点击后应根据持久化类型无缝跳转至对应的专业化详情页。

### 1.2 核心方案
1. **新建按钮鼠标悬停分流（`CreateProductMenu`）**：鼠标悬停在列表顶部「新建产品」按钮上，浮出「实物产品」与「数字产品」两个独立选项，点击分别进入对应独立页面。
2. **实物产品专属页面治理**：
   - 彻底移除首屏截图（1440×900 / 390×844）卡片；
   - 智能链接提取跳过无头浏览器整屏截屏，专注提取商品高清图片并写入素材列表，第一张设为封面；
   - 保留价格、SKU、促销、商品链接；移除品牌战略面板及表单内类型切换 Tab。
3. **数字产品专属页面治理**：
   - 保留双端首屏高清快照（1440×900 + 390×844）与封面切换；
   - 保留六维品牌战略模块；移除价格、SKU、促销字段及表单内类型切换 Tab。
4. **列表卡片精准路由详情页**：点击列表任意产品卡片，根据 `product.kind`（`'physical' | 'digital'`）精准打开对应的详情页面。
5. **安全与保活底线继承**：全量继承数据指纹离开拦截保护（继续编辑 / 放弃修改 / 保存并返回）与列表视图 DOM 保活。

## 2. 详细验收标准（Acceptance Criteria）

### 2.1 新建按钮悬停分流交互 (P0)
- **AC-101**：在产品库列表顶部，鼠标悬停（Hover）在「新建产品」按钮上，流畅展开下拉浮层（防抖 150ms），移出容器延时 200ms 收起。
- **AC-102**：下拉菜单包含「实物产品」与「数字产品」两项，附带清晰说明文案与图标。
- **AC-103**：点击「实物产品」直接跳转至「添加实物产品」全屏二级页（`kind: 'physical'`, `mode: 'create'`）；点击「数字产品」直接跳转至「添加数字产品」全屏二级页（`kind: 'digital'`, `mode: 'create'`）。
- **AC-104**：产品库空状态下的引导按钮同步集成悬停分流能力，点击/悬停行为一致。

### 2.2 实物产品专属页面 (P0)
- **AC-201**：面包屑与标题展示为「产品库 / 添加实物产品」或「产品库 / 编辑实物产品：{name}」。
- **AC-202**：右栏彻底移除「首屏截图」容器与视口卡片，仅保留「分类标签」与「商品图片与素材」。
- **AC-203**：左栏包含产品名称、核心卖点、受众、品牌、特性以及商业化设置（价格、SKU、促销、商品链接）；彻底隐藏「品牌战略」面板。
- **AC-204**：页面内无类型切换 Tab，防止类型混杂。
- **AC-205**：粘贴商品详情链接解析时，跳过无头浏览器整屏截图，提取到的商品图片直接进入素材列表，第一张自动标记为封面。

### 2.3 数字产品专属页面 (P0)
- **AC-301**：面包屑与标题展示为「产品库 / 添加数字产品」或「产品库 / 编辑数字产品：{name}」。
- **AC-302**：右栏包含「首屏截图」卡片群（电脑端 1440×900 与 手机端 390×844），支持一键切换封面。
- **AC-303**：左栏包含产品名称、定位卖点、受众、品牌、官网链接与六维「品牌战略」模块；彻底隐藏价格、SKU、促销输入项。
- **AC-304**：页面内无类型切换 Tab。

### 2.4 列表卡片精准路由 (P0)
- **AC-401**：在产品库列表中点击实物商品卡片，精准打开实物产品详情页（`kind: 'physical'`, `mode: 'edit'`）。
- **AC-402**：在产品库列表中点击数字产品卡片，精准打开数字产品详情页（`kind: 'digital'`, `mode: 'edit'`）。
- **AC-403**：从任一详情页返回列表后，搜索关键词、分类页签与滚动位置完好保持。

### 2.5 防误触拦截与门禁规范 (P0)
- **AC-501**：实物与数字两个表单均具有独立指纹计算，仅在表单字段实质被修改时触发「三选一」防误触弹窗。
- **AC-502**：UI 规范静态扫描 0 违规，无字符图标，无手写未经许可颜色。
