# Spec: 灵感库勾选后显示批量操作栏

- 风险级别: R1（BugFix，不新增 UI 元素与文案）
- 类型: 回归修复

## 1. 问题

灵感社区 → 灵感库中勾选卡片后，卡片显示勾选态，但批量操作栏（「已选 N 项 / 全选本地 / 取消选择 / 删除 (N)」）不出现，用户无法取消选择或批量删除。

根因：「灵感库去掉云端筛选」改动把云端二级筛选行限定到「爆款趋势」栏目时，批量操作栏被一并包进了该条件；而勾选只发生在灵感库（本地条目），所以操作栏永远不显示。

## 2. 用户旅程与期望

1. 打开灵感社区 → 灵感库。
2. 勾选任意一张卡片左上角复选框。
3. 筛选行下方出现批量操作栏，显示「已选 1 项」与「全选本地」「取消选择」「删除 (1)」。
4. 点「取消选择」后操作栏消失，卡片取消勾选。

## 3. 约束

- 不新增、不改写任何元素或文案；沿用现有批量操作栏、文案键与样式。
- 爆款趋势栏目仍保留云端二级筛选行；灵感库仍不显示云端二级筛选行。
- 账号监控栏目不显示批量操作栏。

## 4. 验收用例

- 渲染测试：灵感库勾选一张卡片后，出现「取消选择」按钮与「已选 1 项」；点击「取消选择」后操作栏消失。
- 渲染测试：灵感库中不出现国家等云端二级筛选。
- 真实浏览器：灵感库勾选后截图可见批量操作栏。
