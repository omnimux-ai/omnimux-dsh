# 规格说明书：统一全系统自制弹窗与外悬浮关闭按钮

- 任务 Issue：#2202
- 责任人：齐活林（交付总监）/ 寇豆码（工程师）/ 审秋毫（审查员）/ 严过关（QA）
- 创建日期：2026-09-17
- 状态：已批准实施

## 1. 背景与业务痛点
在此前优化中，技能市场详情弹窗已统一升级为符合设计系统规范的外悬浮关闭按钮（`omnimux-modal-close-btn is-external`）。
经过全系统弹窗排查，发现以下场景仍存在自制窗口或未复用统一关闭按钮的问题：
1. **公共资产库资源预览大弹窗 (`AssetPreviewModal.jsx`)**：仍采用弹窗内部标题栏右侧内嵌旧关闭按钮，弹窗没有外层定位包裹与外悬浮关闭按钮，容易产生误触且视觉风格不统一；
2. **技能市场本地安装弹窗 (`InstallModal.jsx`)**：采用早期手写内嵌的简陋小叉号（`button.modal-close-btn` 直接拼 SVG 细线），缺少系统统一的微边框质感与悬停交互；
3. **技能市场确认安装弹窗 (`ConfirmInstallModal.jsx`)**：采用手写的简易小对话框，未对齐标准确认对话框的按钮层级与规范。

## 2. 关键用户旅程 (Critical User Journeys)

### UJ-1: 公共资产库资源预览关闭交互
1. 用户在公共资产库中点击任意素材（图片、视频、音频、文本等）卡片；
2. 弹出资产全屏预览模态窗；
3. 模态窗容器外侧右上方清晰展示统一的 36px 半透明浮雕圆形关闭按钮（含细线几何 X 图标）；
4. 弹窗内部标题栏不再有多余的小叉号，标题排版舒展大方；
5. 点击外悬浮关闭按钮，弹窗平滑关闭。

### UJ-2: 宽屏与窄屏自适应响应式保障
1. 宽屏环境下（> 1280px），关闭按钮悬浮在弹窗右上角外侧 50px 处；
2. 窄屏或小窗口环境下（<= 1280px），关闭按钮自动贴合至弹窗内部右上角（`top: 14px; right: 14px`），确保按键完整可见且可点击，绝不超出屏幕产生裁切。

### UJ-3: 技能市场安装弹窗规范化
1. 用户打开技能市场手动安装 / 拖放安装弹窗；
2. 弹窗具备与系统统一的关闭按键规范，不再出现手写 SVG 细线与旧式内联样式。

## 3. 详细验收标准 (Acceptance Criteria)

| 编号 | 验收项 | 验证方式 |
| :--- | :--- | :--- |
| **AC-1** | `AssetPreviewModal.jsx` 采用外层 `.omnimux-assets-modal-wrapper` 定位包裹，并在外部右上角渲染统一的 `<button className="omnimux-modal-close-btn is-external omnimux-assets-modal-close-external">` | 代码审查 + DOM 断言 |
| **AC-2** | `AssetPreviewModal.jsx` 头部完全移除原内置的 `IconButton.omnimux-assets-modal-close`，避免两处关闭按钮冲突 | 代码审查 + DOM 断言 |
| **AC-3** | 公共资产库样式表中声明 `.omnimux-assets-modal-wrapper` 与 `.omnimux-modal-close-btn` 系列样式规则，并具备 `<=1280px` 媒体查询响应式自适应 | CSS 审计 + 视口切换测试 |
| **AC-4** | `InstallModal.jsx` 关闭按钮升级为 `omnimux-modal-close-btn`，统一视觉样式与触控规范 | 代码审查 + 单元测试 |
| **AC-5** | 真实 Chrome 浏览器无头环境自动化验证通过，校验关闭按钮尺寸正向（36x36px）、外侧右上方几何位置正向，且点击关闭事件正常触发 | 浏览器实测 + 截图/报告产出 |
| **AC-6** | 现有公共资产库与技能市场全部单测、端到端测试 100% 通过，无回归 | CI / 本地测试套件 |
