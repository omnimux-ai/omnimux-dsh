## 1. 业务目标与问题定义

### 1.1 核心痛点与缺陷根因
1. **弹窗误触丢数据**：原产品库表单运行在模态弹窗内（`ProductFormDialog.jsx`），点击遮罩外围或按 Esc 会直接关闭，无确认直接清空全部已录入或解析出的内容。
2. **长表单视野受限**：包含 10 个基础字段、媒体区、分类标签以及 6 大品牌战略模块，在 85vh 限制的弹窗容器内上下滚动局促，体验差。
3. **脏标记死代码**：原 `setEditingDirty(true)` 从未被调用，原并发版本冲突横幅不可达，且缺失真实的未保存修改检测。
4. **UI 散乱与组件重复造轮子**：多处手写按钮、字符图标（如 `×` 符号触发 `exempt-ui04` 告警）、自绘分区，未对齐套件底座 `dsh-ui-kit`。

### 1.2 核心方案
1. **全屏二级子视图**：同 Tab 内视图切换（`view: { name: 'list' } | { name: 'form', mode: 'create' | 'edit', product }`），`position: absolute; inset: 0; z-index: 300`，彻底移除弹窗遮罩与外壳。
2. **状态指纹脏检测与离开保护**：通过 canonical 序列化计算表单初始指纹与当前指纹，在用户触发「返回」、「取消」或「Esc」时弹出三选一模态拦截弹窗（继续编辑 / 放弃修改 / 保存并返回）。
3. **双栏极简现代布局**：左栏承载 URL 极速解析条、基础信息、商业化与品牌战略；右栏展示自动化捕获的电脑端（1440×900）与手机端（390×844）首屏截图，支持一键设封面。
4. **共享组件标准化复用**：全面复用 `dsh-ui-kit` 的 `PageHeader`, `Button`, `IconButton`, `Badge`, `EmptyState`, `ModalDialog`, `SelectableTile`，并标准化补齐多行文本域与表单分区。

## 2. 详细验收标准（Acceptance Criteria）

### 2.1 视图与导航交互 (P0)
- **AC-101**：点击「添加产品」或点击产品卡片，平滑切入全屏二级页面视图，无模态遮罩层，无浮空关闭叉号。
- **AC-102**：二级页顶部配备常驻导航页头，包含面包屑（`产品库 / 添加产品` 或 `产品库 / 编辑 · {产品名}`）与「←」返回按钮。
- **AC-103**：二级页底部常驻操作栏，包含取消（ghost）与保存产品（primary），内容滚动时操作栏固定可见。
- **AC-104**：返回列表视图后，原列表的滚动位置与筛选条件保持不变（L1 子树保活）。

### 2.2 防误触与脏数据离开保护 (P0)
- **AC-201**：表单在未做任何修改时，点击返回、取消或按 Esc，直接返回列表视图，不弹出拦截确认。
- **AC-202**：表单修改任一字段、添加标签或解析填入数据后，点击返回、取消或按 Esc，必须弹出拦截弹窗（ModalDialog）。
- **AC-203**：拦截弹窗支持三选一操作：
  - 点击「继续编辑」（或按 Esc、点遮罩）：关闭弹窗，停留在二级页，全部输入保留；
  - 点击「放弃修改」：丢弃当前改动，返回列表视图；
  - 点击「保存并返回」：校验并执行保存，成功后返回列表视图。
- **AC-204**：若改动后再次将内容改回初始快照，系统恢复为「未修改」状态，返回时不弹拦截。

### 2.3 落地页解析与双端首屏截图可视化 (P0)
- **AC-301**：落地页解析成功后，表单自动填入相应战略字段，并在右栏直观呈现桌面端（1440×900）与移动端（390×844）两张首屏高清缩略图。
- **AC-302**：截图卡片清晰标注视口名称与分辨率，并带有「封面」高亮角标；点击另一张卡片可快捷切换封面。

### 2.4 UI 规范与共享组件复用 (P0)
- **AC-401**：彻底清除媒体列表与战略字段中的字符 `×`，清零 `exempt-ui04` 豁免项，全面换用标准矢量图标按钮。
- **AC-402**：所有尺寸、字阶、间距与配色严格使用 `--dsw-*` 设计令牌，静态扫描零违规。
- **AC-403**：新建态支持草稿截图只读预览通路，确保在未保存前截图可正常呈现。

## 3. 任务分解与执行路径
- **T01**：规格落盘与底座组件准备。
- **T02**：表单状态机增强（计算指纹、快照比较、纯函数守卫）与草稿媒体只读通路。
- **T03**：产品库二级页面重构（`ProductFormPage.jsx`、双栏布局、双端截图展示）。
- **T04**：列表视图迁移、样式与文案收口、字符图标清退。
- **T05**：全流程集成、自动化测试套件与真实环境验收。
