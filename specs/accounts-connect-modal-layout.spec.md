# 规格：社媒账号连接弹窗排版与状态分级优化

## 1. 业务意图与用户价值
优化社媒账号连接弹窗（ConnectModal）的视觉排版与信息层级：
- 解决原版中因组件内嵌标签导致的“部分平台上下折行变形、部分平台左右横排”排版割裂；
- 解决原版 5 个卡片排成双列网格导致的“右下角大块空白”视觉失衡；
- 执行用户明确确认的「方案 A」：可直接绑定的主流平台（TikTok、Instagram、YouTube）作为主操作卡片置顶呈现；筹备中平台（X、Facebook）收拢于底部次级轻量栏，信息主次分明，现代极简。

## 2. 交互与视觉契约
1. **主操作区（可用平台）**：
   - 支持平台卡片采用标准横向结构（左侧品牌图标、中间名称与描述、右侧悬停箭头微交互）；
   - 卡片高度严格一致（min-height: 68px），无论文本长度如何，保持对齐；
   - 品牌图标统一度量衡为 40px × 40px，圆角 10px，深色模式高对比度；
   - 支持 3 个平台平铺展示（grid-template-columns: repeat(3, minmax(0, 1fr)) 或响应式平铺），填满整行，左右完美对称。
2. **次级信息区（筹备平台）**：
   - 底部设立次级分组条，带有轻量微图标展示 X 与 Facebook；
   - 标明官方接入中，带「即将支持」微胶囊标签；
   - 消除原版双列网格中单数卡片右侧的空洞。
3. **安全提示区**：
   - 底部保留盾牌图标与「通过官方通道安全授权 · 密码不保存在本地」声明。

## 3. 验收标准与测试
- 单元测试验证：
  - 样式契约与结构断言更新，通过 node:test；
  - 平台描述与国际化文案完整对齐；
- 真实浏览器验证：
  - 在隔离环境下完成 DOM 挂载、几何尺寸（width > 0, height > 0）与视觉截图验证。
