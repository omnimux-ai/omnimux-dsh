# 规格说明书：生成模式必显回显与参数浮层面板宽度调宽优化

## 一、背景与问题陈述
用户在使用工作流生成节点（特别是视频生成节点如 Seedance 2.0 旗舰版）时反馈：
1. **生成模式未在按钮标签上必显**：用户在弹窗中选中了「全能参考」，但外层按钮胶囊仅显示 `16:9 · 720P · 5s`，当前选择的核心操作模式被折叠或因门禁隐去，用户无法直观确认当前处于何种生成方式。
2. **默认面板宽度过窄导致 UI 变形**：弹窗浮层原设计宽度仅 420px，在承载 4 个生成模式、7 个画幅比例、4 个清晰度与 2 个有声开关时，各控件行高度拥挤，文字被严重挤压，垂直空间也偏短造成视感局促。

## 二、验收标准（Acceptance Criteria）
- [ ] **AC-1（生成模式必显契约）**：
  - 在视频参数摘要条（`VideoTriggerBar`）中，当前生效的生成模式（如「全能参考」、「文生视频」、「首帧」、「首尾帧」）作为核心数据项必显，其 `dropPolicy` 设为 `'never'`，绝不在常规或折叠状态下被意外隐藏。
  - 在摘要格式化引擎（`summaryFormatter.ts`）中，只要当前存在有效的模式标识或标签，即如实格式化输出，不再受限于多模式门禁而错误输出空串。
- [ ] **AC-2（面板宽度适度调宽）**：
  - 通用浮层视口定位器（`viewportPositioner.ts`）的 `PANEL_WIDTH` 基准宽度由 420px 适度调宽至 500px，最大设计高度由 480px 提升至 580px。
  - 调宽后，生成模式 4 个按钮、比例 7 个卡片、清晰度与有声并排区域舒展大气，彻底消除挤压与变形。
- [ ] **AC-3（视口安全与多端弹性）**：
  - 保留 `max-width: calc(100vw - 24px)` 与左右各 12px 的安全视口边距保护，在小屏幕或窄视口下自动收缩，绝不产生水平横向溢出。
- [ ] **AC-4（图像参数模式同步必显支持）**：
  - 图像参数胶囊在有模式文案时同样保证稳定呈现，视觉分隔统一点号「·」风格。
- [ ] **AC-5（全量测试与质量闭环）**：
  - 更新定位器单测与摘要格式化测试，编写端到端契约测试，全套测试 100% 绿灯通过。
