# 规格：模板与技能卡片横版化、悬停外框与按钮背景可见性优化

## 1. 业务背景与问题分析
根据用户截图反馈：
1. **鼠标悬停选中框顶部被遮挡**：在横滑货架容器中，卡片鼠标悬停触发 `translateY(-4px)` 向上浮动，由于滚动轨道容器 `overflow-x: auto` 缺乏顶部留白缓冲，卡片顶部高亮边框和圆角被容器硬性裁剪；
2. **按钮悬停激活后背景不可见**：卡片悬停浮出的操作按钮（「使用」/「复刻」）消费了未在该专区作用域定义的透明变量，导致按钮背景完全透明，仅有文字与图标，缺乏可点击的按钮质感与悬停高亮反馈；
3. **竖版卡片改为横版**：卡片目前为 `aspect-ratio: 9 / 16` 细长竖版（宽度 200px、高度 355px），在桌面大屏与技能卡片场景下显得过长且信息密度低，需升级为现代大气的横版比例（如 `16:10` / `240px × 150px`）。

## 2. 改进方案与接口设计

### 2.1 修复选中框顶部被裁剪
- 为 `.omnimux-shelf-track` 添加顶部与底部内边距缓冲：
  - `padding-top: 8px; margin-top: -8px;`
  - `padding-bottom: 12px; margin-bottom: -4px;`
- 保证卡片悬停上移 4px 时，外描边与阴影能够完整显示，顶部边界不被任何容器截断。

### 2.2 强化操作按钮背景与悬停高亮
- 为 `.omnimux-tpl-hover-action` 及其内部按钮 `.omnimux-trending-recreate-btn` 设立专属高对比度样式：
  - **默认浮出态**：采用深色磨砂半透明背景（`rgba(20, 21, 28, 0.88)`），叠加 `backdrop-filter: blur(10px)`，边框为 `1px solid rgba(255, 255, 255, 0.2)`，文字与图标为亮白；
  - **悬停激活态 (`:hover`)**：背景高亮转换为高对比纯白实体（`background: #ffffff; color: #0d0e12;`）或官方品牌紫色，边框亮白，阴影饱满立体，确保按钮轮廓极度清晰，彻底解决背景不可见问题。

### 2.3 卡片比例从 9:16 升级为横版
- 尺寸规则：
  - 单张卡片基准宽度：`flex: 0 0 240px;`；
  - 宽高比升级：`aspect-ratio: 16 / 10;`（高度约 150px）；
  - 全量平铺网格适配：`grid-template-columns: repeat(auto-fill, minmax(240px, 1fr));`；
- 卡片内部布局适配：
  - 占位符与标题垂直居中排布，留白紧凑协调；
  - 渐变暗色遮罩高度自适应；
  - 悬停浮动按钮与标题过渡平滑。

## 3. 验收标准
1. 卡片 hover 时，顶部高亮边框和圆角完整呈现，无任何裁切与截断；
2. 操作按钮默认浮出与 hover 激活时，均有明显可见的背景底色与轮廓；
3. 卡片外形为横版（16:10），高度约 150px，在宽屏下横向排列紧凑美观；
4. 单元测试与端到端自动化测试 100% 绿灯通过。
