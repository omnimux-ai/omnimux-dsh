# 规格：灵感社区卡片按钮钉住文字槽

## 目标（Objective）

在完整窗口 CTA 已显示全名的基础上，生产样式必须钉住按钮文字槽可收缩，避免英文中间宽度出现半截字。测试不得再用伪装规则盖住生产缺口。

## 成功标准（Success Criteria）

1. 生产 CSS 含 `.omnimux-inspiration-overlay-cta-btn > .dshUk-Button-label { min-width: 0 }`。
2. 测试 `BASE_CSS` 不再注入该伪装。
3. 卡片宽度测试全绿；完整窗口中文仍显示「详情 / 立即复刻」。

## 边界（Boundaries）

- 总是：保留 200px 分界与现有按钮文案/点击行为。
- 绝不：未确认前写正式版；改网格列数。

## 新用户基线

只改静态样式与测试，不依赖本机模型、密钥或开发目录。
