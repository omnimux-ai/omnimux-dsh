# 一级页页头与内容区统一靠左对齐及内距规范规格（First-Level Header & Content Alignment Spec）

## 1. 业务痛点与用户决策

### 1.1 业务痛点
在桌面端或网页端满屏状态（左侧导航栏收起、右侧工作台铺满窗口）下，使用通用页头组件的一级页面（创作画布/项目库、资产中心、灵感社区、数据分析看板、账号矩阵、内容发布中心）被一条历史遗留的 macOS 红绿灯安全区全局规则强制注入了 `padding-left: 84px !important`。
这导致：
1. **页内基线撕裂 64px**：页面标题与副标题被向右生硬推开至 84px，而下方的「新建项目」主操作按钮、本地项目 Tab 栏、搜索栏、资产/工程卡片网格等仍保持在 20px 标准边距，同一页面内出现两个不同的左边缘。
2. **多插件页面风格不统一**：而「技能/专家」页因历史自研页头结构，左侧内距为 20px（未被错误规则命中），但其顶部内距写为 18px（标准 PageHeader 统一为 12px），导致各插件在全屏状态下呈现出横向有的偏右、纵向高低不齐的破碎体验。

### 1.2 用户明确指令
**「所有的都要统一，我只告诉你目标，具体怎么修代码、怎么改我不懂。我要的就是所有的标签页，就是插件的这个页面的它那个标题和描述啊，包括所有的 table 栏等等它所有都是靠左对齐的。就不要出现那种就是要出现多种样式不统一的问题这个标准修复完了以后，你自己去验收，确保每个页面都是对齐的」**

## 2. 改造方案

### 2.1 错层 84px 规则收窄范围
- **文件**：`plugins/omnimux/src/client/conversation-box.js`
- **成因**：工作台一级页坐落在 `_paneBody_` 内，上方恒有 40px 高度的原生 Tab 页签栏（`[data-dockkit-strip]`）。红绿灯高度范围为 y: 0~30px / x: 0~84px，早已被页签栏本身的 84px 避让规则完美接纳。页头起始位置为 y: 52px，根本不与红绿灯重叠。
- **改动**：将 `.dshUk-PageHeader-pageHeader` 的 84px 规则增加 `[data-dsh-product-stage]` 作用域限定，仅在真正的顶层独立全屏舞台（如无顶栏直接顶格的独立 Stage）才启用该安全区避让；对于常规工作台一级页签，移除多余的 84px 侵入，恢复标准 `padding-left: 20px`。

### 2.2 纵向顶部内距统一收敛至标准 12px
- **文件**：`plugins/omnimux-market/src/client/css.js`
- **成因**：`.sh-plaza-body .sh-mkt` 声明了 `padding: 18px 20px 32px`，顶部内距为 18px；而官方与全站一级页标准均为 12px（`first-level-chrome.md` 规范「上 12px / 左右 20px / 下 12px」）。
- **改动**：将其统一调整为 `padding: 12px 20px 32px`，使「技能/专家」页与创作画布、资产中心等全部一级页在纵向顶部距离上完全一致（起始 Y 坐标均为 52px）。

### 2.3 修复既有回归测试用例
- **文件**：`plugins/omnimux/src/client/page-header-safe-inset.e2e.test.js`
- **成因**：既有测试在左栏收起用例中直接硬编码断言了 `pageHeader.paddingLeft === '84px'`，且未校验左栏收起时的三线对齐，导致错误行为被作为期望值固化。
- **改动**：更新测试断言，确保在普通工作台页面收起左栏时 `paddingLeft` 为 20px，且标题与操作按钮完全同基线对齐（`title.offset === actionRow.offset`）；增加独立舞台（product stage）模式下的安全避让专项断言。

### 2.4 修复样式选择器层级笔误
- **文件**：`plugins/omnimux/src/client/sidebar-toggle-topbar.js`
- **改动**：修复 `body[data-dsh-desktop-platform="darwin"] html[data-omnimux-left-collapsed]` 的祖先选择器层级倒置笔误，确保页签栏自身的 84px 避让选择器语法完全规范。

## 3. 验收标准（Acceptance Criteria）

- **AC-1（横向统一 20px 左基线）**：
  在全屏且侧边栏折叠状态下，访问所有插件一级页（创作画布、资产中心、灵感社区、数据分析看板、技能/专家、账号矩阵、内容发布中心），标题 `h1` / `title` 的视口左坐标 `left` 严格统一为 `20px`。
- **AC-2（页内元素绝对对齐）**：
  各页面内的「标题」、「副标题说明」、「新建/核心操作按钮」、「Tab/Table栏」、「卡片网格」的左侧边缘在同一垂直基线上（20px），偏差为 0。
- **AC-3（纵向统一 12px 顶边距）**：
  所有一级页内容顶边距统一为 12px，标题起始 Y 坐标严格对齐（40px 顶栏 + 12px 内距 = 52px）。
- **AC-4（自动化质量闭环）**：
  相关端到端测试与仓库门禁 100% 绿灯通过，提供真实浏览器环境计算样式取证。
