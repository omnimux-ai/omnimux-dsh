# 规格：修复素材挑选页面 Tab 切换白屏崩溃、重复点击无响应与全屏回顶机制

Issue: #2619

## 目标

在新对话首页中，点输入框加号菜单中的「从资产库选择」「从商品库选择」「从灵感库选择」打开整页素材挑选后：
1. 点击顶部五个分类 Tab（精选、资产库、灵感库、产品库、爆款趋势）时，正常加载并显示对应分类的所有素材卡片，绝不白屏崩溃；
2. 处于素材挑选界面时，再次点击加号菜单的「从资产库选择」「从商品库选择」「从灵感库选择」，能够正确响应并自动切换至对应分类 Tab；
3. 顶部提供醒目易达的返回与关闭机制（支持「返回」按钮与 Esc 快捷键），解决全屏固定层无法退回主页顶部的问题。

## 用户旅程

1. 用户在新对话首页点击「+」菜单，选择「从资产库选择」进入素材挑选界面；
2. 页面全屏展开，顶部显示分类与返回按钮，中间显示素材卡片，底部固定输入框；
3. 用户点击「灵感库」Tab，内容平滑切换为灵感库卡片流，无白屏、无未捕获异常；
4. 用户再次点击输入框「+」菜单中的「从商品库选择」，界面自动切换至「产品库」Tab 并展示产品数据；
5. 用户点击顶部的「返回」按钮（或右上角关闭图标、或按 Esc 键），素材全屏层平滑退出，页面完整恢复为常规首页，主页可自由滚动回顶。

## 验收标准

- **AC-1**：切换任何 Tab 时，组件清理函数安全执行，无 `ReferenceError`，分类卡片流正常渲染。
- **AC-2**：素材界面打开状态下，重复点击加号菜单的三个素材入口，能联动切换至对应的 `assets` / `inspiration` / `products` 分类。
- **AC-3**：素材页面顶栏包含清晰的「返回」入口，点击能正确退出全屏层并使输入框和主页回到原位。
- **AC-4**：键盘按下 Escape 键时能够退出素材全屏层。
