# 助手回复多素材画廊 · 消除黑边与描边精细化修复规格

## 1. 问题与目标

### 1.1 现状与实机反馈缺陷
在实机验收中发现以下 3 处视觉细节问题：

| 问题位置 | 现场证据 | 根因 |
| --- | --- | --- |
| 主舞台上下黑边 | 16:9 素材展示时上下留有大块纯黑背景带 | 容器写死 `height: min(400px, 48vh)` 且图片设置 `object-fit: contain`，当宽度为 474px 时高度应为 266px，硬撑至 400px 导致上下产生空隙 |
| 主舞台预览外边框 | 主视图周围有一道灰色边框线 | `.omx-chat-media-tail__main` 声明了 `border: 1px solid var(--dsw-alias-border-l1)` |
| 缩图左侧边框不完整 | 选中状态缩图的左侧高亮边框线缺失 | `.omx-chat-media-tail__rail` 声明 `overflow-x: hidden` 且无左内边距，缩图外描边 `box-shadow: 0 0 0 1.5px` 被左边缘切掉 |

### 1.2 修复目标
1. **彻底消除黑边**：画廊主舞台按素材原始长宽比自适应（`aspect-ratio` 根据图片自然宽高计算），移除死高度，背景设为透明；
2. **移除主视图边框线**：主视图 `border: none`；
3. **修复缩图高亮描边**：缩图导航栏增加安全内边距（`padding: 2px 3px`），高亮选中态改用内发光描边（`box-shadow: inset 0 0 0 2px var(--dsw-alias-brand-primary)`），100% 不会被父容器边界裁切。

---

## 2. 验收标准（AC）
- **AC-1**：主舞台根据当前图片/视频的自然比例（aspectRatio）自适应尺寸，不产生上下或左右黑边留白。
- **AC-2**：主舞台容器无外圈灰色边框线（`border: none`）。
- **AC-3**：缩图导航栏中处于激活态的缩图，四周（上、下、左、右）边框线全部清晰闭合可见，左侧无任何裁切。
- **AC-4**：自动化测试全绿并通过 UI 规范门禁。
