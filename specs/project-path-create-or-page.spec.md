# 规格：确认创建按路径加页或建项并跳转工作区

Issue: #2519 · 模块: omnimux-workflow · 风险: R2

## 目标

一个文件夹只对应一个项目。点确认时按路径分流：已有项目就加创作页，没有项目就建项；换了文件夹再按会话列表决定是登记工作区还是跳到该工作区的新对话。编辑别人的或官方应用时，在目标项目复制一页「原名_副本」，不另开项目。

新用户基线：未选手动目录、只填名称时写入默认项目库并开新对话。不依赖开发机桌面路径。找不到路径或本机选择取消时，中文提示失败，不覆盖已有档案。

## 命令

- `pnpm --filter omnimux-workflow test`
- 相关单测文件与隔离浏览器验证（本任务工作树内）

## 项目结构

- Host：`plugins/omnimux-workflow/src/projects/`
- 客户端编排：`plugins/omnimux-workflow/src/client/projects/newProject.js`
- 弹窗入口：`NewLocalProjectDialog.jsx`、`CanvasTab.jsx`、`ProjectLibraryPage.jsx`、`promptNewProjectName.js`
- 编辑应用：`AppTab.jsx`、`appLibrary.js`
- 加页带画布：`POST /omnimux-workflow/api/workspaces/:id/project-pages`

## 不变量

| 层 | 身份证 | 规则 |
| --- | --- | --- |
| 文件夹 | 电脑绝对路径 | 项目唯一键 |
| 工作区 | 会话列表对同一路径的登记 | 没有就创建，有了就复用 |
| 会话 | 绑在该工作区上的一场对话 | 不换路径不换对话；换到已有工作区则开新对话并跳转 |
| 项目 | 文件夹内的项目档案 | 一个文件夹最多一份 |
| 创作页 | 项目里一张带画布的页 | 有项目就加页；没项目先建项再出第一页 |

展示名可与文件夹名不同。删除项目只摘档案，不删用户文件夹。弹窗内浏览文件夹保持禁止系统选窗（#2518）。

## 决策树

弹窗默认 = 当前会话文件夹（无会话路径则空，写入默认库）。

1. 路径没变：已有项目 → 当前对话加创作页并打开；还不是项目 → 就地建项 + 第一页，不换对话。
2. 路径变了：会话列表没有该工作区 → 创建工作区 + 开新对话并跳转；已有 → 在该工作区开新对话并跳转。落稳后：已有项目先问「当前工作区已有项目，要在该项目新建创作页吗」；没有项目 → 建项 + 第一页。
3. 当前路径已有项目：确认即加页，不再二次确认。
4. AI 应用：自己的且源在目标项目 → 打开源画布。别人的或官方 → 在目标项目复制一页，标题 `原名_副本`。当前文件夹还不是项目则先就地建项再复制。

## 成功标准

- 当前会话文件夹已有项目档案，确认创建后加一张带空白画布的创作页，不出现英文拒绝码，不另开项目。
- 当前文件夹还不是项目，确认后就地建项并生成第一页，会话不变。
- 改到会话列表没有的文件夹：先登记工作区并开新对话，再按有无项目加页或建项。
- 改到会话列表已有的文件夹：开该工作区新对话（不复用旧聊天）；已有项目需确认后再加页。
- 库外目录只要磁盘上已有档案，按已有项目认领并进入外部登记，项目库能看见。
- 项目库空源文件夹仍写入默认项目库。
- 编辑自己的应用打开源画布；编辑别人的或官方应用在目标项目复制一页「原名_副本」，默认库不出现「应用名 (副本)」新项目。
- 失败提示为中文，不把内部拒绝码直接画在弹窗上。

## 测试策略

- Host：按路径复用已有档案；库外已有档案不抛错；session-binding 能认库外已有项目。
- 编排：同路径加页不建会话；换路径无工作区则创建；换路径有工作区则新会话；空路径默认库新建。
- 编辑应用：官方应用复制页不新建项目；自己的应用打开源。
- 弹窗：已有项目确认走加页；中文提示。
- 隔离浏览器：未建项预填当前文件夹 → 确认加页或建项。

## 边界

- 总是：路径即项目；加页必须带真实画布；中文提示。
- 先问：无（本任务已批准的假设见下）。
- 绝不：系统选文件夹窗口；覆盖已有档案；另开「应用名 (副本)」项目；把开发机路径写进默认值。

## 已拍板假设

1. 自己的应用、源就在目标项目：打开源，不复制。
2. 换到已有工作区：开新对话，不跳进该工作区旧聊天。
3. 当前路径已有项目：确认即加页，不再弹第二次。
4. 普通创建加空白页；只有 AI 应用复制拓扑。
