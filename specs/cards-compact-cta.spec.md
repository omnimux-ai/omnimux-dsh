# 卡片紧凑宽度下 CTA 按钮自适应退化为纯图标规格

**文件：** `specs/cards-compact-cta.spec.md` ｜ **优先级：** P1 ｜ **Issue：** #2246 ｜ **模块：** `plugins/omnimux-inspiration`、`plugins/omnimux-assets`、`plugins/omnimux-market`

## 1. 问题与用户旅程

### 1.1 现状与痛点

用户在窄显示比例下浏览灵感库卡片，卡片悬浮层底部并排两个 CTA 按钮。第二个按钮「立即复刻」只显示出「立即」，右侧文字被卡片边缘硬裁掉，呈现为半截字。同类风险存在于资产库网格卡与专家市场精选卡。

### 1.2 根因定性

1. **省略号规则对匿名文本节点失效**：按钮同时声明 `white-space:nowrap`、`overflow:hidden`、`text-overflow:ellipsis`。文字未包进元素，是 flex 容器里的匿名文本节点，`text-overflow:ellipsis` 只作用于块级容器的行内内容，对匿名 flex item 不生效，于是溢出部分被 `overflow:hidden` 直接硬裁。
2. **列数按视口判定、宽度按容器决定**：灵感库网格列数由 `@media` 视口断点给出（5/4/3/2 列），而卡片真实宽度取决于网格容器宽度。宽视口 + 窄容器（分栏、侧栏）时仍按 5 列排布，卡片被压进文字放不下的区间。
3. **字体简写声明无效**：`.omnimux-inspiration-overlay-cta-btn` 的 `font: 550 12px/16px inherit` 中，`inherit` 不是合法 font-family 值，整条简写被丢弃，按钮字号实际继承父级，文字宽度超出预期。

## 2. 目标与验收标准 (Acceptance Criteria)

### AC-101：紧凑宽度下 CTA 自动退化为纯图标

- **场景**：卡片自身宽度进入紧凑区间（文字无法完整容纳）。
- **预期**：按钮隐藏文字标签，只保留图标，按钮收缩为等宽图标按钮；文字完全不参与布局，不出现半截字、省略号或溢出。
- **判定依据**：由 CSS 容器查询按**卡片自身宽度**判定，不依赖视口宽度，也不依赖 JS 测量。

### AC-102：宽度充足时排版不变

- **场景**：卡片自身宽度充足。
- **预期**：按钮显示「图标 + 文字」，两个按钮等宽平分，外观与现状一致。

### AC-103：无障碍名称不丢失

- **场景**：文字标签被隐藏时。
- **预期**：按钮仍保留 `aria-label`，辅助技术读到的名称与视觉退化前一致。

### AC-104：覆盖全部受影响卡片

- **场景**：分别打开灵感库、资产库网格、专家市场精选卡。
- **预期**：三处卡片的 CTA 均按 AC-101/AC-102 行为工作。

### AC-105：不改动既有语义与交互

- **场景**：点击、键盘 Enter/Space、禁用态、选择态。
- **预期**：按钮的点击目标、事件隔离、禁用与选中行为与改动前完全一致。

### AC-106：字体声明修正生效

- **场景**：任意宽度下观察按钮文字。
- **预期**：按钮字号稳定为 12px、字重 550，不再受父级字号影响。

### AC-107：回归与门禁

- **场景**：运行相关单测、UI 规范门禁与端到端测试。
- **预期**：相关测试 100% 绿灯，UI 规范门禁 0 违规。

## 3. 技术方案

- 在卡片根元素声明 `container-type: inline-size` 与唯一 `container-name`，把卡片自身作为查询容器。
- 按钮文字包进独立标签元素（`...-label`），紧凑时整块 `display:none`。
- 紧凑区间同时把按钮从 `flex: 1 1 0` 切换为固定图标按钮宽度，使剩余空间不再被文字争抢。
- 修正 `font` 简写为可生效的长写属性。
- 容器声明只使用 `inline-size`，卡片高度仍由 `aspect-ratio` 与内容决定，不引入高度塌陷。

## 4. 非目标

- 不改动网格列数规则与断点阈值。
- 不改动按钮文案、语义、点击行为与事件隔离逻辑。
- 不修改共享库 `dsh-ui-kit`（位于另一工作区，本任务无写权限）。
- 不治理纯图标按钮（生成物卡、公共素材卡、数字产品卡），它们不存在文字截断问题。

## 5. 依赖与风险

- 无外部依赖；容器查询在本仓库已有先例（`plugins/omnimux-automation/src/client/styles.js`、`plugins/omnimux/src/client/`）。
- 风险：`container-type: inline-size` 引入 inline 轴 size containment。须实测确认卡片高度与网格行高不变，且 `container-name` 唯一以避免误命中祖先容器。

## 6. 新用户基线

改动只涉及静态样式与已渲染的按钮结构，不依赖任何开发机私有状态、本地服务或凭据。全新安装环境下卡片按同样的容器宽度规则退化，无额外前置条件。
