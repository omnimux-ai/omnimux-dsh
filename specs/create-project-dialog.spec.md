# 规格：新建项目弹窗改为选文件夹卡片

## 1. 业务意图与用户价值

当前「新建本地项目」弹窗用手填绝对路径，难用，且项目库会预填当前工作区路径，容易撞上「该目录已是项目」。

按参考图改成：自定义名称 + 点选本机文件夹 + 选中后变成可移除的目录卡片。

新用户基线：不依赖开发机私有路径。未选手动目录时写入默认项目库。点「添加」后在弹窗内浏览本机文件夹（进入子目录 / 返回上一级 / 选择此文件夹），**禁止弹出系统选文件夹窗口**。取消浏览不改已选状态。

## 2. 交互与视觉契约

1. **标题**：`创建项目`。关闭按钮为矢量图标，禁止字符叉。
2. **名称**：顶部输入框，左侧文件夹图标，占位「项目名称」。可自定义。必填才可点「创建项目」。
3. **源文件夹空态**：标签「源文件夹」；虚线/描边区域文案「在此电脑上添加文件夹」+「添加」胶囊。点击后在弹窗内展开文件夹列表，不弹系统窗口。
4. **选中态**：同一位置切成一行卡片：文件夹图标 + 文件夹名 + 右侧移除。标签行右侧出现「此电脑」。点移除回到空态，可重选。
5. **提交**：有名称即可创建。未选手动目录不传 `projectRoot`，Host 写入默认项目库。选了目录则传该绝对路径。已有项目目录继续红字 `project-exists`，弹窗不关。
6. **入口**：
   - 项目库「创建项目」：不预填当前工作区路径（避免误覆盖）。
   - 画布未建项：可预填当前工作区为已选目录，名称取文件夹名，用于就地建档。
   - 侧栏弹窗与主弹窗一样：点添加后在弹窗内浏览，禁止系统选窗。

## 3. 验收标准

- 空态可见「源文件夹」「在此电脑上添加文件夹」「添加」。
- 点添加后弹窗内展开目录列表，可进入、返回、选择此文件夹，不弹系统窗口。
- 选中后卡片显示文件夹名，移除后回到空态。
- 名称为空时「创建项目」不可点。
- 项目库打开时源文件夹为空，不自动带上当前工作区路径。
- 画布未建项弹窗仍接收 `initialPath`，未改标题时用文件夹名。
- 单测覆盖文案、空态/选中态切换、移除、提交 payload。
- 隔离浏览器验证 DOM 挂载、几何为正、空态与选中态截图。

## 4. 边界

- 总是：弹窗内浏览本机目录；图标走矢量；token 走 `--dsw-alias-*`。
- 绝不：弹出系统选文件夹窗口；合入前不经用户确认演示；把开发机路径写进默认值。
