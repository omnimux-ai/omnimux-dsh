# 三选一引导全屏化与样式对齐（Issue #2590）

## 背景

首次运行的「运行方式」引导上线后是居中小弹窗：三个选项挤在一行、说明文字连成一行，与已批准的高保真原型（全屏卡片式欢迎屏）不符。用户截图反馈：应为全屏页面，按钮样式与文案不符合预期。

## 目标

首次运行引导按已批准原型重排：全屏卡片式页面，官方为主按钮，本机助手与使用自己的密钥为下方并排的次按钮，中间一个「或」；后两步沿用同一全屏框架。不改任何行为逻辑（选择写入、测通、登录门禁、引导只出现一次）。

## 用户旅程

1. 新装或未选过运行方式的安装打开应用 → 出现全屏引导页（非浮动小弹窗）。
2. 看到大标题「运行方式」与一行说明；下方是一个整行宽的主按钮「登录 OmniMux」，其下一行并排两个次按钮「本机助手」「使用自己的密钥」，中间一个「或」。
3. 点「本机助手」→ 同一全屏框架内显示程序选择页，左上角有「上一步」返回。
4. 点「使用自己的密钥」→ 同一全屏框架内显示地址、密钥、模型与媒体勾选表单，左上角有「上一步」。
5. 官方主按钮走既有登录；两步各自的「测试」通过后引导关闭且永不再出现。

## 验收用例

- S1：引导覆盖整个窗口，内容是一张占窗口大部分的大卡片；选择步骤时卡片右侧有装饰画面，表单步骤为单列。
- S2：主按钮整行宽、强调样式（白底黑字）；两个次按钮等高同宽并排，中间「或」；不再出现三个说明文字连成一行的提示。
- S3：后两步与首页同框架，左上角「上一步」可返回选择页。
- S4：保存 + 测试通过后引导关闭；再开不再出现（既有 e2e 保持绿）。
- S5：媒体勾选说明改为「没勾的这项不可用」（与按能力放行的现行行为一致）。
- S6：选了本机助手或自己的密钥之后，启动时不再弹官方账号登录窗；点账号、发布、额度、灵感这些官方账号类动作时仍弹窗。官方方式保持原样（什么都弹）。

## 非目标

- 不改运行方式的行为、接口、设置页区域（设置页样式另行评估）。
- 不动登录门禁逻辑。
