# 灵感社区接入网关灵感分享接口规格（Issue #1937）

## 一、背景与目标
为灵感社区详情弹窗（`InspirationPreviewModal`）接入网关灵感分享能力，支持将本地灵感数据通过网关生成免密公开访问的分享链接。
遵循苹果/推特极致极简美学，移除冗余废话与大段说教文案，提供最轻量的单层直观操作。

## 二、业务规则与权限矩阵
1. **触发位置**：灵感详情弹窗顶部右侧（标题右侧、关闭按钮左侧）。
2. **有效期选项**：
   - `3 天有效`：全员默认支持并默认勾选。
   - `永久有效`：
     - 普通用户：显示为“永久有效（即将开放）”，置灰不可选（`disabled`）；
     - 管理员权限（`is_admin` 或 `role >= 10`）：放开可选，支持生成永久有效链接。
3. **商业化预留**：未来计划向订阅会员开放永久有效权限。
4. **文案奥卡姆剃刀**：
   - 彻底移除冗余的大段说明与引导语，仅保留核心操作项、极简标签与必要反馈。

## 三、用户操作旅程（Critical User Journey）
1. 用户在灵感社区点击任一灵感卡片打开详情弹窗；
2. 弹窗右上角展示克制的「分享」按钮；
3. 点击「分享」展开原地极简浮层（Popover）；
4. 浮层内直观展示「3 天有效」与「永久有效」两个选项：
   - 普通用户点击「永久有效」不生效，显示轻量气泡提示「会员专享，即将开放」；
   - 管理员用户可直接勾选「永久有效」；
5. 点击「创建链接」，平滑变为链接生成态：展示链接输入框与「复制」按钮；
6. 点击「复制」后按钮变为「已复制」，提供即时反馈。

## 四、接口契约（API Contract）
- 请求：`POST /omnimux/inspiration/:id/share`
  - Body: `{ expire: '3days' | 'forever' }`
- 权限校验：
  - 当 `expire === 'forever'` 且用户非管理员时，拦截并返回 `403`（"永久有效仅限管理员使用，普通用户请选择3天有效期"）；
- 响应：
  - 成功：`{ ok: true, data: { shareUrl, expireAt, expire } }`

## 五、验收标准（Acceptance Criteria）
1. **AC-1**：灵感详情弹窗右上角呈现分享按钮，符合设计规范与主题色彩。
2. **AC-2**：点击分享按钮展开极简浮层，包含「3 天有效」和「永久有效」单选。
3. **AC-3**：普通用户视角下，「永久有效」为置灰不可选状态，附带「即将开放」标签。
4. **AC-4**：管理员视角下，「永久有效」可自由勾选。
5. **AC-5**：创建链接接口严格校验权限，越权请求永久有效被服务端拒绝。
6. **AC-6**：创建完成后支持一键复制链接，反馈明确。
7. **AC-7**：界面无多余繁琐废话，风格克制清爽。
