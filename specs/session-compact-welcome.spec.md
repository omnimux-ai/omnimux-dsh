# 规格：会话栏紧凑宽度、贴底输入框与左上角迎宾布局优化

## 1. 背景与目标

在分屏状态（右侧工作台展开）下，中间会话栏当前宽度过宽，挤压右侧核心画布/资产展示空间；同时，会话栏底部的输入框两侧留白过大、底距偏高；此外，空白会话的品牌标识与标语居中悬浮在输入框上方靠下位置，在分屏时造成空间浪费且不够紧凑。

本规格参考现代桌面极简设计（图 3 布局标准），对会话栏布局进行全方位优化：
1. **默认会话栏宽度收窄**：分屏模式下收紧会话栏默认宽度至黄金比例（~420-460px），把宽阔空间留给右侧工作台。
2. **输入框紧凑贴底**：压缩输入框左右边距（收窄至 12-16px 紧凑贴边），降低底部边距使其更紧贴底部（~12-16px）。
3. **左上角迎宾品牌排版**：非全屏（分屏）模式下，将品牌标识与标语移至会话栏左上角，并增加打招呼文案「你好，xxx」（xxx 为当前用户名称，未登录或未指定时优雅兜底）。

## 2. 交互旅程与验收标准（AC）

### AC-1 会话栏默认宽度与空间分配
- 在打开右侧工作台（非全屏分屏态）时，中间会话栏保持紧凑宽度（目标 ~420-460px），右侧工作台分配到更充裕的宽度。
- 窗口缩放或拖拽时，会话栏保持最低保护宽度（>= 360px）。

### AC-2 输入框两侧边距收紧与贴底
- 输入框卡片（`[data-composer-card]` 及包裹容器）两侧边距收窄至紧凑间距（左右留白 12-16px），横向占比充盈不空洞。
- 输入框位置紧贴底部，容器底部 padding/margin 降低至 ~12-16px（原为 ~50px）。

### AC-3 迎宾打招呼与品牌位置迁移（左上角）
- 在非全屏（分屏）模式下，空白会话的品牌与标语脱离底部输入框的弹性挤压，呈现在会话栏左上角：
  - **停靠锚点**：采用绝对定位独立层紧凑固定在会话列左上角（`top: 28px, left: 24px, right: 24px`），中段留白视野开阔；
  - **品牌图标**：紫色圆角方形小幽灵 Logo（尺寸 36x36px，圆角 10px）。
  - **问候主标题**：大号加粗文本「你好，xxx」（xxx 优先读取当前登录用户的显示名称或系统用户名，兜底为「创作者」或「老钟」），单行横向排布；
  - **副标题标语**：清晰副标题「属于你的AI社媒运营团队」，单行横向排布，超长时优雅截断省略，严禁竖排断行变形；
  - **居中外壳收起**：隐藏输入框上方的空占位居中外壳，确保输入框与底部贴合。
- 在纯会话模式（右侧面板完全关闭）下，保留经典居中或优雅展示，全屏与分屏无缝切换。

## 3. 技术约束与规范
- 样式遵循现有的 CSS 变量与设计令牌（`--dsw-alias-*`），严禁硬编码随意颜色。
- 保证已有的对话功能、附件上传与模型选择等底部工具条功能完全可用。
