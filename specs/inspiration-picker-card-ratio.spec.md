# 规格：灵感选择弹窗卡片按原比例、去掉来源标签、勾选框悬停才出现

Issue #2537。只改「从灵感库选择」弹窗里的卡片，不改顶部「全部 / 本地 / 云端」分页，不改搜索、配额和加入卡槽。

## 新用户基线

灵感库可以为空，封面地址可以打不开。空库仍走现有空态；封面打不开时用正方形占位，不依赖开发机上的本地媒体目录。

## 用户看到什么

1. 卡片封面上不再出现「本地」「云端」小标签。顶部三个分页保留，用来区分来源。
2. 有封面的卡片按封面自己的宽高比显示，竖的还是竖的，横的还是横的，不再裁成正方形。同一行卡片可以高低不同。
3. 没有封面、或封面加载失败时，封面区保持正方形占位。
4. 勾选框默认不出现。鼠标移到卡片上、键盘焦点落在卡片上、卡片已选中、或该灵感已在当前会话中时，勾选框出现。移开且未选中时重新隐藏。
5. 点卡片仍能选中或取消。已在会话中的卡片仍不可再选。底部「已选 / 还可添加」、取消、加入卡槽不变。

## 验收

- 打开弹窗后，卡片左下角没有「本地」「云端」文字。
- 竖版封面的封面区高度大于宽度；横版封面的封面区宽度大于高度。
- 不悬停、未选中时，勾选框不可见；悬停、焦点、已选、已在会话中时可见。
- 选中边框、标题、空态、加入卡槽仍可用。

## 边界

- 总是做：只动这个弹窗的卡片样式和勾选框显隐。
- 先问：改顶部来源分页、改每行卡片数量、改加入卡槽之后的缩略图。
- 绝不做：重写资产库或商品库选择弹窗；改灵感库数据接口。
