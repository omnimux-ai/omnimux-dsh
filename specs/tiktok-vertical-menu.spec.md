# TikTok 场景工具栏菜单「上下垂直列表」样式升级规格

## 背景与目标
在 TikTok 场景中，浏览器扩展的触发按钮悬浮贴合在作者头像正上方 8px（位置保持绝对不变）。
根据最新设计要求，浮层菜单由原有的横向胶囊（3 列）升级为符合现代极简设计规范的「上下垂直列表」气泡卡片：
1. 触发图标位置绝对不变（仍固定在头像正上方 8px）。
2. 原生 3 项功能绝对保持不变，不新增任何功能选项（`video` 下载视频、`audio` 保存原声、`save` 收藏到灵感库/素材库）。
3. 菜单改为垂直气泡卡片，带有指向触发图标的微型三角指针，并在触壁翻左时自适应镜像。
4. 每项呈现整行横向排列（图标在左、名称在右），悬停有微透高亮底色。

## 验收条件（Acceptance Criteria）
- **AC-1**: 菜单容器改为 `flex-direction: column`，垂直居中对齐触发器（`top: 50%; transform: translateY(-50%)`）。
- **AC-2**: 菜单容器具备微型指示小三角指针（`::before`），默认向左指向触发按钮，翻左（`.is-left`）时镜像向右指向触发按钮。
- **AC-3**: 列表项 `.omx-item` 呈现整行排布，内部 `flex-direction: row; align-items: center`，图标在左，文字在右。
- **AC-4**: 严格保持 3 项功能操作顺序（`video`、`audio`、`save`），各功能项点击事件分发与宿主导出逻辑保持 100% 契约不变。
- **AC-5**: 兜底渲染宽度与自适应测量与新样式渲染像素保持严格一致。
