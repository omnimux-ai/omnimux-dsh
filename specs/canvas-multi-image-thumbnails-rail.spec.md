# 画布多图候选缩略图纵向滚动收敛规格（Multi-Image Canvas Thumbnails Rail Spec）

## 1. 业务痛点与用户指正
用户实测生成多图并在大图浏览模式下明确指示：
**「当一次生成了多图的时候，用这种方式收敛成可上下滚动切换浏览的样式」**
并附带了精确的设计截图。

### 1.1 核心需求与视觉规范（对标截图）
1. **大图居中为主视觉**：大图在画布中央居中展示，四周无边框线。
2. **多图缩略图栏位于右侧纵向排列**：
   - 当同一批次或会话内生成了多张图片（`mediaList.length > 1`）时，在主视口右上方优雅浮现纵向缩略图卡片栏（`.omx-mv-thumbnails-rail`）。
   - 移除原先在左侧硬切的 70px `filmstrip` 胶卷栏，不再挤压居中大图的视觉重心。
3. **精致横版缩略图卡片（96px x 64px）**：
   - 保持图片本身优美的横版比例，圆角为 10px。
   - **选中态（active）**：高亮亮蓝色轮廓（`border: 2px solid #3b82f6; box-shadow: 0 0 0 1px #3b82f6, 0 6px 20px rgba(59, 130, 246, 0.35);`，微缩放 `transform: scale(1.02);`），100% 像素级对齐截图。
   - **未选中态**：无边框（`border: 2px solid transparent;`），悬停时微浮动与微亮反馈。
4. **支持上下平滑滚动（Vertical Scroll）**：
   - 列表容器设置 `max-height: calc(100vh - 220px); overflow-y: auto;`，当图片数量较多时，支持自然上下滚动。
   - 点击任意一张缩略图，左侧主视口大图立即平滑切换为该图片，保持原生输入框状态与上下文。

## 2. 验收标准（Acceptance Criteria）
- **AC-1（多图候选右侧展示）**：当 `mediaList` 数量大于 1 时，在单图大画布的右上侧展现纵向排列的缩略图列表；当仅有 1 张图时不占位。
- **AC-2（选中态亮蓝高亮框）**：当前展示在大图中的图片，其对应的右侧缩略图卡片呈现醒目的亮蓝色圆角选框。
- **AC-3（点击切换大图）**：点击右侧列表中的任意一张缩略图，左侧主舞台立刻无缝切换为对应的图片预览。
- **AC-4（可上下平滑滚动）**：多图超过可视高度时，缩略图流支持垂直滚动，不溢出视口。
