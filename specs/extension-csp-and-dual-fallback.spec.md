# 规范：扩展网络出口放行与双轨补全降级通道 (Extension CSP & Dual Fallback)

## 1. 业务背景
为确保在本地 OmniMux 宿主尚未重启、未加载新 HTTP 路由时，浏览器助手依然具备高可用文案生成能力：
1. 在 `manifest.json` 的 `connect-src` 中补齐授权的外部大模型直连域名（`https://api.deepseek.com`、`https://api.apikey.fun`）；
2. 在扩展后台维护“本地宿主接口优先（第一通道）+ 外部直连平滑回退（第二/第三通道）”的高可用架构；
3. 确保推特助手在任何环境下点击即能生成神评，杜绝返回空或网络阻断。

## 2. 验收标准
1. `manifest.json` 包含正确的 `connect-src`；
2. 扩展后台在本地服务不可达或返回非 200 时，平滑进入模型供应商直连，无明文硬编码密钥；
3. 扩展单测与 L0 静态门禁 100% 通过；
4. 实机在推特推文 `https://x.com/jaxxchen003/status/2099056701865607327` 点击生成真实神评文案并回填点亮回复按钮。
