# 浮层实体底色治理：清空跨插件历史债务

## 问题
门禁按类别判定后，登记了两处「跨插件历史债务」：素材库的分类尺寸菜单、商品库的缩略图浮层。
两处都裸用了一个宿主并未定义的令牌，浏览器把无效声明整条丢弃，浮层底色退化为全透明，
下层文字直接透出来；商品库那处还叠加了毛玻璃滤镜，透底更明显。

之所以当时只登记不修：两处各自的单元测试把「必须裸写该令牌」当成断言，改源码就会让对方测试变红。

## 验收标准
1. 两处浮层底色都必须带实体回退，计算样式不透明度达到 1（不再依赖未定义令牌）。
2. 商品库浮层不再使用毛玻璃滤镜。
3. 原先钉住旧写法的断言改为接受带回退的写法，不再把错误形态固化为标准。
4. 门禁中的历史债务登记清空；此后任何浮层都必须自带实体底色，无豁免。
5. 真机浏览器验证：两处浮层打开后底色不透明，且截图留证。

## 关键旅程
打开素材库分类的尺寸菜单 → 底色实体；打开商品库缩略图浮层 → 底色实体、无毛玻璃。
