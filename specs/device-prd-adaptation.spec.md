# Spec: 手机管理前端 PRD 适配与 SaaS 专业术语升级

## 1. 业务目标与需求范围
基于最新确认的《OmniMux 创作者内容制作、资产库与手机管理排期分发全链路 PRD》，严格遵循“非必要不新增代码原则”与“SaaS 科技术语”规范，对既有手机管理前端进行 3 项核心能力适配与术语升级：
1. **排期任务 (Schedules)**：
   - 升级为「排期规划管线 (Schedule Pipeline)」；
   - 日历任务卡片集成「双时区智能对齐 (Timezone Alignment)」与「受众高峰黄金档 (Peak Window)」；
   - 增加发帖「履约回执 (Delivery Receipt)」直达交互与线上直链查看。
2. **矩阵账号 (Accounts)**：
   - 升级为「矩阵账号拓扑 (Account Topology)」；
   - 引入卡片级「安全发布配额 (Quota Capacity)」动态进度感知与预警；
   - 引入「健康权重指数 (Health Index)」与硬件宿主路由感知及「无感设备漂移 (Device Drift)」操作。
3. **素材分发 (Content)**：
   - 升级为「资产就绪库 (Asset Inventory)」；
   - 提供直通资产库成片排期入口；
   - 展现「防重发互斥锁 (Anti-duplication Mutex)」与「排期锁定中 (Pipeline Locked)」/「已履约 (Fulfilled)」状态流转。

## 2. 界面验收标准 (Acceptance Criteria)
- [x] **AC-1 (Schedules)**: 周日历卡片清晰展示双时区对照（如：`美西 19:30 · 黄金档 (北京次日 10:30)`），已履约任务带有回执直达入口，点击弹出履约凭证。
- [x] **AC-2 (Accounts)**: 账号卡片不再为空状态，展示账号所属平台徽标、归属地时区、健康权重指数（如 96分 · 状态极佳）、安全配额进度条（如 已发 1 / 上限 3 条），支持漂移操作。
- [x] **AC-3 (Content)**: 素材列表展现直通资产库入口，视频资产具备「待分发 / 排期锁定 / 已履约」三态与防重发互斥锁提示。
- [x] **AC-4 (UI 规范与门禁)**: 100% 遵循 DSH 原生纯黑（#111113）+ 极光紫（#7961f2）体系，主按钮为 Ink CTA（白底黑字），无内联样式，无原生 hex/rgba 裸色，通过 UI 门禁测试。
