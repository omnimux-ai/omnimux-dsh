# 资产库「声音」分类改为横版卡片

## 1. 目标

资产库「全部」里的「声音」一行，现在是竖长卡片（和角色、场景一样高）。声音没有画面，竖长色块里只放一个播放键，又高又空。

用户要的是：声音这一行改成横版，和「风格」那一行一样宽、一样矮。角色、场景、道具、素材仍是竖版。点卡片仍能试听，颜色区分不变。

新用户不需要任何额外配置。声音目录为空时，这一行仍是空的，不报错。

## 2. 用户怎么看

1. 打开资产库，停在「全部」。
2. 往下找到「声音」。标题仍是「声音」，说明仍是「爆款卡点配乐、节奏音频与专业环境音效」，右侧仍是「查看全部」。
3. 这一行的卡片变成横的：宽 300、高 169，比例 16:9。中间仍是白色播放键，底色仍在深青、墨绿、曜蓝、暗紫、深炭之间轮换。
4. 同一页的「角色」仍是竖的：宽 190、高 338，比例 9:16。
5. 声音还在加载时，占位块也是横的，不会先冒出一排竖条再跳成横的。
6. 点进「声音」分类后的瀑布流不改。

## 3. 验收

- 声音行卡片计算样式为宽 300px、高 169px、比例 16 / 9。
- 声音行加载占位块同样是宽 300px、高 169px、比例 16 / 9。
- 角色行卡片仍是宽 190px、高 338px、比例 9 / 16。
- 风格行横版尺寸不变。

## 4. 边界

- 只改资产库「全部」视图里声音这一行的卡片外形。
- 不改播放、配色、文案、查看全部、左右翻页。
- 不改其它分类，不改点进分类后的瀑布流。
