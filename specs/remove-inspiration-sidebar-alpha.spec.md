# 规范：将灵感社区标记为内测版并从左侧侧边栏移除不显示

## 1. 业务目标与背景
为了全力聚焦「工作流」与「应用模板」核心生产力场景，用户明确指示：将「灵感社区」插件在左侧侧边栏入口彻底移除、不予显示，并将其正式收敛标记为「内测版（Alpha）」。
同时，完整保留灵感社区插件的全部业务源码、数据解析、后台服务及工作台内部注册能力，确保后续随时可供内部调用或转正。

## 2. 关键用户旅程与验收标准
1. **左侧侧栏净化与聚焦（AC-1）**：
   - 用户打开主界面，新会话下方的左侧侧边栏导航列表中，彻底隐藏并不再渲染「灵感社区」入口；
   - 核心生产力入口（应用/应用模板、任务看板、工作流/项目、新建项目、资产库、产品库）保持醒目呈现与正常激活。
2. **生命周期内测标记（AC-2）**：
   - 在中枢生命周期名单中将 `omnimux-inspiration` 显式标记为 `stage: "alpha"`，并配置对应工具前缀；
   - 生产环境门禁与自动化打包自动消费同一名单，杜绝未就绪的内测能力外溢。
3. **源码与内部能力完整保留（AC-3）**：
   - 灵感社区插件源码目录与包结构 100% 完整保留；
   - 工作台内部标签页注册、后台抓取与拆解接口、工具定义不受任何破坏。
4. **自动化防线与契约收敛（AC-4）**：
   - 侧边栏协调器在注册拦截时，自动对命中 Alpha 的 `omnimux-inspiration` 执行拦截并阻止插入 DOM；
   - 自动化端到端测试与单测 100% 覆盖并保证全绿。
