# 视频拆解移除伪造假数据与严格成功展示门禁规格说明书 (Spec)

## 1. 业务背景与问题定义
在过去的实现中，视频拆解分析工具（`video_breakdown_analyze`）存在以下两处严重缺陷：
1. **静默降级伪造假数据**：当传入无法直接获取下载流的外网视频链接（如 YouTube、X 等需专业下载器或鉴权的链接），或多模态视听模型未成功返回结构化分镜时，系统静默触发“自适应模板生成”（`generateAdaptiveShotsAndStructure`），捏造了 16 秒固定时长和 4 个假分镜（“黄金前置视觉切入”、“核心主体与细节展示”等），并将其作为真实拉片结果写入本地工件。
2. **盲目提前弹窗**：工具执行逻辑写死在数据生成后立即调用 `sidebar_open`，导致视频根本没下载、多模态分析根本没跑，右侧分析工作台就被强制打开，展示完全脱离真实视频的虚假信息。

## 2. 目标与验收标准 (Acceptance Criteria)
1. **彻底移除假数据生成**：
   - 彻底删除 `generateAdaptiveShotsAndStructure` 在主流程中的兜底调用；
   - 当无法获取可供分析的本地视频文件时，直接抛出明确友好的错误异常，拒绝生成任何空壳或模板数据；
   - 当多模态模型未返回有效分镜（`shots.length === 0`）时，直接抛出错误异常，严禁伪造填充。
2. **失败中断与零脏文件产生**：
   - 当分析失败时，不得生成或覆写 `.vbreakdown` 工件文件；
   - 错误必须直接向外抛出（reject），以便上层智能体和调用方准确捕获真实失败原因并采取正确的补救措施（如下载本地视频后再拆解）。
3. **严格成功展示门禁 (Strict Success Gate for Sidebar)**：
   - 只有在多模态分析 100% 成功、且产出了真实分镜（`shots.length > 0`）并完成工件落盘后，才允许调用 `sidebar_open` 打开右侧页面；
   - 发生任何异常时，`sidebar_open` 绝不允许被调用，右侧工作台保持原状，严禁提前抢跑弹窗。
4. **工具描述指引明确化**：
   - 更新工具参数与功能说明，引导调用方长视频优先传入本地已下载的视频文件路径。

## 3. 关键场景验证用例
1. **无本地视频且无法获取直链时抛错**：
   - 传入 YouTube 等非直链且未下载的 URL，`extractVideoBreakdown` 直接 reject，包含清晰指引。
2. **多模态模型返回空或失败时抛错**：
   - 传入本地视频但模型返回无分镜时，直接 reject，不落盘。
3. **失败场景下 sidebar_open 零触发**：
   - 模拟分析抛错，断言 `sidebar_open` 调用次数严格为 0。
4. **真实成功场景全链路正常**：
   - 传入有效视频并成功解析出分镜，工件正常落盘，`sidebar_open` 触发一次。
