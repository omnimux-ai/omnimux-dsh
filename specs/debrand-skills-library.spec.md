# 112套营销技能库去品牌化与专有工具描述彻底脱敏规范 (Spec)

## 一、背景与业务目标
1. **背景**：针对入库的 112 套专业营销技能，全面排查并彻底清除任何特定第三方品牌（Creatify）和专有私有工具的痕迹。
2. **目标**：
   - 改造 `course-to-short-video` 技能：移除私有 MCP 工具绑定、账号说明与特定域名，改用通用 AI 营销视频裁剪与字幕剪辑流程；
   - 改造 `motion-design-flow` 技能：移除特定编排工具字眼，改用通用的 AI 画面与镜头生成流程；
   - 清理所有 112 个技能的 `metadata.json`：将 `author` 统一变更为 `Official`，清理 `tags` 中的原厂平台标签；
   - 更新 `plugins/omnimux-market/catalog/index.json` 与 `featured-skills.json`：清除原厂标签与私有路径；
   - 确保技能 100% 具备通用性与自主品牌属性，无任何第三方平台残留。

## 二、验收标准与核心用户旅程 (Critical User Journeys)
1. **CUJ-01 技能正文与参考规范纯净化**：
   - 在技能正文中全局检索原厂关键词，命中数为 0；
   - `course-to-short-video` 技能基于标准工作流，不调用私有 MCP，具备通用输入输出；
2. **CUJ-02 检索与标签脱敏**：
   - 技能详情、检索 tags 与前端快照中不再包含原厂品牌词汇；
3. **CUJ-03 自动化回归与质量门禁**：
   - 技能双语门禁、新鲜度门禁、全量单元与端到端测试 100% 绿灯。
