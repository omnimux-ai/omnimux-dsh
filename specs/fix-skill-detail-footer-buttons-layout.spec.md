# 修复技能详情弹窗底栏按钮上下换行折叠问题规格（Issue #2418）

## 一、问题背景与根因定位
在技能市场（`omnimux-market`）的技能详情弹窗（`SkillDetailModal` / `ws-detail-dialog`）底部操作栏中：
1. **子节点塞入错误**：原本将矢量图标 `svg` 与文本（如“分享”、“安装”）作为 `children` 共同传入 `dsh-ui-kit` 的 `Button` 组件，导致图标与文字全部被包裹在组件内部的 `.label` 容器中，未触发组件库标准的 `[slot (图标)] + [label (文本)]` 结构。
2. **宿主环境样式影响**：在宿主环境基础样式（Tailwind Preflight）规则下，`svg` 默认具备块级特性（`display: block`），当图标直接落在普通文本流 `.label` 内部时，图标强制独占一行，将紧随其后的文本挤压到下方，导致按钮变形为“图标在上、文字在下”的异常垂直排布。
3. **缺乏防挤压与不折行样式保护**：底部操作栏 `.ws-footer-actions` 未对内部按钮及子容器声明 `white-space: nowrap` 与 `flex-shrink: 0`，在弹窗处于非最大化尺寸时极易受到挤压变形。

## 二、修复方案
1. **组件层规范契约收敛**：
   - 消费组件库标准属性：将“分享”与“安装”按钮的图标通过 `leadingIcon` 属性传入，`children` 仅保留纯文案，让 DOM 结构转变为标准的两段式水平结构（`<span class="slot">...</span><span class="label">...</span>`）。
   - 更多操作按钮规范化：使用纯图标按钮标准，保证操作栏右侧各按钮高度一致对齐。
2. **样式层加固与防折行防御**：
   - 为 `.ws-detail-footer` 和 `.ws-footer-actions` 添加 `flex-shrink: 0` 防挤压声明；
   - 为 `.ws-footer-actions` 内的按钮及文字容器明确声明 `white-space: nowrap` 与单行水平对齐，确保在任何屏幕尺寸和宿主样式下绝对不发生换行。

## 三、验收标准
1. **AC-1（单行水平排布）**：详情弹窗底部的“分享”与“安装/去对话中试试”按钮严格保持单行水平排列（左侧为图标，右侧为文字），杜绝任何上下折行或方形变异。
2. **AC-2（高度与对齐一致）**：底部所有按钮遵循统一的 28px（sm）紧凑规范，图标与文字垂直居中对齐，与右侧更多操作按钮高度平齐。
3. **AC-3（交互功能零回归）**：点击分享成功呼出分享处理，点击安装/去对话中试试正常触发对应逻辑，更多菜单点击正常展开与收起。
