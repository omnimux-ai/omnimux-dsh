# Issue #2626 — 输入框快捷方式移除实时参数并接入方案 B 会话模型选择器

## 目标 / Objective
用户已明确拍板选择「方案 B」（带自动决策开关的经典单列会话模型面板）：
1. 彻底移除输入框快捷方式底栏的相机生成参数（`MediaParamsPanel` 以及「文生视频 · 720P · 5s」等参数摘要触发按钮），因为输入框内容由 Agent 智能决策参数，而非直接相机式实时生成；
2. 在输入框底栏快捷方式中接入方案 B 经典会话模型面板：
   - 顶部具备「自动 (由 Agent 决策)」开关（默认开启），开启时由 Agent 自主选型；
   - 支持「视频 / 图像」模态 Tab 切换；
   - 呈现单列清晰的模型列表（品牌图标、模型全称、PRO 特性标、简短副标题）；
   - 用户勾选特定模型时，自动关闭「自动决策」，锁定该模型偏好，通过 `/omnimux/session-model` 及 `omnimux:model:changed` 事件与后端中枢及 Agent 决策链无缝对齐；再次开启「自动」时释放锁定恢复自动推荐；
3. 保持与底栏自适应紧凑模式（`composer-compact.js`）的平滑兼容，单按钮形态极简，无变形、无多余滚动条。

## 架构与核心改动
1. **控制面板组件改造**：
   - 在 `plugins/omnimux/src/client/composer-quick-shortcuts/` 中，提供轻量、自包含的会话模型选择器（或封装自 `omnimux-market` 经测试验证的 ModelPicker 契约），不引入任何生图/生视频的参数控件；
   - 废弃快捷方式底栏对 `MediaParamsPanel` 的引用，仅保留会话级模型选择能力；
2. **状态与事件同步**：
   - 读取并同步 `/omnimux/session-model` 与 `sessionStorage` 中 `omnimux:model:<sessionId>` 的存储；
   - 触发 `omnimux:model:changed` 事件，确保整个页面及中枢 Agent 上下文一致感知；
3. **样式与视觉收敛**：
   - 弹窗浮层背景采用实色不透明 `--dsw-alias-bg-layer-2, #1c1c1f`，具备高层叠遮罩与阴影；
   - 彻底解决文字折行、图标错位、多余滚动条等视觉变形问题。

## 验收标准 / Acceptance Criteria
- AC-1: 在未输入或激活「复刻爆款视频」等快捷方式时，底栏不再展示任何「文生视频 · 720P · 5s」等生成参数按钮；
- AC-2: 底栏展示模型选择胶囊（自动态显示「模型」或「自动决策」，锁定时显示当前模型名称与品牌图标）；
- AC-3: 点击胶囊弹出模型面板，顶部有「自动 (由 Agent 决策)」开关与「视频 / 图像」Tab；
- AC-4: 点击某个模型时，锁定该模型，底栏胶囊更新，关闭自动开关；
- AC-5: 重新打开面板并开启「自动」开关时，恢复自动决策态，底栏胶囊恢复「模型」；
- AC-6: 跨会话切换时模型偏好正确隔离；
- AC-7: 全量自动化测试 100% 通过，无语法或构建异常；
- AC-8: 开源代码审查通过，真实浏览器验证通过。
