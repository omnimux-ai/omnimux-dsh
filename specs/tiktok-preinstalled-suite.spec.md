# 规范：TikTok 全能操盘套件上架、出厂预装与可选卸载闭环

> 任务真源：Issue #1697 · 分支 `agent/market-tiktok-preinstalled-suite-issue-1697`。
> 本文件是本任务人与 Agent 共享的验收真相源：写码前定死"建什么、怎样算完成"。

## 1. 业务目标与背景

### 1.1 现状与痛点

1. **出厂自带与技能货架割裂**：系统出厂自带「全能社媒操盘手」（`tiktok-agent`）会话预设，该预设在场景内部配置了 45 个针对 TikTok 的专项技能。但此前这 45 个技能**未作为套件上架到技能市场**，导致用户在普通对话或货架浏览时感知不到这些工具，也无法全局调用；
2. **已安装状态不可卸载**：此前的套件详情页在已安装态下按钮置灰锁死（显示为 disabled 的「已安装」），缺少卸载控制权；
3. **用户明确诉求**：
   > “既然 TikTok全能操盘手 预装，技能没有预装不符合预期，我建议直接把套件预装，相当于依然把套件上架，但是预装，而不是可选安装，而是可选卸载。”

### 1.2 目标

1. 将 45 个细分技能整编封装为「TikTok 全能操盘套件」正式上架技能市场「套件」分类；
2. 该套件出厂状态下默认识别为**预装（已安装）**，技能开箱即用；
3. 详情页提供完整的「可选卸载」交互闭环：已安装态下展示「卸载」按钮，点击确认后调用卸载能力切回未安装态；未安装态下点击「安装」可重新装回。

## 2. 核心交互契约

### 2.1 货架与卡片

- 技能市场「套件」分类下展示「TikTok 全能操盘套件」卡片；
- 卡片构成行清晰展示：`技能 45 · 规则 0 · Agent 0`；
- 出厂默认状态下，卡片识别为已安装。

### 2.2 套件详情展示

- 点击卡片进入详情页，标题为「TikTok 全能操盘套件」；
- 来源显示为官方出厂预装；
- 正文「技能」块完整列出全部 45 个细分技能（涵盖选品、搜索爆款视频、创作视频、生成电商图、创作图片、数据分析、社媒营销等 7 大分类），条目带中文标题与功能说明；
- 规则块与 Agent 块因数量为 0，整块省略不渲染。

### 2.3 可选卸载与安装流转

1. **已安装态（含出厂预装）**：
   - 详情页右上角按钮展示为「卸载」（次级操作样式，非危险红钮，非禁用灰钮）；
   - 点击「卸载」弹出确认框：“确定卸载「TikTok 全能操盘套件」吗？卸载后普通对话将无法直接调用其 45 个细分技能。”
   - 用户确认后，调用 `api('suiteUninstall', { id: 'suite-tiktok-agent', ... })`；
   - 卸载成功后，按钮平滑切为「安装」，界面回执显示“已完成卸载”。
2. **未安装态（卸载后）**：
   - 按钮展示为「安装」；
   - 点击「安装」弹出安装确认框，确认后调用 `api('suiteInstall', ...)`；
   - 安装成功后，按钮恢复为「卸载」，界面回执显示“已完成安装”。
3. **全局普适性**：
   - 这一套「已安装 ↔ 卸载」的交互流转不仅适用于 TikTok 套件，所有已安装的套件（如亚马逊套件等）在安装成功后，均统一获得「卸载」操作权。

## 3. 技术实现方案

### 3.1 数据层与预装标记

- `plugins/omnimux-market/catalog/index.json`：
  - 新增 `suite-tiktok-agent` 条目，`tab: "skills"`, `kind: "suite"`, `category: "sk-suite"`, `preinstalled: true`；
  - 清单 `suite.skills` 包含 45 个技能定义（取自 `presets/tiktok-agent/skills.json` 的真实数据，按 7 大分类排序）；
- `src/expert/catalog.js`：
  - `parseItem` 支持 `preinstalled: boolean` 字段；
  - `isInstalled` 判定逻辑支持预装状态：若 `item.preinstalled === true` 且未在用户本地排除清单中，默认判定为 `true`；若用户执行了卸载，则读取卸载记录判定为 `false`。

### 3.2 卸载状态持久化与服务端接口

- `src/suite-install.ts`：
  - `suiteUninstall`：当卸载预装套件时，持久化记录卸载标记（保存在 `$DSH_HOME/omnimux-market/uninstalled-suites.json`）；当再次 `suiteInstall` 时，自动从卸载标记中移除；
  - 非预装套件卸载时，清空对应的技能文件与规则段，保持既有幂等性。

### 3.3 客户端交互升级

- `src/client/plaza/SuiteDetailModal.jsx`：
  - 右上角操作按钮：`installed` 为 true 时渲染「卸载」按钮（`t(tr, 'suite.uninstall', '卸载')`）；
  - 增加卸载确认弹窗；
  - 点击卸载调用 `api('suiteUninstall', ...)`；
  - 响应后即时切换本地状态并通知外部列表刷新；
- `src/client/i18n.js`：
  - 增补中英文字典：`suite.uninstall`（卸载 / Uninstall）、`suite.uninstallConfirm` 等。
