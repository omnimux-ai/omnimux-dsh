# 图像生成缩略图去除高光漫射与未激活卡片清晰化规格

## 1. 问题与优化目标

在实机反馈中，用户指出缩略图工具栏存在以下 2 处视觉细节问题：

| 问题位置 | 现状与痛点 | 根因与约束 | 优化目标 |
| --- | --- | --- | --- |
| 当前激活项边框 | 边缘有大面积纯白发光漫射泛晕（像灯管），视觉突兀生硬 | `box-shadow: 0 0 14px ... 0 0 28px ...` 发光过度 | 彻底移除刺眼漫射大光晕，改为干净克制的极简浅白细边框 |
| 候选未激活项 | 缩略图整体过暗、黑漆漆一片，内容无法辨别 | `filter: brightness(0.6)` 强行压暗且 `opacity: 0.38` 过低 | 移除压暗滤镜，提升透光清晰度（`opacity: 0.72`），让用户不悬停也能清晰看清缩略图具体内容 |

---

## 2. 验收标准（AC）

- **AC-1**：当前激活项（.active）去除刺眼的漫射发光光晕（无 0 0 14px 等白光阴影），采用极简内敛的纯白/浅色边框与深色底层微投影。
- **AC-2**：候选未激活项（.inactive / 未选中）移除 `brightness(0.6)` 压暗滤镜，`opacity` 提升至 0.72，图片内容自然清晰可辨。
- **AC-3**：保持大小缩略图 1:1 正方形与左右居中几何结构不变。
- **AC-4**：相关单测与端到端测试全绿通过。
