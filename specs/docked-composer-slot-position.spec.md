# 首页吸底时素材卡槽跟着输入框

## 目标

首页选了技能或复刻模板后，输入框会固定在窗口底部。此时已加入的素材缩略图必须贴在这个输入框正上方，左右与输入框对齐。素材为空时不出现空条。收起输入框后，缩略图回到页面里输入框原来的上方位置。

新用户不依赖本机任何私有服务。没有素材时什么都不显示，也不报错。

## 用户操作旅程

1. 打开首页，输入框在页面中部。
2. 点一个会把输入框吸到底部的入口（技能或复刻模板），并加入一张图片或视频。
3. 向下滚动浏览首页内容。
4. 看窗口底部：缩略图在输入框正上方，左右与输入框齐平，不盖住「收起输入框」，也不跑到窗口最上方。
5. 点「收起输入框」：缩略图回到页面内容里，紧挨输入框上方，不再固定在窗口底部。

## 期望界面

- 吸底时，素材条与输入框左边缘相同、宽度相同。
- 素材条底边在输入框顶边上方，中间留出约 8 像素空隙。
- 「收起输入框」在素材条上方，不与缩略图重叠。
- 没有素材时，不显示空的素材条，也不把「收起输入框」额外抬高。

## 验收用例

- 用例一：吸底且有素材时，素材条为固定定位，左边缘和宽度与输入框一致，底边在输入框上方。
- 用例二：吸底且有素材时，「收起输入框」在素材条上方，两者不重叠。
- 用例三：没有素材时，不渲染空素材条。
- 用例四：未吸底时，素材条仍在页面流里，位于输入框上方，不固定到窗口。

## 边界

- 只改素材条在吸底时的位置，不改上传、删除、预览和提交。
- 不改输入框本身的吸底方式。
- 不改首页其它卡片和模板区。
