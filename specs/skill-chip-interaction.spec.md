# 规格：选用技能只显示在技能按钮上

Issue: #2574

## 目标

用户从任意入口选用一款技能后，技能名称只出现在输入框旁的技能按钮右侧标签上。输入框里不出现斜杠指令。用户发送时，这款技能的说明随上下文带给智能体，不写进用户看见的文字，也不自动发送。

适用入口：

1. 新会话技能页点「使用」。
2. 技能市场「去对话试试」。
3. 输入框技能按钮里点选一款技能。
4. 在输入框里打斜杠，从列表里选一款技能。

用户已经写好的文字保留。点标签上的关闭，技能去掉，文字不动。

## 新用户基线

不依赖本机私有模型、密钥或开发目录。技能目录随产品安装。目录里找不到这款技能的说明时，发送仍带上技能名称，并说明正文暂时不可用，不编造步骤。

## 成功标准

- 上述四个入口选中后，技能按钮旁出现该技能的显示名称。
- 输入框草稿不以斜杠指令开头，也不被插入斜杠指令。
- 新会话技能页只预填一句说明请求：「为我解释下这个技能的最佳使用方式。」英文界面为对应英文句。
- 技能市场「去对话试试」不改写输入框。
- 输入框斜杠选中后，斜杠和技能名从输入框消失，光标留在原处。
- 发送时草稿正文不被改写成斜杠指令。技能说明由会话试用通道带入上下文。
- 不自动发送。
- 点关闭后标签消失，已写文字保留。
- 定时任务编辑框里手写斜杠指令的行为不变。
- 安装引导类技能（例如需要先执行安装步骤的技能）仍可把安装步骤写进新会话，不走这套标签。

## 命令

```bash
pnpm --filter omnimux test
pnpm --filter omnimux-market test
```

按改动面只跑相关测试文件，不全量重跑无关套件。

## 结构

- `plugins/omnimux/src/client/composer-add/`：发送时不再把斜杠指令写回草稿。
- `plugins/omnimux/src/client/session-guide/SessionGuide.jsx`：技能页只点亮标签并预填说明句。
- `plugins/omnimux/src/client/composer-commands-i18n.js`：斜杠选中改为点亮标签并清掉斜杠。
- `plugins/omnimux-market/src/client/session-create.js`：去对话试试只点亮标签并挂上会话试用。
- 对应测试与本规格。

## 边界

- 总是：沿用现有技能标签与会话试用通道，不新造第二套状态。
- 先问：改技能目录数据、改定时任务的斜杠插入。
- 绝不：自动发送、把技能说明写进用户看得见的输入框、改正式版安装目录。

## 开放问题

无。用户已确认：全局统一为技能按钮标签，放弃输入框预填斜杠指令。
