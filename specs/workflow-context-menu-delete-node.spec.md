# 规格：画布选中节点右键菜单新增删除功能

## 1. 业务背景与问题定义
用户反馈在工作流画布中：「选中画布节点 新增 删除功能」。
当前原状：
1. 当用户单选画布中的节点后，如果在节点边缘或未直接传递 `node` 的区域呼出右键菜单，由于 `useCanvasContextMenu.ts` 中仅在 `selectedCount > 1` 时才识别为 `selection`，导致上下文被误判为 `pane`。
2. 在 `ContextMenu.tsx` 中，`context.type === 'pane'` 菜单中即便当前存在选中的节点（`hasSelection` 为 true），菜单项中也完全没有提供「删除」选项（只有导入素材、添加节点、撤销、重做、粘贴、全选）。
3. 导致用户在选中节点后，无论通过右键卡片边缘还是空白处，都无法在右键菜单中找到删除操作。

## 2. 交互与功能需求（AC）
- **AC-1（单选节点右键识别）**：在 `useCanvasContextMenu` 中，当触发上下文菜单且未显式指定 `node` 时，如果画布上选中的节点数量为 1（`selectedNodes.length === 1`），上下文必须正确识别为单节点 `{ type: 'node', nodeId: selectedNodes[0].id }`；如果大于 1 则识别为多选选区 `{ type: 'selection' }`。
- **AC-2（空白画布右键联动选中态）**：在 `ContextMenu.tsx` 的背景画布（`pane`）菜单中，若当前画布有选中的节点（`hasSelection === true`），在菜单项中新增「删除选中节点」操作项（快捷键 Del），触发时直接执行 `delete` 动作。
- **AC-3（删除动作执行）**：用户在任何右键菜单分支点击「删除」后，均能通过 `deleteSelectedNodes()` 或按指定节点 ID 准确移除对应的节点与相连连线，并关闭菜单。
- **AC-4（快捷键一致性）**：菜单项中保留与展示 `Del` 快捷键提示，与现有 Delete / Backspace 键盘快捷键行为保持 100% 体验一致。

## 3. 验收场景
1. 选中 1 个表格/材质节点，在节点上或边缘右键呼出菜单，菜单中包含「删除」项。
2. 选中 1 个或多个节点，右键点击画布背景，右键菜单中展示「删除」项，点击后成功删除选中的节点。
3. 未选中任何节点，右键点击画布背景，右键菜单保持原有 6 项（导入素材、添加节点、撤销、重做、粘贴、全选），不展示删除项。
