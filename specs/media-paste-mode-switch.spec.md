# Spec: 粘贴视频自动切到视频模式 + 文生图页签收敛（media-paste-mode-switch）

## 背景
- 粘贴视频在图像模式下会走到「当前生成方式不支持粘贴该类型素材」——应自动切换到视频生成模式并放入视频卡槽。
- 图像模式下文生图页签在只有单操作时只是视觉标签；方式由素材自动推导，可收敛掉。

## 验收标准
- AC-1：图像模式粘贴 .mp4/.webm → 自动切到视频模式，文件进入视频卡槽（若无视频卡槽则提示不支持）。
- AC-2：粘贴图片在视频模式下行为不变（走图像卡槽或提示）。
- AC-3：单操作契约（只有 text_to_image）时文生图页签不再显示为可切换按钮（视觉标签可保留非交互）。
- AC-4：有多操作契约时页签照常可点可切换。

## 改动范围
- `MediaViewerComposer.jsx`：粘贴前置判断跨模态（视频/音频到 image 模式时先切换再入槽）；页签列表单操作时收敛。
- 测试：media-viewer-composer.test.js 增补。
