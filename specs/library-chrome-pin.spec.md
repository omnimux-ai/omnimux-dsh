# 选素材整页：分类钉顶、输入框贴底

Issue: #2573
新用户基线：打开加号三个素材入口不依赖本机私有服务。资产库、灵感库、产品库走已登录后的公开读取；读不到时整页显示已有空态或失败提示，不回退到旧弹窗。

## 目标

从加号进入「从商品库选择 / 从资产库选择 / 从灵感库选择」后，分类栏固定在会话窗口最上沿，输入框固定在窗口最底，中间只滚动卡片。

## 用户旅程

1. 在新对话页点输入框旁的加号。
2. 点「从商品库选择」「从资产库选择」或「从灵感库选择」。
3. 整页出现。分类为：精选、资产库、灵感库、产品库、爆款趋势。
4. 分类栏上沿贴会话窗口顶（侧栏右侧），不再停在内容区中间。
5. 输入框下沿贴近窗口底，技能按钮仍在。
6. 卡片多于一屏时，只滚中间卡片；分类和输入框都不跟着走。
7. 点一张卡片：素材和提示词写入输入框，不自动发送，整页保持打开。
8. 点关闭：整页消失，回到原来的首页，输入框回到原位。

## 验收

- 分类栏 `position` 不再依赖内容区粘性定位；整页容器铺满会话列（侧栏右缘到窗口右缘，顶到底）。
- 卡片网格是整页里唯一滚动的区域。
- 输入框继续用既有吸底，不新画一个输入框。
- 技能按钮在吸底时仍显示。
- 不改提示词槽位的旧弹窗，不改上传文件。
