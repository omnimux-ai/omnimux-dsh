# 灵感库导入生成中复用创作画布有机流光动效与中心极简纯净化规格

**文件：** `specs/inspiration-import-generating-shimmer.spec.md` ｜ **优先级：** P0

## 1. 业务目标与价值
在灵感库通过链接或媒体导入素材（处于解析与下载的生成中状态 `importing`）时，原界面在卡片正中央同时堆叠灰色播放按钮方框、药丸“解析中”文本胶囊以及长网址文字，且背景仅为单薄的灰白色单向线条扫光。这种布局存在明显的视觉层叠冲突与信息过载，缺乏品质感。
本特性旨在将创作画布成熟且高度赞誉的 Transitions.dev Pro 级别有机流体微光折射动效（Organic Shimmer）复用到灵感库导入卡片中，并彻底移除正中央堆叠的文本、按钮与长链接等杂乱元素，只保留纯净、极富科技质感的全屏流体光影，同时保留右上角精致小巧的来源平台标识，带来现代极简的高级感。

## 2. 核心交互与界面规范
1. **复用创作画布有机微光生成动效（Organic Shimmer）**：
   - 当灵感库卡片处于导入中状态（`importing === true`）时，全屏呈现与创作画布同款的流体折射动效；
   - 包含底层多色环状光谱场（蓝、粉、绿、紫、橙散布弥散柔光）、核心 SVG 湍流折射波浪层（4000ms 匀速往返平移）、深层/中层/1px 彩色轮廓三层边缘发光系统，以及动态同步过渡遮罩层；
   - 适配暗色与浅色主题，暗色模式下采用深邃质感背景与暗调流光。
2. **正中区域彻底清空（纯净无干扰）**：
   - 导入生成中状态下，彻底移除中间的占位播放三角形与灰色方圆框（`fallback-icon`）；
   - 彻底移除中间的运行状态胶囊（如“解析中…”、“下载中…”文本药丸）；
   - 彻底移除中间下方的长网址文本（`fallback-title`）；
   - 导入生成中悬停时不显示播放大按钮与操作按钮，确保光影流动一览无余。
3. **保留小巧精致的来源角标**：
   - 右上角继续保留来源平台角标（如 TikTok、YouTube、本地等），支持半透明毛玻璃质感，让用户对素材来源一目了然。
4. **失败态与就绪态保持完备**：
   - 仅在生成中（`importing`）状态呈现纯净动效；
   - 当导入失败（`failed`）时，依然完整展示红色失败胶囊与清晰的失败原因提示，保证可处置性与故障可诊断性；
   - 当导入完成就绪（`ready`）时，正常展示首帧封面、视频与操作交互。

## 3. 验收用例表

| # | 场景 | 操作 | 预期结果 |
|---|---|---|---|
| 1 | 导入生成中动效呈现 | 导入一条视频链接，卡片处于 `import_status: 'importing'` 状态 | 卡片全屏呈现创作画布同款 Organic Shimmer 有机微光动效，多光谱与流体折射平滑流动 |
| 2 | 移除中间文字与按钮 | 检视处于生成中的卡片正中区域 | 无播放三角形按钮框、无居中“解析中…”文本胶囊、无链接文字，中间完全纯净 |
| 3 | 保留右上角来源标识 | 检视导入中卡片的右上角 | 正确展示对应平台名称（如 TikTok、YouTube）或本地标识 |
| 4 | 失败态正常展示原因 | 模拟一条导入失败的记录（`import_status: 'failed'`） | 居中展示红色“导入失败”胶囊与详细失败原因，不被纯净动效隐藏 |
| 5 | 就绪态正常呈现内容 | 模拟导入成功完成的记录（`import_status: 'ready'`） | 正常渲染封面图片/视频画面，悬停可正常触发详情与操作 |
