# 工作流打组工具栏置于节点名称组件右侧规格 (Spec)

## 一、背景与问题根因
此前工作流顶层悬浮工具栏（`GroupTopBar`）与工作流节点名称组件（`GroupHeader`）因使用相同坐标导致两者产生重叠，工具栏遮挡了工作流节点名称。

用户明确要求：
- **工具栏不覆盖工作流节点名称组件，必须排在工作流节点名称组件的右侧**；
- 调色板保持单个图标下拉选择模式；
- 工具栏内部无需重复渲染名称药丸，直接展示：整组执行、保存工作流、发布应用、颜色下拉图标、解体、删除工作流。

---

## 二、架构设计与实现方案
1. **工作流顶部行联动布局 (`wf-group-top-row`)**：
   - 将工作流节点名称组件（`GroupHeader`）与选中态的工具栏（`GroupTopBar`）整合在同一个弹性顶部行容器中；
   - 容器定位在工作流节点左上方（`left: GROUP_CHROME_INSET = 12px`，`top: -(GROUP_HEADER_HEIGHT + GROUP_HEADER_EXTERNAL_GAP)`）；
   - 使用 Flex 布局：`display: inline-flex; align-items: center; gap: 8px;`；
   - 节点名称组件位于最左侧，工具栏紧随其右（带有 8px 呼吸间距），无论名称长短自适应避让，彻底杜绝覆盖与遮挡。
2. **工具栏精简与收敛**：
   - `GroupTopBar` 移除内部重复的名称药丸展示；
   - 操作项：`▷ 整组执行`、`💾 保存工作流`、`🚀 发布应用`、`🎨 调色板下拉图标`、`⚢ 解体`、`🗑 删除工作流`；
   - 整体高度与 `GroupHeader` 胶囊对齐（32px 高度），风格高度统一。

---

## 三、验收标准
1. 工具栏不会遮挡工作流节点名称组件，始终排在节点名称组件的右侧；
2. 工具栏内部不重复渲染名称药丸；
3. 颜色选择器为单个图标下拉选择；
4. 单元测试与端到端测试 100% 绿通过。
