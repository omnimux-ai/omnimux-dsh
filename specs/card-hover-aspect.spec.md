# 规格说明：公共资产库卡片固定比例、满画幅缩放、风格横版及悬停暗化标题浮现

> 关联 Issue: #2225  
> 目标模块: `plugins/omnimux-assets`  
> 质量循环阶段: Spec 门禁规范

---

## 1. 业务目标与需求背景

根据用户提供的设计示范（图 2 纯净满幅无文字、图 3 悬停整面暗化并浮现立体大标题），彻底重构公共资产库卡片版式：
1. **移除独立文字框**：消除卡片下方割裂画面的独立实底文字框，将图片/视频铺满整张卡片（`object-fit: cover`），自适应缩放无黑边。
2. **固定比例体系**：
   - 常规分类（角色、场景、道具、素材、声音）：采用 9:16 竖版卡片（宽 190px，高 338px）；
   - 风格分类（`style`）：采用 16:9 横版卡片（宽 300px，高 169px）；
3. **默认纯图，悬停暗化浮现标题**：
   - 默认态（未悬停）：整张卡片 100% 满画幅沉浸呈现，默认不显示标题文字；
   - 悬停态（`:hover`）：卡片整面覆盖暗化遮罩蒙层（`background: var(--dsw-alias-bg-mask-1)`），底部平滑浮现立体加粗标题与分类描述，右上角操作按钮平滑显露。

---

## 2. 验收标准（Acceptance Criteria）

- **AC-1**：卡片不再有上下割裂的独立文本底框，图片/视频以 cover 方式撑满卡片全部区域。
- **AC-2**：单行流中的常规分类卡片固定为 9:16 竖版比例；风格分类卡片固定为 16:9 横版比例。
- **AC-3**：卡片默认状态不显示标题文本；鼠标悬停时卡片整面暗化，底部平滑浮现纯白大字标题。
- **AC-4**：全量单元测试与 E2E 几何测试 100% 通过，UI01~10 门禁零违规。
- **AC-5**：在独立工作树内通过真实 Web 验收。
