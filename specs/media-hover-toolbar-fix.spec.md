# 浏览器媒体悬浮按钮悬停展开工具栏修复与多重保底机制规格说明

## 1. 背景与缺陷分析

用户反馈在浏览网页视频与图像时，左下角出现 OmniMux 识别图标按钮，但鼠标悬停上去没有展示操作工具栏。

### 根因分析
1. **单一事件绑定的脆弱性**：悬浮胶囊当前仅依赖 `capsule.element` 上的 `pointerenter` 事件触发 `expandCapsule()` 展开两阶段工具栏。
2. **Shadow DOM 穿透与元素边界事件丢失**：胶囊包含品牌图标按钮子节点（`button.omnimux-capsule-brand`），当鼠标直接移动到按钮中心或 SVG 上时，未向图标子节点绑定悬停展开监听。
3. **全局捕获移动事件未补齐展开**：全局文档级别虽然在捕获阶段监听了指针移动（`onPointerMoveTarget`），并在判定位于覆盖层内部（`isInsideOverlay`）时将状态置为 `interactive`，但遗漏了调用 `this.expandCapsule()`，导致鼠标在图标上移动时始终保持收起。
4. **缺少物理屏幕坐标命中保底**：当第三方页面播放器或遮罩层干扰事件传播时，缺乏基于物理像素矩形坐标（`getBoundingClientRect`）的精准命中保底。
5. **移出收起时序健全性**：从交互态移出时，未统一调用 `scheduleCollapse()` 安排带缓冲的折叠，导致状态切换不对称。

## 2. 需求与范围

### 范围包含
- **多事件互补监听**：胶囊容器与内部品牌图标按钮同时监听 `pointerenter`、`mouseenter`、`mouseover`，确保任意一种鼠标事件均可平滑触发展开。
- **全局捕获与坐标命中保底**：在全局移动捕获（`onPointerMoveTarget` / `onPointerOver`）中，不仅通过 DOM 节点判定，同时结合物理矩形坐标（`isPointInsideCapsule`），只要光标处于图标按钮物理范围内即确保触发展开。
- **离开平滑收起**：鼠标移出后统一走带 320ms 缓冲的平滑折叠，防抖动防误关。
- **工具栏与提示气泡健壮性**：工具栏三个功能按钮（灵感、复制、关联会话）同时补充完整的鼠标悬停提示监听。
- **无感体验与零样式破坏**：严格保持既有 24px 微型圆形图标与展开后 64px 黑色毛玻璃胶囊尺寸与无障碍设计标准不变。

### 范围不包含
- 不变动既有三项功能操作协议与后端调用。
- 不影响 TikTok 场景的专属头像锚点逻辑。

## 3. 验收标准 (AC)

- **AC-1**：当媒体悬浮图标显示时，鼠标指针移入胶囊或内部图标按钮，无论通过 `pointerenter` 还是 `mouseenter`，均稳定展开为两阶段工具栏（展开宽度 64px，呈现三个快捷按钮）。
- **AC-2**：当鼠标在胶囊内部移动时，全局捕获监听能稳定感知并保持工具栏处于展开状态。
- **AC-3**：当鼠标离开胶囊后，在 320ms 缓冲期内若重新移入保持展开；超过缓冲期后平滑折叠为圆形图标。
- **AC-4**：工具栏展开后，鼠标悬停于任一功能按钮上时，正常显示纯白提示气泡。
- **AC-5**：全量单元测试与集成测试通过率 100%。
