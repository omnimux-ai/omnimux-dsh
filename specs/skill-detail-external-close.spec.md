# Spec · 技能详情弹窗统一使用外侧右上方关闭按钮

- Issue: #2180
- Date: 2026-09-17
- Owner: agent
- Baseline: brand-new user machine after install/sign-in（开发机私有路径不得作为默认）

## 1. Objective

在技能市场（Marketplace）中，优化技能详情弹窗及套件详情弹窗的关闭按钮交互与布局：
1. 对齐 OmniMux 全局弹窗规范，将关闭按钮统一升级为外侧右上方悬浮的圆形关闭按钮（36px 圆形、半透明浮雕质感、细线几何 X 矢量图标）；
2. 外层使用相对定位容器承载弹窗主体与外悬浮关闭按钮；
3. 移除弹窗内侧 Header 原有的内嵌关闭按钮，消除界面元素冗余，保持设计语言统一；
4. 响应式兼容：宽屏下按钮悬浮于弹窗外侧右上方（`top: 0; right: -50px`），小屏下平滑降级至弹窗右上角内侧，防止超出屏幕视口；
5. 点击外侧关闭按钮或背景遮罩均能正确触发关闭回调。

## 2. User journeys

### UJ-1 点击技能卡片查看详情
1. 用户在「技能/专家」页面浏览技能列表；
2. 点击任意技能卡片（如「Hypit 官方能力接入」）；
3. 弹出全屏居中半透明遮罩与详情弹窗；
4. 弹窗右上方外侧浮现统一规范的圆形关闭按钮；
5. 弹窗头部 Header 区域干净整洁，仅展示标题与分类标签。

### UJ-2 关闭弹窗操作
1. 用户点击外侧右上方圆形关闭按钮，或者点击半透明遮罩背景；
2. 弹窗平滑关闭，返回技能列表；
3. 键盘按下 `Escape` 键同样平滑关闭。

## 3. Acceptance criteria

| ID | Criterion | Evidence |
| --- | --- | --- |
| AC-1 | 详情弹窗外层具备相对定位包裹容器（wrapper），关闭按钮作为外侧兄弟节点定位渲染 | 源码与 DOM 树结构校验 |
| AC-2 | 关闭按钮使用统一类名 `omnimux-modal-close-btn is-external`（或 `ws-detail-external-close`），具备 36px 正圆形、细线 X 图标与 hover 动效 | CSS 规范与单测断言 |
| AC-3 | 弹窗内侧 Header 移除旧的内嵌关闭按钮，杜绝重复按钮 | DOM 结构抽查 |
| AC-4 | 点击外悬浮关闭按钮正确触发 `onClose` 回调 | 自动化交互测试 |
| AC-5 | 响应式自适应：在 <=1280px 宽度下回退至弹窗右上内侧 | 媒体查询样式检查 |
| AC-6 | 静态门禁（UI01~10、代码风格、产品基线）无违规 | `pnpm test:gates` / UI 门禁扫描通过 |

## 4. Product baseline

- **依赖**：仅使用 OmniMux 已有通用样式变量与统一交互设计规范，零第三方外部依赖。
- **缺失时**：即使未加载外部样式，亦有完备的自包含回退样式，确保布局不崩坏。
