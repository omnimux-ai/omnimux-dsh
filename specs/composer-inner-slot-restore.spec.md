# 规格：素材回到输入框内侧，并可用 @ 引用

## 目标

从文件、资产库、商品库、灵感库加入的素材，显示在输入框内侧上方，和官方原生附件同一位置。输入 @ 时，已加入的素材出现在引用菜单最前面；官方的文件与对话记录仍在后面，互不替换。

新用户不依赖本机私有服务。没有素材时，输入框内侧不出现空条，@ 菜单里也不出现空的素材分组。

## 用户怎么用

1. 打开对话，点输入框左下角加号。
2. 任选「上传媒体或文件」「从资产库选择」「从商品库选择」「从灵感库选择」，确认一张图片或一个视频。
3. 看输入框：缩略图出现在文字区上方、框线内侧，可点关闭移除。框外不再单独挂一排。
4. 在文字里输入 @：菜单最上方先列出刚加入的素材，下面仍是原来的文件和对话记录。
5. 点选一条素材：文字里插入可识别的引用，发送时模型仍能拿到这份素材。
6. 关掉卡槽上的素材后，@ 菜单里这条也消失。

## 期望界面

- 缩略图在输入框卡片内部、文字上方，左右贴着卡片内边距。
- 图片和视频仍是小方图，悬停才出现关闭。
- 没有素材时不留空白条。
- @ 菜单里素材排在对话记录之前，一项素材一行，带名字。

## 验收用例

- 用例一：卡槽注册在输入框内侧，不再挂在输入框上方外侧，也不再把内侧整段藏起来。
- 用例二：从四个入口确认素材后，仍写入同一条素材列表，缩略图出现在内侧。
- 用例三：输入 @ 时，已加入的素材排在官方文件与对话记录之前；没有素材时不占一组空标题。
- 用例四：选中一条素材会插入引用；移除该素材后，菜单不再列出它。
- 用例五：官方对话记录引用还在，不被素材引用替换。

## 边界

- 总是做：保留四个入口和现有素材写入；@ 只引用已经加入输入框的素材。
- 先问：让 @ 直接搜索整个资产库、商品库或灵感库。
- 绝不做：改官方输入框源码；拆掉加号四项；用素材引用替换官方对话记录引用。
