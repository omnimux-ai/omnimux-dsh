# #3283 达人工作台增量迁移规格

## 目标与成功标准

调查并迁移 OmniMux influencer 自 2026-10-04 首次角色工作台至 2026-10-13 最新 main 的变更。源版本 f8ccbb171ef8fc04c09de0470808651fd126554d，插件 base 911cb74a60b7dd7d63fd56328b75ae47c0c5e5fb。禁止复制 AGPL 前后端代码；以业务语义独立实现，本仓许可证与中枢边界不变。

- 每项源变更有迁移/已有/不适用/阻断状态，不以大类完成冒充逐项闭环。
- 角色设计、动物角色、随机锁定、描述与参考素材的已核实功能落在插件；保留形象命名和资产归档。
- 历史记录可回填参数、按准确父任务生成多视角、放大预览下载；新任务不能覆盖旧成品。
- 异步受理后续取同一任务直到真实终态；网络/鉴权/下载中断不触发第二次付费提交。
- 视频创作通过中枢 videoGenerate、真实模型目录和分组能力；图片+参考视频两种业务意图有可播放导出结果。模拟证据不冒充真实生成。
- 现有官方主题与公共控件，桌面/窄视口无溢出，加载非空态、提交非空白按钮。
- #3282 已合入新base，保留其来源左对齐及无模型选择的用户体验。

## 新用户基线

仅依赖正式安装的插件、中枢已配置图像/视频渠道及当前账户权限。无模型/渠道时明确不可用而非使用开发机模型、端口、路径。测试使用隔离 ui 合成数据，不读共享开发或正式凭据。缺素材不准提交；缺视频能力不承诺可复刻。

## 命令与测试策略

- 插件测试：`node --test plugins/omnimux-avatar/src/*.test.mjs plugins/omnimux-avatar/src/client/*.test.mjs plugins/omnimux-avatar/src/client/*.test.js plugins/omnimux-avatar/src/client/components/*.test.mjs`。
- 先新增原生账本格式、异步续取、父子关系等失败回归，再最小实现；既有测试不删除不改写。
- 构建：`node plugins/omnimux-avatar/scripts/build-client.mjs`。
- 影响：`node scripts/impact-matrix.mjs --git-diff --base origin/main`。
- 静态按触及面：`pnpm verify:stages`、`node --test scripts/verify-anti-slop.test.mjs`、`pnpm verify:product-baseline`、`pnpm check:boundaries`；若工具/模型/装配有变，加相应最小检查。
- 浏览器：自身工作树完整应用 ui 模式 + 任务 journey，真实截图与逐项断言；先实际验收再写端到端回归。视频 live 验证需任务级授权，本任务不执行。
- 独立审查核对映射、实际diff、当前版本证据。required CI 与正常合并队列，不直推主线。

## 项目结构与复用

- 领域数据/编排/HTTP：`plugins/omnimux-avatar/src/{store,generation,http,paths,rules}.js`。
- 页面：`src/client/AvatarStage.jsx`；控件、hooks与纯逻辑现有分层。
- 分类/灵感：`plugins/omnimux-avatar/data/`，只依已核实数据许可与语义独立建模，不复制未授权素材。
- 中枢拥有提供方HTTP、上传、模型目录与路由；领域不能导入中枢私有模块或持密钥。
- 优先复用 dsh-ui-kit、现有资产选择和中枢上传，不新建平行能力。
- 报告保存在根 `.agent-reports/influencer-avatar-sync/`，最终迁移映射与验收文档进入任务工作树文档目录。

## 代码风格与关键合同

英文标识符、简短中文界面、准确JSDoc。沿用本仓 `createGeneration({ctx, store, paths, imageGenerate, onReady})` 的注入方式；对象结果或明确抛错，不返回空成功。任务采用本地格式为真源，旧properties.input只作兼容读取。模型请求明确组，不猜供应商能力。服务端验证归属与路径。

## 边界

总是：先读规则与文件，先规格测试，可逆切片，追踪未迁移项，只改本工作树，保留真实错误与原任务引用，清理前留存证据。
先问：真实收费视频验证、生产发布、凭据初始化、跨工作区修改、付款、不可逆数据操作、范围外管理员发布/营销体系。
绝不：复制AGPL源码，改官网或官方DSH源码，覆盖他人，UI黑名单遮错，伪进度/伪通过，把预览合格视为收费授权，将未合并源码装入共享开发版。
