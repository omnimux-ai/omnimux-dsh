# 规格说明：客户端直连媒体生成渠道平滑自愈与容灾降级机制

**Issue**: #2869  
**状态**: 实施中  
**范围**: `plugins/omnimux/src/client/media-viewer/`  

---

## 1. 目标与背景

用户在媒体查看器（图像生成）直连提交提示词时，若当前选择的渠道因历史后端 Node 进程未重启而落入不可用分组（如返回 `无权访问 ... 分组` 或 403 / 500 错误），客户端应当：
1. **自动前置映射安全渠道**：当模型为 `gpt-image-2.5` 且渠道为 `standard` 或未显式指定时，自动将请求安全映射至基线实测可用的官方渠道（`economy`）；
2. **客户端多轮容灾自愈（Failover）**：当首次请求收到 403 / 500 等渠道分组错误时，不立刻中断并报错，而是自动尝试切换至备用渠道（`pro` / `economy`）自动静默重试一轮；
3. **保证一次性出图成功率**：彻底规避因 Node 服务进程未重启带来的老分组 403 阻断，保证用户在前端输入提示词后 100% 能够顺利出图并实时展现。

---

## 2. 详细实现契约

在 `MediaViewerTab.jsx` 的 `handleDirectSubmit` 中：
1. 准备候选渠道列表：优先 `effectiveChannel`，次选备用渠道；
2. 若首跳返回非 ok 且报错信息包含分组/权限/渠道不可用特征，自动执行下一候选渠道重试；
3. 成功后更新媒体状态为 `completed`，并挂载真实直链或文件路径。
