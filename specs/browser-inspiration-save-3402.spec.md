# #3402 浏览器收藏与灵感库同步

## 目标与范围
统一浏览器保存入口，主库最终结果为唯一成功依据。素材不全保留已取得内容并同编号补齐；主程序离线提示启动，不增加离线收藏队列。授权覆盖普通 PR、合并与 Dev 交付，不含生产、自动分析、批量采集、新平台、付费生成或官方宿主修改。

新用户基线：已安装并登录的主程序及伴侣扩展，使用现有连接/地址发现能力；没有主程序时明确失败。不得默认开发端口、开发路径或隐式跨实例转投。

## 冻结的交接规则
- 既有 POST `/omnimux/inspiration/local/import-url` 增加可选 `capture` 与 `preserve_available: true`。扩展统一发送 `background:true,auto_analyze:false,return_existing:true,preserve_available:true`；旧调用未开启时保持原默认语义。
- `capture` 白名单：`url,title,text,shape,author,stats,posted_at,cover_url,quoted,poll,media_items`。有序采集媒体为 `{type:'image'|'video',url:string,source_id?:string,poster_url?:string}`；视频只有封面时 `url:''`，不可伪装视频；只允许当前目标同一原帖。禁止本地路径、分析结果、任意记录字段。正文遵守现有2MiB请求上限，不再按2000字符截断。
- 主解析优先，采集内容补缺及引用/投票；解析失败/空返回时采集适配仍进入同一下载流程；不复制下载器，不将封面拼进附件。采集内容已经解码，不重复解码。
- 保存返回必须含有效 `body.data.id` 与 `import_status`（importing/ready/degraded/failed）；不能仅看HTTP成功。新增按 `source_url` 精确过滤的集合GET，沿用 `data.items/total` 形状，最多返回同来源一条，用于收据丢失后核对。GET单条继续读取最终状态。
- 持久记录增加受限 `capture`、`preserve_available`；有序 `media_items` 增加可选 `source_id,source_url,status,error`。新记录 status 为 saved/missing，missing保留类型和固定位置但 `url:''`；旧记录无status按现有兼容处理。原始source_url只可为受安全校验的公开HTTP地址，不能用它替代已保存本地url供创作。
- 正文完整且明确无附件的纯文字帖为ready；已知素材有缺失或仅原帖链接为degraded并写具体原因；完整文件均在库才ready。浏览器缓存成功永不代表主库成功。
- 每份媒体下载/验证独立，成功项保留，失败项原位标缺失。补齐按可靠来源身份匹配，不能因数组过滤/新解析顺序移动已引用素材；未知身份不猜。只清理本次新增且未被记录引用文件，不删除复用旧文件。
- 重试只改处理中状态，不清空正文/素材；保持原编号、收藏、标签、手写草稿和有效媒体，缺失素材不允许播放/分析/创作。保留正文与成功单素材分析，整帖分析须素材完整；新素材变更使相关分析/参考失效，不串索引。旧远程链接视频记录需按文件存在性原位修复，不批量迁移历史缓存。

## 扩展统一保存
- 后台为唯一提交者；侧栏、顶部、媒体预览、视频悬浮及现有作品快捷入口共用保存任务能力。推特点击时采集当前媒体所属原帖，不用首页/第一条/引用帖/媒体地址冒充目标。复制/附件不改，图片悬浮继续资产库。
- 后台持久化小型任务收据：任务标识、固定宿主、规范帖子地址、条目编号、状态和更新时间；不新增离线内容队列。提交前绑定当前已握手宿主或现有受控发现结果，等待设置就绪；发送后不能切换宿主重投。
- 初次受理立即返回任务状态，界面订阅同一存储变化；界面打开时1秒核对、关闭时单一1分钟闹钟恢复，所有终态停止。工作者启动/浏览器启动/界面打开恢复，失联显示待核对并在恢复连接/打开后续查。无收据先精确来源查回，结果未知不自动再次提交。
- 状态文案：保存中/已保存/部分保存/已在灵感库/结果待确认/保存失败。部分保存说明缺失并提供同编号重试；缓存成功不画成功星。过期浮条结果不可影响下一条媒体。

## 实施与验收
主程序、扩展分别独立工作树；集成后运行影响面并集检查、独立评审及真实浏览器验证。主程序包测、扩展包测/类型检查/构建、产品基线、Stage和反遮盖门禁；不默认全仓测试。新增有意义故障回归，替换仅字符串/自演流程的假闭环断言；E2E在取得实际运行证据后编写。

覆盖受理后失败不误报、四图缺一保留三图、视频封面不算视频、纯文字、来源精确匹配、部分与旧记录同编号补齐、索引稳定、工作者重启/收据丢失不重复、主程序离线/缓存成功不能入库、有效文件拒绝错误类型/危险网址、写入失败仅清理新文件。浏览器必须点击真实组件、走实际本地HTTP保存处理器、读回条目及文件；外部社媒和模型用隔离ui替身，不碰用户真库。保留截图、报告和数据身份，单测绿不代替验收。
