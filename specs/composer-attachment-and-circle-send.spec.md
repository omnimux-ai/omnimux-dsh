# 规格说明：输入框加号替换为附件曲别针图标且发送按钮升级为纯白正圆形

## 1. 业务目标与背景
用户要求对浏览器插件输入框（包含侧边栏工作台与浮动工作台）进行视觉与交互重塑，对标主流大模型及推特极简设计规范：
1. 将输入框左下角原有的加号（+）按钮替换为官方单色曲别针/附件图标（PaperclipIcon），自然传达添加附件/图片的语义。
2. 占位提示文案对标更新为“随便问点什么”（英文“Ask anything...”）。
3. 将发送按钮升级为 34px 纯白饱满高对比度正圆形按钮（圆角 50%），内嵌黑色向上箭头或停止图标，悬停微缩放放大（1.05）。
4. 彻底消除多余的模式切换按钮，保持底栏左右两极对称与极致纯净大留白。

## 2. 关键验收标准与指标

### 2.1 附件曲别针图标
- 使用单色矢量 SVG 规范：
  - `viewBox="0 0 24 24"`
  - 图标大小：18px，居中于 32px-34px 圆形悬停响应区内。
  - SVG 路径对标推特原生曲别针：
    `M14 4c-1.66 0-3 1.34-3 3v8c0 .55.45 1 1 1s1-.45 1-1V8h2v7c0 1.66-1.34 3-3 3s-3-1.34-3-3V7c0-2.76 2.24-5 5-5s5 2.24 5 5v8c0 3.87-3.13 7-7 7s-7-3.13-7-7V8h2v7c0 2.76 2.24 5 5 5s5-2.24 5-5V7c0-1.66-1.34-3-3-3z`。
  - 彻底替换原有 `PlusSvgIcon`（+号）。

### 2.2 纯白饱满正圆形发送按钮
- 尺寸：34px × 34px，`border-radius: 50%`。
- 深色模式下：
  - 默认未激活：深色半透明圆底 `#27272a`，文本灰色 `#71717a`。
  - 激活态（输入有文字或有附件）：高对比度纯白实心背景 `#ffffff`，图标为深黑 `#09090b`，带有轻柔阴影 `0 2px 8px rgba(0, 0, 0, 0.35)`。
  - 悬停态：`transform: scale(1.05)`，点击 `transform: scale(0.95)`。

### 2.3 输入框卡片与留白
- 卡片圆角：20px 平滑大圆角。
- 文本占位提示：`随便问点什么`（英文 `Ask anything...`）。
- 底栏左右分布：左侧仅附件曲别针图标，右侧仅圆形发送/停止按钮，无模式标签干扰。
