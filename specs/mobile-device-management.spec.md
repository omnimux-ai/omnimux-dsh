# 规格：主界面接入「手机管理」一级侧边栏入口与工作台

## 一、 需求背景与业务价值
根据用户最高指示，移动端设备自动化绝不能作为脱离主界面的外部独立网页，必须作为 OmniMux 主界面的原生内置功能，在主界面左侧导航栏（新会话下方）正式挂载 **【手机管理】** 一级常驻入口。
创作者与运营者在左侧侧边栏一键点击【手机管理】，主工作视口直接全屏无缝滑出设备集群管理与双脑发片工作台。

## 二、 关键用户旅程 (Critical User Journey)
1. **侧边栏入口发现**：用户打开 OmniMux 桌面端，在左侧导航栏（与「账号」、「发布」、「资产库」同级、位于 rank 3.5 黄金位置）看到带有手机图标的 **【手机管理】** 入口；
2. **工作台 Stage 激活**：用户点击【手机管理】，触发 `window.__omnimuxWorkbench.openTab('omnimux-device:library')`，主界面全屏平滑展开 `DeviceStage`；
3. **全流程静态交互**：
   - 切换 5 大功能视图（真机大屏与体检、周排期发布日历、故障断点对比器、苹果开发者证书、全自主养号策略）；
   - 点击设备卡片滑出 11 项体检抽屉；
   - 点击故障自愈一键演示弹窗自动关闭与任务无感恢复。
4. **平滑关闭与返回**：点击顶部的关闭按钮，平滑返回上一个活动工作区或会话。

## 三、 验收标准 (Acceptance Criteria)
- [ ] 侧边栏行契约：符合 `docs/contracts/sidebar-extra-entries.md` 规范（高度 32px，内边距 `0 8px`，图标 14×14，文字 14px，圆角 8px，悬停高亮）；
- [ ] 唯一激活态契约：符合单激活槽位规则，左侧高亮严格与主视口聚焦的 `omnimux-device:library` 保持一致；
- [ ] 视觉规范：100% 消费官方 `--dsw-alias-*` 原生纯黑（#111113）底色与极光紫（#7961f2）微光，主按钮采用 Ink CTA（纯白底黑字）；
- [ ] 无外部网页跳出：所有交互全量闭环在 OmniMux 宿主客户端内部。
