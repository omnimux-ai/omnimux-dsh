# 画布输入框靠底停靠与评论挂件贴合规格 (Canvas Composer Bottom Dock & Attachment Alignment Spec)

## 1. 业务痛点与用户指正
用户实测全屏画布并明确指正两个核心问题：
1. **「第一是把输入框 靠底迁移」**：
   - 现输入框座席固定在 `bottom: 24px`，在全屏大图下下方留有宽达近 40px 的黑色空隙，悬浮过高，挤压主画布纵向空间。用户要求将其贴底迁移（对标下方红箭头）。
2. **「第二是评论在提交后，没有挂到输入框上作为挂件」**：
   - 此前评论胶囊挂件尝试通过独立 fixed 浮层停靠，因位于右侧面板 DOM 树内部而受父级局部坐标系影响被遮挡或偏移；
   - 用户明确圈出输入框卡片内部、文本输入行正上方的红色矩形区域，要求将「⊕ X 个评论」真正**作为挂件挂在输入框卡片内部**。

## 2. 改造方案

### 2.1 靠底迁移优化 (`conversation-collapse.js`)
- 将 `html[data-omnimux-conversation-collapsed] [data-composer-seat]` 的底部间距从 `bottom: 24px !important;` 优化为 `bottom: 10px !important;`。
- 保证输入框卡片紧密停靠在视口底端，留出极致纯粹的视口留白，主图纵向空间利用率最大化。

### 2.2 挂件物理贴合输入框卡片 (`MediaViewerTab.jsx` + `styles.js`)
- **真实挂载机制**：
  - 在 `[data-composer-card]` 内部顶部插入/对齐专用挂载槽 `.omx-composer-comment-mount`（位于卡片第一子节点，输入文本行正上方）；
  - 利用 React Portal 或生命周期管理，将评论挂件组件直接渲染注入到该挂载槽中；
  - 彻底摆脱多层父容器坐标干扰，挂件成为原生输入框卡片内壁的原生一部分。
- **挂件视觉规范**：
  - 胶囊药丸：黑底微圆角磨砂胶囊（高度 26px，圆角 9999px），内含蓝色徽标数字或加号、纯白文字「X 个评论」及微型关闭按钮 `✕`；
  - 点击挂件可重新激活画布打点与高亮，点击 `✕` 可一键清除当前评论并退出。

## 3. 验收标准 (Acceptance Criteria)
- **AC-1 (输入框靠底停靠)**：在折叠全屏画布模式下，`[data-composer-seat]` 距视口底部仅 10px，无多余大黑条空隙。
- **AC-2 (挂件精准嵌套于输入框)**：图片存在已保存评论时，`[data-composer-card]` 内部文本行上方立即浮现「⊕ X 个评论」挂件，完全命中用户指正的红框区域。
- **AC-3 (一键清除与联动)**：点击挂件右侧 `✕` 关闭按钮，评论挂件与画面图钉同步清除，顶部工具栏恢复「+ 添加评论」状态。
