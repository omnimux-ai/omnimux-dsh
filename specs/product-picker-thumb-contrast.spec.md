# 规格文档：产品选择器缩略小图高对比度与尺寸优化（对标参考图清晰白边与防吞投影）

**文件：** `specs/product-picker-thumb-contrast.spec.md` ｜ **优先级：** P0 ｜ **模块：** `plugins/omnimux`
**变更面：** Client / ProductPicker / ProductPickerCard

---

## 1. 业务目标与问题根因

在实机与用户真机反馈中，商品卡片左下角的缩略小图虽然已成功加载，但在白底/浅色电商商品封面图（如女士香水、文胸）上：
1. **尺寸过小**：原 22px 尺寸在 1:1 商品大图上比例过小，微缩图细节看不清；
2. **缺少高对比度边框与阴影**：原半透明边框在浅色大图背景上对比度极低，小图容易与商品大图融为一体，导致用户视觉上误以为“小图没有显示”，只注意到了高对比度的黑色 `+xx` 徽标；
3. **对标参考图 2 关键特征**：参考图中的小缩略图具有明显的**高对比度白边（白色圆角线框）**、**适度放大的尺寸（28px）**以及**立体投影（防背景融合）**。

---

## 2. 详细验收标准（Acceptance Criteria）

### 2.1 缩略小图尺寸与清晰度提升 (P0)
- **AC-101**：`.omx-product-pick-card__sub-thumb` 尺寸调整为 `28px × 28px`，圆角提升为 `5px`，`object-fit: cover`。
- **AC-102**：缩略小图采用高对比度白色线框描边（`border: 1.5px solid rgba(255, 255, 255, 0.9)`）与立体悬浮投影（`box-shadow: 0 2px 6px rgba(0, 0, 0, 0.55)`），彻底消除白底或复杂背景下的视觉吞噬。

### 2.2 超量计数徽标尺寸与风格统一 (P0)
- **AC-201**：`.omx-product-pick-card__sub-badge` 尺寸对齐高度 `28px`，`min-width: 28px`，圆角 `5px`。
- **AC-202**：超量徽标同样带有白色线框描边与立体投影，背景为半透明实底深黑（`rgba(0, 0, 0, 0.75)`），字体为白色加粗 11px，居中对齐。

### 2.3 布局与间距优化 (P0)
- **AC-301**：微缩图队列 `.omx-product-pick-card__thumbs-row` 子项间距设定为 `gap: 6px`，左下定位 `left: 8px; bottom: 8px;`。
- **AC-302**：最多显示 3 个小图，超过部分在第 4 位展示 `+xx`。
