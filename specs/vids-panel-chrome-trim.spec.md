# 规格：生成面板去除无意义的面板外壳（Issue #3205）

## 背景

生成能力并入剪辑窗口左列后，面板顶部仍保留独立舞台形态的头部（「Google Vids」标题 + 「内测版」微标 + 「向导」按钮），下方又固定渲染一行「生成记录 (0)」。这两块在剪辑窗口里既不能操作也不承载信息，属视觉噪音。

## 用户操作旅程

1. 用户打开剪辑窗口 → 左列生成面板**顶部不再出现标题栏**，第一眼看到的就是模式芯片行。
2. 用户没有任何生成记录时 → **不出现「生成记录 (0)」标题行**，面板保持简洁；一旦产生记录，记录列表与标题照常出现。
3. 用户点开输入框或展开箭头 → 收起/展开行为与既有契约完全一致（不受本次改动影响）。

## 期望界面反馈

| 元素 | 改动前 | 改动后 |
|---|---|---|
| 顶部标题栏（Google Vids / 内测版 / 向导） | 剪辑面板内始终显示 | 剪辑面板内**不渲染**；独立舞台形态仍保留 |
| 「生成记录 (0)」空标题行 | 无记录时也显示 | 无记录时**整块隐藏**；有记录时照常显示 |
| 模式芯片行、输入框、参数胶囊、发送键 | — | 不变 |

## 验收用例

- AC1：剪辑面板内不存在头部标题栏（`.gvids-header` 不可见），也不存在「内测版」微标与「向导」按钮。
- AC2：无生成记录时 `.gvids-feed` 不可见，页面不出现「生成记录」字样。
- AC3：有生成记录时 `.gvids-feed` 可见且显示「生成记录 (N)」。
- AC4：收起/展开契约不变：默认 `collapsed`，点箭头或点输入框变 `expanded`，再点收起。
- AC5：四模式芯片、参数胶囊、清除/发送键仍在位可用。

## 保留项（不得移除）

- 未就绪时的门禁提示条（「请在右侧创建或打开剪辑工程」+「新建工程」）——它是可用性引导，不是噪音。
- 生成记录列表本身及其「插入到时间线 / 重新生成 / 修改提示词」等操作。

## 验证方式

- 真机验收旅程 `scripts/qa/vids-panel-chrome-trim.mjs`：剪辑窗口内取证收起态与展开态，断言头部不可见、无记录时无「生成记录」字样、展开契约不变；留存截图供人眼复检。
- 门禁：`pnpm --filter omnimux-video test`、`pnpm verify:stages`、`node --test scripts/verify-anti-slop.test.mjs`、`pnpm check:boundaries`、`pnpm verify:product-baseline`。
