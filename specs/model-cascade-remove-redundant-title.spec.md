# 移除模型级联选择面板「选择模型」冗余标题规格（Remove Redundant Model Title Spec）

## 1. 业务痛点与用户决策
在工作流画布中打开模型配置级联面板（ModelCascadeMenu）时：
- 第一列（品牌列表）顶部存在一个写着「选择模型」的文字元素：
  ```tsx
  <div className="wf-loomi-section-title">
    选择模型
  </div>
  ```
- 用户明确指示并要求：
  **「模型配置面板的 选择模型 元素 移除 多余」**

### 1.1 现状分析与视觉失衡
1. **语义重复**：底部的触发栏已经常驻显示当前选中模型，弹出的级联面板本身就是模型与渠道选择浮层，左上角单独放置「选择模型」四字信息冗余。
2. **列间顶部未对齐**：
   - 第一列（品牌列表）顶部有「选择模型」标题，导致下方品牌选项（xAI、MiniMax、Seedance 等）下移；
   - 第二列（模型列表）直接从第一个模型选项（如 Seedance 2.0）开始，顶部没有任何标题；
   - 导致第一列品牌按钮与第二列模型按钮顶部不对齐，视觉产生明显断层和高低落差。
3. **极简体验**：移除第一列顶部的「选择模型」后，第一列与第二列在顶部整齐划一，界面更加紧凑干净、符合现代极简设计。

## 2. 改造方案
1. **移除第一列顶部标题**：
   - 彻底移除 `ModelCascadeMenu.tsx` 中 `className="wf-loomi-col wf-loomi-col--brand"` 下的 `<div className="wf-loomi-section-title">选择模型</div>`。
   - 保留品牌容器的 `role="group"` 与 `aria-label="选择品牌"`，保证无障碍属性完备。
2. **样式与对齐自适应**：
   - 移除后，品牌列表第一项（如 xAI）与第二列模型列表第一项在顶部对齐，无需多余空白。
   - 检查 `components.css` 中 `.wf-loomi-section-title` 是否仍有其他引用或保持整洁。
3. **测试更新与验证**：
   - 检查并更新现有的自动化测试与端到端测试断言，确保没有强依赖「选择模型」文字选择器的用例被破坏。
   - 新增/更新单元测试，验证面板展开后第一列不再渲染「选择模型」文本。

## 3. 验收标准（Acceptance Criteria）
- **AC-1（冗余标题移除）**：模型配置级联菜单展开后，第一列品牌列表顶部不再渲染「选择模型」文字元素。
- **AC-2（顶部对齐自然）**：第一列品牌项与第二列模型项在顶部高度自然对齐，无错位或多余空白。
- **AC-3（交互功能完整）**：品牌悬停切换、点击固定、模型选择、渠道策略勾选等交互行为完全不受影响。
- **AC-4（测试全绿）**：工作流及模型选择相关测试 100% 通过。
