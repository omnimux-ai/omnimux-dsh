# 规格说明：生成方式切换迁移至输入框内侧卡槽上方并从参数面板移除

**Issue**: #2863  
**状态**: 实施中  
**范围**: `plugins/omnimux/src/client/media-viewer/`  

---

## 1. 目标与用户意图对齐

根据用户最新附图与指令要求：
1. **生成方式切换位置重构**：
   - 将原位于参数配置面板/底栏的生成方式切换功能，完整迁移到**输入框内侧的素材卡槽上方**（`.omx-composer-header-row`）；
   - 以高质感胶囊形式呈现（包含精致图标与简短白名单文案）：
     - 视频模式：`参考`（双图图标）、`首帧/首尾帧`（胶片图标）、`编辑`（铅笔图标）；
     - 图像模式：`文生图`（星光图标）、`参考`（双图图标）、`编辑`（铅笔图标）；
     - 右侧配套全屏展开按钮（`⤢`）；
2. **参数配置面板瘦身**：
   - 彻底从底部的参数配置面板中移除“生成方式”选择分组（`omx-param-group`）；
   - 底栏参数胶囊回显收敛为纯粹模型核心参数（如：`480P · 9:16 · 15s` 或 `1:1 · 1K · 1`），不再在底栏冗余混合展示生成方式。
3. **联动驱动**：
   - 点击上方生成方式胶囊，自动驱动下方素材卡槽做相应的自适应展开与布局契约变更。
