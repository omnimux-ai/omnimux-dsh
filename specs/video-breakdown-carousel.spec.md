# Spec: 视频拆解工作台图文轮播（Carousel）支持（Issue #2900）

## 背景

视频分析工作台只认视频素材。对图文轮播（一组可翻页的静态图，TikTok/Ins carousel、灵感库 `type:image` 条目）执行拆解直接报错拒绝，工作台也没有对应展示形态。

## 目标（可测验收）

1. `video_breakdown_analyze` 的 `url` 参数接受 `@inspiration/<id>` 指向 `type:image` 条目时进入轮播流水线，产出 `media_type:'carousel'` 的 `.vbreakdown`；不再抛「图文轮播不是视频」。
2. 工件 `carousel` 段含 `pages:[{index,image_url,local_path}]`；每页被多模态逐页拆解，映射为分镜条目（`page_index` 与 `time_range` 写 `第N页`）。
3. 查看器：carousel 工件左侧换成图片翻页器——当前页大图（沿用画幅自适应）、`第 n/共 m 页` 计数、前后翻按钮；右侧分镜列表不变，点击某条分镜可联动翻页（可选增强，若实现须可测）。
4. 视频工件行为零回归：既有画幅自适应、播放、翻译完全不变。

## 关键用户旅程

1. 用户在灵感社区选中一篇图文轮播作品 → 让助手拆解 → 工作台打开，左侧是可翻页的大图，右侧每页一条拆解卡片。
2. 用户打开任一历史视频 `.vbreakdown` → 与之前完全一致。

## 新用户基线

灵感条目走本机灵感接口（`127.0.0.1`）；远程页图下载失败则该页记 `image_url` 原值、页面照常展示占位，不整单失败。

## 非目标

- 分镜缩略图逐帧（frame 提取是视频专属）。
- 新输入渠道（显式图片数组、本地图片目录）。
- 翻页键盘快捷键与手势。
