# 规格：插件入口页面级全屏与分栏独立视窗记忆体系

## 一、背景与问题陈述
官方 DSH 原生右侧面板（`ui-sidebar-right`）在设计上将全屏状态（`data-sidebar-right-panel="fullscreen"`）记录在整个会话全局（Session 维度），而没有针对单个页面（Tab 维度）做视窗模式隔离。
这导致用户在某个页面（例如资产库）点击右上角“收起全屏”进入分栏模式展示会话栏后，切换到其他插件页面（如灵感社区、账号中心等）时，其他页面也被迫以分栏模式打开；反之，若在其他页面切为全屏，之前设定好分栏的页面也会被覆盖丢失。

此外，用户明确要求：所有插件入口页面打开时应默认全屏铺满展开，且每次用户对特定页面做出的分栏/全屏选择，系统应精准且独立地记住，切换不同页面时自动调和与还原。

## 二、需求与用户旅程

### 旅程 1：全新打开插件页面默认全屏
- **前置条件**：用户处于会话中，未曾手动调整过任何页面的视窗模式。
- **操作**：用户点击左侧栏的插件入口（例如“资产库”或“灵感社区”）。
- **预期结果**：右侧面板打开并默认以全屏模式（`fullscreen`）铺满，中间会话栏平滑收起。

### 旅程 2：单页面收起全屏并展示会话栏（独立记录）
- **前置条件**：用户当前在“资产库”全屏页面。
- **操作**：用户点击右上角模式切换按钮（退出全屏）。
- **预期结果**：右侧面板切换为非全屏（`push`），中间会话栏展开显示；系统**仅将资产库（`omnimux-assets:library`）**的视窗偏好持久化更新为分栏（`split`）。

### 旅程 3：跨页面切换保持各自视窗记忆
- **前置条件**：“资产库”当前已被用户设定为分栏模式。
- **操作 1**：用户点击左侧栏或右栏 Tab 切换到“灵感社区”（未曾调整过）。
- **预期结果 1**：右侧面板自动切换为全屏模式，中间会话栏平滑收起。
- **操作 2**：用户点击左侧栏或右栏 Tab 切回“资产库”。
- **预期结果 2**：右侧面板自动恢复为分栏模式，中间会话栏自动展开显示。

### 旅程 4：重新切换全屏更新记忆
- **前置条件**：“资产库”处于分栏模式。
- **操作**：用户在“资产库”再次点击右上角“全屏铺满”按钮。
- **预期结果**：右侧面板进入全屏，中间会话栏收起；资产库的偏好记录更新为全屏（`gui`）。后续切换其他页面再切回，资产库均保持全屏。

## 三、架构设计与契约约束

### 3.1 默认视窗偏好收敛 (`focus-state.js`)
- `resolveDefaultFocus(tabId)`：统一返回 `WORKBENCH_FOCUS.gui`（即全屏），取代历史的 `split`。
- `focusRecordForTab(sessionId, tabId)`：确保每个 Tab 返回独立的记录对象，优先读取持久化记录，无记录则落回 `WORKBENCH_FOCUS.gui`。

### 3.2 原生全屏控制对称能力 (`host-fullscreen.js`)
- 现有 `exitHostRightSidebarFullscreen(doc)`：寻找 `button[data-sidebar-right-mode="push"]` 并点击。
- 新增 `enterHostRightSidebarFullscreen(doc)`：寻找 `button[data-sidebar-right-mode="fullscreen"]` 或全屏按钮并点击，触发原生全屏模式。

### 3.3 页面级视窗模式调和器 (`tab-viewport-reconciler.js`)
- 模块生命周期：在客户端初始化时调用 `installTabViewportReconciler(doc)`，在卸载时执行清理。
- 监听机制：
  1. 监听宿主 DOM 中当前激活 Tab 变化（通过观察 `[data-sidebar-right-panel]`、`data-sidebar-right-open`、激活 Tab 的属性变化）；
  2. 监听宿主面板模式（`data-sidebar-right-panel="fullscreen"` vs `push`）的变化；
- 调和流转：
  - 当检测到模式切换由用户点击产生时，将新模式写回当前活跃 Tab 偏好（`fullscreen` -> `gui`, `push` -> `split`）；
  - 当检测到当前激活 Tab 发生切换时，读取目标 Tab 记忆模式：
    - 若目标 Tab 偏好为全屏，而当前宿主面板为 `push`，自动调用 `enterHostRightSidebarFullscreen`；
    - 若目标 Tab 偏好为分栏，而当前宿主面板为 `fullscreen`，自动调用 `exitHostRightSidebarFullscreen`。

## 四、验证标准与门禁
1. **单元测试**：
   - 偏好解析与读写测试：100% 覆盖默认全屏与多 Tab 独立性；
   - 原生控制函数测试：正确识别与触发模式按钮；
   - 调和器状态机测试：模拟 Tab 切换与模式监听流转。
2. **端到端测试**：
   - 多场景联动：资产库(全屏) -> 资产库(退出全屏) -> 切灵感(自动全屏) -> 切回资产库(自动分栏)。
3. **真实环境要求**：
   - 无任何强制 CSS 侵入或死循环，无界面闪烁。
