# 图像生成大橱窗与队列双向纯视觉同步规格说明书 (Media Viewer Pure Visual Sync Spec)

> 关联任务：图像生成模块交互优化与纯视觉体验升级
> 交付目标：彻底解决大图在生成时停留在旧图、缺乏执行反馈、死板固定卡片尺寸以及突兀边框线等体验问题，实现纯视觉（零文字）流体微光动效与原生比例自适应的原位蜕变。

---

## 1. 核心业务痛点与改进目标

### 1.1 现状痛点
1. **状态割裂与滞后**：点击立即生成后，中央大橱窗依旧死板停留在生成前的旧图上，只有左侧小卡片在等待，造成用户产生“系统是不是没响应”、“新构思到底有没有在生成”的心理疑虑；
2. **机械文字与状态噪音**：旧版尝试中混入了大块提示文字、计时胶囊与机械转圈，严重干扰了纯净的画面沉浸感；
3. **生硬外边框与死板写死尺寸**：大图被束缚在写死的像素尺寸与突兀边框线中，无法原汁原味还原素材本身的长宽比；
4. **生成结果保留与回溯**：生成成果未能自然有序地沉淀在历史流中，无法随时无缝对比查看。

### 1.2 预期验收标准 (Acceptance Criteria)
- **AC-1（提交即同步激活）**：用户在输入框点击立即生成时，左侧单列队列顶部新增任务执行小卡片，同时**中央大橱窗立即同步化身为当前任务的原位执行大卡片**；
- **AC-2（纯视觉 100% 零文字）**：在任务执行过程中，大卡片与小卡片**绝对不渲染任何文字描述、进度文字或秒数计时胶囊**，纯视觉呈现创作画布同款 `OrganicShimmer` 流体微光折射动效；
- **AC-3（彻底消除边框线）**：卡片容器彻底清除 `border` 描边，仅依靠深邃柔和的环境光晕及圆角几何与深色背景浑然一体；
- **AC-4（素材原生比例自适应）**：卡片自适应贴合当前选定或素材自身的真实宽高比（如 1:1、16:9、9:16、4:3），弹性舒展，不写死固定宽高；
- **AC-5（原位 300ms 平滑蜕变）**：任务就绪返回图片时，微光层以 300ms 柔和淡出，高清实图在同一卡片容器中同步淡入，原位完成形态蜕变（Morph）；
- **AC-6（双向自由回溯与多任务并发）**：生成期间用户随时可点击左侧已完成历史查看旧图；点回执行中任务，大橱窗立刻响应切回该任务的实时微光动效；解除前端串行提交死锁。

## 2. 界面与交互状态机

### 2.1 条目模型统一
```typescript
interface MediaItem {
  id: string;
  status: 'generating' | 'completed' | 'failed';
  url?: string;
  thumb?: string;
  title?: string;
  prompt?: string;
  aspectRatio?: '1:1' | '16:9' | '9:16' | '4:3' | string;
  timestamp: number;
}
```

### 2.2 大橱窗渲染决策
- 当 `activeItem.status === 'generating'`：
  - 渲染 `omx-media-slot`（无边框，自适应比例），内嵌纯视觉 `OrganicShimmer` 动效；
- 当 `activeItem.status === 'completed'`：
  - 渲染 `omx-media-slot`（无边框，自适应比例），内嵌高清实图，并保留 300ms 淡入平滑过渡。

---

## 3. 测试与验证路径
1. 单元测试验证：
   - 任务派发时 `activeId` 正确指向正在生成的任务项；
   - 任务执行态时不包含任何文本节点；
   - 样式层锁定无边框线契约（`border: none`）；
2. 真实浏览器端到端验收：
   - 在独立工作树中通过自动化测试验证 DOM 挂载、几何尺寸、零文字与状态切换。
