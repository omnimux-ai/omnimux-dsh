# 规格说明：资产库中心新增「生成的（Generations）」标签页与全链路素材收敛（切片 1：界面层）

## 1. 业务背景与用户价值
在现有的 OmniMux 资产库中心（`plugins/omnimux-assets`）中，顶栏提供「本地素材（local）」、「云端素材（cloud）」以及「产品库（product）」三个一级标签页。
用户在日常使用中，通过智能体助手对话（如 `image_generate` / `video_generate`）、独立图像生成功能、以及创作画布（Workflow 节点）生成了大量优质图片与视频素材。目前这些生成结果分散在聊天流、独立历史记录或各个项目工作流目录中，缺乏统一入口进行集中查看、检索与长期资产化沉淀。

本切片（切片 1：界面层）的目标是在资产库中心顶栏新增「生成的（Generations）」一级标签页，并提供来源筛选与多模态瀑布流卡片网格呈现，打通查看、多维过滤、大图/视频预览与快捷流转的完整界面体验。

## 2. 详细设计与交互规范

### 2.1 顶栏标签页扩展
- **一级 Tab**：在 `AssetsFilterBar` 的 `Tabs` 组件中新增第四项：
  ```javascript
  { id: 'generations', label: t('source.generations') || '生成的' }
  ```
- **多语言适配**：
  - 中文（zh）：`source.generations: '生成的'`
  - 英文（en）：`source.generations: 'Generations'`

### 2.2 二级过滤胶囊导航（GenerationsCategoryNav）
当选中「生成的」标签页时，在顶栏搜索框下方渲染专属分类胶囊行：
1. **来源分类（Source Filter）**：
   - 全部（All）
   - 智能体对话（Agent / Chat）
   - 图像生成（Image）
   - 创作画布（Canvas）
2. **类型分类（Type Filter）**：
   - 全部（All）
   - 图片（Image）
   - 视频（Video）
   - 音频（Audio）
3. 统计计数：胶囊内实时展示对应条件下的素材条数。

### 2.3 生成素材卡片展示与网格流
- **网格规范**：复用既有的自适应列数（2~5 列）与原始比例无黑边瀑布流网格（`masonry-grid` / `AssetGrid`）。
- **卡片内容**：
  - 封面：图片显示原图，视频显示首帧/视频预览；
  - 来源标识：右上角角标清晰指示来源（「智能体」/「生图」/「画布」）；
  - 标题与时间：生成提示词摘要作为标题，副标题显示相对生成时间（如“10分钟前”）；
  - 悬停快捷工具：点击全屏预览、一键复制素材引用句、一键加入对话。

### 2.4 空状态与检索
- 当尚未产生生成素材时，展示友好空状态图文与引导动作（如“去生成素材”直接唤起智能体或生图）。
- 搜索框支持根据标题、提示词、模型名进行即时过滤。

## 3. 验收标准与验证方案
1. **单测覆盖**：
   - 新增 `GenerationsView.test.js`，断言顶栏 Tab 切换、二级分类切换、条目计数与搜索过滤逻辑。
   - `AssetsStage.test.js` 包含对 `generations` Tab 的切换渲染与吸附栏高度校验。
2. **静态门禁**：
   - UI01~10 规范静态检查 0 违规；
   - 杜绝硬编码裸色与反引号 CSS 破坏。
3. **真实浏览器验证**：
   - 页面成功加载「生成的」标签页；
   - 点击可流畅切换视图，二级胶囊行与搜索栏正常工作；
   - 瀑布流卡片自适应呈现，大图预览弹窗正常唤起。
