# 规格：移除音频卡片操作文本提示元素 (Issue #3081)

## 1. 目标（Objective）
用户在画布音频卡片上点击下载（保存）或外部打开/定位文件按钮后，卡片底部控制栏会触发并渲染内联文本提示（例如「仅支持 HTTPS 或已识别的同源媒体」、「已请求系统打开项目副本」），这些文本占据并撑大了右侧动作区的宽度，破坏了三段式 Flex 布局，导致居中的核心播放按钮向左挤压移位甚至与图标重叠。
本任务目标是彻底移除音频卡片底部控制栏的内联文本提示元素，恢复纯图标三段式对称稳定布局。

## 2. 变更范围（Scope）
- `plugins/omnimux-workflow/src/canvas/editor/components/MaterialNode/AudioPreview.tsx`:
  - 移除 `wf-audio__status` 内部渲染的 `<span>{statusText}</span>` 内联文本提示元素。
  - 保留纯图标按钮交互，确保控制栏几何结构稳定不抖动。
  - 保留必要重试按钮（若波形渲染失败），但不再渲染挤占空间的行内文本。

## 3. 验收标准（Acceptance Criteria）
1. 音频卡片底部控制栏结构恒定：无论用户是否点击下载、打开或定位，控制栏都不会出现文本提示撑大布局，播放按钮始终保持居中。
2. 单元测试与相关门禁全绿通过。
3. Dev App 实机验证：点击下载或打开按钮后，截图确认按钮位置正常，无文字遮挡与重叠。
