# 规格：垫图（multi_reference）剩余模型闭环验证

## 背景

`#3148` 已闭环 Seedream 5.0 Pro（文生图 + 垫图，PR #3149 已合入主干）。本次任务处理垫图线上仍未上架的模型，逐条给出真实状态。

## 目标（可测）

对下列每个模型，给出唯一终态之一，且终态必须有可复核证据：

| 模型 | 期望终态 |
| --- | --- |
| nano-banana-2 | 上架（研究状态已验证 + 上架判定为真 + 画布白名单可见） |
| nano-banana-pro | 上架 或 阻塞（附上游不可读证据） |
| mj-v7 | 上架 或 阻塞（附上游不可读证据） |
| mj-v8-1 | 上架 或 阻塞（附上游不可读证据） |
| gpt-image-2.5-hd | 阻塞（上游能力合同 404，无契约依据） |
| grok-imagine-image-2-0 | 阻塞（同上） |
| grok-imagine-image-quality | 阻塞（同上） |

## 用户操作旅程

1. 用户在创作画布打开图片生成节点。
2. 模型下拉中能看到已上架的垫图模型。
3. 用户选该模型 + 上传 1 张以上参考图 + 输入提示词 → 提交 → 画布返回可播放、可下载的成图。

## 验收标准

- **A1 契约存在**：上游能力合同接口对该模型返回 200，且能力清单含图生图。
- **A2 真机最小生成**：经本仓真实缝隙执行一次垫图（实跑模式），拿到可读任务号与产物地址，产物落盘并记录字节数与尺寸。
- **A3 上架一致性**：该模型在规格中研究状态为已验证（绑定证据文件路径）、实现状态为就绪，且上架判定为真。
- **A4 画布可见**：画布图片白名单含该模型；跨插件对齐与自动调度两个门禁退出码为 0。
- **A5 门禁全绿**：严格契约门禁与目录回归全通过。
- **B1 阻塞留痕**：无法上架的模型，必须在 `docs/evidence/` 留下原始响应证据（状态码与响应体），并在 issue 中记录原因。

## 禁止事项

- 仅凭「命令可发现、接口存活、静态模拟」判定成功。
- 未取到产物就宣称上架。
- 把上游不可读当作本仓缺陷去改网关代码（属另一仓库，需授权）。

## 收尾核验

以本仓既有门禁脚本为准：严格契约门禁、目录回归、跨插件对齐、自动调度四项退出码为 0。
