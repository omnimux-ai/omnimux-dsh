# 助手回复多素材卡片 · 画廊结构化重构规格

## 1. 问题与目标

### 1.1 现状与缺陷
在对话回复中，当助手产出多个素材（如从视频拆解或关键帧抽取中得到 3 张及以上多表情图像或视频）时，`assistantMessageMediaEnhancer.ts` 采用横排平铺模式（`.omx-chat-media-tail__grid`，即三联平铺）。

| 现状缺陷 | 业务影响 |
| --- | --- |
| 盲目横排等分平铺 | 素材一旦达到 3 张及以上，卡片被过度挤压成极窄条，严重破坏对话气泡布局与纵深美感 |
| 无法细看焦点素材 | 所有素材尺寸均等且偏小，用户无法放大核验面部表情、构图与画质等关键细节 |
| 视频无法交互预览 | 视频只能作为静止小缩略图挤在格子里，无法就地播放预览 |
| 缺少结构化筛选流 | 无法直观感知“当前第几张、共几张”，无法在对话内进行主次点选切换 |

### 1.2 改造目标
将平铺式卡片结构化重构为轻量微画廊模式（1 主视图 + 右侧 N 缩图筛选）：
1. **左侧主舞台**：完整聚焦呈现当前选中的高清图像或视频，受限最大高度，保证阅读节奏；
2. **右侧缩图栏**：高度与主舞台等高对齐，超出高度后栏内纵向平滑滚动，两端具备渐隐遮罩；
3. **响应式与多态**：单素材自动简化为主视图，多素材自动展开画廊；
4. **统一设计语言**：100% 消费官方原生 `--dsw-alias-*` 色彩矩阵与圆角规范，支持深浅主题无缝切换。

## 2. 交互与布局设计

### 2.1 排布架构（左大右小）

```
┌──────────────────────────────────────┬────────────┐
│                               [2/6]  │ ┌────────┐ │
│                                      │ │  缩图 1 │ │
│                                      │ └────────┘ │
│            左侧核心主舞台              │ ┌────────┐ │  ← 右侧缩图导航栏
│        （高清图片 / 视频播控）          │ │▶ 缩图 2 │ │    等高对齐、超出竖滚
│                                      │ └────────┘ │    两端渐隐提示
│                                      │ ┌────────┐ │
│                                      │ │  缩图 3 │ │
│                                      │ └────────┘ │
└──────────────────────────────────────┴────────────┘
```

- **容器几何**：
  - 容器最大高度限制：`max-height: min(480px, 55vh)`，避免在长文本中撑爆纵向视口；
  - 缩图栏固定宽度：`96px ~ 104px`，弹性收缩；
  - 缩图长宽比：`4:3`，圆角 `8px`，激活项带高对比度品牌外发光高亮（`--dsw-alias-brand-primary`）；
- **数量自适应多态**：
  - 单素材（`length === 1`）：仅渲染主卡片，隐藏缩图栏与计数角标；
  - 多素材（`length >= 2`）：激活左主右辅画廊排布。

### 2.2 交互行为规则
1. **点选切换**：点击右侧任意缩略图，立即将对应素材置入主舞台，缩图栏调用滚动确保当前项处于可视区；
2. **键盘控制**：聚焦画廊容器时，响应 `ArrowLeft` 与 `ArrowRight`（或 `ArrowUp` / `ArrowDown`）循环切换前后素材；
3. **视频多态与互斥**：
   - 缩图如果是视频，右下角展示时长角标（格式 `mm:ss`）；
   - 主视图如果是视频，提供居中轻量播放/暂停控制与底部进度条；
   - 切换选中素材时，若前一素材为视频，立即重置并暂停播放，防止并发发声。
4. **工作台衔接**：主视图保留悬浮“图像生成”胶囊按钮，点击直接激活右侧全功能媒体工作台。

## 3. 验收标准（Acceptance Criteria）

- **AC-1（单素材多态）**：传入单张素材时，仅渲染主视图卡片，不生成缩图栏与总数计数器。
- **AC-2（多素材画廊结构）**：传入 2 个及以上素材时，DOM 结构包含主舞台容器与右侧缩图容器。
- **AC-3（状态与计数显示）**：主舞台右上角显示形如 `1 / 4` 的当前索引与总数文本。
- **AC-4（缩图点选联动）**：点击索引为 `k` 的缩图，主舞台更新为对应素材，该缩图标记为激活态。
- **AC-5（等高约束与溢出滚动）**：右侧缩图栏与主舞台高度等高，缩图总高超出时缩图栏内纵向滚动（`overflow-y: auto`），页面不产生意外滚动。
- **AC-6（滚动端点渐隐提示）**：缩图栏有可滚动内容时，通过渐变遮罩提示“上方/下方还有更多”。
- **AC-7（视频素材支持与互斥）**：视频素材在缩图显示时长标签，主视图支持播放状态切换，切换素材时原播放状态自动清除。
- **AC-8（键盘无障碍导航）**：支持使用键盘方向键顺序切换选中的素材。
- **AC-9（设计规范与令牌遵循）**：所有背景色、文字颜色、边框、描边均采用 `--dsw-alias-*` 变量，无硬编码非规范颜色。
