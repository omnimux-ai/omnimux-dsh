# Spec · 彻底移除点击使用 Skill 后的遮挡提示弹窗 (Toast)

## 1. 业务背景与用户明确指示
用户截取了点击技能后弹出的深色居中提示框（“✔ 已激活技能【电影级视觉大片】并预填引导话术”），并明确指示：“使用 skill 后这个提示 移除”。
当用户在首页技能库点击「使用」按钮后，输入框已经直接预填了 `/<skill-slug> ` 指令并已高亮聚焦，用户可以直接看到输入框内容。此时界面中间再弹出一个巨大的 Toast 气泡，不仅多余，而且遮挡视线、打断操作心流。

## 2. 解决方案
1. **移除多余 Toast 弹窗调用**：
   - 在 `SessionGuide.jsx` 的 `handleExploreSkillApply(payload)` 中，删除 `showToast(`已激活技能【${skillTitle}】并预填引导话术`)` 调用；
2. **保持输入框顺畅静默预填与聚焦**：
   - 保持 `applyDraftToComposer` 的指令预填、光标聚焦与呼吸效果，零弹窗干扰，体验丝滑自然。

## 3. 验收标准
- **AC-1 彻底移除使用技能提示**：点击技能卡片上的使用按钮后，界面绝不弹出「已激活技能...」的 Toast 提示；
- **AC-2 输入框预填不受任何影响**：输入框依然正常预填 `/<slug> ` 指令草稿并保持自动聚焦；
- **AC-3 全套测试通过**。
