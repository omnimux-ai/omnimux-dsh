# 表单下拉菜单防透视穿透与商品主图复合控件升级 · 规格说明书（Issue #2622）

## 1. 背景与缺陷分析
1. **下拉菜单透视穿透（图 1）**：
   - 工作区应用标签页（`AppTab.jsx`）中点开「解说人声音色」等下拉菜单时，浮层背景变量未正确绑定不透明实体背景，导致深色主题下浮层呈半透明/完全透明状态，下方的「视频成片比例」文字和 `9:16` 按钮完全透射出来，产生严重的文字重叠。
2. **商品类主图输入粗糙且占位过大（图 2）**：
   - 现有电商类应用在「商品主图 / 白底图」字段上渲染为占位巨大的大虚线框（`media-uploader`），不仅占用大量垂直空间，而且无法直接输入商品链接，更未打通用户现有的「商品库」，造成操作割裂。

## 2. 改进目标与详细规范
### 2.1 修复下拉菜单透视穿透
- `plugins/omnimux-workflow/src/client/styles.js` 中 `.omx-apptab-select-options`：
  - 强制使用设计规范的不透明浮层背景：`background-color: var(--dsw-alias-bg-elevated, #1c1c1f) !important;`；
  - 提升浮层层叠权重至 `z-index: 100`，下拉框展开时其父容器声明 `z-index: 50`；
  - 确保下拉菜单展开时 100% 遮蔽下方表单元素，彻底杜绝任何透视重叠。

### 2.2 升级商品主图为「商品链接 + 商品库选择 + 本地上传」紧凑型三合一复合控件
- 将商品主图输入区域从原有的大虚线框重构为 **40px 标准紧凑单行条**：
  - **核心输入框**：支持直接粘贴电商商品链接（回车或失焦自动解析并锁定为商品卡片）；
  - **右侧功能按钮 1**：【从商品库选择】（`IconStore` 图标），点击打开商品库弹窗，一键挑选已有商品并回填缩略图与标题；
  - **右侧功能按钮 2**：【本地上传】（`IconUpload` 图标），点击唤起本地文件选择器选择商品白底图，同时输入条依然支持拖拽直接投递图片；
  - **回填状态统一**：无论来自链接、商品库还是本地上传，确认后均渲染为统一的高质感卡片（缩略图 + 标题 + 来源标签 + 一键移除「×」按钮），清空后无缝恢复为 40px 单行输入条。
- **经典旧应用预设翻新**：
  - 更新 `plugins/omnimux-apps/catalog/builtin-apps.json` 与 `src/shared/builtinCatalogData.ts`：将 7 款经典旧预设应用（`app-creatify-*`）的 `product_image` 字段配置绑定为该复合控件类型，确保「巨型商品撞屏与荒诞追逐」等经典工程打开即享紧凑清爽的三合一体验。

## 3. 验收标准
1. 音色下拉菜单展开时，完全遮盖下方比例文字与卡片，背景 100% 不透明，文字清晰可读；
2. 商品主图呈现为 40px 紧凑单行复合输入框，带商品库与上传双按钮，支持粘贴链接、选库与传图；
3. `omnimux-workflow` 与 `omnimux-apps` 全部自动化测试保持 100% 全绿；
4. 通过两轮开源代码审查与真实浏览器验收，0 门禁违规。
