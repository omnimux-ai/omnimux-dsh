# 画布模型级联面板悬停抖动修复规格（Model Cascade Menu Hover Jitter Fix Spec）

## 1. 业务痛点与现场分析
在创作画布中，用户点击底部操作栏的模型选择胶囊时，会弹出一个多列级联选择菜单（包含品牌列、型号列和渠道策略列）。
用户反馈：
**「在画布的模型选择面板中当鼠标悬停在一级菜单上 会出现持续的抖动 修复下」**

### 1.1 根因分析
1. **各列高度不一致**：
   - 第一列（品牌列）和第二列（型号列）的样式固定为 `height: 360px`；
   - 第三列（渠道策略列）由于包含策略切换卡、多个渠道选项及底部操作栏，实际展开高度约为 `486px`（样式上限 `max-height: 520px`）；
   - 三列之间的高度落差达到 `126px`。
2. **底端定位与顶端对齐的几何矛盾**：
   - 浮层容器整体采用底部定位（`bottom` 紧贴胶囊栏上方），而容器内部各列采用顶端平齐对齐（`align-items: flex-start`）；
   - 根据交互约定，鼠标悬停在非当前选中品牌（如 Wan）时，第三列会被收起；
   - 第三列一旦收起，整个浮层容器的高度瞬间从 `486px` 跌落至 `360px`；
   - 在底端锚点不变的情况下，容器顶部连同第一列整体向下骤降 `126px`；
   - 导致用户原本停留在该品牌上的鼠标光标瞬间滑出目标项，触发状态重置并重新展开第三列，整个面板又被向上顶起 `126px`；
   - 鼠标重新撞上目标项，再次触发收起与下坠，形成一秒几十次的持续剧烈抽搐抖动。

## 2. 改造与修复方案
1. **三列高度统一为 480px 黄金尺寸**：
   - 将第一列（品牌列）、第二列（型号列）和第三列（渠道列）的外框高度统一锁定为 `480px`；
   - 第三列的 5 个渠道项、策略卡及底部全选栏正好自然呈现在 480px 面板内，无任何截断；
   - 第一列与第二列在高度统一后，无论第三列展开还是收起，容器与各列的高度始终完全恒定。
2. **位置绝对锁定与防溢出保护**：
   - 由于各列高度与容器高度始终保持 480px 恒定，悬停切换二级或三级时，第一列在屏幕上的物理坐标绝对静止，彻底粉碎导致抖动的几何振荡闭环；
   - 在屏幕较矮的视口场景下，增加顶部安全间距限制，确保浮层顶端不会溢出视口外部。
3. **视觉与交互规范完备**：
   - 保持顶端平齐、底端平齐的严整极简布局；
   - 品牌悬停预览、型号悬停展开、点击确认选择与渠道策略勾选等交互契约保持 100% 完好。

## 3. 验收标准（Acceptance Criteria）
- **AC-1（悬停静止无抖动）**：鼠标在第一列任意品牌项（无论是当前选中还是非选中品牌）之间悬停或划过时，一级菜单与二级菜单在屏幕上的位置完全静止，彻底杜绝任何上下跳动或高频抖动。
- **AC-2（高度与对齐规范）**：级联菜单展开后，品牌列、型号列与渠道列在高度上保持统一，顶端与底端自然平齐，排版整洁紧凑。
- **AC-3（功能交互完整）**：所有模型的品牌切换、型号选择、策略单选与渠道多选功能完全正常。
- **AC-4（测试 100% 通过）**：工作流自动化测试全量通过，无任何回归缺陷。
