# 全局各插件双层 Tab 上下间距呼吸规范与收敛规格

## 1. 背景与业务痛点
业务负责人在开发版实测中指出：
- 在「技能/专家」等页面中，第一层 Tab（`Skill`、`我的 Skill`、`专家市场` 下划线）与第二层分类药丸胶囊（`全部`、`选品`、`创作视频`）之间的纵向上下间距过小（实测仅 2px），贴脸挤压感严重。
- 要求排查全库所有存在双层 Tab/标签栏的插件，彻底收敛上下垂直间距至统一标准舒适区间（14px ~ 16px）。

## 2. 全库排查与根因收敛

### 2.1 技能市场 (omnimux-market)
- **根因**：`.nav-bar` 声明了 `margin-bottom: 0`，导致紧随其后的 `.category-bar` 顶部与第一层下划线净距仅有 2px。
- **收敛规则**：将 `.nav-bar` 的底部外边距更新为 `margin-bottom: 14px`，使第一层导航下划线指示器到底部第二层胶囊顶部保持 **14px ~ 16px 标准呼吸间距**。

### 2.2 资产库 (omnimux-assets)
- **基线**：`.omnimux-assets-local-nav` 的顶部外间距为 `12px`，实测下划线到底部胶囊净距 14px，符合规范。

### 2.3 数据分析看板 (omnimux-analytics)
- **基线**：`omnimux-analytics-stage-action-row` 的底部留白为 `padding-bottom: 12px`，与下方过滤栏保持自然呼吸衔接。

## 3. 验收标准
- **AC-1**：技能市场页面中，第一层 Tab 下划线底部与第二层分类胶囊顶部之间的纵向净空在 14px ~ 16px 之间（实测 16px），彻底消除 2px 贴脸挤压感。
- **AC-2**：全库所有带双层 Tab 的插件均符合 14px 呼吸间距规范，全量静态门禁与自动化测试全绿通过。
