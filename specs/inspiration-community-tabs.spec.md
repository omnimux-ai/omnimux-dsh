# 规格：灵感社区栏目改为爆款趋势、灵感库、账号监控

Issue #2546。只改灵感社区顶部三个栏目的名称、顺序和默认打开项。

## 新用户基线

云端灵感需要登录。未登录时，「爆款趋势」仍走现有登录提示，不拿本地内容填进去。本地灵感库可以为空，空时仍显示现有空态。

## 用户看到什么

1. 打开灵感社区，顶部只有三项，从左到右是：爆款趋势、灵感库、账号监控。
2. 默认停在「爆款趋势」，列表只显示原来的云端内容。
3. 「灵感库」只显示原来的本地内容。
4. 「账号监控」内容和操作不变。
5. 顶部不再出现「全部」「本地」「云端」。
6. 在「灵感库」或「账号监控」导入一条内容后，仍落到「灵感库」，方便马上看到刚导入的内容。

## 验收

- 初次打开时，「爆款趋势」处于选中状态。
- 三个栏目的文字和顺序与上面一致。
- 切换后各自内容不串：云端不进灵感库，本地不进爆款趋势。

## 边界

- 总是做：改栏目名称、顺序、默认项，以及导入后的落点。
- 先问：把「全部」加回来，或改账号监控里的筛选。
- 绝不做：改选择弹窗里的「全部 / 本地 / 云端」，改导入接口，改卡片比例。
