# Spec · 首页卡片画幅调优：锁定 Skills 技能库为横版卡片，其余所有模板与短视频应用卡片调整为竖版

## 1. 业务背景与问题分析
用户明确提供实机界面截图并提出明确要求：
> “除了 skill 是横版卡片 其他卡片都是竖版 调整下”

### 现状痛点：
1. **短视频素材与横版画幅冲突**：
   - 「王牌短视频应用」、「软件应用与 SaaS」以及其余创意模板（如 TikTok 热门、黄金开场、真实种草、视效大片等）的底层素材和封面图均采用标准 9:16（1080x1920 或 450x800 / 358x640）竖版短视频画幅；
   - 现行样式中将 `.omnimux-tpl-card` 统一设定为 `aspect-ratio: 16 / 10` 横版，导致封面图片通过 `object-fit: cover` 渲染时，上下大半部分画面被严重裁切，关键信息（如操作手势、电脑屏幕、人像头部）残缺不全。
2. **Skills 技能库横版视觉需求**：
   - 「Skills 技能库」卡片展示的是抽象的 AI 技能（如“UGC 告白”、“电影级视觉大片”），采用极光流光色彩与点阵质感，居中加粗大标题与认证对勾，横版 16:10 构图非常协调大气，用户明确要求继续保持横版。

## 2. 改造方案与技术实现
1. **卡片画幅差异化定位**：
   - **技能库卡片（`.omnimux-tpl-card.is-skill-card`）**：
     - 保持 `aspect-ratio: 16 / 10` 黄金横版比例；
     - 在横向滚动轨道中保持基准宽度 `flex: 0 0 240px`；
     - 维持圆角 `border-radius: 14px` 与动态极光流光质感。
   - **其他所有卡片（`.omnimux-tpl-card:not(.is-skill-card)` / 默认 `.omnimux-tpl-card`）**：
     - 调整为 `aspect-ratio: 9 / 16` 标准短视频竖版黄金画幅；
     - 在横向滚动轨道中基准宽度设为 `flex: 0 0 170px`，高度约为 302px，与短视频信息流视觉体量完美协调；
     - 底部渐变遮罩、标题文本与悬停操作按键在 170px 竖版宽度下对齐排版，文字优雅支持双行省略，悬停按键精致完整。
2. **全量网格视图（`TemplatesGridView`）自适应**：
   - 在全量网格视图中，默认模板网格列宽采用 `minmax(170px, 1fr)`，自适应填满屏幕形成高质量短视频海报流；
   - 当分类为 `skills` 时，网格列宽保持 `minmax(240px, 1fr)`，横版整齐展示。
3. **测试套件与自动化验证同步更新**：
   - 更新 `plugins/omnimux/src/client/session-guide/templates/card-horizontal-hover-fix.test.js` 与 `plugins/omnimux/tests/e2e/card-horizontal-hover.e2e.test.mjs`，确保全面覆盖：
     - 验证技能卡片保持 `16:10` 横版与 `240px` 宽度；
     - 验证普通短视频与应用卡片升级为 `9:16` 竖版与 `170px` 宽度；
     - 验证货架轨道与悬停交互正常。

## 3. 验收标准 (AC)
- **AC-1 技能卡片保持横版**：
  - 「Skills 技能库」货架及相关技能卡片必须保持 16:10 横版比例与 240px 宽度。
- **AC-2 其他卡片均为竖版**：
  - 「王牌短视频应用」、「软件应用与 SaaS」以及其余所有创意模板卡片必须呈现 9:16 竖版画幅，基准宽度为 170px。
- **AC-3 封面与文字完整无截断**：
  - 竖版卡片中 9:16 短视频封面图片完整展现，不再被硬性上下裁切，底部渐变与两行文字清晰可见，悬停操作按钮功能完备。
- **AC-4 全量测试通过**：
  - 相关单元测试与自动化验证全部通过，零回归问题。
