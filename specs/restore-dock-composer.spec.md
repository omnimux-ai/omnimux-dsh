# 恢复使用技能与复刻按钮触发输入框吸底联动规范 (Restore Dock Composer Spec)

## 一、需求背景与目标
- **业务诉求**：用户反馈在首页点击使用技能或复刻按钮时，原本存在的“将顶部输入框显示到页面底部”的吸底联动机制缺失了，需要彻底查清原因并完整恢复该机制及其全套交互逻辑。
- **根因分析**：
  1. 早期版本中，输入框吸底控制器（Docking Controller）直接硬编码在 `TrendingReplicateSection` 内部；
  2. 首页重构成探索模板货架专区（`ExploreTemplatesSection`）后，`TrendingReplicateSection` 被收纳隐藏；
  3. 卡片点击仅调用 `applyDraftToComposer` 写入草稿与聚焦，未触发 `data-omnimux-dock-open` 与几何测量动画，导致输入框一直滞留在页面最顶部，下方操作与输入视线割裂。
- **改造目标**：
  将输入框吸底机制提升为首页引导层级（`SessionGuide`）的一等公民交互能力，抽离通用的吸底联动机制，支持 Skills 技能卡片「使用」、模板卡片「复刻」、TikTok 热门卡片「复刻」等全场景统一触发，并完整恢复平滑过渡、收起归还、滚动迟滞等全部交互逻辑。

## 二、关键交互与视觉契约
1. **吸底停靠与 FLIP 动画**：
   - 触发条件：点击技能卡片上的「使用」按钮，或点击模板/热门视频卡片上的「复刻」按钮；
   - 宿主标记：为 `[data-omnimux-starter-host]` 打上 `data-omnimux-dock-open` 属性；
   - 占位防塌：顶部输入框所在的原槽位（`band`）记录当前真实高度并写回 `minHeight`，防止脱离流后下方内容突兀上移；
   - 几何适配：实时计算并注入 `--omnimux-dock-left`、`--omnimux-dock-width`、`--omnimux-dock-bottom`、`--omnimux-dock-card-height`；
   - 平滑位移：变更瞬间计算首尾视口绝对坐标，执行 380ms 缓动过渡（FLIP 动画）；
   - 聚焦防跳：`focusEditor()` 必须带 `{ preventScroll: true }`，禁止原生聚焦触发浏览器强制滚顶。
2. **收起/归还按钮（Undock Button）**：
   - 吸底状态下，在停靠输入框的右上方悬浮渲染收起气泡按钮（`.omnimux-trending-undock`）；
   - 带有向下/向上指引图标及「收起」文案；
   - 用户点击后立即平滑解除吸底，输入框平稳恢复至顶部流内原位。
3. **滚动迟滞判定（Scroll Hysteresis）**：
   - 监听宿主 `scrollBody` 与外部滚动容器；
   - 离开顶部（`scrollTop > 20px`）并触发动作后，输入框保持吸底；
   - 用户主动向上滑动、真正回到页面最顶部（`scrollTop <= 10px` 且此前已滑离顶部）时，输入框平滑自动解除吸底切回顶部 inline 原位；
   - 用户再次向下滑离顶部时，输入框再次自动吸底停靠。
4. **反悔与注销清理**：
   - 再次点击当前已处于激活状态的同一张卡片，取消选中并解除吸底；
   - 切换会话或组件卸载时，严格移除 `data-omnimux-dock-open` 属性、清理所有 CSS 变量、清理 `minHeight` 占位和过渡样式，杜绝内存泄漏与视觉残留。

## 三、验收标准
1. 点击 Skills 技能卡片「使用」后，输入框立即从顶部吸底到视口底部，右上角出现「收起」按钮；
2. 点击「收起」按钮后，输入框解除吸底并平滑回到顶部原位；
3. 吸底状态下，向上滑回页面顶部（`scrollTop <= 10px`），输入框自动解除吸底回到原位；向下滑动又自动吸底；
4. 点击模板卡片「复刻」同样具备上述完整的吸底与归还能力；
5. 所有单元测试、组件契约测试与端到端回归测试 100% 通过。
