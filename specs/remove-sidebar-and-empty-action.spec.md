# 规格文档：移除产品库空状态冗余操作按钮与侧边栏产品库独立入口

**文件：** `specs/remove-sidebar-and-empty-action.spec.md` ｜ **优先级：** P0 ｜ **模块：** `plugins/omnimux-assets` + `plugins/omnimux-products`
**变更面：** Client / Stage / 侧边栏导航 / 页面空状态
**设计依据：** 用户明确要求（移除空状态中的添加产品按钮及其展开菜单、移除左侧侧边栏的产品库入口）、[first-level-page-layout.md](../docs/contracts/first-level-page-layout.md)

---

## 1. 业务目标与改造方案

### 1.1 背景与需求定义
- **问题 1：空状态按钮冗余与菜单遮挡**：
  - 在资产库顶部的动作行中已经明确具备一级主操作 `[ + 添加产品 ⌄ ]`；
  - 空状态大卡片内部再次渲染了带下拉箭头的按钮及其展开的浮动菜单（`实物产品` / `数字产品`），造成视界遮挡与重复入口。
  - **解法**：彻底移除空状态内部的操作按钮及下拉菜单，空状态只保留纯净的提示文案 `暂无产品数据。点击上方「添加产品」录入首件标品。`，主操作入口完全收敛至顶部动作行。
- **问题 2：侧边栏产品库入口冗余**：
  - 产品库已经作为一级选项卡无缝整合入「资产库」；
  - 左侧边栏如果继续保留独立的「产品库」导航项，会导致入口重复、功能重叠。
  - **解法**：在 `omnimux-products` 客户端入口中停止挂载侧边栏入口（移除 `mountSidebarEntry`），左侧侧边栏导航列表中不再显示「产品库」项目；保留产品库底座能力与工作台 Tab 注册机制，支撑从资产库中无缝唤起产品二级页。

---

## 2. 验收标准（Acceptance Criteria）

### 2.1 空状态容器纯净化 (P0)
- **AC-101**：在「产品库」选项卡下，空状态卡片内部不再渲染任何按钮或展开的下拉浮动菜单。
- **AC-102**：空状态提示文案更新为：`暂无产品数据。点击上方「添加产品」录入首件标品。`，引导用户聚焦顶部操作栏。

### 2.2 侧边栏产品库入口移除 (P0)
- **AC-201**：`omnimux-products` 客户端生命周期中停止注册侧边栏导航项，应用左侧侧边栏彻底移除「产品库」入口。
- **AC-202**：工作台 Tab 注册保持正常，从资产库点击添加产品仍可正常唤起。
- **AC-203**：相关单元测试与端到端回归测试 100% 通过。
