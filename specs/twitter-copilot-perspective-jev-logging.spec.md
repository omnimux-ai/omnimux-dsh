# 规格：推特助手候选池评分、Jev 视角决策、去 AI 味规则与生成日志（#3100）

## 1. 背景
- 发帖框为空时只固定取信息流前 3 条，无评分、无关键词适配。
- 文案无鲜明视角，AI 腔重（大词套话、假升华、机械排比）。
- 生成过程无可追溯记录，无法复盘与调优。

## 2. 新用户基线
- 依赖：出厂浏览器扩展 + 出厂 `omnimux-browser` 插件 + 执行中枢（`textComplete`、`decisions` 席位）+ `$DSH_HOME`。
- 未登录 / 未配置 Jev：视角改由本地规则决定，日志标 `source:"rules"` 与原因；文案生成走原有补全通道，失败时提示「模型服务暂未响应」。
- 日志写入失败（服务未连通）：仅保留扩展本地缓存，条目标 `persisted:false`；不影响生成。

## 3. 行为规格

### 3.1 候选池与评分（发新帖、发帖框为空）
- 自上而下扫描页面已渲染的推文，最多 50 条；跳过广告/推广、正文 < 25 字、发帖框所在推文。
- 不自动滚动页面；可见不足 20 条时按实际数量处理，日志如实记录 `candidatesScanned`。
- 四维得分（0–100），总分 = 0.30×关键词 + 0.30×争议度 + 0.20×信息密度 + 0.20×爆发力：
  - 关键词：命中关键词数 / 关键词数；无关键词时 50（中性）。
  - 争议度：回复数相对转发数的比值（含平滑），封顶 100。
  - 信息密度：数字、英文专有名词、正文长度。
  - 爆发力：(回复+转发+点赞) / 存活小时数，对数映射。
- 总分 ≥ 75 的入选，按总分降序最多 3 条；无达标则走「纯原创」（`inputMode: PURE_ORIGINAL`），不硬塞灵感。

### 3.2 六大视角
| ID | 名称 | 写作指令要点 |
| --- | --- | --- |
| P1_CONTRARIAN | 反常识批判者 | 首句给出反直觉判断，挑战主流共识，结尾抛出站队式反问 |
| P2_PRACTITIONER | 一线实战老兵 | 只用素材里出现的场景与数字，写「原以为 A，实际是 B」的落差 |
| P3_SIMPLIFIER | 降维普及者 | 不用黑话，用一个生活类比讲清本质，说明和普通人的关系 |
| P4_ARBITRAGEUR | 商业套利猎手 | 从成本、时间、回报算账，点出确定收益或亏损陷阱 |
| P5_OBSERVER | 冷眼趋势观察家 | 跳出单品争论，讲二阶影响：谁受益、谁被替代 |
| P6_PEER | 真实同壕战友 | 平视同路人口吻，说出普遍的困境与真实感受，克制收尾 |

### 3.3 视角决策
- 首选 Jev：桥方法 `bridge.evaluateDecision`（服务端经 `ctx.get('decisions').evaluate`），3 秒预算。
- Jev 不可用、超时、返回不在候选内 → 本地规则：争议 → 工程数字 → 新名词 → 商业词 → 格局词 → 情绪词，均不命中默认 P2。
- 视角只作用于「发新帖」「引用转发」；回复类场景不注入视角。

### 3.4 去 AI 味规则
- 全部菜单项的系统提示词使用统一的「去 AI 味母语编辑」规则段（中/英两版），替换原严格规则段，保留零前言、单条、字数铁律（中文 45–85 字，英文 ≤ 220 字符）。
- 生成后扫描禁用表达（深入探讨、至关重要、赋能、闭环、底层逻辑、不仅是…更是、标志着…新篇章、让我们拭目以待、未来可期 等）；命中则带违规清单重试 1 次，仍命中照常回填并写入日志。

### 3.5 新菜单项
- 「多视角爆款创作」（`ai-perspective-post`），场景：发新帖、引用转发。

### 3.6 生成日志
- 文件：`$DSH_HOME/omnimux-browser/twitter-copilot.ndjson`（经 `dshHomePath`），每行一条。
- 扩展缓存：`chrome.storage.local['omnimux_twitter_copilot_log']`，环形保留 100 条。
- 字段白名单：`traceId, ts, scene, itemId, locale, inputMode, keywords, candidatesScanned, qualifiedCount, seeds[{author,textSnippet≤200,total,scores}], perspective{id,source,confidence?,latencyMs?,fallbackReason?}, generation{latencyMs,rawLength,finalLength,retried,humanizeViolations[]}, outcome{status,reason?}`。
- 不记录完整原推、草稿全文或任何凭据；单条 ≤ 16KB。
- 「用户最终是否发送」本期不采集。

### 3.7 设置
- 扩展设置页新增「推特赛道关键词」文本框，逗号分隔，存本地；提取器读取后与草稿合并使用。

## 4. 验收标准
- AC-1 候选过滤与评分：单测覆盖广告/短文过滤、四维边界、阈值截断、无达标走纯原创。
- AC-2 视角规则：12 条标注样例（每视角 2 条）全部判对；Jev 参数截断正确。
- AC-3 去 AI 味：所有菜单项提示词含统一规则段；违规扫描单测正确；提示词无 `undefined`。
- AC-4 桥方法：成功 / 参数非法 / 未授权 / 依赖缺失 均有用例；日志追加到 `dshHomePath` 下。
- AC-5 产品基线、模块边界、反兜底门禁通过。
- AC-6 真机（ego-browser，任务工作树构建产物）：空发帖框多视角生成回填并点亮发帖按钮；引用弹窗生成；详情页回帖菜单不回归；日志文件出现对应 traceId；全程不点击发送。

## 5. 非目标
- 不采集发送结果、不做数据看板、不自动滚动页面、不改执行中枢、不新增模型。
