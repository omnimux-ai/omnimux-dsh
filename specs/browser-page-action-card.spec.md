# 规格说明书：浏览器插件聊天面板页面操作卡片视觉规范优化（Issue #1778）

## 1. 业务背景与问题定义
在浏览器插件扩展的侧栏聊天面板中，AI 在执行页面操作（如读取页面、点击元素等工具调用）时，界面会渲染一行工具操作卡片（`ToolActivity`）。
当前存在以下显著视觉缺陷：
- **暗色模式断层**：`.tool-activity` 背景写死 `background: rgba(255, 255, 255, 0.7)`，在深黑背景上呈现出刺眼浅灰实心大色块，破坏沉浸感；
- **硬编码色彩违规**：边框写死 `#dfe5f5`，时间线竖线写死 `#d5ddfb`，未完全消费官方 `--dsw-alias-*` / CSS 变量体系，违背 `design.md` 规范；
- **排版生硬臃肿**：操作详情直接裸露英文代码字串，字体与排版层级未区分，完成状态字色弱化且对比度过低。

用户已明确拍板选择「方案 A：极简暗色沉浸卡片」。

## 2. 交互与视觉设计规格（对标 design.md）
### 2.1 容器与几何
- 边框与背景：
  - 暗色模式下：背景为深色微透底色（`var(--surface)` 或 `rgba(255, 255, 255, 0.04)`），边框为极细内描边 `var(--line)`（`rgba(255, 255, 255, 0.08)`）；
  - 亮色模式下：背景为 `var(--canvas-deep)`（`#f0f1f3`），边框为 `var(--line)`（`rgba(0, 0, 0, 0.08)`）；
  - 运行中状态（`.running`）：边框高亮 `var(--line-strong)`，背景微光提示；
  - 圆角：遵循 `design.md` 2.2 规范，卡片容器圆角统一为 `10px`。
- 时间线竖线（`.row.tool::before`）：
  - 背景统一消费 `var(--line)`，消除刺眼亮紫蓝色。

### 2.2 图标与排版层级
- 图标容器（`.tool-icon`）：
  - 尺寸统一为 `24px × 24px`，圆角 `6px`；
  - 容器背景采用微透弱底 `rgba(255, 255, 255, 0.06)`（亮色 `rgba(0, 0, 0, 0.05)`），图标文字采用 `var(--muted)`。
- 标题标签（`.tool-label`）：
  - 字号 `11px`，字重 `600`，字色采用 `var(--faint)`。
- 执行步骤与内容（`.tool-summary`）：
  - 字号 `12px`，字色 `var(--ink)`；
  - 采用清晰的层次结构，对 `→` 分隔的步骤提供视觉间隙与柔和微标签。
- 完成状态微标（`.tool-state`）：
  - 完成态展示柔和绿意徽标（包含微圆点与“已完成”文字，背景 `rgba(16, 185, 129, 0.1)`，文字 `#10b981`）；
  - 运行中状态展示细腻平滑的旋转微指示器。

## 3. 核心验收标准（Acceptance Criteria）
1. **暗黑与明亮模式无缝自适应**：完全通过 CSS 变量级联，无任何硬编码写死颜色。
2. **零硬伤视觉**：暗色模式下绝无任何刺眼实心浅灰大色块，卡片融入整体对话流。
3. **无障碍对比度（WCAG AA）**：文字在暗色与明亮模式下对比度均大于等于 4.5:1。
4. **测试全绿**：工程构建与相关插件测试通过。
