# OmniMux 全局重复 UI 组件样式收敛与归一化规格

## 1. 背景与业务目标

在 OmniMux 多个业务插件（资产库、产品库、技能市场、数据分析、创作画布等）的独立开发中，逐渐产生了重复实现、样式分歧及圆角混乱等视觉割裂问题。
依据业务负责人于 2026-09-15 确立的最终样式仲裁决议与微调指导指令，启动全局 UI 组件归一化改造，实现全库界面的极致极简、高质感与统一视觉体验。

## 2. 仲裁决议与核心规范定义

### 2.1 分类筛选胶囊 (Filter Pills)
- **形态与尺寸**：高度固定为 `28px`，圆角严格统一为 `999px`（全圆角胶囊），内边距 `0 14px`。
- **字阶与字重**：字号 `12px`，**激活态/选中态文字统一加粗（`font-weight: 600`）**，未选中态字重为 `500`。
- **色彩与反相**：选中态统一为纯白底色（`var(--dsw-alias-label-primary)`）反相黑字（`var(--dsw-alias-label-primary-foreground)`），消灭技能市场原有的 16px 方圆角与低对比暗灰底。

### 2.2 下拉选择器 (DropdownSelect)
- **黄金文案契约**：
  - 触发器默认全量态显示为纯实体名（如 `[ 平台 ▾ ]`、`[ 状态 ▾ ]`），严禁拼接定语为 `[ 全部平台 ▾ ]` 或 `[ 全部账号 ▾ ]`。
  - 下拉面板首项（重置项）名称唯一强制为 **`全部` (All)**。
- **视觉规格**：触发器高度统一为 `32px`，圆角 `8px`；浮层采用 `#1c1c1f` 毛玻璃暗黑面板（`backdrop-filter: blur(16px)`），圆角 `10px`。

### 2.3 统一圆角体系与搜索框
- **四层硬性圆角体系**：
  - 基础常规控件（按钮、输入框、下拉框）：严格统一为 **`8px`**；
  - 浮层面板、下拉菜单、卡片容器：统一为 **`10~12px`**；
  - 模态弹窗外壳（Modal Dialog）：统一为 **`16px`**；
  - 药丸型分类胶囊与底栏同类触发器：统一为 **`999px`**；
  - **严禁**出现 16px 方圆角、2px、6px 等非标杂质尺寸。
- **搜索输入框**：基准高度 `32px`，圆角 `8px`，左侧固定 14px 矢量放大镜图标，输入内容时右侧平滑显现清除叉号，焦点态带蓝色微光晕。

### 2.4 状态徽标与标签 (Badge)
- **视觉风格**：高度 `20px`（紧凑）或 `24px`，圆角 `4px` 或 `999px`。
- **色彩规范**：降低背景饱和度与明度，改用更加低调沉浸的低饱和暗色半透明底色（`rgba(..., 0.08~0.12)`），文字色保持清晰语义区分，避免高亮刺眼。

### 2.5 确认删除弹窗 (ConfirmRemoveDialog)
- **归一化**：彻底废除各业务插件内部自建的同名包装组件，直接消费共享 `ConfirmModal` 单例。
- **信息完整性**：弹窗提示文案必须动态呈现待删除对象的具体名称与受影响范围，防范误操作风险。

### 2.6 页面顶栏与分割线 (PageHeader)
- **分割线规约**：全页严格仅保留一条底部分割线，两侧必须保留严格 `20px` 对齐留白，杜绝分割线穿透整个视口边缘。

## 3. 验收标准 (Acceptance Criteria)

- **AC-1**：所有分类筛选胶囊均为 999px 全圆角，选中激活态下文字呈现 `font-weight: 600` 加粗，底色为高对比实心底反相字。
- **AC-2**：全库筛选下拉触发器默认文案为纯实体词（如「平台」），下拉第一项唯一展示为「全部」，无拼接语病。
- **AC-3**：常规操作按钮与搜索输入框的圆角 100% 收敛为 8px，基准高 32px，废除非标圆角。
- **AC-4**：状态徽标背景采用低饱和暗色半透明，无刺眼高饱和实心色块。
- **AC-5**：全库删除确认弹窗统一复用共享库规范，提示文案中包含目标对象名称。
- **AC-6**：全库自动化测试、静态设计门禁（UI01~UI10）全部通过，无回退。
