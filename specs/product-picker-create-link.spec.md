# 产品选择弹窗：链接创建产品

关联任务：#2328。交付边界：先演示，确认前不合入、不向共享开发环境物化。

## 目标与验收
在产品选择弹窗的卡片列表首位增加「创建产品」，不改变已有产品选择语义。

1. 打开产品选择弹窗，创建卡片在现有产品前显示；无产品或搜索无结果时仍可操作。
2. 点击创建卡片，进入链接输入弹窗；输入有效 HTTP(S) 商品链接并提交，展示解析中状态，禁止重复提交。
3. 复用 POST /omnimux/products/import-from-link 获取真实草稿，再通过 POST /omnimux/products 保存。解析成功不等于保存成功；只有保存成功才能宣告创建完成。
4. 保存成功关闭创建弹窗，回到产品选择弹窗，新产品可见并选中；必要时清除分类、标签和搜索过滤。不自动触发外层确认，用户仍点击「确认选择」。
5. 空链接、非法链接阻止提交。解析失败、保存失败均显示可理解错误、保留输入，不创建虚假产品；保存失败重试应避免不必要的重复解析。
6. 关闭/取消创建恢复产品选择，不意外关闭父层；过期异步返回不得覆盖后续新会话状态。若保存请求已经发出，不可虚假承诺已撤销服务端写入。
7. 保留原有筛选、搜索、选择、取消和确认功能；键盘焦点、关闭层级和小视口无溢出。

## 新用户基线
依赖已安装并启用的现有产品库和中枢解析能力，不依赖开发机模型别名、本地代理或私人目录。缺少产品服务、未配置可用解析能力、网络或目标站点阻断时清晰报错，不伪造成功或静默切换私人服务。

## 现有结构与复用边界
- 选择器：plugins/omnimux/src/client/components/product-picker/ProductPicker.jsx。
- 选择器翻译与过滤：同目录 picker-model.js。
- 现有产品路由：plugins/omnimux-products/src/http-routes.js。
- POST /omnimux/products/import-from-link 返回 { success: true, data }，只生成草稿。
- POST /omnimux/products 返回 { product, revision }，持久化产品。
- 通过已有公开 HTTP 路径协作，不导入产品插件私有模块；不新增爬虫、模型客户端、密钥存储或平行路由。
