# 规格说明 · 导入社媒灵感智能链接分析与导入按钮状态联动

## 1. 业务目标与背景
用户在「导入社媒灵感」弹窗中输入或粘贴社媒链接后，系统将对该链接进行异步格式识别与合规性分析。为防止用户在分析结果尚未确定前过早提交导致无效请求或异常，需建立前置状态门禁：
1. **输入即刻锁定**：只要输入框为空，或正在分析中，或分析未通过，「导入」按钮必须处于不可用（置灰禁用）状态。
2. **异步分析感知**：用户输入/修改链接后自动触发轻量防抖分析，回显“正在分析并校验链接，请稍候...”。
3. **校验通过放行**：只有当后台明确返回该链接为合法有效的内容（如合规视频或对标账号）时，「导入」按钮才切换为可点击状态。
4. **修改即刻重置**：用户只要更改链接内容，此前判定的结果立即作废，导入按钮重新锁定并重新触发分析。

## 2. 关键交互状态定义

| 状态标识 | 触发条件 | 回显区域提示 | 导入按钮状态 |
| :--- | :--- | :--- | :--- |
| **未输入** (`idle`) | 输入框为空或被清空 | 无回显或默认状态 | 置灰禁用 (`disabled=true`) |
| **分析中** (`classifying`) | 输入非空链接，正在异步请求分类识别 | “正在分析并校验链接，请稍候...” | 置灰禁用 (`disabled=true`) |
| **内容可用** (`valid-content`) | 识别为有效视频/帖子内容 | “将导入内容” | 高亮可用 (`disabled=false`) |
| **账号可用** (`valid-account`) | 识别为有效对标账号 | “将导入账号 @xxx（平台）” | 高亮可用 (`disabled=false`) |
| **不支持/错误** (`error`) | 无法识别该链接或分类接口报错 | 对应错误提示文案（标红） | 置灰禁用 (`disabled=true`) |

## 3. 验收标准（Acceptance Criteria）
- [ ] AC-1: 弹窗初次打开时，输入框为空，导入按钮处于 disabled 状态。
- [ ] AC-2: 用户粘贴或键入 URL 时，即刻清除旧的成功状态，导入按钮保持 disabled。
- [ ] AC-3: 在链接分析请求完成前，导入按钮不可点击。
- [ ] AC-4: 分析成功且返回类型为 `content` 或 `account` 时，回显对应说明，导入按钮切换为可用。
- [ ] AC-5: 分析返回错误或未知链接类型时，显示错误提示，导入按钮继续保持 disabled。
- [ ] AC-6: 当用户已识别成功后，再次删除或修改 URL 的字符，导入按钮瞬间变回 disabled，不可误提交。
- [ ] AC-7: 现有单元测试与新建回归测试 100% 通过。
