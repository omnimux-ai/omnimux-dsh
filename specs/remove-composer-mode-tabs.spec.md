# 规格：移除新建会话创作模式三项切换栏（Agent / 营销 / 短剧）

## 1. 业务目标与背景
在新建会话（Hero 阶段），原有大标题下方挂载了「Agent / 营销 / 短剧」胶囊式模式切换选项栏。
根据产品极简设计与业务决策，移除新会话界面的该三项切换胶囊栏，使新会话输入界面保持干净纯粹、避免概念冗余。

## 2. 界面行为与契约
1. **新建会话无模式切换胶囊**：在新建会话页面（未提交消息状态），不再渲染包含「Agent / 营销 / 短剧」的 Tab 切换栏；
2. **DOM 锚点清理**：页面上不再创建或插入 `#omnimux-composer-mode-anchor` 占位节点；
3. **分屏与对话过程一致**：无论在全屏、分屏，还是发送消息进入对话后，均不展示该胶囊栏；
4. **默认模式安全保障**：底层会话模式维持默认 `agent` 模式，所有下游关联组件按默认规范稳定运行。

## 3. 关键验收场景（Acceptance Criteria）
- **AC-1**：新会话初始化时，DOM 中不存在 `#omnimux-composer-mode-anchor`，亦不出现 `.omnimux-composer-mode-wrap` 或 `.omnimux-composer-mode-pill`；
- **AC-2**：切换或进入任何会话，界面均不展示「Agent / 营销 / 短剧」三个 Tab；
- **AC-3**：相关自动化测试与质量环门禁 100% 绿灯通过。
