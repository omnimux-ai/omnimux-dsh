# 规格：新会话封面卡片悬停时整卡调暗

## 目标

新会话页探索模板里的封面卡片（黄金开场、软件应用、真实种草、视效大片等竖版短视频卡，以及王牌应用卡）在鼠标悬停时，把整张封面压暗，让叠在画面上的标题、说明和底部按钮更清楚。

新用户安装并登录后即可看到这些卡片，不依赖本机额外配置。卡片没有封面图时仍显示原有占位，悬停同样压暗。

## 用户操作与期望

1. 打开新会话页，找到「黄金开场 Hook」一类封面卡片。
2. 未悬停：封面保持原亮度，底部标题可读。
3. 鼠标移入卡片：整张卡片变暗，标题和说明保持纯白高亮，不给文字加阴影，底部「打开应用」或「复刻」按钮仍可点。
4. 鼠标移出：封面恢复原亮度，说明文字收回。
5. 键盘聚焦同一张卡时，效果与悬停一致。
6. 技能卡片（横版极光卡）不套这层压暗，避免盖住原有浅色底。

## 范围

- 只改新会话封面卡片的悬停视觉。
- 不改文案、不改卡片尺寸、不改点击后的打开行为。
- 压暗用现有深色遮罩色，不新增配色。

## 验收

- 悬停或聚焦时，暗层盖住整张卡片；标题和说明仍在暗层之上，颜色为纯白，没有文字阴影。
- 技能卡没有这层暗层。
- 相关卡片样式检查通过。
