# 规格 · 选择素材弹层与输入框左右对齐（Issue #3012）

## 1. 目标

媒体查看器底部输入框上方弹出的「选择素材」弹层，左右边缘必须与输入框卡片的左右边缘完全对齐。当前弹层按外层容器定位，外层容器还包含左侧「图像/视频」切换栏，导致弹层左边多伸出一截。

## 2. 用户操作旅程

1. 用户打开媒体查看器（图像生成页），切到图像或视频模式。
2. 点击输入框里任意素材卡槽，弹出「选择素材」弹层。
3. 期望：弹层左边与输入框卡片左边齐平，右边与输入框卡片右边齐平；不再与左侧「图像/视频」切换栏对齐。

## 3. UI 元素与文案

不新增、不删除、不改写任何元素与文案。弹层内容（Tab、只看我的、关闭、上传卡、素材网格）保持现状。

## 4. 验收标准

1. 图像模式与视频模式下，弹层左边缘与输入框卡片左边缘的水平差 ≤ 1px，右边缘同理。
2. 弹层仍在输入框正上方 8px 弹出，宽度随输入框宽度变化。
3. 输入框本身位置、宽度、左侧切换栏位置不变。
4. 媒体查看器相关既有测试全部通过。
5. 真实浏览器截图留存对齐后的几何证据。

## 5. 边界

- 只改定位容器与弹层定位，不改弹层内部布局、不改选材/绑定逻辑。
- 样式只用既有 `--dsw-alias-*` Token。

## 6. 追加需求（Issue #3012 第二轮：弹层布局修正与数据加载优化，PM_PREFLIGHT: APPROVED）

以下验收点为产品经理核定（PM_PREFLIGHT: APPROVED），UI 元素与文案为硬约束。

### 6.1 布局

1. 本地 Tab：左侧固定「从本地上传」卡（宽 120px，高 = 两行素材 = 190px，顶底与网格对齐，不随网格滚动）；右侧素材网格为独立滚动区域，固定两行可视高度，超出部分只在该区域内纵向滚动。上传卡与第一列素材的间距等于网格间距 10px，不重叠。
2. 其他 Tab 没有上传卡，网格占满宽度，同样两行高、超出纵向滚动。
3. 弹层内容区高度刚好容纳两行，底部只保留标准内边距（12px），不再有约 60px 空白；素材不超过两行时不出现滚动条。禁止横向滚动、禁止整个弹层滚动。
4. 上传卡移出网格后 `.omx-ref-picker-upload-card` 规则块仍保留 `grid-row: span 2;`、`min-width: 120px;`、`min-height: 190px;`（既有测试断言锁定），且不含 `aspect-ratio: 1 / 1;`。

### 6.2 缓存（模块级，跨弹层开关复用，key 为 Tab）

5. 「只看我的」是前端过滤，过滤结果不得污染缓存、不得串到另一开关状态。
6. 再次打开弹层或切回已访问 Tab：立刻显示缓存，不出现骨架；同时后台静默刷新（stale-while-revalidate）。刷新无任何可见反馈；数据未变（按 id 列表比较）不触发重渲染；数据变化时保留滚动位置。
7. 已有缓存时刷新失败：继续显示缓存，不得用离线占位替换。
8. 同一 Tab 并发请求去重（复用同一个 in-flight Promise）。
9. loading 状态按 Tab 记录（不得用单一布尔），不得出现早退后 loading 卡死。

### 6.3 加载态与缩略图

10. 首次加载且无缓存：显示骨架卡（与素材卡同尺寸、同圆角、同间距，灰色底 + 轻微扫光），数量铺满两行可视格（按 8 个）。
11. 只有「无缓存且请求失败」才退回 `PRESET_REFERENCE_ASSETS` 离线占位。
12. img 保持 `loading="lazy"`，加 `decoding="async"`；加载完成前显示骨架底色，`onLoad` 后约 200ms 淡入。
13. `@media (prefers-reduced-motion: reduce)` 下关闭扫光与淡入，只留静态底色。

### 6.4 红线

14. 整个改动新增可见文字数量为 0：禁止「加载中」「加载失败」「重试」等任何字样、toast、角标、刷新按钮、渐隐遮罩、箭头、分页器。
15. 不改 Tab 名称、「只看我的」、关闭按钮、上传卡文案「从本地上传」；素材卡不渲染可见名称，保留 `aria-label`/`title`/`alt=""`。
16. 样式只用 `var(--dsw-alias-*)` Token，不写裸色值（rgba 阴影若必须，按文件内 `/* exempt-ui03: ... */` 注释写法）。
