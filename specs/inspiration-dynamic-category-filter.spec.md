# 灵感社区分类筛选动态化（Issue #2497）

## 背景

- 云端公共灵感库 `GET /omnimux/inspiration` 数据充足（实测 total=2943），但前端分类下拉写死为 9 个中文电商类目（美妆护肤/厨房用品/数码科技…），而云端 `category` 字段是自由文本（`digital`、`Health & Wellness`、`女装和内衣`、`健康` 等中英混杂），两者几乎零交集：用户选中任一分类 → 列表全空（实测 `category=数码科技` → total=0，`category=digital` → total=1178）。
- 云端无分类聚合接口（`/categories` 上游返回 invalid parameter）；`/api/inspiration/v1/tags` 返回的是标签而非分类，不可用。
- 分页性能实测：page_size=100 约 0.94s/页、约 550KB/页，共约 30 页，全量聚合可行但需要并发与缓存控制。

## 目标

1. 中枢新增聚合端点 `GET /omnimux/inspiration/categories`：以 page_size=100、并发 5 分页拉取云端列表，聚合 `category` 去重 + 计数，按计数降序返回 `{ data: [{ name, count }] }`。
   - 空/缺失 `category` 的处理决策：**剔除**（空桶对下拉选项无意义，「全部」选项已覆盖未筛选语义）。
   - 服务端内存缓存 10 分钟，SWR：有陈缓存先返回陈缓存并后台刷新；上游失败时有陈缓存返回陈缓存、无缓存返回 `200 + { data: [] }`，绝不让页面报错。
   - 仅 GET，沿用现有 PAT 通道，不引入管理员限制。
   - 路由注册顺序：`${PREFIX}/categories` 必须在 `${PREFIX}/:id` 通配分支之前匹配，否则会被当成 id 转发上游。
2. 前端分类下拉改为动态选项：首项固定 `{ value: '', label: t('category.all') }`（文案恰为「全部」），其后为端点返回的分类；加载失败/为空时降级为仅首项，不报错；当前已选值不在新选项中时保留该选项显示，避免下拉空白。
3. 仅「全部 / 云端」tab 语境加载该数据；账号监控 tab 不受影响。

## 验收标准

1. 打开灵感社区「全部」或「云端」tab，分类下拉首项恰为「全部」，其后列出云端真实分类（如 `digital`），选中某分类后列表返回对应条目而非全空。
2. 分类端点失败或返回空时，下拉仅显示「全部」，页面无任何报错。
3. 已选中某分类后选项刷新，若该值不在新选项中，下拉仍显示该已选值。
4. `GET /omnimux/inspiration/categories` 返回 `{ data: [{ name, count }] }`，计数降序；10 分钟内重复请求命中缓存（不重复拉取上游）；上游失败且无缓存时返回 200 + 空数组。
5. 账号监控 tab 的筛选行与之前完全一致，不发分类请求。
6. 文案门禁：首选项 label 恰为「全部」，正则 `/全部(平台|账号|来源|类型|状态|分类|发布方式)/` 不命中任何客户端代码。

## 范围外

- 不改动云端上游服务，不新增上游聚合接口。
- 不改动账号监控 tab 的任何逻辑。
- 不做分类文案的中英翻译/归一映射（云端自由文本原样展示）。
- 不引入持久化缓存（仅进程内存缓存）。
- 不推送分支、不开 PR（由主理人统一收口）。

## 风险

- 全量聚合约 30 页 × 0.94s，并发 5 下首刷约 6s：用 10 分钟缓存 + SWR 摊薄；首刷失败降级为空数组，页面不阻塞。
- 并发刷新踩踏：聚合刷新用单 in-flight Promise 去重。
- 路由顺序错误会把 `categories` 当 id 转发上游：单测覆盖该路由不与 `:id` 冲突。
- 本地 tab 的分类筛选失去原 9 个写死选项：这些选项本就与云端数据零交集，属缺陷本身；本地 tab 降级为仅「全部」。

## 测试要点

- 中枢（plugins/omnimux）：
  - 聚合逻辑：多页拉取、并发上限 5 不被突破、去重计数、按计数降序、空/缺失 category 剔除。
  - 缓存：TTL 内命中不重复请求；陈缓存先返回并后台刷新；上游失败时有陈缓存返回陈缓存、无缓存返回 200 + `{ data: [] }`。
  - 路由：`GET /omnimux/inspiration/categories` 命中聚合分支而非 `:id` 通配。
- 前端（plugins/omnimux-inspiration）：
  - `listCategories()` 请求 `/omnimux/inspiration/categories`。
  - 选项构建：首项固定「全部」、动态项追加、已选值保留、空数据降级仅首项。
  - 渲染门禁：分类下拉在全部/云端 tab 渲染动态选项；端点失败时仅「全部」。
- 回归：`pnpm --filter omnimux test`、`pnpm --filter omnimux-inspiration test`、`pnpm verify:stages`、`pnpm test:gates`。
