# Spec · 首页 Skills 技能库卡片极简重构：移除冗余徽标/胶囊/星标与使用量

## 1. 业务背景与用户明确指示
用户针对首页 Skills 技能卡片截图标注了 4 处红色箭头，明确要求“移除截图的元素”：
- **箭头 1**：左上角水滴火苗图标（`omnimux-creatify-badge-hot`）；
- **箭头 2**：左上角分类胶囊（`omnimux-creatify-pill-cat`，如“⬡ 产品...”）；
- **箭头 3**：右上角收藏五角星按键（`omnimux-creatify-star-btn`）；
- **箭头 4**：底部使用量（`138 uses`）以及遮挡居中大标题的英文简介浮层。

## 2. 解决方案与视觉规范（奥卡姆剃刀极致极简）
1. **彻底移除所有冗余装饰性元素**：
   - 移除左上角徽标与分类胶囊，避免在横向货架 240px 紧凑宽度下出现文字截断（如“产品...”）；
   - 移除右上角收藏星标；
   - 移除覆盖在大标题上方的两行文字抽屉与底部的“138 uses”使用量；
2. **保留核心视觉资产与极简排版**：
   - 保留绚丽的高饱和度 14 套精选极光流光色彩光学算法（`resolveSkillAuroraStyle`）；
   - 保留表面细腻的半透明点阵网格（`omnimux-creatify-dot-overlay`）；
   - 居中呈现醒目纯白加粗标题与纯矢量官方认证打勾徽章（`UGC 告白 ✔`、`电影级 ✔`、`UGC 展示 ✔`）；
   - 鼠标悬停（Hover）时，与普通模板卡片完全对齐：底部平滑升起清爽小巧的毛玻璃「↺ 使用」按钮，点击直接带入创作工作流，绝不遮挡居中标题。

## 3. 验收标准
- **AC-1 冗余元素 100% 移除**：卡片上不再出现左上角水滴、分类胶囊、右上角收藏星标、使用量数字及大段描述文字；
- **AC-2 极简极光卡片正常呈现**：极光渐变、点阵网格与居中标题对勾清晰完整；
- **AC-3 悬停与使用正常**：悬停平滑呈现「↺ 使用」按键，点击成功带入对话；
- **AC-4 门禁与自动化测试全绿**。
