# 规格说明：推特评论区内联回复助手图标挂载与孤立图标清理规范

## 一、背景与问题定义
在推特（X）推文详情页的评论区域，当回复框处于未激活（收起/占位）状态时：
1. 插件扫描到收起态占位栏中的回复按钮，错误地在未展开的单行占位条上挂载了 OmniMux 图标；
2. 用户点击该图标时，鼠标按下事件冒泡触发了推特外层容器的展开机制，导致输入框突然激活展开；
3. 输入框展开后，推特在底部生成了包含发送按钮的全新工具栏，插件再次注入了底部图标；而顶部原先注入的旧图标未能被清理，导致同一输入区上方残留一个孤立图标、下方又蹦出一个新图标，造成双图标重叠与交互异常。

## 二、验收标准（Acceptance Criteria）
1. **收起态占位过滤**：推特评论区内联回复处于未激活收起状态（无激活的可编辑富文本输入框、无媒体工具栏的紧凑占位栏）时，绝不挂载 OmniMux 图标，保持原生界面的清爽与纯净；
2. **展开态精准挂载**：用户点击占位栏激活并展开回复框后（具备可编辑的输入框及底部工具栏），底部的真正回复按钮右侧精准、单一挂载 OmniMux 图标；
3. **僵尸与孤立图标自动清理**：每次扫描挂载时，自动巡检页面上所有已存在的 OmniMux 图标，凡是关联按钮已失效、处于收起态或不在合法工具栏中的残留图标，一律彻底销毁移除，确保同一编辑区绝对单实例；
4. **事件隔离防穿透**：图标交互阻止 `mousedown`、`pointerdown`、`mouseup`、`pointerup` 与 `click` 的事件冒泡与默认行为，杜绝任何对推特外层容器状态的非预期触发。

## 三、影响范围
- `plugins/omnimux-browser/extension/src/content/twitter-copilot/anchor.ts`：挂载前置状态判定、孤立残留图标自动清理、交互事件冒泡隔离。
- `plugins/omnimux-browser/extension/tests/twitter-copilot.spec.ts`：单元测试与场景回归用例。
