# 规格：从资产库添加后输入框卡槽显示缩略图

Issue: #2115
插件: omnimux
日期: 2026-09-17

## 1. 目标

从资产库选中素材并确认后，输入框卡槽必须显示该素材的封面缩略图，不得只显示空白图图标。灵感视频与资产库素材使用同一套官方原生附件卡槽样式。

## 2. 成功标准

1. 确认添加后，卡槽里出现封面图，不是空白占位图标。
2. 预览地址必须带上封面文件，加载才能成功。
3. 灵感视频与资产库素材卡槽同尺寸、同圆角、同关闭按钮，走官方原生附件样式。
4. 取消或移除后卡槽消失。

## 3. 边界

- 总是：资产库素材确认后卡槽显示封面；与原生附件同一套样式
- 绝不：改选择窗内部；另做一套资产库专用卡槽

## 4. 验证

相关测试覆盖：实例化结果的预览地址包含封面文件参数。
