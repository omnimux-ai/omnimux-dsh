# 技能市场「去对话试试」输入框自动预填技能名称 规格说明书 (Spec)

## 1. 业务背景与问题
- **背景**：在先前的界面演进中，输入框左侧常驻的技能按钮/选择器已做隐藏收敛，以保持输入框的极致极简与清爽。
- **痛点**：用户在技能市场（Marketplace / Plaza）浏览技能并点击「去对话试试」（Try in Chat）时，由于输入框底部的技能药丸按钮处于隐藏状态，在会话界面上缺乏直观的视觉反馈，用户无法直观确认当前选中的技能是否已生效。
- **目标**：当用户从技能市场点击任意技能的「去对话试试」时，系统自动在输入框预填该技能对应的斜杠指令（`/{slug} `），让用户在输入框内一眼看到选中的技能标识，并可直接在指令后输入提示词开展对话，形成完整的操作闭环与即时反馈。

## 2. 核心用户旅程与操作路径
1. 用户打开「技能市场」（Skills 页面）；
2. 用户在精选卡片悬停上点击「去对话中试试」，或点击卡片进入详情弹窗后点击「去对话中试试」；
3. 界面自动展开中间对话区域并定位激活当前输入框；
4. 输入框光标就绪，且输入框内已自动预填该技能名称指令 `/{slug} `；
5. 用户无需手动输入指令，直接打字输入业务需求并发送即可。

## 3. 验收标准与契约约束 (AC)
- **AC-1（格式规范）**：预填格式为 `/{slug} `，末尾附带单个空格，光标聚焦于指令末尾，方便用户无缝续写。
- **AC-2（新建会话支持）**：若当前无活跃会话，系统在唤起新会话的同时将 `/{slug} ` 安全写入新会话输入框。
- **AC-3（已有会话支持）**：若当前已有活跃会话，系统在确保会话栏展开显露的同时，异步等待并将 `/{slug} ` 注入输入框。
- **AC-4（智能合并与防重复）**：
  - 若输入框已有当前技能指令，不重复追加；
  - 若输入框已有其他历史技能指令（如 `/old-skill`），自动平滑替换为当前选中的 `/{slug}`；
  - 若输入框已有普通用户提示词（如 `帮我写个短视频脚本`），自动将 `/{slug} ` 前置插入，保留用户既有输入不丢失。
- **AC-5（严禁自动发送）**：仅预填文本与聚焦光标，严格禁止触发自动提交发送，保障用户的绝对掌控权。
- **AC-6（双模式兼容）**：支持标准富文本输入框（contenteditable）与传统文本框（textarea），兼容官方状态监听与受控组件。
