# 推特爆速角标 · 三档深色分层配色规格

## 背景（用户已确认设计）

上一轮把「爆款」档改成了纯黑白高对比（黑底 + 白描边 + 白字），用户反馈"太冷静、缺少氛围渲染"。本轮按用户批准的三分层深色方案改版，要求四条：

1. **一定的透明处理**：底色半透明 + 毛玻璃，卡片底色可透出；
2. **色系更暗**：明度压在低区间，去掉刺眼纯白描边；
3. **必须有分层的颜色氛围区分**：暖 → 冷的色系过渡作为热度刻度（橙红 → 琥珀 → 冷灰）；
4. **体现热度但不太有存在感**：字号/高度克制，发光极弱，悬停只小幅提亮。

禁区不变：仍不得使用紫色（已有硬门禁 `tests/no-purple-theme.spec.ts` 守护）。

## 目标配色（用户已预览确认）

| 档位 | 底色 | 描边 | 文字 | 发光 |
| --- | --- | --- | --- | --- |
| 爆款（最热） | `linear-gradient(180deg, rgba(92,28,16,.60), rgba(46,14,9,.52))` | `1px solid rgba(255,122,74,.34)` | `rgba(255,197,173,.95)` | `0 0 14px rgba(255,88,42,.16)` + 内高光 `inset 0 1px 0 rgba(255,190,160,.10)` |
| 飙升（次热） | `linear-gradient(180deg, rgba(72,46,8,.54), rgba(38,24,5,.48))` | `1px solid rgba(240,172,74,.29)` | `rgba(249,220,170,.90)` | `0 0 12px rgba(228,150,44,.11)` + 内高光 `inset 0 1px 0 rgba(255,226,180,.08)` |
| 正常（常态） | `rgba(22,28,38,.46)` | `1px solid rgba(150,166,186,.22)` | `rgba(198,210,225,.76)` | 无 |

基座：`backdrop-filter: blur(10px) saturate(115%)`；悬停 `translateY(-1px)` + `filter: brightness(1.14)`。

## 影响面

- `content/twitter-velocity/styles.css`：徽标基座与三档配色。
- `content/twitter-velocity/panel.ts`：面板头部档位标签色随档位调整（`#ffb193` / `#fbd38d` / `#a9b6c8`），与徽标同色系。
- 不改：角标尺寸（20px/11px 字号）、位置、交互与抓取逻辑。

## 验收标准

1. 真机（x.com 时间线）读取三档徽标计算样式：底色为半透明（`rgba(...)` 且 alpha < 1）、无纯白描边、三档色相落在橙红 / 琥珀 / 冷灰三个区间。
2. 三档在同一行并排时视觉可区分（截图）。
3. `tests/no-purple-theme.spec.ts` 全线通过（三档色相均不在紫区）。
4. 既有推特助手用例不回归。

## 非目标

- 不改动「飙升」橙色与「正常」冷灰的语义定位，只调整明度/透明度/描边强度。
- 不引入新设计令牌，不改其它功能配色。
