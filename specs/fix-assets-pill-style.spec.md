# 资产库分类胶囊统一对齐方案 B 暗灰底白字加粗方案规格

## 1. 背景与业务决策
业务负责人在开发版实机走查资产中心（资产库）时指出：
- 本地与云端分类胶囊选项卡（如「全部 3」、「角色 2」）仍呈现刺眼、高反差的纯白实心大药丸底色（`rgb(249, 250, 251)`），与技能市场已经优化统一的【方案 B（暗灰低调自定义版）】严重脱节，属于未收敛的旧样式；
- 必须将资产库分类胶囊全面对齐方案 B：半透明暗灰色底色（`rgba(255, 255, 255, 0.16)`）+ 纯白文字（`#ffffff`）+ 强对比 700 加粗字重，消除纯白药丸的高亮割裂。

## 2. 规范定义
- `.omnimux-assets-cloud-chip[aria-pressed="true"]`：
  - 背景底色：`var(--dsw-alias-interactive-bg-active, rgba(255, 255, 255, 0.16))`
  - 文字颜色：`var(--dsw-alias-label-primary, #ffffff)`
  - 边框描边：`1px solid var(--dsw-alias-border-l3, rgba(255, 255, 255, 0.28))`
  - 字重属性：`font-weight: 700`（强对比加粗）
  - 几何形态：`border-radius: 999px; padding: 0 12px;`
- `.omnimux-assets-cloud-dimension-btn[aria-pressed="true"]`：
  - 同样收敛至方案 B 一致的半透明暗灰底与纯白加粗样式。

## 3. 验收标准
- **AC-1**：资产库页面（本地及云端）选中的分类胶囊在暗黑模式下呈现克制高级的半透明暗灰底色（`rgba(255, 255, 255, 0.16)`），文字为纯白加粗（700），与技能市场分类按钮完全一致。
- **AC-2**：彻底消除纯白实心大底色反相黑字块，暗黑模式沉浸感 100%。
- **AC-3**：全量单测、契约测试与 UI01~UI10 静态门禁扫描 0 违规通过。
