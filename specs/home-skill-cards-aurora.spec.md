# Spec · 首页 Skills 技能库卡片全面对齐技能插件高饱和度极光流光样式

## 1. 业务背景与问题分析
用户明确提供两张对比图：
- **图 1（当前首页现状）**：首页会话引导中「Skills 技能库」货架行的技能卡片（如“UGC 告白”、“电影级”、“UGC 展示”、“电子商务”、“静态图片”）呈现单调灰黑色，中间仅有一个四角星小图标，文字靠左下角堆叠，毫无质感与视觉冲击力；
- **图 2（目标标杆）**：技能插件/技能市场（Creatify 风格）中的技能卡片，具备：
  1. 全幅高饱和度极光流光渐变背景（覆盖蓝、橙、紫、粉、绿等全色系明艳渐变）；
  2. 细腻的点阵网格覆盖（Dot Matrix Overlay）；
  3. 左上角热门火苗徽标（ICON_FIRE）与半透明分类胶囊（包含分类矢量小图标与分类中文名称，如 `👤 UGC 和用户评价`、`▶ 视频广告`、`⬡ 产品展示`）；
  4. 右上角半透明方形收藏星标（★）；
  5. 居中纯白加粗大标题与纯矢量认证打勾徽章（ICON_VERIFIED）；
  6. 悬停浮层平滑升起，呈现使用量与快捷使用入口。

### 根因深度剖析：
1. **渲染组件割裂**：首页探索模板专区（`ExploreTemplatesSection.jsx`）中的 Skills 技能库货架行直接使用了通用模板卡片 `TemplateCardItem.jsx`，其默认尝试加载外部不存在的图片，失败后降级为 `omnimux-tpl-placeholder`（居中四角星 + 底栏靠左文字）；
2. **算法未引入 Hub 插件**：高颜值 14 套极光流光色彩光学算法（`resolveSkillAuroraStyle`）之前仅在 `omnimux-market` 插件内实现，未引入 `omnimux` 核心引导中；
3. **数据源映射字段丢失**：在 `ExploreTemplatesSection.jsx` 构建 `allSkillsItems` 时，只映射了简单字段，丢失了 `category`、`tags`、`isHot`、`downloads` 等核心元数据，导致卡片无法呈现左上角分类胶囊与火苗徽标。

## 2. 解决方案与重构目标
1. **极光流光色彩光学算法引入与复用**：
   - 在 `plugins/omnimux/src/client/session-guide/skills/auroraGradients.js` 提供完整的 14 套高饱和度流光渐变算法与确定性哈希散列引擎；
   - 确保首页全量技能卡片零图片依赖，首帧即绽放璀璨夺目的高颜值流光。
2. **升级首页卡片与技能卡片组件对齐图 2 结构**：
   - 补齐 `allSkillsItems` 元数据透传（`...sk`，保留 `category`, `tags`, `isHot`, `isNew`, `downloads`）；
   - 在 `TemplateCardItem.jsx` 中，对技能卡片（`isSkill`）专门渲染对齐图 2 的结构：
     - 极光背景层 + 点阵纹理 Overlay；
     - 左上角：火苗徽标（热门精选）+ 分类胶囊（分类矢量图标 + 分类中文名）；
     - 右上角：收藏五角星按钮；
     - 居中：白色加粗大标题 + 官方认证打勾徽章；
     - 悬停浮层：升起简介、使用量与「使用」按钮；
   - 同步升级 `SkillCard.jsx` 消除图片加载失败降级为黑灰色的历史缺陷。
3. **样式与布局统一保障**：
   - 在 `styles.js` 中适配横版 16:10 / 3:2 货架轨道（`.omnimux-shelf-track`）与网格视图（`.omnimux-tpl-full-grid`），保持与整个首页的和谐统一与高档视觉质感。

## 3. 验收标准
- **AC-1 首页技能卡片 100% 极光流光呈现**：
  - 首页「Skills 技能库」货架上的每张卡片（UGC 告白、电影级、UGC 展示等）均呈现明艳独特的炫彩极光渐变，彻底消除死板灰黑底色；
- **AC-2 点阵网格与居中标题对勾完整对齐**：
  - 卡片覆盖点阵网格，居中呈现白色加粗大标题与认证对勾徽章；
- **AC-3 左上分类胶囊与右上星标完整**：
  - 左上角展示分类胶囊（如 `UGC 和用户评价` 等）与火苗；右上角展示半透明收藏星标；
- **AC-4 交互完整与测试 100% 通过**：
  - 点击卡片或快捷按钮正常触发会话预填该技能；
  - 相关单元测试与自动化验证全部绿灯。
