# 视频媒体悬浮工具栏可见性保障与控制栏防误杀遮挡修复规格说明

## 1. 缺陷与用户反馈现场

用户实测反馈：
> “图片的按钮悬停能激活工具栏，但是视频看不到工具栏 只能看到工具提示”

### 根因深度剖析
1. **展开态可见性脱节**：`capsule.ts` 与 `overlay.ts` 的 `expand()` 仅切换了 `is-expanded` 样式类，未强制保证胶囊具有 `is-visible` 类。若胶囊此前因离开视频边界被调用过 `hide()`，其类名中缺少 `is-visible`，导致 CSS 规则维持 `opacity: 0`（完全隐形）。
2. **提示气泡自管可见性导致反差**：光标移入隐形胶囊的按钮时，按钮的悬停事件正常触发了 `tooltip.show()`，而气泡自身拥有独立的 `classList.add('is-visible')`，因此纯白说明气泡（如“加入灵感库”）清晰浮现，而正下方的工具栏却处于 0 透明度不可见状态。
3. **视频底部控制条边缘误杀**：在视频播放场景中，底部具有播放/暂停条、时间戳（如 `0:04`）及进度条（通常占底边 48px 区域）。当光标在时间标签或控制栏附近移动时，坐标极易超出 `<video>` 画面矩形底边，原逻辑在非范围内立即执行 `hideNow(true)` 强行隐藏胶囊，导致胶囊瞬间变透明。
4. **层级与背景遮蔽隐患**：在视频复杂背景与半透明控制条叠加下，胶囊需具备强对比度的实心深黑毛玻璃底色、白描边与阴影轮廓，确保在深色视频底栏上清晰可见。

## 2. 修复方案

1. **展开必可见强契约**：在 `capsule.expand()` 与 `overlay.expandCapsule()` 中，显式添加 `is-visible` 类名，确保任何展开态下的胶囊必须 100% 可见，杜绝“展开却透明隐形”的幽灵态。
2. **视频控制栏底部容差**：在光标命中区域计算（`isPointNearAnchorOrCapsule`）中，为视频元素底部增加 48px 控制栏呼吸容差，允许光标在底部控制条与时间戳区域平滑移动而不触发误判隐藏。
3. **离开缓冲保护**：光标离开媒体与胶囊附近时，走平滑缓冲定时器，消除瞬间闪隐。
4. **视觉与层级强化**：确保展开状态下的工具栏具备完整的边框、阴影与高对比度图标呈现。

## 3. 验收标准 (AC)

- **AC-1**：在视频媒体上，悬停至左下角图标时，工具栏按钮（灵感库、复制、会话）与纯白提示气泡必须**同时清晰可见**，杜绝单独只露气泡而工具栏隐形。
- **AC-2**：光标在视频底部控制栏（含时间戳 `0:04` 区域）移动时，胶囊保持稳定呈现，不发生因轻微位移导致的瞬间隐藏。
- **AC-3**：图片场景下的悬停与展开体验不受任何影响，保持原有丝滑展开与收起。
- **AC-4**：全量单元测试与无头浏览器真实 CDP 实机预演 100% 通过。
