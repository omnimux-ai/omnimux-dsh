## 用户旅程

已登录用户从灵感详情对整帖/视频点击分析。当前素材理解服务为 pending 时，页面不能误报缺少官方 API Key，必须保留真实原因。pending 时就地显示“使用 OmniMux 分析服务”，经用户点击仅确认 analysis 一项；不暴露模型 ID 或渠道分组。已配置或明确选择的渠道继续按原选择执行，其他用途不受影响。分析运行中仍维持“解析中...”禁用与关闭重开状态保持。

## 新用户基线

依赖正常安装的 Hub、正式账号/凭据服务、可供素材理解的正式注册模型服务。不得借用开发机代理、端口、其他 profile、磁盘密钥或把身份 ACCESS_TOKEN 当模型 API Key。缺少服务时明确提示素材理解尚未配置；缺少执行凭据、凭据服务异常、上游拒绝分别保留真实原因。

## 方案约束

- 使用现行 Host 模型设置与 Hub seam，不恢复退役全局用途配置卡片，不修改官方 DSH 源码。
- 官方账号调用凭据由现有个人资料页的明确动作启用：列表只给本人脱敏密钥，用户选用后由 Hub 私下获取并存入账号绑定的凭据引用；不自动新建密钥，不发明额度/有效期政策。无可用密钥引导官方控制台 /keys/ 创建后回来选择，不要求复制密钥。
- 不自动覆盖用户 per-scenario 或显式 request 选择，不自动触发收费回退。
- 文档影响：更新本规格及必要的 owning Hub/设置合同，明确实际恢复行为；不复制通用说明。
