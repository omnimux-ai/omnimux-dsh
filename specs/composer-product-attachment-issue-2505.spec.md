# 规格说明书 · 输入框选中产品后消息卡片附加缩略图与上下文注入 (Issue #2505)

## 1. 业务目标与背景
用户在会话输入框底栏通过「产品」按钮选定商品后：
1. **直观可视**：提交出去的用户消息卡片（对话气泡）顶部上方，必须附加该产品的封面缩略图与产品卡片，使用户能一眼看清该条消息关联的具体产品信息。
2. **上下文深度注入**：选定产品后，该商品的全量档案（封面图片、核心卖点、产品特性、目标受众、价格等）必须同步登记至会话附件中心，在后台静默注入给 AI 模型，使生成的文案、分镜与营销内容能真正理解商品。
3. **状态生命周期闭环**：换选商品、移除商品或消息发送完毕后，输入框底栏、输入框标签与附件池保持严格一致与纯净，不产生脏数据与状态残留。

## 2. 核心用户旅程与交互契约
1. **产品选定**：
   - 用户在输入框底栏点击「产品」，在原生商品库弹窗中选中一件商品（如“5ml便携迷你香水喷雾瓶”）；
   - 底栏按钮切换为选中态（18px 封面小图 + 商品名称 + 悬停移除按钮）；
   - 输入框内插入产品胶囊标签；
   - 内部状态将该商品的结构化档案（ID、名称、价格、品牌、封面、卖点、特性、受众）登记入本轮会话附件池。
2. **消息提交**：
   - 用户输入文字并按回车或点击发送；
   - 本轮商品上下文经后台安全信封注入 AI 模型；
   - 输入框已发送，底栏按钮自动平滑恢复为未选中态，准备下一次输入；
3. **消息卡片呈现**：
   - 对话流中，该条用户消息气泡的正上方展示商品专属微型卡片：
     - 包含商品的封面缩略图（高清适配、微圆角）；
     - 包含商品名称（超长优雅省略）；
     - 视觉规范严格遵循 DSH 原生纯黑（#18181b / #212124）与极光紫边框交互微光，与既有图片/视频附件轨完全统一。

## 3. 验收标准 (Acceptance Criteria)
- [ ] **AC-1 (底栏选择联动附件)**：底栏 `ProductPickerButton` 选中商品时，自动将商品打包并登记至会话附件池；换选商品时移除旧商品附件并添加新商品附件；移除时同步清理附件。
- [ ] **AC-2 (发送后底栏重置)**：消息提交后，底栏产品按钮监听提交事件并恢复默认未选中态，防止后续会话产生非意图绑定。
- [ ] **AC-3 (消息卡片缩略图渲染)**：`userMessageAttachmentsEnhancer` 增强器支持 `kind === 'product'` 的附件类型，在用户消息气泡上方直观渲染带封面缩略图与名称的商品卡片。
- [ ] **AC-4 (上下文全量对账)**：商品核心卖点、特性参数、品牌受众等结构化信息正确注入上下文数据块中，供 AI 决策与创作。
- [ ] **AC-5 (单文件演示与回归测试)**：提供 `docs/demos/composer-product-attachment-demo.html` 独立交互演示页，并通过现有 E2E 与单元测试门禁。
