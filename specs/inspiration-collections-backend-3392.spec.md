# 灵感合集持久化与请求边界（#3392）

本任务为已确认灵感库拖动合集的服务端子任务，父任务提供用户交互规格。复用现有本地库文件、原子写入及统一请求链，不新增模型、凭据或服务。旧版文件兼容，所有原有条目写入保留合集；单/批量删除同步清理成员。

本地条目在根层和合集之间只有一个归属，集合保存有序本地ID。创建、加入、重命名、移出均原子操作，校验失败不部分写入；空合集保留。名称去首尾空白，1至20个Unicode字符且不重复。客户端只发送操作参数，不能写入任意旧库快照。

列表增加明确的root_only与collection_id范围；根列表在分页之前排除成员，合集独立字段返回，预览从全库取。正常未指定范围的调用兼容旧语义。已有page_size传递错误在此直接相关接点修正。根筛选可按合集名或成员命中，合集内成员保持加入顺序。

新增/加入/重命名/移出返回服务端生成的最近操作撤销凭据。撤销仅修改合集元数据，校验当前后态与本地记录存在性，冲突拒绝；不覆盖期间新增或编辑的素材，不复活已删除素材。缺失文件可建立空库，损坏或不可写库失败明确，禁止当空库覆盖。

新用户使用插件现有本地存储即可，无开发机路径或模型配置依赖。离线存储及真实插件注册入口测试须覆盖持久化、过滤分页、错误/并发/删除/替换、路由优先级与无外发；UI实际浏览器证据与回归由父任务补齐。只允许修改本插件服务端文件及其单元/集成测试，不改客户端或主工作区。

实现约定：同一库文件顶层增加独立collections数组；旧文件缺省为空但损坏文件拒绝读取和写入。合集内部持久化随机修订标识，用来拒绝已发生后续关系变更的旧撤销。撤销凭据仅保留在进程内，默认60秒且一次有效；重启、真实删除、过期或冲突返回409。创建至少两条不同的真实本地记录，已在别组的成员整批拒绝，同组重复添加不重复保存；名称按Unicode码点计数。新增普通条目也须在写入前拒绝非法或重复本地标识，避免写入后让严格读取把整个库判损坏。

对外请求约定：根列表root_only=true返回collections及全库collection_names；collection_id返回collection。原无范围查询保持全库语义。新增/加入/移出/重命名成功直接返回顶层data和undo_token，撤销成功返回data.undone及当前collection（创建撤销时为null），undo_token为null。合集预览至多三条真实本地记录，按成员顺序从全库提取，筛选不截断预览。

文档影响：本规格和服务端类型注释记录新增关系与请求边界；不修改产品定位、云能力、凭据或安装配置。父任务负责交互说明和浏览器验收。

离线验证：插件完整检查1403+261项通过，失败和跳过均为0；存储与真实注册入口专项43项通过、零外发；产品新用户基线及插件职责边界通过。另用真实插件注册入口和动态本地服务完成23次HTTP请求，验证新插件实例重读、分页顺序、撤销保护和删除/损坏边界，外部能力执行0次，服务及临时库均清理。实际命令、首次环境失败原因、代码指纹与原始结果保留在任务交付报告中。前端真实浏览器、共享开发版人工验收和合入由父任务负责，不以本报告代替。

追加读取闭合：成员条目在get、分页list和已缓存读取快照中根据顶层合集关系附加只读collection_id；未归组条目保持原字段形状。该字段不持久化，普通保存即使携带读取结果或伪造值也忽略它。重新导入仍保留顶层成员关系，后续权威读取可让客户端进入实际合集。过期导入状态扫尾后，HTTP读取也使用当前带归属的存储结果，不用无归属的临时更新返回值覆盖它。
