# 规格：ComfyUI 工作流节点卡片内嵌页面（Issue #3751）

## 业务目标

用户给了目标样式：这个节点的卡片里**直接就是 ComfyUI 页面**，不用先点「打开」；卡片带加载状态、底部显示工作流名与「使用模板」、悬浮工具栏有「全屏」和「添加到会话」；全屏要真的铺满并置顶（现在还能看到画布背景），卡片要能随意拖动缩放。

现状：卡片只有「图标 + 地址 + 状态 + 打开按钮」，真页面在另一个整层覆盖里；节点没有那两个工具栏按钮；全站节点都没有缩放能力。

## 用户关键操作旅程

1. 拖出节点 → 卡片立刻出现，并显示加载状态（未安装 / 安装中 / 已装未启动 / 就绪 / 失败都能在卡片里看清）。
2. 后端就绪 → 卡片里直接是 ComfyUI 页面，能直接在里面干活；不需要额外点「打开」。
3. 点工具栏「全屏」→ 同一张卡片铺满屏幕、盖住画布、无背景露出；再点一次（或按 Esc）回到原位原尺寸；**期间页面不重新加载**（已打开的工作流还在）。
4. 拖动卡片边角 → 任意调整大小；刷新画布后尺寸仍然是刚才那样。
5. 点底部「使用模板」→ 打开画布已有的工作流模板面板。
6. 点工具栏「添加到会话」→ 与物料节点同款行为（把该节点带进会话）。

## 期望 UI 反馈

- 卡片：加载态有明确视觉（不是白屏）；失败态给原因与唯一主行动（沿用 M3 的失败矩阵文案）。
- 全屏：不透明底、层级高于画布与画布浮层；标题栏保留「关闭/退出全屏」与状态。
- 缩放：右下角有可见的拖拽点，光标变化；最小尺寸有下限，避免缩到看不清。
- 底部：左边工作流名（默认「未命名工作流」），右边「使用模板」；不留解释性副标题。

## 变更点

1. `nodes/definitions/comfyPage.tsx`：卡片改为承载状态机 + 真页面；保留既有探测与托管状态读取逻辑（`comfyBackendClient`），不重复实现一套。
2. **单宿主**：全屏不再另开覆盖层，而是给同一张卡片加整屏样式（fixed + 高层级 + 不透明底）。`ComfyPageOverlay.tsx` 若因此没有入口，连同其专用样式一起删除，不留死代码；其状态机渲染要迁到卡片里（或抽成两边共用的组件）。
3. 加载态：页面加载中 / 就绪 / 失败（含原因）三态；失败要能重试。
4. iframe 挂载策略（用户已选）：**只在节点可见或选中时挂载**；缩放到很小或完全不可见时卸载或降级为占位，避免同屏多个节点无限挂载；全屏切换**不重新挂载**（同一 DOM 节点放大）。
5. 工具栏：复用物料节点同款的「全屏」与「添加到会话」按钮（图标、位置、文案规范一致；`useAddToConversation` 复用，不另写一套）。
6. 缩放：仅这个节点类型支持拖动调整大小；尺寸写进节点数据并持久化；其它节点类型行为不变。
7. 底部：工作流名称（默认「未命名工作流」）+「使用模板」（打开 `WorkflowTemplatePanel`）。
8. i18n 中英双语；新文案遵循仓库文案规范。

## 非目标

不驱动 ComfyUI 页面内部 UI（不注入脚本改它的界面）；不抓取/注入 ComfyUI 自带模板库；不改后端安装与状态机语义；不给其它节点类型加缩放；不改节点连线/端口语义（这个节点仍不参与物料连线）。

## 新用户基线

新用户拖出节点后看到的是「加载中 → 可用」的正常路径；不依赖任何本机开发状态；未安装时卡片里就说清体积与安装入口（沿用 M2c/M3/M4 文案），不假装页面可用。

## 假设

1. 假设 React Flow 的节点可以承载 iframe，且画布缩放/平移时 iframe 不阻塞交互（需要实测；若阻塞则改为「选中时才挂载」）。
2. 假设全屏可以只靠样式提升同一张卡片（fixed + 高层级）实现，不需要移动 DOM，因此页面不重载。
3. 假设「添加到会话」的既有能力（`useAddToConversation`）可以在这个节点类型上复用，不需要新接口。
4. 假设节点数据可以存宽高（沿用画布既有的节点数据持久化路径），刷新后能恢复。
5. 假设「使用模板」打开画布自己的工作流模板面板即可满足需求（ComfyUI 自带模板库这条路本次不做）。

## 证伪方式

1. 若卡片仍需点按钮才显示页面，则不成立——断言就绪后卡片内存在 iframe。
2. 若全屏后仍能看到画布背景，则不成立——断言全屏层不透明且层级高于画布浮层（实测截图 + 层级值）。
3. 若全屏导致页面重载，则不成立——断言切换前后 iframe 元素未被重建（例如页面内已打开的工作流仍在）。
4. 若缩放不持久化，则不成立——断言改尺寸后刷新画布尺寸仍在。
5. 若同屏多个节点各自常驻 iframe，则不成立——断言不可见/未选中的节点没有挂载 iframe。
6. 若删掉覆盖层后仍有死代码或第二入口，则不成立——lint/anti-slop + 人工检查。

## 验收标准

1. 新建节点即显示卡片与加载态；就绪后卡片内直接是 ComfyUI 页面。
2. 全屏：同一卡片铺满、置顶、不透明、无背景露出；退出后回原位原尺寸；页面不重载。
3. 工具栏两个按钮行为与物料节点一致。
4. 缩放可用并持久化；最小尺寸有下限。
5. 底部名称与「使用模板」可用；中英双语。
6. 单测/typecheck/anti-slop 全绿；真机浏览器证据覆盖：卡片内页面、加载态、全屏无背景、缩放持久化、工具栏两个按钮。

## 旧标准变更

本次**没有删除或削弱任何既有用例**（`ComfyPageOverlay` 与其 `wf-comfy-page-overlay*` 类名、`COMFY_PAGE_OPEN_EVENT`、`comfyPage.card.open` 文案键都无测试引用，已核对）。
新增用例：`plugins/omnimux-workflow/src/canvas/editor/utils/comfyPageCard.test.mjs`（9 例，纯逻辑）、`plugins/omnimux-workflow/src/canvas/nodes/definitions/comfyPage.test.mjs`（7 例，源码契约）、`plugins/omnimux-workflow/tests/comfy-node-card.e2e.test.mjs`（5 例，端到端契约：可见性坐标、单宿主、全屏不重建、缩放落盘、挂载双向）。

## 验证证据

真机浏览器（ego-browser，1728×883，harness 4832，卡片尺寸 2200×1600 / 视口缩放 0.23）：

| 验收点 | 实测 |
| --- | --- |
| 卡片内真页面 | `frameInsideCard=true`、`frameSrc=http://localhost:4832`、旧「打开」入口不存在 |
| 底部 | 名称「未命名工作流」+「使用模板」；点击派发 `omnimux-workflow:comfy-page-use-template`（detail.nodeId=comfy-1） |
| 工具栏 | 胶囊两个按钮：「全屏」「添加到会话」 |
| 全屏几何 | 卡片矩形 1728×883（=视口）、背景 `rgb(17,17,17)` 不透明 |
| 全屏层级 | 节点 z-index 1000、`.react-flow` 40（> 工具栏 20、页头控件 30）；四点采样全为面板内容，无背景露出 |
| 不重载 | 全屏前后 iframe 运行时标记 `__cardProbe=keep-me`、`data-probe-tag=tag-1` 均保持 |
| 退出整屏 | 回到 506×368，标记仍保持；根节点整屏类被摘除 |
| 缩放 | 拖右下角手柄 2200×1600 → 2121×1547，写入节点 width/height |
| 挂载策略 | 移出视口 → iframe 卸载；回到视口 → 重新挂载；缩到屏幕宽 69px → 占位「页面已暂停」 |
