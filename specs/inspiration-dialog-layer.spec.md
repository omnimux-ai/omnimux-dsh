# 灵感详情统一顶层显示

- Issue: #3393；base: e3f802f36e17a88a8362fbdf81cd780ec8d9f7c3。
- 用户目标：灵感社区卡片打开的帖子详情完整遮住侧栏，不再出现透明或侧栏压住面板的效果。
- 当前证据：开发版详情和遮罩背景均为不透明颜色，但直接库入口没有原生顶层，工作区 z30 被侧栏 z35 和拖拽条 z510 压住。推荐服务单独拥有原生层，旧验收未覆盖库入口。
- 最小方案：详情自身复用已有原生弹窗层，推荐服务去掉重复外包装；正常退出键由原生取消事件统一处理。保留分享、图片与创作子层优先关闭，以及原来的不透明底色。
- 新用户基线：只依赖应用已有浏览器原生弹窗与共享界面能力，不需要本机服务、账号、密钥或模型。无 showModal 的离线测试环境沿用已有 open 属性回退，不将其当成实际浏览器证据。
- 验收：真实灵感库卡片打开；高层侧栏/拖拽条不可覆盖或点击；恰好一个原生顶层；推荐入口不重复；图片、创作、分享关闭与焦点正确；深浅色、桌面和窄屏；关闭后焦点与滚动锁恢复。
- 文档影响：此规格与交付报告记录界面修复；不改变产品定义、接口或用户流程，无需另改业务合同。
- 范围外：不改全局侧栏层数，不改变导入/模型/创作功能，不进行生产发布或生成收费视频。
- 验证：受影响组件与完整灵感包测试、页面契约、防劣化检查；实际工作树浏览器及截图，独立评审；当前版本必需检查和合并队列通过后交付开发版并清理本任务。
