# 灵感弹窗全面升级对齐视频分析工具双栏工作台布局与分镜卡片视觉规格说明 (Issue #2297)

## 1. 背景与目标
灵感库弹窗原三栏横向布局在短视频深度拉片场景下存在局限：
1. **横向空间局促**：播放器、文案、解构横向瓜分弹窗宽度，文字排版拥挤；
2. **格式杂音严重**：原字幕中裸露显示 `<br>`、裸露引号 `""`、Markdown 粗体 `**` 及 `Overlay):` 等未清洗的前缀字符；
3. **缺少专业视听语言**：缺少分镜时间轴点选跳转、视听属性胶囊标签、麦克风台词气泡以及播放状态呼吸灯联动。

本任务实施方案 A：全面对齐视频分析工具（`omnimux-video-preview`）的视听工作台布局与卡片设计规范。

## 2. 核心验收准则 (Acceptance Criteria)

| 编号 | 模块 | 输入/前置条件 | 预期行为与结果 |
| :--- | :--- | :--- | :--- |
| **AC-1** | 双栏工作台架构 | 打开灵感预览弹窗 | 采用左侧 9:16 大幅播放器与元数据栏 + 右侧分段选项卡（分镜 ↔ 结构拆解）的两栏工作台布局，彻底告别三栏拥挤排版。 |
| **AC-2** | 文本彻底纯净化 | 遇到含 `<br>`、模板标签或括号前缀的台词 | 过滤所有 `<br>`、`**` 星号、`""` 裸引号以及 `Overlay):` 等前缀，输出纯净专业的台词文本。 |
| **AC-3** | 分镜卡片视听质感 | 切换至【分镜】Tab | 逐镜头呈现时间跨度徽标、视听属性标签胶囊、画面动作描述、带麦克风图标的原声台词气泡及 AI Prompt 复制盒。 |
| **AC-4** | 声画播放联动 | 播放视频或点击分镜卡片 | 点击任意分镜卡片，左侧视频自动跳转至对应秒数播放；播放进行时，当前正在发生的分镜卡片动态点亮绿色呼吸灯及激活高亮边框。 |
| **AC-5** | 结构拆解专业流 | 切换至【结构拆解】Tab | 呈现精炼标准的五维商业拆解卡片（黄金 3 秒 Hook、转化目标、叙事与人声、视觉语言、复刻策略）。 |
| **AC-6** | 一键复刻闭环保持 | 用户点击“立即复刻” | 保持底部全局固定复刻按键，向会话及创作画布投递完整的结构化分镜与五维策略。 |

## 3. 技术设计
1. `plugins/omnimux-inspiration/src/client/InspirationPreviewModal.jsx`：
   - 布局改造为 `omnimux-inspiration-modal-workbench`（两栏结构）；
   - 左侧：9:16 Player Box + 底部作者/标题/外链元数据条；
   - 右侧：顶部 Segmented Tabs（`shots` ↔ `structure`），支持双重视角切换；
   - 视频播放联动：监听 `<video>` 的 `onTimeUpdate`，计算当前所在分镜索引并在分镜卡片上展示 `isCurrent` 呼吸灯徽标；
2. 文本清洗纯函数 `cleanScriptDisplay(text)`：
   - 过滤 `<br>` 替换为空格，剥离 `**`，剥离 `Overlay):` 等脏前缀；
3. `plugins/omnimux-inspiration/src/client/styles.js`：
   - 深度复刻视频分析工具的 Segmented Tabs、分镜卡片、呼吸脉冲灯动画（`omnimux-pulse`）及麦克风台词气泡样式，100% 消费官方设计变量。
