# 资产库分类导航栏上下呼吸留白规格（Issue #1977 视觉调优）

- 任务单：Issue #1977（公共与本地二级分类导航栏上下留白优化）
- 分支：`fix/assets-tab-spacing-issue-1977`
- 关联设计：`design.md` 呼吸间距节奏（4/8/12/16/20/24）

## 1. 目标（Objective）

**问题**：
用户截图反馈：在资产中心（尤其是「公共」分类页签）中，二级分类胶囊行（全部、角色、场景...）上方紧贴一级 Tab 栏（本地/公共/产品库的白横线），下方直接紧贴卡片上沿，上下均无留白，挤压严重。

**根因**：
- `.omnimux-assets-cloud-nav` 原先声明 `padding: 0;`。当页面吸附置顶后，吸附栏 `top: 48px` 紧挨着一级栏底边（0px 间距），胶囊内部高度仅 28px，下方的卡片滚动时直接抵着胶囊底边，上下间距均为 0px。
- `.omnimux-assets-local-nav` 原先为 `padding: 8px 24px 10px;`，间距偏紧。

**修复方案**：
- 为 `.omnimux-assets-cloud-nav` 设置标准呼吸留白：`padding: 12px 0 14px;`。
  - 上方保持 12px 透气距离，不再与一级 Tab 横线贴脸；
  - 下方保持 14px 沉浸缓冲，卡片在胶囊下方拥有舒缓的视觉过渡区。
- 同步收敛 `.omnimux-assets-local-nav` 为 `padding: 12px 24px 14px;`，保证本地与公共两级导航的上下呼吸感完全一致。

## 2. 验收标准（可测）

| ID | 场景 | 期望 |
|---|---|---|
| AC-1 | 资产中心公共分类导航（未滚动） | 胶囊行上方距离一级 Tab 有良好留白（>= 12px），下方距离卡片有良好留白（>= 14px） |
| AC-2 | 资产中心公共分类导航（滚动吸附置顶） | 吸附态下，胶囊上方距离一级栏底边保持 12px，卡片向上滚动时在胶囊下方 14px 外滑入遮挡区 |
| AC-3 | 资产中心本地分类导航 | 上下留白与公共保持一致节奏（12px 顶留白，14px 底留白） |
| AC-4 | 门禁与静态扫描 | `pnpm verify:stage-scroll` 7/7 页面合规，`pnpm test:ui` 0 违规 |

## 3. 边界（Boundaries）

- **总是**：遵循 8/12/14/16/20/24 间距节奏；左右 24px 严格对齐基准线。
- **绝不**：改变各分类项过滤逻辑与原有层级结构。
