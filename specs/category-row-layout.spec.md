# 规格说明：公共资产库全部列表单行分类流布局与刷新随机排序缓存机制

> 关联 Issue: #2198  
> 目标模块: `plugins/omnimux-assets`  
> 质量循环阶段: Spec 门禁规范

---

## 1. 业务目标与需求背景

公共资产库目前在「全部」分类下，将所有类别的素材混排在同一网格瀑布流中，缺乏按分类导流的结构化组织。
根据用户给出的现代暗色流式卡片设计（参考 UGC Style / Photo to Clip 版式），升级公共资产库的展示体系：
1. 在「全部」视图下，每个业务分类（角色、场景、道具、素材、风格、声音）各展示为一行独立的内容卡片流。
2. 每行顶部包含分类标题、描述说明与右侧「查看全部 →」按钮。
3. 单行卡片支持水平横向平滑滚动，并配备悬浮圆形翻页箭头按钮。
4. 点击「查看全部 →」或分类标题，立即平滑切换到该分类专属标签页，展示该分类的全量多列瀑布流。
5. **刷新随机排序与缓存机制**：每次刷新时每个分类展示的卡片随机洗牌显示，避免固定排序陈旧；但在当前浏览会话/标签切换过程中保持顺序稳定缓存，不跳动乱序。

---

## 2. 关键用户旅程与交互规格

### 旅程 1：全部概览分行浏览
1. 用户进入资产中心「公共」选项卡，默认停留在「全部」分类；
2. 页面垂直依次展现：
   - **角色** 行：展示精选角色卡片，支持试听与加入对话；
   - **场景** 行：展示高清实景与空间卡片；
   - **道具** 行：展示拍摄好物与带货模型卡片；
   - **素材** 行：展示绿幕与穿搭贴片卡片；
   - **风格** 行：展示生图生视频预设卡片；
   - **声音** 行：展示卡点 BGM 与音效卡片（带试听底板）；
3. 用户在单行上向右横向滑动，或点击右侧悬浮圆形箭头 `>`，卡片平滑向右滚动；滚动后左侧悬浮出现 `<` 箭头支持返回。

### 旅程 2：一键直达分类
1. 用户对某一行（如「场景」）感兴趣，点击该行右上角的「查看全部 →」按钮；
2. 顶部水平分类胶囊栏同步将「场景」置为高亮激活态；
3. 视图无缝切换为「场景」专属视图，展现该分类的二级分类（城市街景、生活室内等）与多列瀑布流全量网格。
4. 用户点击顶部分类胶囊中的「全部」，平滑返回全部分类行布局。

### 旅程 3：刷新随机显示与会话缓存
1. 页面加载或用户主动触发刷新时，各分类加载的数据池通过安全随机洗牌生成当前会话的卡片序列并写入缓存；
2. 用户在「全部」与各具体分类之间频繁切换、点击卡片预览、加入对话等操作时，直接读取会话缓存，卡片顺序保持绝对一致，零闪烁跳动；
3. 当用户点击顶栏「刷新」按钮时，清空随机序列缓存，重新随机打乱并呈现全新内容。

## 3. 架构设计与契约边界

### 3.1 模块职责划分
- `category-shuffle-cache.js`（纯逻辑）：
  - `shuffleArray(items, seed?)`：安全无副作用的洗牌算法；
  - `CategoryShuffleCache`：按 `categoryId` 维护随机序列缓存，支持 `get(catId)`、`set(catId, items)`、`invalidate()` 与 `has(catId)`；
  - 导出单例或 Hook 供组件消费，具备完整的单元测试覆盖。
- `CloudCategoryRow.jsx` / `CloudAssetsView.jsx`（UI 渲染）：
  - `CloudCategoryRow`：单分类行组件，包含标头区（标题、描述、查看全部按钮）、水平滚动视口容器与左右悬浮圆形翻页箭头；
  - `CloudAllCategoryRows`：在 `category === 'all'` 且无搜索关键词时接管渲染；
  - 当 `category !== 'all'` 或搜索激活时，无缝回退至原有的全量网格/瀑布流。
- `styles.js`（样式体系）：
  - 100% 消费官方 `--dsw-alias-*` 设计令牌，严禁裸写 hex/rgba；
  - 单行容器 `overflow-x: auto; scrollbar-width: none; scroll-behavior: smooth;`；
  - 悬浮翻页圆钮 `width: 36px; height: 36px; border-radius: 50%; backdrop-filter: blur(8px);`。

## 4. 验收标准（Acceptance Criteria）

- **AC-1**：在公共资产库处于「全部」且未激活搜索时，按分类逐行呈现（角色、场景、道具、素材、风格、声音），不再混排单一大瀑布流。
- **AC-2**：每行卡片横向单行排列，支持平滑横向滚动，右侧悬浮圆形翻页按钮正常运作。
- **AC-3**：点击「查看全部 →」或分类标题，准确切换至对应分类 tab，顶部胶囊栏联动激活。
- **AC-4**：刷新时各分类卡片随机排序，会话内来回切换保持缓存稳定不跳动；主动刷新重置随机序列。
- **AC-5**：全量单元测试与回归测试 100% 通过（UI01~10 门禁零违规）。
- **AC-6**：在独立工作树内通过应用级真实浏览器验证取证。
