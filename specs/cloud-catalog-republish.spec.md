# 云端资产货架全量重构与重新发布规格说明书 (Issue #1945)

## 1. 业务目标与背景
经过全量本地资产物理盘点与用户验收确认，彻底消除历史遗留的分类混淆、外链杂音与不可直接出片的灵感废料，确立以官方唯一公共资产桶 `omnimux-public` 与公网加速域名 `https://assets.omnimux.ai/` 为核心的全新云端资产分发体系。

## 2. 资产范围与收敛规格（6 大核心品类，共 6,536 项）
1. **角色 (character, 429款)**：
   - 二级分类极简呈现：
     - `digital-human`：数字人（359款，合并原有 329 款实景数字人 + 30 款写实人类原型）；
     - `meme`：流行网梗（25款）；
     - `fantasy`：奇幻世界（25款）；
     - `animal`：动物拟人（20款）。
   - **写实人类原型 30 条数据 8 维精细归属**：
     - 逐一根据角色职业、形象、背景赋予准确的 `gender`, `age`, `figure`, `industry`, `scene`, `pose`, `outfit`，使在「数字人」8 维下拉中 100% 精确可查；
   - **数字人音频安全核验**：
     - 确认发布版本使用已合成无版权安全音频（22.05kHz AAC）的全新 `video.mp4`，杜绝任何版权风险。
2. **素材 (material, 855项)**：
   - 彻底剔除 543 项不可直接出片的灵感参考图（服饰、萌宠、人像、插画、分镜、概念艺术等）；
   - 仅保留纯粹生产原料：【前三秒钩子 (705)】 + 【动态绿幕透明贴片 (150)】；
   - 修复视频流式预览与首帧自动抓取，彻底消灭破图。
3. **声音 (audio, 640项)**：
   - 配音 (527款)：100% 对齐画布音色库，打通「语言、口音、性别、场景」4 维下拉筛选；
   - 背景音乐 (108首) + 转场音效 (5款)：保留高品质音频试听。
4. **场景 (scene, 3,521项)**：
   - 全盘扩大检索范围，从 139 项扩充至 3,521 项真实实景空间拍摄素材；
   - 落地「场景 》6大二级类目 》三级细分小药丸」精准过滤（自然山水/生活室内/城市街景/出行车载/商务办公/休闲娱乐）。
5. **道具 (prop, 940项)**：
   - 彻底清退 125 个老旧生锈飞机机械零件；
   - 建立 3C数码 (172)、美妆个护 (114)、咖啡饮品 (124)、图书文具 (488)、乐器潮玩 (42) 5 大出片道具分类。
6. **风格 (style, 151款)**：
   - 保留真人影视、2D动漫、3D动画、调性氛围等 151 款 Prompt 出片预设。

- 唯一公共存储桶：`omnimux-public`
- 唯一对外加速域名：`https://assets.omnimux.ai/`
- 严禁任何 `media.aftermark.ai` 或临时未托管外部链接。

## 4. 验收与测试门禁
- 自动化单测覆盖率 100%；
- 分片编译生成完整 `manifest.json`、`index.json` 及各大类分页 JSON，结构合法无坏死引用；
