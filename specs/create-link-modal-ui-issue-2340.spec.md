# 从链接创建产品弹窗 UI 对齐参考交互

## 目标
参考图1（Creatify 风格）调整图2「从链接创建产品」弹窗：居中大标题、平台支持条、大输入框、主按钮「分析链接」+ 次链「或手动创建」。

## 用户旅程
1. 用户点「创建产品」→ 打开链接创建弹窗
2. 看到居中引导标题与支持平台标识
3. 粘贴链接 → 点「分析链接」（加载转圈）
4. 成功：关闭并选中新产品；失败：文案错误提示
5. 可选：点「或手动创建」进入手动创建路径（回调）

## 验收
- [ ] 无底部「取消/解析并创建」双按钮条；主 CTA 居中在输入框下
- [ ] 标题居中，关键词高亮
- [ ] 平台 logo 行可见
- [ ] 加载态主按钮显示转圈且禁用重复提交
- [ ] 业务：仍走 createProductFromLink（解析+保存）
- [ ] 演示页可交互验收

## 边界
- 总是：token 变量；busy 时禁止关闭误触可选
- 绝不：改后端 import 契约
