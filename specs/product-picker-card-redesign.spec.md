# 规格文档：产品选择器卡片视觉重构（1:1创建卡、多图缩略微标、移除价格标签）

**文件：** `specs/product-picker-card-redesign.spec.md` ｜ **优先级：** P0 ｜ **模块：** `plugins/omnimux` + `plugins/omnimux-products`
**变更面：** Client / ProductPicker / ProductPickerCard / ProductPickerAddCard / ProductGrid / Library View

---

## 1. 业务目标与需求对齐

根据设计参考图 1 与产品指令，对产品库选择器弹窗内的商品卡片和创建入口进行现代极简视觉重构：
1. **「创建产品」入口做大 1:1**：对标参考图 1/图 3 的 "Add product" 模块，将「创建产品」整卡做成 1:1 正方形，采用虚线边框、内部垂直水平居中购物袋矢量图标与标题，去掉冗余二级副标题，与产品卡片等比例统一。
2. **卡片内显示多个缩略图（最多 3 个 + 超量计数）**：在产品卡片封面大图左下角悬浮展示该产品包含的素材缩略微图队列，最多显示 3 个，若总图数超过 3 个，则在第 4 个位置展示 `+xx` 超量计数徽标（如 `+11`）。
3. **移除当前的价格标签**：彻底移除当前卡片封面左下角浮动的价格胶囊标签（如 `¥S$8.00` 等），降低视觉噪点，聚焦商品图片与核心素材。

---

## 2. 详细验收标准（Acceptance Criteria）

### 2.1 「创建产品」1:1 正方形卡片 (P0)
- **AC-101**：`ProductPickerAddCard` 整体尺寸比例为 `1 / 1` 正方形，网格内占据一个标准产品卡宽度。
- **AC-102**：卡片样式为圆角（14px）与灰色虚线边框（`1.5px dashed var(--dsw-alias-border-l3)`），背景透明微层底色。
- **AC-103**：卡片内部垂直居中且水平居中，包含一个精致的线框购物袋矢量图标（Shopping Bag Icon，零 Emoji）与「创建产品」文字标签，移除原底部独立的 `omx-product-pick-card__body` 描述区域。
- **AC-104**：整卡具备完整的键盘无障碍（`role="button"`, `tabIndex={0}`, Enter/Space 激活）与点击唤起链接创建弹窗能力。

### 2.2 多图缩略微图与超量徽标 (P0)
- **AC-201**：商品卡片（`ProductPickerCard`）封面大图左下角支持渲染多图预览条（`.omx-product-pick-card__thumbs-row`）。
- **AC-202**：缩略图队列最多渲染 3 个，单图尺寸 22×22px，圆角 3px，带 1px 细微半透明边框，`object-fit: cover`。
- **AC-203**：当商品关联图片数大于 3 时，在第 4 位渲染超量指示器徽标（如总数 14 张，前 3 张展示图片，第 4 位展示 `+11`）。
- **AC-204**：当商品仅有 1 张图或无素材时，不展示底部缩略微图条，保持封面纯净。
- **AC-205**：服务端 `listViewOf` 增加 `media_previews` 字段（包含可用图片列表的前若干项），前端优先读取该字段及 `product.media` / `product.thumbnails`，并支持生成标准的图片预览地址。

### 2.3 价格标签移除 (P0)
- **AC-301**：`ProductPickerCard` 中彻底移除 `omx-product-pick-card__badge` 及其价格展示节点。
- **AC-302**：保留产品名称（单行省略）与产品分类（`typeLabel`）。
- **AC-303**：保留左上角单选勾选框，确保选中态视觉一致。

## 3. 设计规范与质量门禁

- **零 Emoji 准则**：所有图标均采用无侵入的干净 SVG 矢量图。
- **设计令牌**：严格遵循 `--dsw-alias-*` 系列全局设计变量与深色极简风格。
- **真实浏览器验证**：在独立工作树中生成端到端测试用例与高保真交互演示单页，通过真实浏览器完成视觉走查与截图留证。
