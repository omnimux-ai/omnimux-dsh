# #3395 精简模型配置并保留官方账号入口

## 目标
开发版移除 OmniMux 多余的模型服务、自带密钥、本地代理与画布默认模型配置页面。保留 OmniMux 账号入口，以及官方深度求索账号/API 配置；修复实际缺失的本仓装配。

## 边界
不修改官方 Harness、其他源码工作区或生产安装。不删除凭据、会话和项目，不发送真实模型请求。开发版非秘密设置是用户明确指定的目标：经最小范围备份及恢复校验后，仅移除本机中转渠道、撤销清空官方目录的覆盖，并将指向已移除渠道的默认值改为当前清单已有的 OmniMux 模型；保留其余设置与文件权限。

## 新用户基线
仅依赖随包安装的官方账号服务和 OmniMux 插件。未登录时显示既有登录或密钥配置流程；不依赖开发机私有代理、端口或模型别名。

## 验收
- 多余模型配置的注册来源被移除，不能用 CSS/DOM 遮挡。
- OmniMux 账号入口可达，官方深度求索配置来自官方现有服务。
- 本仓适用自动检查通过，并在隔离工作树取得真实浏览器功能路径证据；区别局部证据与完整装配状态。
- 独立评审通过，按仓库流程合并并更新开发版，保留证据后清理任务工作树。

## 已查明的版本边界
当前开发安装包提供官方 API 密钥配置，未包含新版官方账号网页登录包。此次恢复官方 API 目录，不伪造新版登录能力，也不包含跨仓运行包升级。

## 文档影响
更新设置归属合同，描述当前实际保留的配置入口；不改变模型路由合同。
