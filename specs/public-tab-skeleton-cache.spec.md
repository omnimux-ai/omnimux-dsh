# 资产中心「公共」页签 · 骨架屏 · 缓存 规格 (Issue #1990)

## 1. 背景
资产中心顶部有「本地 / 云端 / 产品库」三个页签。用户要求：
1. 「云端」这个名字不够直白，改为「公共」；
2. 切页签或翻页时，卡片区是一片空白然后突然出现，缺少加载过渡，观感突兀；
3. 每次进入或切回都要重新请求，访问速度与稳定性都不够，需要缓存。

## 2. 目标

### 2.1 页签更名
- 中文页签由「云端」改为「公共」；英文由 `Cloud` 改为 `Public`。
- 其余页签（本地 / 产品库）不变。

### 2.2 骨架屏加载过渡
- 首次加载（清单或首页分片在途、且当前没有任何卡片）时，卡片区渲染**骨架卡片网格**，数量与真实网格一致（按当前网格列数铺满一屏）。
- 骨架卡片必须占位在真实卡片的位置与尺寸上（同一个缩略图高度、同一行标题高度），数据到达时**不产生布局跳动**。
- 骨架带**克制的呼吸动画**（透明度或微光扫过），跟随主题 token，深浅色下均可用，不做花哨动效。
- 骨架期间不显示「没有素材」空状态；数据为空且已加载完成时才显示空状态。
- 加载更多（已有卡片、在途追加）不铺骨架，沿用既有按钮在途态。

### 2.3 缓存
- **分页缓存**：已加载过的（分类 + 二级分类 + 筛选 + 页码）结果缓存在内存里；再次命中同一组合时**同步返回缓存**，不发请求，卡片立即可见。
- **媒体缓存**：同一张图片/视频 URL 在一次会话内不重复解码加载；滚动来回不闪白。
- **清单缓存**：`manifest.json` 拉取成功后缓存，页签来回切换不重复请求。
- 缓存**有容量上限**，超出按最久未用淘汰，不得无限增长。
- 缓存**不得跨账号/跨环境串数据**：键必须包含分类与筛选条件；错误结果不入缓存。

## 3. 验收标准
- **AC-1** 中文界面上页签文案为「公共」，英文为「Public」；`source.cloud` 在两种语言下均不再出现「云端 / Cloud」字样。
- **AC-2** 首次进入公共页签时，卡片出现前有骨架网格；骨架卡片数量等于网格列数（至少 6 张）。
- **AC-3** 骨架与真实卡片的缩略图高度一致，切换瞬间无高度跳动。
- **AC-4** 数据加载完成后骨架完全消失，不残留任何骨架节点。
- **AC-5** 空结果显示空状态而非骨架。
- **AC-6** 同一分类来回切换第二次不发新请求、卡片立即出现。
- **AC-7** 缓存容量有上限且按最久未用淘汰（有单测锁定）。
- **AC-8** 既有单元测试与端到端测试不回归（基线上 `tabs-spacing.e2e.test.js` 的既有失败除外）。
