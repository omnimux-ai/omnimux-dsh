# #1934 工作台页面检查当前模型规格

## 1. 问题与目标

共享页面检查仍模拟旧右栏状态，并断言左栏入口打开后进入已取消的全屏焦点，因此在现行“官方右栏当前页签 + 分栏打开 + 会话记录优先”行为下产生误报。目标是只更新受控 Host、检查断言和对应合同，使检查表达当前真实业务规则，不修改账户或其他一级页的产品代码。

## 2. 当前规则

1. 官方右栏是否展开及其当前页签是页面激活的真实来源。
2. 一级页从左栏打开时使用分栏，保留中间会话列。
3. 当可见会话记录行处于选中状态时，它占用左栏唯一激活位，所有插件入口保持非激活；该状态结束后，当前右栏页签对应入口才激活。
4. 同一页面重复打开只保留一个页签；关闭、重开和切换会话时状态互不泄漏。

## 3. 实施范围

- 在共享受控 Host 中提供当前官方右栏的展开状态和当前页签，并在状态变化时同步单一激活裁决。
- 将页签已注册/已打开与左栏入口是否高亮分开断言。
- 将过期的全屏焦点断言更新为分栏，并补充“会话记录优先”的明确回归。
- 更新 `docs/contracts/workbench-split.md` 中已经过期的默认焦点、一级页入口和单一激活说明。
- 不修改任何账户插件产品代码或真实运行时行为。

## 4. 验收标准

| 编号 | 可观察结果 | 判定方式 |
| --- | --- | --- |
| S-1 | 所有发布中的一级页均能在受控 Host 内注册并打开官方右栏页签 | 页面检查全部通过 |
| S-2 | 打开与重开保持分栏，中间会话可见，不再要求全屏焦点 | 检查断言与真实浏览器几何 |
| S-3 | 当前页签只出现一次，关闭后可重开；会话 A 与会话 B 的页签状态隔离 | 页面检查 |
| S-4 | 会话记录可见且被选中时，插件左栏入口不高亮；会话不再占位时，当前页签入口恢复高亮 | 自动化断言与真实浏览器旅程 |
| S-5 | 右栏页签已挂载且宽高均大于零，操作过程没有控制台错误 | 隔离真实浏览器证据 |
| S-6 | 工作台合同明确一级页默认分栏、官方右栏当前页签和会话优先规则 | 文档检查与独立复核 |
| S-7 | 账户业务代码和其他一级页业务代码无改动 | 实际差异 |

## 5. 真实浏览器旅程

在当前任务工作树中使用动态端口、隔离资料目录和自清理运行：

1. 打开包含可见且已选中会话记录的工作台夹具。
2. 点击“账号”；确认右栏账号页签挂载、宽高为正、只出现一个页签，中间会话仍可见。
3. 确认会话记录仍是左栏唯一激活项，账号入口不高亮。
4. 让会话记录不再占用激活位，确认账号入口随当前右栏页签高亮。
5. 重复点击账号、关闭并重开右栏，确认页签不重复且仍为分栏。
6. 切换到另一会话再返回，确认状态隔离与恢复；保存截图和结构化结果，关闭所有临时浏览器空间与进程。

## 6. 检查顺序

1. 页面检查定向运行。
2. 与右栏、分栏、侧栏单一激活相关的回归测试。
3. 任务工作树内真实浏览器验证。
4. 门禁脚本测试、页面静态门禁与完整仓库门禁。

## 7. 非目标

- 不恢复全屏打开，不更改页面视觉设计，不新增交互。
- 不更改生产设置、账户数据、登录、凭据或发布行为。
- 不使用开发版 45120 作为 Agent 交付证据。
- 不通过豁免、跳过或放宽检查取得通过。
