# 素材卡槽悬浮预览：卡片随图比例 + 操作按钮外置

## 用户操作旅程

1. 用户在创作画布上把上游素材（图片 / 视频）连到下游节点的「参考素材」槽位。
2. 鼠标悬停该槽位，弹出预览卡片。
3. 用户看到：**卡片尺寸与图片本身比例一致**（竖图是竖卡、横图是横卡、方图是方卡，卡片不为固定比例预留空白），图片下方、卡片外侧排着「替换」「停用」两个按钮。
4. 用户点「替换」或「停用」执行操作，或把鼠标移开卡片与按钮区域后自动关闭。

## 验收标准

| 编号 | 判定要求 | 判定方式 |
| --- | --- | --- |
| A1 | 卡片宽度由图片自身尺寸决定，不占满一个固定宽度 | 真机取卡片矩形与图片自然尺寸比对 |
| A2 | 卡片宽高比与图片自然宽高比一致（容差 ±3%） | 同一张方形图与同一张竖图分别悬停，卡片比例随之变化 |
| A3 | 操作按钮组位于卡片**外侧**，纵向在卡片下方 | 真机取两者矩形，按钮上沿 ≥ 卡片下沿 |
| A4 | 卡片自身仍有背景、边框与圆角（视觉上是一张卡） | 真机取计算样式 |
| A5 | 两个按钮仍为横向单行，文案为「替换」「停用」 | 真机取按钮矩形与文案 |
| A6 | 媒体超高时卡片高度被视口夹紧，按钮组不被挤出可视区 | 压力场景：把媒体高度拉到 520px |
| A7 | 悬停区判定不被破坏：指针在卡片或按钮组内不关闭，移出约 180ms 后关闭 | 真机指针移动验证 |

## 非目标

- 不改变悬停触发时机、关闭延迟、键盘可达性（Esc / Tab）与无障碍语义。
- 不改变卡片内的文案（`替换` / `停用`）与既有配色令牌体系。
- 不引入新的定位算法：仍复用 `calculatePopoverPosition` 的视口夹紧与上下翻转策略。

## 基线（改动前）

- 卡片与操作按钮同属一个容器：卡片背景/边框包住「媒体 + 按钮行」。
- 卡片宽度固定为 240，媒体按 `max-width: 100%` 撑满，卡片恒为 240 宽，小图会在卡内留下空白。
- 按钮在卡片内侧。

## 影响面

- 仅 `SlotHoverPreview.tsx` 与 `components.css` 的 `.wf-slot-hover-preview*` 规则。
- 弹层的既有查询选择器都是「祖先 + 后代」形式（`.wf-slot-hover-preview button`、`.closest('.wf-slot-hover-preview')`），结构下沉一层后仍成立。
