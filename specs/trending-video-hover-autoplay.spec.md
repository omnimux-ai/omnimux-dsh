# 爆款对标视频卡片鼠标悬停自动播放规格 (Issue #2070)

## 1. 业务背景
在欢迎页与会话引导的爆款对标板块（`TrendingReplicateSection`）中，用户浏览热门视频卡片（`TrendingVideoCard`）时，当前卡片仅展示静态封面或矢量构图。用户反馈希望在不发生页面跳转或弹窗打断的情况下，快速了解视频的动态表现与黄金前3秒镜头节奏：
- **需求目标**：鼠标光标悬停在视频卡片上时，卡片支持自动静音循环播放视频片段预览；光标移出后立即停止播放并平滑复位，恢复封面静态展示。
- **新增轮播图格式**：新增横向单行轮播图浏览格式（Carousel），鼠标悬停于轮播区域时，浮现圆润毛玻璃左右切换按钮，支持平滑左右滚动切换，悬停在单个卡片上同样支持自动播放预览。

## 2. 交互与技术架构设计
1. **数据源规范化与链路贯通**：
   - 灵感库返回的原始行数据中可能携带 `media_urls`、`video_url`、`videoUrl`、`video` 等不同命名的媒体直链或网关路径；
   - 在 `trending-source.js` 的 `mapSourceItem` 中新增 `videoUrl` 字段提取与规范化（`normalizeVideoUrl`），支持本地媒体路径（`/omnimux/inspiration/local/media/...`）、云端媒体网关路径（`/omnimux/inspiration/media/...`）及远程标准 HTTP/HTTPS 直链。
2. **悬停激活与防抖机制**：
   - 在卡片媒体区（`TrendingCover` / `TrendingVideoCard`）监听光标进入与离开；
   - 引入 150ms 悬停延迟防抖（hover debounce），避免用户快速扫过网格时瞬间触发大量视频并发解码造成掉帧与卡顿；
   - 光标移出卡片时，立即取消延迟定时器、停止播放并将播放进度归零（`currentTime = 0`），隐藏或卸载播放器实例，平滑展现静态封面。
3. **播放性能与浏览器策略兼容**：
   - 视频标签配置：`muted={true}`（现代浏览器硬性静音自动播放策略）、`playsInline={true}`、`loop={true}`、`autoPlay={true}`、`preload="metadata"`；
   - 样式层级与事件穿透：视频元素应用 `pointer-events: none` 与 `position: absolute; inset: 0; object-fit: cover;`，绝不干扰卡片的原有点击行为（卡片点击选择、复刻 CTA 按钮点击、拖拽等保持绝对灵敏）；
   - 视觉过渡与优雅降级：视频采用淡入淡出（opacity 240ms 过渡），首帧就绪后柔和展示；若视频资源缺失或加载失败（`onError`），自动平滑降级，仅展示静态封面，不出现破图或报错提示。
4. **轮播图格式与左右滑动切换**：
   - 在工具栏右侧提供视图模式切换器（网格 / 轮播图），支持无缝切换与偏好记忆；
   - 轮播图模式（`TrendingCarousel`）采用平滑横向滚动轨道，隐藏原生滚动条；
   - 鼠标悬停在轮播区域时，左右两侧圆形毛玻璃导航按钮平滑淡入（`opacity: 1`），移出时淡出；
   - 点击左/右按钮按视口步长平滑滑动（`scrollBy`），边界自动禁用对应按钮。
5. **卡内多图轮播（多图卡片）**：
   - `trending-source.js` 新增 `readImages`，从 `images` / `media_urls` / `slides` 提取图集并归一化路径；`mapSourceItem` 输出 `images` 与 `isCarousel`（图数 > 1 即为轮播卡）；
   - 多图卡片在卡片内部叠放整组图片（`is-carousel-layer`），靠透明度切换实现交叉淡入，翻图不闪白；
   - 鼠标悬停在卡片上时，卡内左右两侧浮现圆形翻图按钮（静置时完全不可见），点击原地逐张切换并循环；
   - 卡片右上角常显 `当前张/总张` 页码标记，悬停时顶部浮现分页圆点；
   - 多图卡片**翻图优先**：同一张卡上翻图与视频预览互斥，避免两种动作抢同一块画面；
   - 翻图按钮使用 `preventDefault` + `stopPropagation`，绝不冒泡触发卡片自身的点击（复刻 / 选择）；
   - 单张图加载失败自动从图集剔除，不回落到破图。

## 3. 验收标准（AC）
- **AC-1（数据源提取）**：`mapSourceItem` 能从灵感库原始记录中准确提取并规范化 `videoUrl` 字段，缺失时安全降级为空串。
- **AC-2（悬停自动播放）**：鼠标光标悬停在有视频资源的对标卡片上超过 150ms 时，自动挂载并播放静音循环视频（`muted`、`loop`、`playsInline`）。
- **AC-3（移出即时复位）**：鼠标光标移出卡片时，视频立即停止播放并复位，平滑恢复静态封面。
- **AC-4（无视频/异常优雅降级）**：无视频资源或视频加载失败时，卡片保持清晰静态封面，绝不白屏、绝不报错。
- **AC-5（原生动作与交互不受阻）**：视频元素具备 `pointer-events: none`，卡片内复刻按钮、卡片本身的点击与焦点行为完全不受影响。
- **AC-6（视图模式切换）**：工具栏支持在网格与轮播图之间切换，切换即时生效。
- **AC-7（轮播图悬停显示左右按钮）**：轮播图格式下鼠标悬停时平滑显示左右滑动按钮，离开时隐去；点击按钮平滑左右滚动。
- **AC-8（卡内多图轮播）**：多图卡片（`images.length > 1`）在卡片内部提供左右翻图按钮、页码标记与分页圆点；点击翻图逐张切换并循环，且不触发卡片自身点击。
- **AC-9（单图卡不受污染）**：单图卡片不出现任何翻图控件，且悬停仍走视频预览路径。
- **AC-10（质量门禁与全绿测试）**：全量单元测试与回归测试 100% 通过。
