# 规格说明书：三分栏会话栏宽度改为「派生态」，废除记忆式基准（工单 #2074 续 3）

## 1. 背景与问题定义

三分栏（左栏 + 会话栏 + 工作台）的栅格同时被三方写入：外壳 authored 的内联
`grid-template-columns`（第 1、3 轨）、插件样式表的 `!important` 规则（收起态保宽）、
插件 JS 发布的 `--omnimux-conversation-width`。前两轮修复（#2087 / #2091）让「收起左栏保宽」
在正常路径上稳定，但开发版真机 CDP 复测暴露第三个缺口：

```
收起左栏 → 拖动会话栏/工作台分界线 +260 → 会话栏 476px 纹丝不动（渲染被保宽钉住）
          但外壳内部第三轨 1164px → 904px（外壳照常处理拖拽）
再次展开 → 会话栏 476px → 736px   ← 两份状态分叉后，展开时宽度跳变
```

根因有两条，都在「记忆式基准」这一设计上：

1. 保宽值来自**记忆**（`lastGoodConversationWidth` + 取样阈值 + 点击瞬间快照），
   与外壳当前的分栏输入无关；收起态把它钉在第二轨，于是分界线拖拽在渲染上被吞掉。
2. 几何同步循环只由 ResizeObserver（侧栏列 / 工作台面板 / 标签栏）与既有属性观察者触发。
   收起态保宽让工作台**渲染宽度不变**，ResizeObserver 不触发；外壳改写内联栅格也无人观察
   —— 实测拖拽全程 `--omnimux-conversation-width` 零次写入（`setProperty` 计数不变）。

## 2. 验收标准（Acceptance Criteria）

- **AC-401（派生态取代记忆态）**：`--omnimux-conversation-width` 由「外壳 authored 内联栅格 + 视口宽度」
  当帧推导，不再来自记忆基准、取样阈值或点击瞬间快照；对应的记忆状态（`lastGoodConversationWidth`）、
  取样函数与快照调用一并删除。
- **AC-402（展开态零改写）**：左栏展开时插件不改写栅格（沿用外壳原生 `1fr` 弹性列），
  派生值与原生剩余宽度一致；分界线拖拽由外壳原生处理。
- **AC-403（收起仍保宽）**：收起左栏时会话栏像素宽度不变（等价 AC-101），
  释放的左栏宽度全部交给工作台（等价 AC-102），第一轨 0px。
- **AC-404（分界线双向可用）**：无论左栏展开还是收起，拖动原生分界线都会改变会话栏宽度；
  外壳 authored 第三轨与渲染结果保持同步，因此随后的展开/收起不再产生宽度跳变。
- **AC-405（拖拽可观测）**：几何同步循环必须观察外壳 authored 内联栅格的改写，
  使派生值在拖拽过程中逐帧跟随（收起态下工作台渲染宽度不变，ResizeObserver 不会触发）。
- **AC-406（非分栏形态不污染）**：外壳未暴露第三轨（右栏收起 / 尚未挂载）时，
  派生值回到契约回退值，且该形态的样式规则不消费该变量。

## 3. 非目标

- 不改动原生外壳（`omnimux-desktop-fork`）任何代码。
- 不新增样式规则；收起态保宽规则与右栏收起、会话栏收起的既有规则保持不变。
- 不引入新的持久化（localStorage / 会话存储）。

## 4. 测试与验证要求

1. 单元测试：`deriveConversationWidthPx` 在三分栏展开态等于「视口 − 左栏 − 外壳第三轨」；
   在收起态等于同一数值（保宽）；外壳第三轨为 0 / 缺失时回退到契约值；
   派生值不低于地板值；导出面不再包含记忆式取样函数。
2. 源码契约回归：保宽规则仍引用 `--omnimux-conversation-width`，且几何写入方仍发布该变量。
3. 真机 CDP 复测（开发版 1920 视口）：收起左栏 → 拖动分界线 → 会话栏宽度随拖拽变化 →
   展开左栏后会话栏保持拖拽后的宽度、工作台恢复原宽度（无跳变）。
