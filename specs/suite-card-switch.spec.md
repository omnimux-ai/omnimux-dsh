# 规范：套件卡片支持安装/卸载状态开关与弹窗交互闭环

> 任务真源：Issue #1722 · 分支 `agent/market-suite-card-switch-issue-1722`。
> 本文件是本任务人与 Agent 共享的验收真相源：写码前定死"建什么、怎样算完成"。

## 1. 业务目标与背景

### 1.1 现状与痛点

1. **视觉规范不统一**：技能市场普通单技能卡片右侧均具备圆角滑动开关（`WorkshopSwitch`），已安装开、未安装关；唯独套件分类下的套件卡片右上角留白空旷，没有任何开关，视觉上显得缺位；
2. **状态感知较弱**：用户无法扫一眼列表直观知道哪些套件已就位、哪些未就位；
3. **用户明确诉求**：
   > “套件应该也有一个安装开关？展示状态和触发安装/卸载事件？评估下？立即实施”

### 1.2 目标

1. 在技能市场所有套件卡片右侧（包含套件分类、以及全部列表里的套件卡）统一渲染 `WorkshopSwitch` 开关，与普通技能卡片视觉形态 100% 保持一致；
2. 开关实时反映当前套件的安装状态：已安装（或出厂预装且未卸载）展示为开启高亮；未安装展示为关闭；
3. 兼顾快捷与批量操作防误触：点击开关阻断卡片点击冒泡，按状态流转打开安装或卸载确认弹窗，确认后平滑切换开关状态。

## 2. 交互与视觉契约

### 2.1 卡片排版与开关位置

- 卡片复用既有的 `.regular-card` 结构；
- 卡片右侧挂载 `WorkshopSwitch`（`.toggle-wrap`），与左侧信息区自适应并排；
- 点击卡片左侧信息区：仍然打开对应的套件详情弹窗（`SuiteDetailModal`）；
- 点击卡片右侧开关：`e.stopPropagation()` 阻止打开详情弹窗，根据开关当前状态触发确认逻辑。

### 2.2 开关触发流转（防误触弹窗守卫）

1. **未安装态（开关处于关闭/置灰状态）**：
   - 用户点击开关：弹出该套件的「安装确认弹窗」（列出包含的技能数、规则数、Agent数；若有规则则允许选择写入当前项目或全局）；
   - 用户点击「取消」：弹窗关闭，开关维持关闭状态；
   - 用户点击「确认安装」：调用 `api('suiteInstall', ...)`，安装成功后开关平滑切为开启状态，卡片标记为已安装。
2. **已安装态（开关处于开启/绿色高亮状态）**：
   - 用户点击开关：弹出该套件的「卸载确认弹窗」（提示确定卸载「xxx」吗？将影响 xx 个技能）；
   - 用户点击「取消」：弹窗关闭，开关维持开启状态；
   - 用户点击「确认卸载」：调用 `api('suiteUninstall', ...)`，卸载成功后开关平滑切为关闭状态，卡片标记为未安装。
3. **与详情页操作的双向同步**：
   - 在详情页中点击安装或卸载，关闭详情页后，货架卡片上的开关状态同步更新；
   - 在卡片上拨动开关完成安装或卸载，点进详情页后，按钮状态同步更新。

## 3. 技术落点

- `plugins/omnimux-market/src/client/plaza/PlazaCardGrid.jsx`:
  - 移除对套件卡片隐藏开关的硬编码限制（`isSuite ? null : h(WorkshopSwitch, ...)` 改为套件也正常渲染 `WorkshopSwitch`，`checked: isChecked`）；
  - `onSwitchChange` 传入 `(e) => { e?.stopPropagation?.(); onToggle(item); }`；
- `plugins/omnimux-market/src/client/skill-plaza.js`:
  - 在 `renderPlazaModals` 或 `onConfirm` / `onToggle` 逻辑中，当 `item.kind === 'suite'` 时，拦截单技能的快捷开关，打开对应的套件安装/卸载模态弹窗；
- `plugins/omnimux-market/tests/e2e/suite-marketplace.spec.js`:
  - 更新 E2E 测试用例：断言套件卡片包含 `.toggle-wrap`，并且 TikTok 套件卡片开关为 checked=true，未安装套件为 checked=false；
- 真实 Chrome 浏览器验证留存截图与报告。

## 4. 验收标准（可测）

- [ ] **A1 开关挂载**：套件分类下的所有套件卡片右侧均渲染 `WorkshopSwitch`（包含 `.toggle-wrap`）。
- [ ] **A2 状态准确**：TikTok 预装套件出厂开关默认开启；未安装套件（如亚马逊套件）开关默认关闭。
- [ ] **A3 冒泡隔离**：点击开关不会直接展开详情页，而是弹出对应的安装/卸载确认框。
- [ ] **A4 卸载触发**：点击开启态开关，弹出卸载确认框；确认卸载后开关切为关闭。
- [ ] **A5 安装触发**：点击关闭态开关，弹出安装确认框；确认安装后开关切为开启。
- [ ] **A6 详情页联动**：在详情页完成卸载或安装后，卡片开关实时联动更新。
- [ ] **A7 测试全绿**：单测与端到端测试 100% 跑通。
- [ ] **A8 真实浏览器验证**：在隔离工作树通过真实 Chrome 执行验证并留存截图与结构化报告。

## 5. 边界

- **总是**：防误触弹窗守卫（不得对套件做静默秒开秒关）；点击开关阻止冒泡；不影响普通技能卡片既有逻辑。
- **绝不**：把规格镜像到主检出；在主干直接 commit；改动其他非相关插件。
