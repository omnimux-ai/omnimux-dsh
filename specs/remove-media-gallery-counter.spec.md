# 助手回复多素材画廊 · 移除右上角序号角标规格

## 1. 背景与目标
在多素材画廊已具备右侧纵向缩略图列表和当前选中高亮指示的情况下，主视图右上角浮动的序号角标（例如 `3 / 3`）存在信息冗余，且遮挡了主图片/视频的右上角画面。
目标：彻底移除主视图右上角的序号角标元素及对应样式。

## 2. 验收标准
- **AC-1**：多素材画廊中不再渲染 `.omx-chat-media-tail__counter` 元素。
- **AC-2**：单元测试与端到端测试同步断言无序号角标。
- **AC-3**：实机运行画面右上角无任何角标遮挡。
