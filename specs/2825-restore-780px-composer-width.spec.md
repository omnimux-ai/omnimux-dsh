# 规格：恢复新会话输入框 780px 经典舒适打字宽度 (Issue #2825)

## 一、背景与问题定义
在新会话引导页（全宽大屏及默认状态下），当前输入框上限被拉宽为 952px（来自 `--dsh-composer-card-max-width`），导致大屏下输入框过于扁平空旷，破坏了与下方 1200px 内容卡片的金字塔视觉重心比例。

## 二、架构设计原则：黄金舒适打字宽度
1. **输入框与工作区选择行独立收敛**：
   - 输入框卡片：`max-width: min(780px, calc(100% - 24px))!important;`
   - 工作区选择行：`max-width: min(780px, calc(100% - 24px))!important;`
   - 两者保持居中（`margin-inline: auto!important;`），与下方 1200px 内容区形成舒展有度的视觉梯度。
2. **吸底停靠几何对齐**：
   - 停靠计算（`dockGeometry` / `DOCK_MAX_WIDTH`）：对齐 780px 上限，确保无论在 inline 还是 docked 态下，输入框宽度保持一致，消除跳动。

## 三、用户关键旅程与验证规范
1. **全宽大屏新会话首页**：
   - 输入框最大宽度封顶 780px，水平优雅居中；
   - 视觉比例匀称，消除 952px 扁平拉伸死区。
2. **吸底停靠态**：
   - 滚动并点击卡片吸底时，输入框停靠宽度保持 780px 居中。
