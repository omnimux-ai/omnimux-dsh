# 规格：会话级视窗模式状态机与会话栏记忆彻底收敛

> **已被替代（Issue #2516）**：点会话必须看见聊天。新对话是会话全屏，不继承上一条会话的三栏。旧会话仅在用户亲手打开过聊天时恢复三栏。右侧全屏只属于页面入口，不得随会话点击带回来。现行真源：`specs/primary-entry-fullscreen.spec.md`。

Issue: #2362
插件: omnimux
日期: 2026-09-18

## 1. 目标

解决用户在右侧侧边栏点击全屏后，切换右侧页签再返回时始终默认显示中间会话栏展开、无法在该会话中保持全屏状态的缺陷；彻底消除在不同会话间切换时会话栏跳来跳去、一会儿开一会儿关的恶性循环。
将全屏/分栏（会话栏折叠/展开）的视窗模式所有权完全收敛到**会话唯一标识（Session ID）**，在同一个会话内切换任意页签始终锁定用户偏好；不同会话间严格隔离并持久化记忆。

## 2. 成功标准

1. **同会话内切页视窗绝对锁定**：用户在某个会话中开启全屏后，在右侧面板切换任意工作台页签（如从“项目”切到“图像生成”再切回），视窗模式始终保持全屏，中间会话栏绝不自动弹出或跳变。
2. **多会话严格隔离与持久化记忆**：同一工作区内的每个会话独立持久化记录自己的视窗开闭偏好（`fullscreen` 全屏折叠 / `split` 分栏展开），保存在以 `sessionId` 为隔离键的本地持久化中。会话 A 设为全屏、会话 B 设为分栏，互不干扰。
3. **切换会话平滑精准还原**：彻底剔除会话列表点击监听中的暴力重置代码。切换到会话 A 时自动平滑还原 A 的全屏偏好；切换到会话 B 时自动还原 B 的分栏偏好；新会话或无记录时默认分栏。
4. **消除跨会话模块级缓存串扰**：`conversation-collapse.js` 内部消除模块级单例共享变量，全面改为以 `sessionId` 为键的隔离缓存与持久化映射。
5. **自动化与回归验证 100% 绿灯**：覆盖同会话切页全屏锁定、跨会话状态独立还原、点击会话行不误杀全屏等全量单元测试与真实无头浏览器验证。

## 3. 边界规范

- **总是**：
  - 以当前会话 `sessionId` 作为视窗开闭记忆的唯一真源主键。
  - 用户手动点击全屏或退出全屏时，同步写入当前 `sessionId` 的持久化状态。
  - 切换会话时，根据目标 `sessionId` 的存储值平滑联动右侧面板模式与会话栏折叠状态。
- **绝不**：
  - 绝不在右侧切换 Tab 时因为目标 Tab 未记录全屏而擅自调用 `exitFullscreen()`。
  - 绝不在点击左侧会话列表项时盲目调用 `ensureConversationVisible()` 暴力抹杀全屏。
