# 规格：三栏状态下右侧切换标签用户当前状态优先（禁止全屏覆盖）

Issue: #2212
插件: omnimux
日期: 2026-09-17

## 1. 目标

在三栏工作状态下（左侧导航 + 中间会话展开 + 右侧工作台分栏展示，面板模式为 `push`），用户在右栏顶部 Tab 栏切换标签页时，用户当前的三栏并排工作流状态绝对优先，禁止因为目标标签曾存有全屏历史偏好而自动执行全屏拉伸，确保中间会话栏恒定可见展开，不被强制全屏破坏或折叠覆盖。

## 2. 成功标准

1. **当前状态优先护栏**：当宿主右栏处于分栏模式（`currentMode === 'push'`）时，无论目标 Tab 历史记录是否为 `gui` 且 `explicit: true`，切换 Tab 恒定保持 `push` 分栏模式，绝对不调用 `enterFullscreen()`。
2. **中间会话栏零折叠**：三栏分栏状态下切换任意 Tab，`document.documentElement` 上的 `data-omnimux-conversation-collapsed` 与 `data-omnimux-fullscreen-collapse-snapshot` 恒定不被设置，中间会话栏保持展开。
3. **健康分栏宽度保底**：三栏分栏状态下切换 Tab 时，继续执行 `ensureHealthySplitWidth(doc)`，确保右侧面板维持舒适黄金比例宽度（≥500px）。
4. **全屏进入权归还用户**：从分栏进入全屏，必须且仅能由用户主动点击右上角全屏按钮触发，切换 Tab 过程中全面禁止自动进入全屏。
5. **单测与回归测试 100% 绿灯**：覆盖分栏状态下切换历史全屏 Tab 保持分栏、用户主动点击全屏仍可正常进入全屏等全部场景。

## 3. 边界

- **总是**：尊重用户当前正在三栏对话的工作流意图；保持会话区域清晰可见；零破坏原生全屏按钮功能。
- **绝不**：在分栏状态下因切 Tab 自动调用 `enterFullscreen()`。

## 4. 验证

- 单测：在 `push` 状态下，切换到已记录 `mode: 'gui', explicit: true` 的工作台页签，面板状态保持 `push`，不进入全屏。
- 单测：在 `fullscreen` 状态下，切换到已记录 `mode: 'split', explicit: true` 的工作台页签，调和退出全屏至 `push`。
- 端到端：模拟三栏状态下连续切换创作画布、资产库、自动化、灵感社区、项目等标签，会话栏持续展开。
