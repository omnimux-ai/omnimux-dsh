# 灵感库卡片：默认只显示内容，悬停显示操作层（Issue #3502）

## 授权与范围

用户 2026-10-21 基于 Dev 实机截图提出：卡片默认只显示内容（图片/视频只显示封面；帖子显示收敛正文且高度不超过竖屏比例），标题/元信息/角标/⋯/复选框/CTA 等非内容元素在悬停或键盘聚焦时显示；「详情」「立即复刻」在卡片内水平居中；每张内容卡都要有 ⋯ 更多菜单，支持「添加到对话」与「删除」（云端卡仅添加到对话）；失败状态收敛为常显小图标，悬停图标才显示原因。

交付含实现、最小充分检查、隔离工作树真实浏览器证据、独立评审、常规 PR/Merge Queue、主干同步、Dev 物化与工作树清理。不改 HTTP、存储、schema；账号监控卡与弹窗不动；合集文件夹卡的删除不在本次范围。

## 新用户基线

已安装并登录的新用户无需额外配置即可浏览本地灵感库与云端爆款；卡片只消费既有列表响应、本地媒体路由与官方 composer 附件桥。空库、无活动会话、附件桥不可用均给出明确提示，不伪造成功。

## 确定行为

- 媒体卡（根层与合集成员）：默认只有封面；悬停或键盘聚焦时封面出现渐变操作层，包含两行标题、元信息行（平台 · 播放量（有数据时）· 时间）、水平居中的「详情 / 立即复刻」。类型/时长角标不再常显，也不在悬停层重复。
- 帖子卡：默认显示最多 3 行收敛正文（正文即内容，不隐藏）；高度 `max(144, 24 + 行数×20 + 24 + 2)` 且不超过 `(列宽−2) × 16/9`。悬停时显示元信息行、水平居中 CTA、⋯ 菜单与复选框。
- ⋯ 菜单默认隐藏，悬停/聚焦出现：本地卡为「添加到对话」「加入合集」（合集内为「移出合集」）「删除」；云端卡仅「添加到对话」。删除复用既有批量删除确认弹窗（n=1），确认后移入废纸篓并刷新列表。
- 「添加到对话」复用「加入会话」语义：生成该卡片的 Markdown 附件并通过官方 composer 原生文件入口挂到当前输入框；不发送、不覆盖草稿、不开新会话；成功/重复/失败均有 toast 文案。
- 失败状态收敛：封面右上角常显 16px 图标（导入失败红 / AI 拆解失败黄），图标 `title`、`aria-label` 与悬停提示承载完整原因；导入中不显示图标（保留既有 shimmer/阶段正文）。
- 复选框保持既有选择语义：悬停出现、选择模式常显；帖子卡复选框不压正文首行。
- 账号监控卡、详情弹窗、合集文件夹卡的信息结构不变；合集悬停 CTA 也水平居中。

## 假设

悬停层用 CSS 绝对定位叠在封面/卡片底部，不改变卡片高度与瀑布流几何；默认态只显示内容（封面或 3 行正文），悬停/键盘聚焦用 `:hover` 与 `:focus-within` 显示标题、元信息、⋯、复选框与居中 CTA。失败原因以常显小图标的 `title`/`aria-label` 承载，不新增弹层组件；「添加到对话」复用合集附件的原生文件入口，生成单个 Markdown 文件，避免媒体下载与附件 kind 扩展。

## 证伪方式

以下任一可观测结果即证明假设错误：默认态截图里仍出现标题、元信息、⋯、复选框或 CTA；媒体卡高度不等于封面 + 2（真机几何断言失败）；帖子卡高度超过 `(列宽−2)×16/9` 或同一列卡片重叠；失败卡片没有常显图标或图标 `title`/`aria-label` 为空；⋯ 菜单在云端卡出现「删除」或本地卡缺少「添加到对话」；添加到对话没有生成 `灵感卡.md`、或发送了消息/覆盖了草稿。验证命令：`node --test src/client/*.test.js src/client/*.e2e.test.js`（真实 Chrome 几何门禁）、`node .workbuddy/evidence/inspiration-card-hover-chrome/run.mjs`（默认/悬停/失败图标/菜单状态截图 + report.json）、`node scripts/scan-ui-gates.mjs` 与干净 main 对比。
