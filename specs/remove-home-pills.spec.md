# 移除首页输入框下方四个快捷按钮

## 目标与验收

新对话首页全宽时，输入框正下方不再出现这四个按钮，也不再出现它们点开后的面板：

- 技能
- 视频广告
- 图片广告
- 竞争对手研究

成功标准：

1. 全宽空白首页的引导区域里，这四个按钮的数量为 0，弹出面板数量为 0。
2. 下方「探索模板」区域仍在，技能货架仍在。技能市场、侧栏入口、输入框里的技能标识都不动。
3. 分栏、窄列、输入框收起时，首页仍只保留简洁对话，不把整页卡片挤回去。
4. 新用户不需要任何新配置。缺配置时没有新增报错，因为本改动只删界面，不引入新依赖。

## 范围

只删首页这一排按钮及其专用面板。不删技能数据、广告模板、市场分类，也不改加号菜单里的文件、资产库、商品库、灵感库。
