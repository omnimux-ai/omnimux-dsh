# 悬停预览卡只保留图像（Issue #3123）

## 背景

创作画布「资产」抽屉在鼠标悬停素材条目时弹出预览卡（`HoverInspector`）。卡片由两部分组成：上方 140px 高的缩略图区域，下方一条深色信息区——素材名 + 导入/生成徽标、更新时间、分辨率、文件大小、本地路径 / Prompt、标签。

用户反馈：悬停时只想要看到图像本身，底部深色信息区里的这些元素都不要。

## 验收标准

1. **信息区彻底移除**：悬停任意素材条目，预览卡只渲染图像区域；DOM 中不再出现素材名、导入/生成徽标、更新时间、分辨率、文件大小、本地路径 / Prompt、标签这些节点。
2. **图像渲染不受影响**：图片素材显示图片本身；视频素材显示首帧；音频等无预览地址的素材显示占位图标。
3. **时长角标保留**：视频素材的时长角标仍然可见，且位于图像区域内（它属于图像本身，不属于被移除的信息区）。
4. **定位行为不变**：卡片仍固定在侧边栏外侧左侧、垂直对齐条目，并保留视口边界保护（不越界、不遮挡侧边栏）。
5. **无残留副作用**：不再产生与被移除信息区相关的控制台报错；素材列表、网格视图与画布节点的行为不受影响。

## 用户关键操作旅程

1. 用户打开创作画布，切到右侧「资产」页签。
2. 鼠标悬停在一个已导入的图片素材上 → 预览卡出现，**只有图像**，图像下方没有任何文字信息。
3. 鼠标悬停在一个已导入的视频素材上 → 预览卡显示视频首帧，右下角仍有时长角标，图像下方没有任何文字信息。
4. 鼠标悬停在一个音频素材上 → 预览卡显示类型占位图标，图像下方没有任何文字信息。
5. 鼠标移开 → 预览卡消失。

## 测试计划

- 单元/契约测试：源码契约断言——`HoverInspector` 不再渲染信息区容器与其子节点；仍渲染缩略图容器与时长角标；仅被信息区使用的图标引用与日期格式化逻辑已清理；失效样式规则已删除。
- 真实浏览器验证（隔离工作树内）：用真实 `HoverInspector` 组件 + 真实主题样式渲染图片 / 视频 / 音频三类素材，断言图像区域内媒体节点正常、信息区节点数量为 0、卡片定位与边界保护符合预期，并留存截图。
- 回归：workflow 插件全量测试套件；`pnpm verify:stages`；`node --test scripts/verify-anti-slop.test.mjs`。

## 非目标

- 不改动素材列表 / 网格视图的缩略图与信息展示；
- 不改动画布节点的悬停行为；
- 不为被移除的信息新增替代入口（例如点击查看详情）——本次只做减法；
- 不改动悬停触发的时机与卡片出现/消失动画。

## 产品基线与文档影响

- 产品基线：不新增开发机路径、端口或别名；不引入新的运行时数据来源；纯渲染层减法。
- 文档影响：不涉及契约、README 或用户文档改动；`docs/` 无需同步。
