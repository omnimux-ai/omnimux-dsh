# 灵感弹窗大屏重构为左中右三栏终极视听工作台规格说明 (Issue #2315)

## 1. 背景与业务价值
在大屏或全屏弹窗展示下，横向可用宽度极为充裕（1200px+）。如果采用双栏+右侧 Tab 切换模式，会导致右侧大面积空间浪费，且在比对视频画面、镜头分镜和商业逻辑时需要频繁点击 Tab 切换。
用户明确指示：在大屏下无需分 Tab，直接重构为左、中、右三栏并列展开的终极视听拉片工作台！

## 2. 核心验收准则 (Acceptance Criteria)

| 编号 | 模块 | 输入/前置条件 | 预期行为与结果 |
| :--- | :--- | :--- | :--- |
| **AC-1** | 三栏工作台架构 | 打开素材预览弹窗 | 彻底移除右侧 Segmented Tabs 切换栏；页面自左向右铺展为：左栏【视频预览】、中栏【分镜脚本】、右栏【结构拆解】三栏独立滚动并列工作台。 |
| **AC-2** | 比例与留白适配 | 大屏展示 | 左栏固定 340px-360px 呈现 9:16 大幅视频与元数据卡片；中栏分配 380px-440px 呈现逐镜头分镜流；右栏自适应分配剩余宽度呈现商业逻辑拆解。 |
| **AC-3** | 分镜脚本精致呈现 | 中栏分镜流 | 完整呈现镜头切点徽标、阶段标识、视听胶囊标签、麦克风图标纯净原声台词气泡、AI Prompt 复制盒；视频播放时激活镜头动态点亮呼吸绿灯。 |
| **AC-4** | 结构拆解同屏可视 | 右栏拆解流 | 黄金 3 秒钩子、核心转化目标、叙事与人声 DNA、画面与镜头语言、核心复刻策略同屏一览无余，无需任何 Tab 点击切换。 |
| **AC-5** | 全局复刻能力保持 | 弹窗底部操作条 | 底部继续固定一键复刻按钮，向下游创作会话或画布投递完整的分镜与策略数据。 |
