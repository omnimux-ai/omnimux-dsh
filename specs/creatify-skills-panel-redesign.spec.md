# Spec · 1:1复刻Creatify技能面板视觉样式并移除关闭按钮支持全局点击收起

## 1. 业务背景与用户诉求
用户明确指示并提供了 Creatify 线上真实面板（`https://app.creatify.ai/creative-agent`）截图：
1. **1:1 复刻面板样式**：
   - 顶部搜索栏：左侧精致放大镜图标、Search skills 占位符、右侧精致紫色高亮 `Browse all` 按钮；
   - 列表项区域：左侧精致灰白线框图标（如人像图标、立方体图标）、加粗亮白标题（最近项前带小时钟标记）、正下方单行高级灰描述（单行溢出省略号截断 `text-overflow: ellipsis`）；
   - 底部快速通道：`⚡ Browse all skills →`；
   - 整体面板采用高质感深色微透/实底圆角矩形（16px 圆角），深邃弥散阴影与高光细腻边框。
2. **彻底移除关闭按钮**：
   - 用户明确强调：“**另外 不需要关闭按钮 点击任意位置就能隐藏列表菜单**”；
   - 移除 Skills 面板以及视频/图片/竞品提示词面板右上角的所有 `×` 关闭按钮。
3. **全局点击任意位置收起**：
   - 点击面板外部空白、点击列表项选择提示词、或再次点击激活按钮，面板即时平滑隐藏，恢复为胶囊按钮状态。

## 2. 详细设计规格
1. **顶部搜索控制栏**：
   - 移除原先右上角的 `×` 关闭按钮；
   - 搜索输入框：高 34px，圆角 8px，内边距 `0 10px`，左侧矢量放大镜图标（14px），右侧清空输入；
   - `Browse all` 按钮：圆角 8px，高度 34px，内边距 `0 16px`，底色 `rgba(97, 97, 255, 0.16)`，文字颜色 `rgb(165, 160, 255)`，字号 13px，字重 500；点击可跳转/切换技能库。
2. **列表项视觉（1:1 复刻用户截图）**：
   - 每一项结构：
     - 左侧图标：矢量人像图标 `<UserIcon />` 或立方体 `<BoxIcon />`，颜色 `var(--dsw-alias-label-secondary)`；
     - 标题行：字号 14px，字重 600，颜色 `var(--dsw-alias-label-primary)`，如果是最近项则前面渲染微型时钟图标 🕒；
     - 描述行：字号 12px，行高 1.4，颜色 `var(--dsw-alias-label-tertiary)`，严格单行截断（`white-space: nowrap; overflow: hidden; text-overflow: ellipsis;`）；
     - 容器悬停：悬停背景 `var(--dsw-alias-interactive-bg-hover)`，平滑过渡，圆角 8px，内边距 `8px 12px`。
3. **底部分类通道**：
   - 列表底部渲染 `⚡ Browse all skills →` 导航行，与原版保持一致。
4. **子提示词面板对齐**：
   - 视频广告、图片广告、竞品研究面板同样移除右上角关闭按钮；
   - 保持极简纯净的标题 + 选项排版，点击选项直接填入输入框并关闭面板。
5. **交互逻辑**：
   - 监听全局 pointerdown/click 事件，点击页面任意非面板区域立即平滑收起。

## 3. 验收标准与测试矩阵
- **场景 1：面板视觉 1:1 对标**
  - 打开技能面板，验证顶部无关闭按钮，右侧显示精致紫色 Browse all 按钮；
  - 验证列表项带有左侧矢量图标，标题亮白加粗，描述单行省略截断。
- **场景 2：移除关闭按钮**
  - 验证无论在技能面板还是子提示词面板中，均不包含任何 `×` 关闭按钮。
- **场景 3：点击任意位置隐藏**
  - 点击面板外部任意位置，面板立即关闭，恢复为 4 个胶囊按钮；
  - 点击列表中的任意选项，选项注入输入框且面板立即关闭恢复。
- **场景 4：自动化回归与设计门禁**
  - 遵循纯设计系统 CSS token，零裸颜色；
  - 现有及新增 E2E 测试全部 100% 绿灯。
