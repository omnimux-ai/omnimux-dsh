## Problem Statement

浏览器素材识别的角标工具栏与悬浮胶囊均提供加入灵感库、复制链接与加入对话。用户需要图片成为可复用的本地资产，视频继续作为灵感收藏。只更改按钮文字却仍将图片写入灵感库不符合真实保存目的地。

## Solution

两处入口均保持三个动作及现有展开方式。第一动作按素材业务类型分流：图片显示加入资产库，保存真实图片文件并登记至当前宿主资产库；视频显示加入灵感库，保留现有视频收藏流程。复制链接和加入对话保持既有行为和文案。图片成功反馈只能来自真实持久化回执。

## User Stories

1. 作为网页用户，希望图片的第一动作显示加入资产库，以便识别保存目的地。
2. 作为网页用户，希望角标与胶囊行为一致，以免同一素材收到不同承诺。
3. 作为图片采集用户，希望保存真实文件而非仅链接，以便来源失效后仍可复用。
4. 作为图片采集用户，希望保存后资产库中可见且可预览，以便确认完成。
5. 作为视频收藏用户，希望视频仍走加入灵感库，以保留既有习惯。
6. 作为作品浏览用户，希望视频静态封面仍视为视频作品，以免误存成图片。
7. 作为图片采集用户，希望重复或并发点击同一图片不会建重复资产。
8. 作为图片采集用户，希望保存进行中无法重复提交，以免下载和反馈错乱。
9. 作为新用户，希望未连接宿主或资产库缺失时明确失败，以便正确处理。
10. 作为图片采集用户，希望下载失败、空内容或非图片响应不显示保存成功。
11. 作为图片采集用户，希望过大、超时、私网或不安全地址被拒绝，以保护设备。
12. 作为图片采集用户，希望不同图片同名时不覆盖，以保留全部素材。
13. 作为网页用户，希望复制链接和加入对话继续正常工作。
14. 作为键盘用户，希望第一动作可访问名称与媒体类型一致。
15. 作为中英文用户，希望提示和回执用当前语言一致表达目的地。
16. 作为新用户，希望默认路径不依赖开发机私有目录或数据。
17. 作为切换素材的用户，希望旧保存回执不会给新素材点亮已保存状态。
18. 作为资产库用户，希望复用既有列表、预览和引用能力，不出现第二套库。

## Implementation Decisions

- 类型分流以作品语义为准，不只看缩略图标签；视频作品链接和真实播放器优先于静态封面。
- 保持现有三个槽位及顺序，无新增入口、分类弹窗、营销说明或徽章。产品经理另层核定 UI 元素与逐字文案。
- 真实入库沿用资产库受管文件和记录模型；源 URL 是来源信息，不能代替文件。未指定创作分类时使用现有自定义类型。
- 只保存至当前已连接宿主，不能为副作用请求轮询多个宿主、跨 profile 保存或失败后转存灵感库。
- 复用现有可信调用与配对边界，不放宽跨站写入保护，不增加免认证写接口。
- 复用既有安全媒体下载和文件物化能力；校验公共地址、DNS、每次重定向、响应图片类型及实际内容，限制大小和总超时；文件名不授予路径权限。
- 每次操作独占暂存区并负责清理；失败不得残留空资产，不能以部分登记冒充成功，不得删除用户原文件。
- 同一规范化图片来源重复保存复用已有可用资产，并发同源保存合并进行中的操作。文件缺失的既有记录不能作为成功证据。
- 新用户基线为宿主可连接且资产库已启用；缺失时明确报错，不自动安装插件、不访问其他 profile、不请求秘密、不重启桌面应用。
- 图片写入经当前 token 验证且握手完成的本机 WebSocket 桥承载，提供窄图片保存 RPC；只接收图片 URL、页面来源和有限名称，不接收本机路径、目标目录、任意请求头或网站凭据。配对成功须绑定所批准目标地址，实例切换不得重投旧请求。
- 宿主复用公开媒体下载模块的默认 8 MiB 解压字节上限、9 秒总预算、最多 5 跳逐跳校验，以及已有 DNS/socket 防私网策略（保留当前 fake-IP 代理兼容规则，不新造网络策略）。取消与连接代次绑定；不能在尚未开始保存时以丢失回执为由换宿主写入。
- 复用宿主 attachments 的只校验图片能力进行实际栅格解码，不调用保存附件建立第二份持久副本。首版接收 JPEG/PNG/WebP/GIF 与宿主支持集的交集；缺失 MIME、octet-stream、SVG、HTML、损坏或 MIME/字节不一致的内容明确拒绝，无校验能力明确不可用。
- 资产插件公开仅供宿主使用的窄保存服务，持有现有活跃资产库实例，浏览器插件通过服务获取能力而非导入私有源码或创建另一实例。物化、登记及 changed 事件须由同一拥有者完成，资产页打开时也能发现新增图片。
- 同源标识采用去掉 fragment、保留 query 的规范 URL 摘要，保存在既有 source 字段；去重只覆盖当前宿主同一来源，不承诺不同签名 URL 的内容全局去重。完整旧资产可复用，旧资产文件缺失不能返回成功。
- 宿主生成安全文件名和与验证 MIME 相符的后缀；显示名最长 40 字、清理路径与控制字符，缺省名称使用产品字典。不同图同名递增而不覆盖。仅保存当前单张，默认 custom，不新增分类器或全图集采集。
- 保存服务必须保证账本、内存 revision 和受管文件失败一致性，不允许仅 catch 报错却留下可列表的幽灵资产；成功回执含明确 saved/duplicate、非空 assetId/fileId 和 revision，回执丢失按未确认反馈，禁止假成功。
- 不新增依赖或实施数据迁移。若现有安全接缝无法承载功能，应公开缺口并调整方案，不以弱化保护解决。

## Testing Decisions

以下接缝和范围已由用户在本会话确认，新增规格与回归测试的路径登记亦已获明确授权。测试外部行为，不把源码关键词、模拟回执或内部状态当作端到端成功。

- 界面/动作：两入口在图片、视频和视频静态封面间切换，检查提示、可访问名称、目的地和反馈；复制与对话回归。
- 宿主/资产库：真实受管目录及登记，用外部下载接缝替身输入图片，不替身资产登记、列表或预览；检查真实文件字节、登记、revision、列表及可预览。
- 错误/安全：未连接、库缺失、非图片、空文件、超限、超时、非法地址、DNS/私网/重定向拒绝、持久化失败、同名、重复和并发。失败不写灵感、不建空资产、不误报成功。
- 浏览器：任务隔离空间操作真实实现，从两入口触发图片入库并检查资产预览；保留对应 PNG 和结构化报告，标明夹具与真实扩展链路的区别，不冒充共享 Dev 更新。
- 每个垂直切片先失败测试跑红，再最小实现跑绿。结束跑涉及包完整测试、类型与构建检查，记录真实退出码、用例与 skip，不全仓无差别跑测。
- 产品签收、独立代码审查和 QA 各自举证，不能互相替代。

## Out of Scope

- 新增第四动作、重做布局、改变复制/对话业务行为。
- 视频下载、音频采集、批量采集、反爬绕过或携带网站凭据下载。
- 不安全地址的协议切换或隐式绕过兜底。
- 智能分类、提示词分析、平行素材库与数据迁移。
- 生产发布、桌面应用重启、未合并产物进入公共 Dev/Prod。
- 未经用户看过演示并明确确认即合入正式代码。

实施分两票：V1 悬浮胶囊图片真实入库（无阻塞）；V2 角标复用并完成两入口类型/重复/失败及真实浏览器闭环（阻塞 V1）。两票都含必要前后端执行分工，不按技术层独立拆票。
