# feat(device): 集群卡片 iPhone 真机比例与外壳（Issue #2432）

## 背景与目标
手机管理「集群」视图设备卡片的模拟屏是通用黑色矩形（.omx-mock-screen-box，180px 高）。用户要求改用 iPhone 真机比例与外壳展示，强化「物理真机集群」感知。

## 设计（遵循纯白黑+极光紫设计铁律，无蓝色）
- 卡片即手机：竖屏真机比例（aspect-ratio 9/19.5），深色钛金属边框（圆角外壳 + 细微高光描边）、屏幕纯黑（#000）带极弱纵向暗渐变；
- 屏幕内自上而下：灵动岛（顶部居中胶囊）、状态栏（左时间 09:41 / 右电量）、屏幕中央 TikTok 账号与运行状态、底部端口信息与 Home 指示条；
- 手机下方一行图注：状态点 + 编号/机型 + 代理延迟；点击整机仍打开设备抽屉；
- 网格列宽收敛（minmax 150px），一行容纳更多真机；hover 细描边提亮 + 1px 上浮（与既有交互一致）；
- 状态语义色沿用既有绿/琥珀/玫红（非蓝）。

## 改动文件
- `plugins/omnimux-device/src/client/DeviceStage.jsx`：集群卡片结构（手机外壳 + 图注）
- `plugins/omnimux-device/src/client/styles.js`：`.omx-phone*` 系列样式与网格列宽；移除 `.omx-mock-screen-box`

## 新用户基线
纯 CSS/结构改动，无开发机私有路径与运行时依赖。

## 验收标准
1. 真实浏览器渲染修复后打包产物：真机比例、外壳、灵动岛、状态栏、Home 指示条可见（截图证据）。
2. 先演示给用户确认，确认后再合入。
3. `pnpm --filter omnimux-device test` 通过；E2E 增补卡片结构断言。

## 文档影响
纯界面样式演进，不改契约与产品边界；无需更新文档。

## 风险
低：仅集群视图卡片展示层，交互（点击抽屉）不变。
