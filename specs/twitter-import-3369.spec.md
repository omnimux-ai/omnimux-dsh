# #3369 推特链接导入中断修复

- 范围：修复云端解析内部中断误判用户取消；已接收的后台导入独立于提交连接继续执行。
- 新用户基线：安装并登录后走已注册社媒工具；云端失败使用现有公开备用解析；未取得公开内容时明确失败，不创建成功空记录。不依赖本地开发服务或凭据。
- 验收：未取消调用方的上游 AbortError 能进入已有备用解析；真正取消立即停止且不保存；后台接受后连接取消不会破坏任务；离线回归和隔离浏览器路径验证。
- 非目标：不修改上游/生产配置，不创建新平台，不调用付费生成。
- 文档影响：只修正既有导入恢复行为和后台生命周期，无新增公共能力；验证结果记录在任务报告。

## 用户补充验收：帖子全部素材

- 必须导入帖子自身的视频、图片；实际截图帖子含1视频+1独立图片，不以正文成功替代素材成功。
- 通过hub既有社媒能力获取官方公开嵌入资料，网络来源逻辑只在hub；域插件解析、下载和管理其自身文件。
- `media_items` 保存有序素材列表 `Array<{type:'video'|'image',url:string}>`，url为本地媒体路由；`media_urls`继续保存视频地址兼容旧消费者；`local_paths`仅保存string路径，首视频为video，额外视频video_2等、图片image_1等，cover仅预览封面。
- 相同素材跨信封去重；每视频仅下载最高质量可下载MP4；封面不能当独立照片；所有图片落盘。
- 全部解析素材保存成功才ready；任一素材失败需清理本次全部文件并明确失败；正文仅为link/degraded，不谎报媒体成功。
- 替换、删除、批删与取消需处理全部保存文件。详情可切换视频/图片，图片不进入视频播放器。
- 真实验证视频可播放、独立图片可解码、多图和混合素材集合；保留截图/结构化验收和文件证据。
