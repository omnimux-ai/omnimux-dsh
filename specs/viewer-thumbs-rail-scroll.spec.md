# 规格：大图预览页左侧缩略图栏——去壳贴边 + 滚轮可滚动

## 目标
单图大画布模式（omx-mv-single-stage）左侧缩略图栏 `.omx-mv-thumbnails-rail`：
1. 移除悬浮胶囊外壳（背景/边框/圆角/磨砂/投影/上下偏移），缩略图列从画布顶部贴到底部。
2. 内容超出可用高度时，鼠标悬停在栏上滚轮可上下滚动；不再被大图画布缩放拦截。

## 根因
- `MediaViewerTab.jsx` 在 stage 上挂 wheel 监听 `{ passive: false }` 且 `e.preventDefault()`，拦截一切滚轮做画布缩放，滚轮到不了 rail。
- `styles.js` 中 rail 为 `top:20px; left:20px; max-height:calc(100vh-180px)` 的胶囊卡片。

## 用户操作旅程与验收标准
1. 多素材单图模式：缩略图列从画布顶到底排列，无胶囊外框，顶部无 20px 空隙。
2. 数量超出高度：鼠标悬在缩略图栏上滚轮下滚，列表向下滚动露出底部项；上滚回顶部。
3. 滚到顶/底后：不触发画布缩放、不泄漏给父级页面滚动。
4. 鼠标在栏外的画布上滚轮：缩放行为与现状一致。
5. 点击任一缩略图仍可切换当前图；生成中/失败占位块可点选、可滚动。

## 命令
- 契约测试：`node --test` 运行 rail 相关既有与新增用例。
- 浏览器验收：工作树内真实渲染 rail，滚轮验证滚动与缩放隔离，留 PNG 证据。

## 代码风格
沿用文件内中文注释；不新增组件；最小改动：一处 wheel 守卫 + rail CSS 块改写。

## 测试策略
更新 image-preview-redesign 断言（贴顶贴底、无外壳）；新增 rail 滚动契约（overflow-y:auto、top:0、bottom:0、overscroll-behavior-y:contain、wheel 守卫存在）。

## 边界
- 总是：不动选中/点击逻辑；不改生成中/失败占位块语义；滚动条继续隐藏。
- 绝不做：不改画布缩放上下限与系数；不引入新依赖；不用黑名单掩数据。
