# #2339 图像与媒体查看器移除未完成生成状态占位卡片规格

## Objective
在 OmniMux 图像与媒体查看器（MediaViewerTab）中，彻底移除视口顶部未完成的生成任务占位卡片（包含「提交状态待确认」等黑色 GeneratingStateCard 占位面板）。
让媒体查看器保持为纯粹沉浸式的高清图片/视频大图浏览、缩放平移与画廊展示舞台，避免在已有大图上方硬塞大黑块卡片破坏视口布局，生成进度统一由主对话流负责呈现。

## Acceptance Criteria
1. **移除顶部占位卡片**：
   - 当会话中产生新的生成请求处于 pending/running 等未就绪状态时，媒体查看器视口展示区顶部不再渲染黑色占位卡片（GeneratingStateCard）。
   - 移除 `data-has-generation` 对视口 Flex 布局的垂直破坏，确保单图大图展示区始终占据视口全部空间，支持平滑缩放、拖拽与居中。
2. **保留正常媒体展示**：
   - 会话中已有或新生成的真实图片、视频素材完整保留展示，大图模式、左上角微型缩略图切换轨、四宫格时间线瀑布流等功能 100% 正常可用。
3. **向后兼容与稳定性**：
   - 媒体查看器 Store 订阅与事件流转不报错，未完成状态下不抛出异常。
4. **验证门禁**：
   - 产出高保真演示页面与真实浏览器实测截图，直观呈现移除前后的视口变化。
