# 媒体生成提供商：模型配置默认折叠与纵向单列规格说明（Issue #2613）

## 背景与问题陈述
在设置的「对话与媒体生成模型」卡片中，选中「媒体生成提供商」Tab 后，当前的图片模型、视频模型、音频模型采用 3 列横向网格并排平铺展示。在常规视口下显得拥挤，且用户大多数情况下仅需配置一次 API Key 和基础连接，细分模型映射默认一直展开占用了大量垂直纵向视线空间。

## 改造目标
1. **默认折叠收起**：
   - 媒体提供商表单中的模型映射区域默认处于收起（折叠态）；
   - 提供直观的点击展开触发栏，显示当前选中的模型简要摘要或「高级模型映射 (展开/收起)」；
   - 点击该栏即可平滑展开详细的模型下拉配置列表，再次点击可收起。
2. **上下纵向排列（非左右并列）**：
   - 展开后的细分模态由原本的 3 列左右横排（`grid-template-columns: repeat(3, 1fr)`）改为**上下单列纵向排列**（`flex-direction: column`）；
   - 每一个模态项（图片模型、视频模型、音频模型）完整占满单行宽度，布局从容，标签居上，下拉菜单清晰易读。
3. **视觉与交互细节**：
   - 折叠条遵循设计规范，消费标准语义 Token；
   - 展开状态在表单切换服务商时保持或恢复默认，各模态修改后保持正常联动与保存逻辑；
   - 无语法、门禁违规，自动化端到端测试 100% 覆盖。

## 验收断言标准 (Spec Criteria)
- **S1 (默认折叠态)**：表单初次渲染时，多模态详细下拉容器处于收起状态（DOM 不展开或不显现模型下拉框）。
- **S2 (交互展开态)**：点击折叠触发栏后，展开区域显现，图片、视频、音频三个下拉选择框正常可见。
- **S3 (上下纵向布局)**：展开区域容器采用纵向排列布局（`.omx-caps-column` 或纵向 flex 结构），三个模态卡片纵向叠放，非横向三列并排。
- **S4 (自动化回归通过)**：相关 E2E 测试及既有单测 100% 绿灯。
