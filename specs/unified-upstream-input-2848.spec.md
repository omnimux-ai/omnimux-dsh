# 统一上游输入卡槽

Issue: #2848
Status: Approved requirements and test seams; implementation plan pending review
Date: 2026-09-30

## Problem

创作画布将素材入口限定为媒体输入，文本沿独立连线合并路径消费。只有视频槽借用场景获得验证，不能证明文本、图片、音频新建空节点符合要求。用户无法一致发现可用上游输入，选择器类型筛选与具体格式、组合限制、消费状态和最终提交判定不完全一致。

## Objective

所有生成节点只要当前模型的允许生成方式支持任意上游输入，即在空态默认显示同一素材入口；支持上游文本亦满足显示条件。点击后可选素材由模型、生成方式、渠道的有效输入契约确定。统一发现、选择、绑定、预览、替换、停用、切换复核与提交机制，不以输出为文本、图片、视频或音频分别实现输入规则。

## Confirmed decisions

- 文本是上游素材，不能以没有媒体输入为由隐藏入口。
- 同模型其他允许方式的能力可供发现；选材需要切换方式时在当前弹窗明示目标方式，点击添加一并确认。不得在计费提交时暗切。
- 单正文语音任务将已使用上游文本按绑定顺序合并，随后追加本地输入文字；均作为正文朗读，不朗读来源名称或来源标记。支持独立表达字段的任务按自身契约映射，不套所有音频输出特判。
- 首版包含画布文本和本地 TXT、Markdown 解析为上游文本。PDF、Office 不自动解释为纯文本；文档仅在类型、格式、导入和执行路径均支持时开放。
- 一组选材必须能被一个允许生成方式在合格渠道上完整承接。不同方式或渠道的类型、格式、容量不可拼接成虚假能力。
- 供给不等于使用。停用保留源节点及连线，但该输入不再进入生成请求。
- 切模型、方式、渠道保留绑定意图与素材；不兼容明确可见且阻断生成，不能静默截断或忽略。

## Domain

素材是可作为生成输入的上游内容，包括正文和受支持的媒体、文档。输入契约描述来源、类型、格式、用途、限制与允许的组合。供给是上游可提供的内容；绑定是用户明确使用的内容及用途。直接手写文本是本节点的值，不伪造为上游节点。最终请求字段的数量不等于上游文本来源数量。

## Required behavior

### Empty state and discovery

无结果、无上游连线、无本地文字的新建节点亦可显示入口。只有确无上游能力的有效方案不展示入口；目录缺失或未知能力不得制造可选类型。首帧、尾帧等角色槽与通用入口使用同一选择和绑定机制，区别仅为契约角色约束。

### Effective contract

有效契约无损保留操作准入、输入组、来源映射、文本组合、格式、大小、时长、数量、必填角色及渠道限制。契约缺失须显式作为未知，不将未知 MIME、零草稿大小或未声明上限视为支持任意格式、已验证大小或无限容量。不提升未核实操作的准入状态。

### Selection and binding

画布选择包含就绪文本来源；本地文本读取有真实解析证据。每次勾选及最终添加校验已有使用输入与全部待添加输入的整体可行性。添加与必要的方式切换、连线、绑定组成单次原子变更。取消不改图；无完整方案不得报告部分成功或悄悄退回供给。缺必需输入可继续装填，不能提前生成。

### Consumption and submission

所有上游文本、媒体和文档由同一绑定遍历决定使用。停用、替换、恢复使用、撤销具有一致行为；编辑器引用标记不是独立消费真源。只使用已绑定的当前有效输出，来源内容不复制进编辑器，不重复加入请求。异步提交前冻结输入及配置快照，执行端重新校验，不从所有供给补回未使用文本。

### Text behavior

普通生成的上游正文按已批准的来源与本地要求组合规则映射。单正文朗读采用上游顺序后接本地正文，以段落间隔连接，不插入素材名。多个来源的总字数按最终契约限制验证，超限显式拒绝，不截断。空文件、读取失败或无法解析的文件不成为就绪正文。TXT、Markdown 的字符编码和大小读取规则须通过实际导入适配证明；不得默认支持未知二进制文本。

## Non-goals

不新造第二套输入引擎、选择器、模型能力接口或视觉系统；不顺手改首页、生成结果布局、计费或渠道配置页面；不绕过模型准入、不硬编码参考图槽、不自动转码或抽取 Office/PDF；不重启应用，不将未合并代码安装到共享开发版，不擅自发起付费模型请求。

## New-user baseline

依赖产品提供的模型目录、真实可用渠道与已有画布/文件选择入口，不依赖开发机私有夹具。模型目录不可用时保留可恢复的错误反馈并阻断生成，不静态兜底能力；本地文件失效时显示不可用且不静默忽略。仅手写内容满足有效契约时允许独立生成，卡槽不是强迫用户必须连接上游。

## Acceptance criteria

1. 支持上游文本的文本、图片、视频、音频新建空节点，都默认显示素材入口。
2. 同一选择器能选择画布正文及真实导入的 TXT、Markdown，不向不支持类型的模型开放素材。
3. 对具体格式、容量、大小、时长、角色和输入组，选择、绑定、可生成状态与最终提交判定一致。
4. 全组素材必须有完整方式与渠道方案；分别可用而共同不可用的素材不得共同添加为就绪输入。
5. 文本停用保留源和边，实际请求不再含该正文；恢复使用后只出现一次。
6. 单正文语音的请求严格为上游绑定顺序后接本地文字，名称和提示标记不进入朗读正文。
7. 模型、方式、渠道变化不静默删除原素材或截取首份；未决不兼容项阻断生成。
8. 本地文本导入与画布正文走同一使用状态和请求组装规则。
9. 必要元信息未知为待验证，不显示可生成；读取失败有可见原因。
10. 旧图迁移只恢复已有消费意图，不自动使用新增供给；旧结果和源内容不改。
11. UI 按现有设计规范与产品白名单；四类真实功能路径截图确认入口、选择、填入、停用与冲突状态。
12. 交付分别报告离线请求捕获、真实浏览器交互与供应商真实生成；不得以模拟、探活或首页截图代替未执行层。

## Agreed test seams

- 契约目录到画布投影的字段无损与准入一致性。
- 同一模式及渠道承接完整输入的参数化判定，覆盖四类输出及正反边界。
- 用户选材到原子绑定变更；取消、替换、停用、恢复和撤销。
- 已使用绑定到实际请求捕获；文本顺序、不重复、停用不再消费及单正文朗读。
- 文件读取边界；合法 TXT/Markdown、空文件、失效路径、未知元信息、超限。
- 四类新建空节点的真实浏览器导航和交互截图；功能路径而非首页冒烟。
