# 规格：修复会话切换时工作台视口模式误判折叠导致中间会话栏空白死区缺陷

Issue: #2352
插件: omnimux
日期: 2026-09-18

## 1. 目标

解决从左侧列表切换至打开了右侧工作台（如图像生成、创作画布等）的会话时，中间会话栏被误判折叠隐藏、形成纯黑死区（空会话栏状态）且输入框消失的严重布局缺陷。确保会话切换时，未由用户显式指定全屏的前提下恒定以正常三栏分栏（`WORKBENCH_FOCUS.split`）并排呈现，中间对话内容与底部输入框恒定可见。

## 2. 成功标准

1. **统一视窗模式默认值**：所有工作台页签（包括 `omnimux:media-viewer` 图像生成）的未指定视窗偏好默认值一律收敛为分栏模式（`WORKBENCH_FOCUS.split`）。
2. **切换会话免误折叠护栏**：在会话挂载与存储初始化链路（`syncAttachedPanelFocus`）中，必须要求 `record.explicit === true` 且 `record.mode === WORKBENCH_FOCUS.gui` 才允许自动折叠会话栏；未显式选过全屏的会话切换一律保持分栏。
3. **消除右侧面板铺满死黑空隙**：修正 `conversation-collapse.js` 中让右侧面板向左铺满的选择器规则，移除误将带有 `data-sidebar-right-panel` 属性的面板排查在外的 `:not([data-sidebar-right-panel])` 语法，确保折叠态下右侧面板 100% 铺满，杜绝任何死黑空洞。
4. **端到端契约与单测 100% 绿灯**：覆盖会话切换至图像生成页签保持分栏、会话切换时会话栏与输入框恒定可见、右侧面板选择器正确铺满等场景。

## 3. 边界规范

- **总是**：保持三栏分栏舒适度，会话内容恒定可见；右侧面板保持黄金比例宽度。
- **绝不**：在用户未显式点击全屏的情况下，自动折叠会话栏。
