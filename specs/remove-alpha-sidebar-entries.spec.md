# 规范：将内测版从左侧侧边栏入口移除并保持源码完整

## 1. 业务目标与背景
用户明确指示：将所有「内测版」功能从左侧侧边栏入口移除、不予显示，同时完整保留所有插件的源码与内部能力。
在当前系统中，处于内测阶段（Alpha）的插件在 `plugin-lifecycle.json` 中定义为 `stage: "alpha"`，涵盖账号（`omnimux-accounts`）、发布（`omnimux-publish`）、数据分析（`omnimux-analytics`）、任务表单（`omnimux-forms`）、自动化（`omnimux-automation`）。此前中枢侧边栏协调器会在这些入口旁渲染 `Alpha · 内测` 徽章。
本规范要求：侧边栏协调器收敛内测版入口展示，将其从左侧导航区彻底隐藏并停止插入 DOM，但所有插件的内部实现、工作台 Tab 注册、工具与数据结构完全保留。

## 2. 关键用户旅程与验收标准
1. **左侧侧栏净化**：
   - 用户打开主界面，新会话下方的侧边栏区域不再显示任何带有 Alpha / 内测标记的入口（如账号、发布、数据分析、自动化等）；
   - 正式入口（应用、任务看板、项目、新建项目、资产库、产品库、灵感社区）保持原有位序与激活行为不变。
2. **插件源码与功能完整性**：
   - 账号、发布、数据分析、自动化、任务表单等插件源码目录完整保留；
   - 内部已注册的工作台 Tab 及相关后端路由、工具服务不受任何影响；
   - 后续若某个功能结束内测转正，只需在中枢生命周期名单中调整状态，即可自动恢复侧边栏显示。
3. **协调器防线**：
   - `plugins/omnimux/src/client/sidebar-coordinator.js` 统一根据 `pluginLifecycle` 判定，当 entry 属于 `alpha` 时，不将其推入渲染序列，不产生 DOM 插入；
   - 对应协调器测试更新为“Alpha 内测版条目从侧栏移除不显示”。
