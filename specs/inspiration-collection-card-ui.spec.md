# 灵感库合集详情卡片 UI（Issue #3459）

## 授权与范围

用户要求优化「合集详情」的卡片 UI，并已批准实施计划（media-first 卡片、失败态收敛、合集页头）。交付包含实现、最小充分检查、隔离工作树真实浏览器验证、独立审查、常规 PR/Merge Queue、主干同步、Dev 物化与任务工作树清理。仅改 `omnimux-inspiration` 客户端与其样式/文案/测试/构建产物；不改 HTTP 路由、本地库存储、schema，不调用付费媒体生成，不做发布或账号写入。

## 新用户基线与复用

已安装并登录的新用户无需额外配置即可打开本地灵感库与合集：唯一依赖为既有本地库文件、原子写入与 HTTP 分发器。合集为空时保留现有空态；库文件缺失/损坏时给出明确错误，不伪造成功。复用既有卡片组件、瀑布流几何、详情弹窗、官方 Button/EmptyState、主题 token 与容器查询 CTA 契约。

## 确定行为

- 合集详情成员卡使用 `media-first` 形态：媒体框 4:5 + `object-fit: cover`（仅合集层，根层保持原有 contain），标题 13/18 最多 2 行，元信息行 11/16 展示「平台 · 时长或图数 · 加入时间」，右侧状态胶囊。
- 卡面不再渲染绝对定位的失败原因块；导入失败/已入库但 AI 拆解失败以 18px 状态胶囊进入元信息行，完整原因经胶囊 `title` 与详情弹窗（既有 `role="alert"`）可达。无媒体的文本卡保留现有 inline 原因正文。
- 角标收敛：类型左下、时长/图数右下；复选框保持在封面左上；`•••` 仅在悬停时出现在右上；合集层不显示「本地」角标（成员均为本地）。
- 悬停层改为封面底部 28px 工具条（详情 / 立即复刻），不再有居中播放钮与 footer；紧凑宽度沿用既有容器查询退化为纯图标。
- 合集页头：返回、合集名、加入会话（主）、重命名（次），吸附在工具栏下方（`var(--stage-sticky-offset, 44px)`）；标题不显示成员数（遵守 #3392）。
- `rivalCardHeightPx` 与真实渲染高度一致（媒体 + 82 + 2 描边），网格不重叠；非合集层、账号监控卡片行为不变。

## 实施边界与文档影响

单插件客户端展示层与样式；不新增模型、发布、工具或全局模式。更新插件 `README.md` 合集一节与本规格；能力矩阵仅依据最终代码与真实证据。
