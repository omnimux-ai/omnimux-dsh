## 1. 产品概况与目标（PRD Overview）

### 1.1 业务背景与痛点
在现有 OmniMux 桌面端与 Web 端三栏交互中：
- 当用户在中间会话栏点击输入框底部的「+」（指令菜单）并选择「从资产库选择 / 从商品库选择 / 从灵感库选择」时，系统会弹出 1920×1050 的固定全屏遮罩层（`.omnimux-library-stage`），或者触发 `conversation-collapse` 将中间会话栏直接置为 `display: none`；
- **致命缺陷**：用户在挑选素材时彻底丢失正在进行的会话上下文，无法对照上方生成的脚本分镜、提示词规划或历史对话来挑选对应资产；操作打断感极强，破坏了多模态协同创作的连续心流。

### 1.2 核心价值与改造成果
参考顶级多模态创作工具（CreatOK、Linear）的现代化三栏协同范式：
1. **右栏常驻协同（Inline Asset Hub）**：
   将素材中心从“全屏打断式遮罩”重构为**三栏体系中第三栏（右侧边栏工作台）的原生工作模式**。
2. **中栏会话永不折叠（Context Retention）**：
   中间会话栏始终保持在视觉焦点区域（锁定 380px 黄金控制台宽度），无论右侧素材库如何翻页、筛选、切换 Tab，中间对话内容、生成消息与输入框 100% 实时可见。
3. **即选即用（Click-to-Attach）**：
   点击右栏任意素材卡片，直接注入中间会话输入框的附件槽中，无需弹窗确认，不自动提交，用户可随时对照左侧分镜微调 Prompt。
4. **灵活视野控制（Expand / Collapse）**：
   右栏右上角提供极简【全屏】与【收起】控制，兼顾高密度精细筛选与专注会话交互两种场景。

### 1.3 明确不做的范围（Non-Goals — 显式红线）
- ❌ **严禁弹出全屏灰色遮罩**：常规挑选素材流程中绝对不允许出现 `.omnimux-library-stage` 或阻断主界面的全屏固定模态。
- ❌ **严禁会话折叠隐藏**：严禁在选择素材时对会话栏应用 `conversation-collapse`、`width: 0` 或 `display: none`。
- ❌ **严禁点击卡片后自动发送**：点击卡片仅作附件注入，绝不自动调用发送 API。
- ❌ **严禁多余修饰与营销噪音**：砍掉任何“热门推荐”、“新手必备”、“爆款精选”、“💎 高级”、“🔥 推荐”等装饰性图标、空洞形容词副标题与无意义徽章。

## 4. 交互流转与联动核心规格

### 4.1 输入框「+」菜单唤起链路（Router Linkage）
1. 用户在中间会话栏点击输入框加号按钮 `[+]`；
2. 菜单弹出以下三项素材指令：
   - `从资产库选择`
   - `从灵感库选择`
   - `从商品库选择`
3. 用户点击任意一项时，系统执行以下精确原子动作：
   - **步骤 A（工作台展开）**：检测右侧边栏状态，若处于折叠态则平滑展开至三栏默认宽（`usableWidth - 380px` 或基准宽度）；
   - **步骤 B（Tab 路由激活）**：
     - 点击「从资产库选择」 $\rightarrow$ 切换激活一级 Tab `资产库`；
     - 点击「从灵感库选择」 $\rightarrow$ 切换激活一级 Tab `灵感库`；
     - 点击「从商品库选择」 $\rightarrow$ 切换激活一级 Tab `商品库`；
   - **步骤 C（会话栏保活）**：中间会话栏保持 380px 宽度，禁止应用任何隐藏或离屏样式；
   - **步骤 D（消除旧遮罩）**：彻底卸载/不渲染全屏层 `.omnimux-library-stage`。

### 4.2 卡片点击注入附件交互（Click-to-Attach）
1. 用户鼠标点击右栏任意一张素材卡片；
2. **瞬时反馈**：卡片呈现微小压下动画（`scale(0.98)`）与边框微蓝光反馈；右上角显示选中勾选标记；
3. **附件槽注入**：
   - 提取素材对象：`{ id, name, type, url, thumbnail, duration, dimensions }`；
   - 将该对象添加至当前激活会话输入框的附件集合（`composer.attachments`）；
   - 若输入框已有同 ID 素材，不重复添加，但给予轻量聚焦提示；
4. **输入框形态联动**：
   - 中间会话输入框上方附件槽即时渲染该素材微缩胶囊，显示小缩略图、文件名以及 `[×]` 移除按钮；
   - 用户可直接在输入框继续打字，或再次点击右栏其他素材继续追加附件；
   - 整个流程**绝不自动触发消息发送**。

### 4.3 全屏放大与收起专注交互（Viewport Modes）
1. **全屏切换（Fullscreen Toggle）**：
   - 点击右栏顶栏右上角 `[全屏]` 图标按钮；
   - 右栏以平滑过渡动画（`200ms ease-out`）横向扩展，暂时覆盖中间会话栏（提供沉浸式高密度挑片视口）；
   - 顶栏右上角图标即时切换为 `[退出全屏]`；
   - 按键盘 `Esc` 键或再次点击 `[退出全屏]`，工作台平滑退回三栏右侧边栏位置，中栏会话原位恢复，无视觉抖动。
2. **收起工作台（Collapse）**：
   - 点击右栏顶栏右上角 `[收起]` 图标按钮；
   - 右侧边栏收起折叠至最右侧边缘，触发 `workbench:collapsed` 事件；
   - 中间会话栏自动平滑铺满主视口或居中呈现（符合 Linear 单聊模式规范）。

## 6. PM 验收标准（Acceptance Criteria）

- [ ] **AC-1：三栏共存与会话上下文零丢失（Zero Context Loss）**
  - 在任何分辨率（1280px / 1440px / 1920px）下点击加号菜单「从资产库/灵感库/商品库选择」，中间会话栏必须清晰可见（宽度不小于 380px），历史聊天记录完整可读；
  - DOM 树中绝对不允许出现 `.omnimux-library-stage` 全屏覆盖层，会话容器绝无 `display: none`。
- [ ] **AC-2：加号菜单与一级 Tab 严格联动（Tab Routing）**
  - 点击「从资产库选择」 $\rightarrow$ 右栏展开并高亮「资产库」Tab；
  - 点击「从灵感库选择」 $\rightarrow$ 右栏高亮「灵感库」Tab；
  - 点击「从商品库选择」 $\rightarrow$ 右栏高亮「商品库」Tab；
  - 切换 Tab 过程响应时间 $\le 100\text{ms}$，无白屏与控制台未捕获异常。
- [ ] **AC-3：现代 SaaS 极简文案与 UI 元素 100% 吻合（Zero Overdesign）**
  - 一级 Tab 严格为 `画布`、`资产库`、`灵感库`、`商品库`，无多余副标题；
  - 各 Tab 二级筛选首项必须为 `全部`，后续标签完全符合 3.2 节白名单字面值；
  - 严禁出现任何 `💎`、`🔥`、`高画质`、`爆款推荐` 等非法装饰性图标与冗余徽章。
- [ ] **AC-4：即选即注入与输入框无缝协同（Instant Attach）**
  - 点击右栏任一素材卡片，中间输入框附件区立刻呈现对应素材胶囊；
  - 重复点击相同素材不重复堆叠；点击附件胶囊的 `×` 可正常移除；
  - 整个选材过程绝不发生自动发送消息动作。
- [ ] **AC-5：全屏深入查看与收起控制链路完整（Viewport Flexibility）**
  - 点击右上角全屏按钮能平滑占满右侧/主视口进行大图检视，再次点击或按键盘 `Esc` 键能够精准退出全屏，恢复三栏状态；
