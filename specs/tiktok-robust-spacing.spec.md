# TikTok 场景入口范围与避让规格 (Issue #2035)

## 1. 业务目标
1. **入口只在首页信息流出现**：用户反馈「到处有头像都会看到这个按钮」。入口必须只挂在 TikTok 首页信息流（站点根地址及其两个信息流标签地址），作品页、博主主页、搜索页、探索页等一律不挂，避免按钮贴在用户并未要求它装饰的头像上。
2. **站内跳转即时生效**：TikTok 是单页应用，点进作品、返回首页都不产生导航事件，入口必须在同一次会话内自己撤下、自己回来。
3. **对手图标不重叠**：首页信息流里若存在第三方插件按钮（如 CreatOK），它必须被整体顶升到入口上方并保留充裕留白，入口始终紧贴创作者头像正上方。
4. **当前作品可识别**：首页推荐流不把作品包在常规链接里，而是挂载西瓜播放器容器，必须能从该容器读出真实作品编号，杜绝「这一页没有可操作的作品」。

## 2. 验收标准

- **AC-1（仅首页挂载）**：`https://www.tiktok.com/`、`/foryou`、`/following` 挂载入口；`/@user`、`/@user/video/<id>`、`/search`、`/explore`、`/messages` 不挂载任何宿主元素。
- **AC-2（站内跳转自愈）**：从首页跳到博主主页，入口自行撤除（宿主元素从文档移除）；从博主主页跳回首页，入口自行恢复，无需刷新。
- **AC-3（地址改写兜底）**：整页加载作品地址时，即便地址是在页面提交之后被改写进来、期间没有任何界面变化，入口也不得残留；地址复检周期不超过 400ms。
- **AC-4（纯几何顶升）**：第三方元素只要与入口处于同一水平走廊，且其底边侵占入口顶部 24px 留白区，即被整体施加 `translateY` 顶升；不依赖任何头像基准点。多个第三方元素依次向上顺延，互不挤压。
- **AC-5（真实作品编号提取）**：首页存在 `[id*="xgwrapper-"]` 播放器容器时，从其 id 中提取 19 位作品编号，结合卡片内作者名合成标准作品地址；首页无播放器时不猜，如实回答「这一页没有可操作的作品」。
