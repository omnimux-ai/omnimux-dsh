# 规格：素材工作台与新会话共享 Tab 栏（Asset Hub Shared Tabs）PRD 原型与 UI 元素/文案字典规格（Spec Plan）

- **文档状态**：**PM 签发锁定（PM Spec Locked）**
- **产品负责人**：产品经理 许清楚（Xu）
- **实施协同**：前端开发（裴像素）、架构师、QA 测试团队
- **归档路径**：`specs/asset-hub-shared-tabs.spec.md`
- **关联需求与缺陷**：
  - 根除素材工作台不符合定位的「画布」Tab，将其纠正为「精选」（Featured），对齐新会话能力；
  - 素材工作台补齐「爆款趋势」（Trending）与「Skills」两大主库，与新会话的一级 Tab 100% 对齐为 6 大主库；

  - 严格贯彻现代 SaaS 科技极简准则（Anti-Overdesign Law），根除「全部资产」「全部商品」等冗余文案与营销副标题。
- **影响代码模块**：
  - 共享层（新增/抽离）：`plugins/omnimux/src/client/shared/asset-hub-tabs/` 或 `session-guide/templates/shared-tabs-catalog.js`

## 1. 产品概况与目标（PRD Overview）

### 1.1 业务背景与用户痛点深度解构
OmniMux 定位为新一代 AI 多模态创作与生产力平台。在日常创作流程中，素材、模板、应用与技能是贯穿始终的生产资料。然而当前系统存在严重的**场景割裂与定位错位**：

1. **素材工作台定位错位（「画布」混入素材中枢）**：
   - 素材工作台（Asset Hub）的定位是“为当前会话实时检索、浏览并注入多模态素材（图片/视频/音频/商品/灵感/技能）”。
   - 当前素材工作台一级 Tab 错误地包含了「画布」（Canvas）。画布属于节点流式创作空间，其本身是一个独立编辑器视图，既不能作为卡片供用户挑选，也无法作为附件注入会话输入框，点击后显示空白，完全违背了素材工作台的职能定义。
   - 用户明确指出：这个位置预期应该是新会话全屏状态下的「精选」数据（7 大王牌 AI 应用与精选创意模板）。

2. **能力缺失与双轨割裂（缺乏「爆款趋势」与「Skills」）**：
   - 新会话全屏引导页（Session Guide）拥有完整的 6 大类生产资料：精选、资产库、灵感库、商品库、爆款趋势、Skills；
   - 而会话进行中的右侧素材工作台却只有残缺的 4 个 Tab，用户在对话过程中想要选用一个专业 Skill（如黄金 Hook 提取、分镜提示词生成）或参考一段 TikTok 爆款视频时，无法在右侧工作台直接选用，必须新建会话或在输入框凭记忆输入，严重打断了多模态创作的心流；
   - 两处的数据源、分类枚举、图标与样式各自维护，存在多套标准，维护成本高且极易产生样式与文案不一致。

3. **文案层叠与过度设计残留（违反极简铁律）**：
   - 现有二级筛选标签中存在「全部资产」「全部灵感」「全部商品」「全部爆款」「全部技能」等同义赘字，破坏了专业 SaaS 的克制美感；
   - 必须通过本期规格，彻底统一为纯粹的「全部」，并锁定全套中英文字典。

### 1.2 核心价值与改造目标
1. **六大主库 100% 对齐（Six Core Creative Libraries）**：
   彻底移除素材工作台的「画布」Tab，将其纠正为「精选」，并补齐「爆款趋势」和「Skills」，使素材工作台与新会话的一级导航完全统一为 6 大主库：
   `精选 (featured)` · `资产库 (assets)` · `灵感库 (inspiration)` · `商品库 (products)` · `爆款趋势 (trending)` · `Skills (skills)`。
2. **数据与交互契约抽离共享（Shared Tabs & Catalog Architecture）**：
   将 6 大一级 Tab、二级分类白名单、标准矢量 SVG 图标及中英文本地化字典抽离为统一共享源，支持新会话全屏与右栏素材工作台双端消费，消除代码重复与体验差异。
3. **双端无缝消费范式（Dual-Surface Experience）**：
   - **场景 A（新会话全屏）**：顶层展示，原地切换货架/网格，点击卡片吸底预填或启动应用；
   - **场景 B（会话中/三栏状态）**：中栏会话保持 $\ge 380\text{px}$ 黄金控制台，右栏消费共享 Tab 展现对应库卡片，点击执行 **Click-to-Attach**（注入附件槽并追加 Prompt，绝不自动发送消息）。
4. **极简现代 SaaS 工业美学（Anti-Overdesign）**：
   32px 控件高基准、矢量 SVG 图标、实体名词锚定、零冗余 Badge、零装饰 Emoji、零营销副标题。

### 1.3 明确不做的范围（Non-Goals — 显式红线）
- ❌ **严禁在素材工作台中保留「画布」Tab**：画布属于高阶编辑器视图，禁止作为素材工作台的选项卡。
- ❌ **严禁点击卡片自动发送消息**：无论点击精选应用、素材、灵感、爆款还是 Skill，必须将控制权留给用户，只执行“附件注入 + Prompt 草稿追加”，绝对禁止自动调用发送 API。
- ❌ **严禁破坏中间会话栏 $\ge 380\text{px}$ 黄金视口**：任何模式下打开右栏工作台，会话栏都必须常驻保活，严禁出现 `display: none` 或全屏阻断遮罩。
- ❌ **严禁出现「全部 XX」等冗余分类文案**：二级分类第一项必须严格且唯一显示为「全部」，严禁出现「全部资产」「全部商品」「全部爆款」等叠词。
- ❌ **严禁非标准修饰与营销标签**：严禁在卡片或 Tab 上添加 `💎`、`🔥`、`✨` 等 Emoji，严禁出现“高画质”“极速版”“爆款推荐”等非授权主观副标题与彩色胶囊 Badge。

## 2. 双端消费与交互场景规格（Dual-Surface Consumption Spec）

```text
                                  +-----------------------------------------------+
                                  |   OmniMux 全局会话状态机 (Session Context)    |
                                  +-----------------------------------------------+
                                                          |
                                      +-------------------+-------------------+
                                      |                                       |
                       [isBlank && !isCompact]                     [有消息 / 分栏中 / 激活右栏]
                                      |                                       |
                                      v                                       v
                     +---------------------------------+     +---------------------------------+
                     |    场景 A：新会话全屏探索专区   |     |   场景 B：会话中/三栏素材工作台 |
                     |   (Session Guide Fullscreen)    |     |      (Inline Rightbar Hub)      |
                     +---------------------------------+     +---------------------------------+
                     | - 消费共享 6 大一级 Tab 栏      |     | - 中栏会话保持 >= 380px 视口    |
                     | - 原地展示多行货架与大网格流    |     | - 右栏顶部消费共享 6 大 Tab 栏  |
                     | - 点击卡片：吸底预填 / 应用直通 |     | - 点击卡片：Click-to-Attach     |
                     | - 面向：新开会话快速选方向/模板 |     | - 面向：会话中随时补充创作生产资料 |
                     +---------------------------------+     +---------------------------------+
```

### 2.1 场景 A：新会话全屏状态（ExploreTemplates Section）
- **触发与存在条件**：
  当前会话为空白状态（`isBlankConversation(session, hasTargets) === true`），且宿主未开启右侧边栏、未处于紧凑分栏状态（`!isCompact`）。
- **界面与布局形态**：
  - 居中全宽呈现，顶栏承载共享 6 大一级 Tab（精选、资产库、灵感库、商品库、爆款趋势、Skills）；
  - Tab 下方承载当前所选库的二级分类胶囊筛选流；
  - 内容区在「精选」下展示官方 7 大王牌应用货架与全量灵感模板网格；在其他库下展示对应沉浸式卡片流；
- **交互行为**：
  - 用户在当前全屏页面内直接点击卡片完成交互；
  - 点击应用卡片直接启动应用（直通 ApplicationManifest）；
  - 点击模板/爆款/Skill 卡片，触发底部输入框“吸底”，并在输入框中就位预填 Prompt 草稿，用户确认后再点击发送。

### 2.2 场景 B：会话进行中或三栏状态（Rightbar Asset Hub）
- **触发与存在条件**：
  1. 会话已有历史消息或正在生成中；
  2. 用户在中间会话输入框底部的「+」（加号菜单）中点击「从资产库选择 / 从灵感库选择 / 从商品库选择 / 选用技能 / 参考爆款」；
  3. 用户点击顶部右侧边栏切换按钮手动展开素材工作台。
- **界面与布局形态（严格保宽）**：
  - **中栏黄金视口**：中间会话栏物理宽度权威锁定 **$\ge 380\text{px}$**，对话上下文、消息流、输入框 100% 实时可见，绝不折叠；
  - **右栏素材中枢**：右侧边栏占用剩余空间（宽度自适应 $420\text{px} \sim 720\text{px}$，全屏时弹性放大）；
  - **顶栏共享 Tab**：右栏顶部消费同一个 `SharedHubTabBar`，呈现 6 大主库，高度 48px，右侧包含全屏与收起控制；
  - **工具栏**：高度 40px，包含搜索框、对应库的二级分类胶囊标签（首项为「全部」）、以及上下文动作（如「上传」「添加商品」）。
- **核心交互契约：即选即注入（Click-to-Attach）**：
  - 用户在右侧边栏浏览任意卡片，悬停可预览视频/大图；
  - **单击任意卡片**，触发原子注入操作：
    1. 调用 `AttachmentStore.addAttachment(sessionId, payload)`，卡片瞬时挂载到中栏输入框上方的附件槽中（支持去重与配额校验）；
    2. 将卡片关联的推荐 Prompt 或对标指令追加到输入框草稿中（`mergeLibraryPrompt`）；
    3. 中间会话输入框自动获得焦点（`preventScroll: true`）；
    4. **严禁自动提交**：绝不调用发送消息接口，保留用户修改 Prompt 与确认发送的主动权。

## 3. 架构设计与共享模块抽离决策（Shared Architecture）

### 3.1 抽离方案决策：单一真源（Single Source of Truth）
为了彻底解决双端数据模型、分类字典、图标与样式漂移问题，采用 **共享契约抽象层**：

```text
[ Shared Layer: shared-tabs-catalog.js ]
├── PRIMARY_TABS_CONFIG (6 大一级 Tab 唯一元数据：id, nameZh, nameEn, iconName)
├── SUB_CATEGORIES_WHITELIST (6 大库二级分类白名单字典，首项严格固定为 '全部')
├── TAB_ICONS_MAP (6 个专属 15x15 矢量 SVG 图标定义)
└── ASSET_HUB_I18N_SPEC (文案与状态机标准字典)
                    |
      +-------------+-------------+
      |                           |
      v                           v
[ 消费端 1: 新会话全屏 ]        [ 消费端 2: 素材工作台 (右栏) ]
ExploreTemplatesSection.jsx     AssetHubHeader.jsx / AssetHubToolbar.jsx
- 全屏沉浸式货架与网格          - 紧凑型右侧边栏 48px Header + 40px Toolbar
- 吸底 Prompt 预填联动          - Click-to-Attach 附件注入 + Prompt 追加
```

### 3.2 共享数据结构契约（Shared Spec Definitions）


## 5. UI 元素与文案白名单规格表（UI & Copy Spec — 唯一真源）

> **红线原则**：本规格表内所有中英文文案字面值 100% 锁定，禁止添加任何括号说明、装饰 Emoji 或修饰副标题。

### 5.1 六大一级 Tab 规格白名单（Primary Tabs Whitelist）

| Tab ID | 元素类型 | 中文显示文案（锁定） | 英文显示文案（锁定） | 矢量图标名称（SVG） | 对应数据通道与职能 |
|---|---|---|---|---|---|
| `featured` | 导航 Tab | `精选` | `Featured` | `book-open` | 官方 7 大 AI 应用与高转化灵感模板 |
| `assets` | 导航 Tab | `资产库` | `Assets` | `folder` | 用户个人/团队的本地上传、生成及角色资产 |
| `inspiration` | 导航 Tab | `灵感库` | `Inspiration` | `lightbulb` | 行业高品质视频、分镜脚本、分段提示词及视觉风格 |
| `products` | 导航 Tab | `商品库` | `Products` | `shopping-bag` | 电商多模态商品实体、主图、模特图与场景图 |
| `trending` | 导航 Tab | `爆款趋势` | `Trending` | `trending-up` | TikTok/社媒带货热门视频与分镜逆向拆解 |
| `skills` | 导航 Tab | `Skills` | `Skills` | `zap` | 专业视频/分镜/文案 AI Agent 工作流技能 |

- **显式废除项**：`canvas`（画布）彻底移出一级 Tab。
- **外观规范**：高 32px，外间距 4px，水平内边距 10px，字体大小 13px，字重 500；激活态高亮底色背景，未激活态微弱灰字悬停微高亮；禁止任何红色角标或“HOT”提示。

### 5.2 六大主库二级细分分类白名单字典（Secondary Filters Whitelist）

> **铁律**：所有库的二级分类**首项必须严格且唯一固定为「全部」**，严禁使用「全部资产」「全部灵感」等变体。

| 一级库 ID | 二级分类 ID | 中文文案（逐字锁定） | 英文文案（逐字锁定） | 语义与过滤规则 |
|---|---|---|---|---|
| **`featured` (精选)** | `all` | `全部` | `All` | 全量精选应用与灵感模板 |
| | `hook-intro` | `黄金开场` | `Hook & Intro` | 专治前3秒滑走：巨型碰撞、穿屏破框 |

### 5.5 Click-to-Attach 载荷与提示词追加规格（Payload & Prompt Spec）

当用户在场景 B（素材工作台）中点击卡片时，系统必须根据卡片所属主库生成标准 `AttachmentPayload` 并追加对应 Prompt：

| 库类别 (`lane`) | 附件类型 (`kind`) | 扩展名 (`ext`) | 生成的 Prompt 草稿模板（追加到输入框） |
|---|---|---|---|
| `featured` (模板) | `inspiration` | `TPL` | `请基于模板「${title}」，结合我的产品卖点生成对应视频脚本。` |
| `assets` (图片/视频) | `asset` | `MP4`/`PNG`/`JPG` | `请参考附件素材「${title}」，进行风格对标与内容生成。` |
| `inspiration` (灵感) | `inspiration` | `MP4`/`JPG` | `请基于灵感参考「${title}」，提炼其镜头节奏并复刻脚本。` |
| `products` (商品) | `product` | `JSON` | `请基于商品「${title}」，分析核心卖点并规划宣传文案。` |
| `trending` (爆款) | `inspiration` | `MP4` | `请对标热门爆款「${title}」，还原其前3秒黄金Hook与分镜结构。` |
| `skills` (技能) | `skill` | `SKILL` | `为我运行技能「${title}」，指导下一步创作流程。` |

   - 将 `ExploreTemplatesSection.jsx` 中的本地 Tab 数组与二级分类替换为消费 `shared-tabs-catalog.js`；
   - 验证全屏下 6 大 Tab 的切换、货架与网格渲染完整性；
3. **阶段三：素材工作台端重构（Asset Hub Workbench）**
   - 彻底废除 `workbench/` 中对 `canvas` Tab 的定义，替换为 `featured`, `assets`, `inspiration`, `products`, `trending`, `skills` 6 大主库；
