# 规格说明书：macOS 三分栏折叠左侧栏时保持会话栏比例并自适应放大右侧工作台

## 1. 业务背景与问题定义
在 macOS 桌面端环境下，用户在进行三分栏工作（左侧应用/会话导航栏 + 中间对话会话栏 + 右侧工作台/创作画布）时，点击左上角「收起侧边栏」按钮隐藏左侧边栏。
- **用户预期**：保持会话栏比例（与像素宽度）不变，整体向左平移靠齐，将左侧导航栏释放出的全部宽度（如 280px）自动分配给右侧工作台（创作画布），使右侧画布获得更大、更开阔的创作展示空间。
- **现状缺陷**：此前在 `conversation-box.js` 中由于历史遗留的选择器 `:not([data-details-collapsed="true"])` 与 `auto !important` 规则，导致右侧边栏在与弹性列 `1fr` 竞争时被瞬间挤压为 `0px`，中间会话栏直接膨胀为 1920px 全屏状态，工作台完全消失。

## 2. 验收标准（Acceptance Criteria）
- **AC-101（会话栏保宽左移）**：在三分栏（左栏展开、右栏展开）状态下点击收起左侧边栏，中间会话栏维持原有的物理像素宽度（由动态 CSS 变量 `--omnimux-conversation-width` 提供，基准保持在 ~485px / 480px），网格第一轨归零（0px），会话栏整体左移贴靠。
- **AC-102（右侧工作台吸收释放空间）**：左侧边栏释放出的全部水平宽度（如 280px）自适应分配给右侧工作台（第三轨为 `minmax(0px, 1fr)`），右侧工作台宽度显著扩大（例如 1155px → 1435px），绝不出现右栏被压灭（0px）或中间栏全屏吞没右栏的现象。
- **AC-103（折叠状态互斥严密性）**：
  - 当右侧工作台已收起（`[data-rightbar-collapsed="true"]`）时，左侧栏收起仍旧保持会话栏占满 100vw 的独占形态。
  - 当中间会话栏收起（`html[data-omnimux-conversation-collapsed]`）时，右侧工作台全屏铺满。
- **AC-104（双向切换平滑还原）**：再次点击左上角「展开侧边栏」按钮时，左侧栏恢复至展开宽度（280px），中间会话栏与右侧工作台无缝还原为初始分栏宽度，且顶栏按钮与标签栏零重叠。

## 3. 测试与验证要求
1. 单元测试：断言网格样式规则不再包含将第三列强行压为 0px 的 `auto !important` 粗暴规则，且包含对 `--omnimux-conversation-width` 及 `minmax(0px, 1fr)` 的正确定义。
2. 几何验证：在真实 DOM 环境模拟中，三栏展开 → 左栏收起后，center 宽度保持，rightbar 宽度等于 `viewport - centerWidth`，且 `rightbar > 0`。
3. CDP 真机验收：在 Dev App（1920 视口）中点击收起左栏，测量 `center.width === 485px`，`rightbar.width === 1435px`，截图留存证据。
