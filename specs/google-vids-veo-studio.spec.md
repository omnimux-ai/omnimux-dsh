# 特性规格：Google Vids (Veo) 智能视频生成中枢与剪辑时间轴协同系统
- **Issue ID**: #2655
- **分支**: agent/cross-google-vids-veo-issue-2655
- **责任模块**: `omnimux-video`, `omnimux-clip`

## 一、核心用户旅程与交互契约

### 1. 旅程 1：开箱环境就绪向导（Onboarding Wizard）
- **触发条件**：首次打开视频生成工作台中枢页面；
- **交互行为**：
  1. 弹出居中向导浮层卡片，呈现四步环境检查项；
  2. 自动巡检驱动环境（OpenCLI）、浏览器扩展桥接、Google 账号登录态、剪辑工程就绪态；
  3. 支持逐步点击自愈配置，4/4 全绿后高亮“开始体验创作工作台”按钮；
  4. 点击进入后向导平滑淡出，本地持久化记录状态，后续无需重复检查；
  5. 顶部保留“⚙️ 环境自检向导”按钮支持随时重新唤出。

### 2. 旅程 2：剪辑项目准入状态硬门禁自愈
- **触发条件**：右侧未打开/未新建剪辑工程；
- **交互行为**：
  1. 中栏顶部悬浮醒目黄色门禁条：“⚠️ 请新建或打开项目，进入编辑器页面后方可提交生成”；
  2. 底部提示词输入框、素材卡槽、生成按钮绝对锁定置灰；
  3. 右侧点击“新建空白项目并进入”后，0.2 秒内左侧门禁条转绿并平滑淡出，生成功能全量激活。

### 3. 旅程 3：静默无弹窗视频生成与时间线卡片流
- **触发条件**：输入有效提示词或挂载参考素材并点击生成；
- **交互行为**：
  1. 任务在 ego 独立任务空间中后台静默调度（`--window background`），杜绝桌面弹出独立浏览器窗口；
  2. 时间线顶部插入浅蓝卡片，实时呈现递增百分比进度（如 3%）与取消操作；
  3. 云端完成渲染后带凭据无损流式拉取 MP4 落地到工作区内部安全存储目录。

### 4. 旅程 4：成片秒级自动无缝注入时间轴主轨
- **触发条件**：在成片卡片动作栏点击「← 插入」；
- **交互行为**：
  1. 系统检索当前工程的主视频轨道（`track_video_main`）；
  2. 计算末尾时间点，执行原子添加指令，严格 0 间距拼接在前序切片尾部；
  3. 时间轴总时长自动延长，播放头吸附至新切片起点，监看播放器即刻起播。

### 5. 旅程 5：成片高阶动作栏跨模式联动穿透
- **「⧉ 延续」**：驱动底部切到【扩展】Tab，自动挂载当前视频，占位符更新为剧情续写提示；
- **「✎ 编辑」**：驱动底部切到【修改】Tab，视频作为基底载入，浮现 `+ 添加` 卡槽；
- **「⛶ 升频」**：卡片切回进行中状态，完成后规格徽标升级为 `1080p • 0:10 (已升频)`；
- **「⋮ 移除」**：带有缩小淡出动画从时间线生成流中平滑删除。

## 二、验收用例（Acceptance Criteria）
- **AC-1**：四步向导开箱检测与逐步自愈交互 100% 畅通，全绿后平滑解锁；
- **AC-2**：未进入项目时左侧强门禁锁定，进入后 0.2s 自愈解锁；
- **AC-3**：后台静默调度零桌面弹窗，进度卡片数字递增，支持取消；
- **AC-4**：成片无损落盘至工作区内部目录，杜绝 `/tmp/` 跨区拦截；
- **AC-5**：点击插入 1 秒内无缝 0 间距贴合 V1 视频主轨末尾并起播；
- **AC-6**：延续与编辑跨组件状态无缝穿透；
- **AC-7**：自动化单测 100% 通过，两轮开源 OCR 0 缺陷通过。
