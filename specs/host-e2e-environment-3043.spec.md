# #3043：恢复原生评论与生成反馈的真实浏览器测试

## 目标与边界
用户要求修复测试宿主，让 comment-native 与 generation-feedback 实际执行通过；不得新增 skip 掩盖失败、削弱有效断言或用仿制组件冒充生产页面。禁止修改或重启用户正在使用的桌面应用，不复制用户凭据/profile，不调用付费生成服务，不修改官方 DSH 源码。修复范围为本仓测试环境装配与有效契约同步。

## 已证实的现象
- 原生评论：私有宿主的聚合客户端请求返回 HTTP 431。设置该进程请求头上限为 64KiB 后同一路径返回 200；再构建本工作树 Hub/viewer、安装拆分后的 viewer、预置无凭据合成运行选择，并通过真实全屏按钮恢复分栏，即可执行原生评论流程。安装日期不能证明版本不兼容。
- 生成反馈：独立 esbuild 夹具构建失败，仍引用已拆分到 omnimux-viewer 的 MediaViewerTab 路径。改为私有源码 staging 构建、解析正式公开 omnimux-viewer/client export，并运行该客户端的 factory/apply 后消费 sidebar 注册的真实组件；不跨插件私有导入。该夹具不启动桌面包，与评论故障分别诊断；构建用 Node runner 显式传入可执行路径，不将 ego 内部 Electron 当作 Node。

## 操作旅程与反馈
评论测试在隔离工作树装配真实宿主、正式插件及合成会话，经过首启与原生评论添加、发送前全文扩展、移除流程；保存截图、浏览器与会话证据。外层测试拒绝真实模型调用。
生成反馈测试由真实生产桥接接收合成传输事件，驱动当前真实查看器组件；验证请求隔离、结果归属、媒体可读性与正常/异常生命周期。已退役界面由现行规格核定，不重新恢复旧任务卡。

## 新用户与运行前置
测试依赖正式宿主、声明的开发依赖、真实浏览器驱动和正式侧栏桥接包。宿主路径可显式传 OMNIMUX_E2E_EXECUTABLE/OMNIMUX_E2E_CLI，约定安装包缺失时报可读失败；侧栏优先读取仓库声明的依赖，当前声明 0.18 与本机宿主布局的实际不兼容已取证，完整原生验收须显式传 OMNIMUX_E2E_SIDEBAR 指向已验证的正式桥接代码包并记录版本/内容 hash。不默认搜索用户 profile、不复制凭据或设置；显式输入代码包不冒称干净机器无配置即能执行。构建复用正式脚本但输出位于每次独有的私有 staging，动态端口与测试进程在 finally 清理。

## 测试接缝与验收
1. 获取评论模块加载失败的实际请求响应/异常（并保留脱敏证据），修复装配而非延长等待掩盖失败。
2. 生成反馈夹具可构建并在真实浏览器挂载现行生产组件；有效测试断言经当前产品契约核定。
3. 两个指定测试实际执行，退出码为 0，核心业务场景不全跳过；截图和结构化报告属于同次运行。
4. 测试失败仍保留诊断、关闭任务浏览器和私有服务；不残留测试进程。
5. 相关本地回归、独立代码审查和必要 CI 通过后按 PR 流程交付。

## 文档影响
本规格与最终证据说明拥有本次环境修复的前置条件、诊断结论和验收；若宿主启动接口发生变更，同步所属测试环境合同说明。产品 UI、文案、模型能力与正式发布不在范围内。
