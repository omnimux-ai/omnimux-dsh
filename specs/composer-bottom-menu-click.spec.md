# 规格：首页沉底输入框指令菜单可点

Issue: #2112
插件: omnimux
日期: 2026-09-16

## 1. 目标

首页输入框沉在页面底部时，打开指令菜单后点「从资产库添加」必须立刻打开选择窗。点击必须落在菜单上，不得穿透到后面的灵感卡片。

## 2. 成功标准

1. 输入框在底部、菜单开在输入框上方时，点「从资产库添加」立刻出现选择窗。
2. 菜单打开时，菜单项所在位置的最上层是菜单本身，不是后面的灵感卡片。
3. 输入框在顶部居中时，原有「点开即出选择窗」行为保持不变。
4. 取消选择窗不新增附件。

## 3. 边界

- 总是：沉底菜单可点；不穿透到后面卡片
- 绝不：改灵感卡片交互；改选择窗内部

## 4. 验证

相关单测覆盖：沉底时菜单可接收点击；打开菜单后菜单项在最上层。
