# 规格：输入框 @ 实体引用一级图标与二级悬停点击菜单完整交互规范

## 一、背景与问题定义

输入框在键入 `@` 字符弹出素材引用菜单时，存在以下体验断层：
1. **分类入口缺失图标**：「角色」与「产品」一级分类选项左侧缺少直观的视觉图标，与普通素材的缩略图及对话引用的气泡图标产生割裂；
2. **分类入口识别判定过于严格导致未激活**：真机宿主 DOM 的 `<button role="option">` 未包含 `data-value` 属性，导致 `isCharEntry` 与 `isProdEntry` 假阴性漏判，使得指示箭头未渲染、悬停监听器未挂载；
3. **点击未支持展开**：用户通过鼠标点击或移动端触控一级选项「角色」或「产品」时，直接静默失效，缺少点击展开二级菜单的交互闭环；
4. **二级菜单渲染多层级容器**：二级悬停菜单内部采用冗余的 `createPortal(..., document.body)`，可能在复杂多层容器中丢失定位。

---

## 二、关键用户旅程 (Critical User Journeys)

### Journey 1: 输入 @ 呈现标准带图标的一级入口
- 用户在对话输入框键入 `@`；
- 弹出的建议列表中，常驻首项为「角色」，左侧展示精致 Character SVG 矢量图标，右侧带展开指示箭头 `›`；
- 常驻次项为「产品」，左侧展示精致 Product/Box SVG 矢量图标，右侧带展开指示箭头 `›`；
- 鼠标悬停或方向键导航到选项时，左侧图标与背景平滑高亮。

### Journey 2: 鼠标悬停或点击流畅展开二级菜单
- **悬停交互**：鼠标移入「角色」或「产品」选项，40ms 防抖后向右（视口受限时向左）平滑滑出二级实体列表；移出选项有 180ms 延时保护；
- **点击交互**：鼠标点击「角色」或「产品」选项时，阻止冒泡并即刻展开二级菜单，保持稳定可见供用户点选。

### Journey 3: 二级实体选择与双向联动
- 二级菜单单行展示「实体缩略图 + 实体全称」，彻底无冗余分组标题与副标题描述；
- 点击二级列表中的某个角色（如“Mariam outside”）或商品（如“女士高级淡香水50ml”）：
  * 对应实体即时加入输入框卡槽（AttachmentTray），商品标明 JSON，角色标明 ASSET；
  * 输入框原光标处的 `@` 符号被精确剥离，无缝替换为对应的标准胶囊节点（Mention Chip）；
  * 二级与一级菜单同时关闭，光标定位在胶囊之后。

## 三、验收标准与门禁规范

1. **视觉与样式规范**：
   - 「角色」行左侧具备 18×18 尺寸 Character 矢量图标；
   - 「产品」行左侧具备 18×18 尺寸 Product 矢量图标；
   - 右侧具备统一的指示展开箭头 `›`；
   - 二级菜单层级 `z-index: 10005`，高于宿主浮层，无穿透。
2. **健壮性与兼容性**：
   - 兼顾 `data-value` 契约判别与 `itemName` 全等精确匹配（`itemName === '角色'` / `itemName === '产品'`），即使宿主 DOM 未透传 `data-value` 也 100% 稳健识别；
   - 不误伤任何以「角色」或「产品」为名称前缀的普通素材文件；
   - 支持 Hover 与 Click 双交互通道。
3. **测试门禁**：
   - 补充定向自动化单元与 E2E 测试用例，测试通过率 100%。
