# 底栏剩余控件收敛（分段器 / ASR 模型触发器 / 空态提示 / 段间分隔符）

- 任务：`.worktrees/workflow-bar-converge-remainder`（分支 `feat/workflow-bar-converge-remainder`）
- 日期：2026-09-14
- 上游：Issue #1805 / PR #1807 已完成素材节点（图片 / 视频）底栏三个触发器的收敛；本任务承接其遗留的未收敛项，用户于 2026-09-14 明确「统一收敛」。

## 1. 问题

底栏 `wf-config-panel__params-group` 的控件家族中，仍有四类未收敛：

| 控件 | 类名 | 现状 | 类别 |
| --- | --- | --- | --- |
| 模型选择（图片 / 视频 / 文本） | `wf-model-cascade-capsule` | 胶囊 + 五态，已在共享组 | 触发器 |
| 模型选择（转写 ASR） | `wf-param-bar__select--model` | antd 默认样式，不在共享组 | 触发器 |
| 音色 | `wf-voice-trigger` | 胶囊 + 五态，已在共享组 | 触发器 |
| 参数摘要（图片 / 视频） | `wf-cfg-summary-bar` / `wf-video-trigger-bar` | 胶囊 + 五态，已在共享组 | 触发器 |
| 生成方式（文本 / ASR） | `wf-cfg-seg` | 8px 方角容器 + 6px 内块 | 分段控件 |
| 零候选空态提示 | `wf-param-pill--empty-models` | 内联样式，8px 方角 | 状态提示 |
| 段间分隔 | `wf-param-pill__divider` | `|` 文本字符 | 分隔符 |

后果：文本 / 转写节点的底栏仍是「胶囊 + 方角」并存；ASR 模型触发器与其余触发器同类却不同源；分隔符仍是字符节点（摘要条早已改为 CSS 竖线）。

## 2. 目标

把上述四类未收敛项收敛到既有规格：同类控件同源，不同类控件共享同一套几何与色彩 token，消除遗留的第二种做法。

## 3. 验收标准（可测试）

### 3.1 触发器（含 ASR）

- AC-1 ASR 模型触发器与其余三个触发器计算样式一致：`height: 32px`、胶囊圆角、同一底色与描边、`padding: 0 8px 0 10px`。
- AC-2 ASR 模型触发器具备五态：hover 提亮、open 品牌描边、按压回弹、键盘焦点环、不可用淡化。
- AC-3 四个触发器共用同一份共享组声明（不允许为 ASR 单独复制几何）。

### 3.2 分段控件

- AC-4 `.wf-cfg-seg` 容器圆角为胶囊，内块 `.wf-cfg-seg__item` 圆角为胶囊；高度契约保持（容器 32px / 内块 26px / 内边距 2px）。
- AC-5 分段控件的选中态品牌内描边、键盘焦点环、禁用态淡化保留。
- AC-6 底栏与浮层内的分段控件外观一致（同一份声明，不分裂为两套）。

### 3.3 空态与分隔符

- AC-7 零候选空态提示与触发器同几何（胶囊 / 32px / 同底色与描边），不再使用内联业务样式。
- AC-8 底栏段间分隔不再出现字符节点（`|`），改为语义化 CSS 竖线，与摘要条一致。

### 3.4 回归

- AC-9 既有断言全绿；`scan-ui-gates` 0 违规；`verify:stages` PASS；`typecheck` PASS。
- AC-10 真实浏览器实测：各类控件计算样式与状态反馈符合上述条目，留存截图与结构化结果。

## 4. 不在范围

- 面板错误边界的「重试」按钮（`wf-param-pill--btn`，异常态，非底栏正常运行控件）。
- 浮层内部除分段控件外的其它控件。

## 5. 验证方式

- 静态：相关单测 + `node scripts/scan-ui-gates.mjs` + `node scripts/verify-stage-contracts.mjs`。
- 浏览器：本工作树内隔离运行，读取各控件计算样式与状态值，留存截图与结构化报告。
