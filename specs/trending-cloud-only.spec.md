# 规格：爆款趋势只加载云端数据，取消本地导入素材混入

用户反馈：灵感社区「爆款趋势」Tab 会混入本地导入的灵感素材；本规格把它收敛为纯云端目录。

## 用户看到什么

1. 打开灵感社区，默认停在「爆款趋势」，列表只显示云端目录内容，绝不出现自己导入的本地素材。
2. 在灵感社区任意 Tab 点「导入灵感」成功：本地行不再被插进当前网格顶部一闪而过；列表切到「灵感库」，落地卡片由钉住机制显示。
3. 新会话页爆款对标区同样只取云端目录，不再请求本地灵感库接口。
4. 未登录时爆款趋势仍走登录提示，不拿本地内容填充。

## 验收

- 爆款趋势首屏与翻页请求只发向云端接口，不发 `/omnimux/inspiration/local`。
- 在爆款趋势页导入一条素材：导入完成前该 Tab 列表里不出现本地卡片；导入完成后停在灵感库且新卡片可见。
- 灵感库、账号监控行为不变；云端列表、筛选、翻页、去重逻辑不变。

## 边界

- 总是做：去掉「爆款趋势」两处的本地数据源与导入时的就地前插。
- 绝不做：改云端目录接口、改灵感库 Tab、改卡片样式与复刻交互。
