# 规格文档：资产库内产品库 Tab 布局与原产品库页面 1:1 像素级对齐还原

**文件：** `specs/align-products-layout.spec.md` ｜ **优先级：** P0 ｜ **模块：** `plugins/omnimux-assets` + `plugins/omnimux-products`
**变更面：** Client / Stage / 视图布局 / 空状态与筛选
**设计依据：** 用户实机对比反馈截图、产品库原页面布局标准（`plugins/omnimux-products/src/client/ProductsStage.jsx`）、[design.md](../design.md)

---

## 1. 业务目标与问题根因

### 1.1 核心痛点与缺陷分析
- **痛点**：用户在资产库中点击切换至「产品库」选项卡后，发现布局结构与原独立产品库页面存在明显偏差：
  1. 动作栏按钮缺少下拉小箭头与分流交互，未能呈现标准菜单胶囊；
  2. 搜索框右侧多出了网格/列表切换小图标；
  3. 下方额外多出了一行冗余的圆角计数胶囊（`全部 0`、`实物产品 0`、`数字产品 0`），破坏了原本单层干净的 Tab 呼吸感；
  4. 空状态居左偏置，未对齐原产品库全宽居中、大虚线圆角边框的标准空状态设计。

### 1.2 改造方案（1:1 对齐还原）
1. **操作栏动作对齐**：切换到产品库时，主按钮切换为带下拉小箭头与悬停分流菜单的白色胶囊按钮（`+ 添加产品 ⌄` 或 `+ 新建产品 ⌄`），次按钮为 `[ 💬 对话中添加 ]`。
2. **工具栏与分类对齐**：
   - 在「产品库」Tab 下，筛选栏直接采用产品库原生下划线 Tab（`全部`、`实物产品`、`数字产品`）；
   - 移除下方多余的胶囊行；
   - 搜索框采用 `stretch` 全宽，占位符为 `搜索产品名称、卖点、品牌`，并隐藏网格/列表切换图标。
3. **空状态 1:1 还原**：
   - 严格对齐原产品库 `.omnimux-products-empty`：自适应全宽、带有虚线圆角边框（`1px dashed var(--dsw-alias-border-l4)`）；
   - 居中文案：`暂无产品数据。点击「添加产品」录入首件标品。`；
   - 下方居中展示带下拉小箭头的操作胶囊按钮。
4. **卡片网格样式对齐**：全量注入并复用原产品库的 `.omnimux-products-grid`、`.omnimux-products-card` 样式与卡片结构。

## 2. 验收标准（Acceptance Criteria）

### 2.1 动作行与按钮组件 (P0)
- **AC-101**：在「产品库」Tab 下，主按钮渲染带下箭头的创建菜单，鼠标悬停可弹出分流菜单（实物产品 / 数字产品）。
- **AC-102**：次按钮保持 `[ 💬 对话中添加 ]`。
- **AC-103**：切回「本地」或「云端」后，恢复为 `[ + 添加资产 ]` 和 `[ ⇧ 导入资产包 ]`。

### 2.2 筛选栏与视图纯净度 (P0)
- **AC-201**：在「产品库」Tab 下，隐藏网格/列表视图切换开关。
- **AC-202**：搜索框占位文案展示为 `搜索产品名称、卖点、品牌`。
- **AC-203**：移除重复的分类胶囊行，子分类筛选采用产品库原版下划线样式。

### 2.3 空状态容器视觉与内容 (P0)
- **AC-301**：空状态容器带有全宽虚线圆角边框，高度适中且内容垂直水平居中。
- **AC-302**：空状态文案与按钮完整对齐原页面。
