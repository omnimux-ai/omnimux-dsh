# TikTok 场景图标冲突避让顶升与当前视频识别规格 (Issue #2035)

## 1. 业务目标与价值
解决 TikTok 网页端中，OmniMux 幽灵图标与其他第三方扩展/竞品按钮重叠遮挡问题，以及首页信息流下点击下载提示“这一页没有可操作的作品”的问题。

## 2. 核心交互与物理排布拓扑（从上到下）
1. **顶层**：对手的第三方竞品按钮（如橙色 CK 插件图标及其他辅助圆点），被算法强制向上推移（至少相距 8px 安全间隔），排在最上方；
2. **中间（首要黄金位）**：OmniMux 紫色幽灵按钮，坚守锚定在创作者头像正上方 8px（坐标：`avatar.top - 56px`），位置稳定不妥协；
3. **基准底座**：TikTok 原生创作者头像（带关注加号按钮）；
4. **下方原生操作项**：点赞、评论、收藏等原生按钮依序向下自然排列。

## 3. 验收标准 (AC)
- **AC-1 (冲突检测与避让)**：当检测到创作者头像正上方区域存在第三方图标侵占高度时，自动计算偏移量，将第三方图标通过 `transform: translateY` 向上推升，使其底部与幽灵图标顶部保持至少 8px 间距。
- **AC-2 (级联顺延推移)**：若对手图标上方还有其他扩展按钮，依次向上顺延推移，互不挤压、互不遮挡。
- **AC-3 (优雅恢复)**：当页面无冲突或插件卸载时，原样恢复第三方元素样式。
- **AC-4 (信息流当前视频识别)**：当页面处于 TikTok 首页推荐流且地址栏未携带具体作品 ID 后缀时，优先从当前屏幕中心或活跃卡片中提取当前作品信息，杜绝“这一页没有可操作的作品”误报。
