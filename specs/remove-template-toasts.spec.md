# 规格：彻底移除卡片复刻与点击触发的遮挡提示弹窗 (Remove Template Toasts Spec)

## 一、需求背景与现状分析
- **业务诉求**：根据用户提供的界面截图，点击模板卡片上的「复刻」按钮后，屏幕中央弹出了半透明黑色气泡 `✔ 已装配【拍摄与投放揭示】提示词`。用户明确指示：“把这个提示元素 移除 不要做这种提示”。
- **根因分析**：
  1. `SessionGuide.jsx` 中的 `handleExploreTemplateApply` 遗留了 `showToast('已装配【...】提示词')` 和 `showToast('已为您打开【...】')`；
  2. `handleExploreTrendingApply` 遗留了 `showToast('已挂载灵感文件 ... 分镜上下文')`；
  3. 按照复刻模式全链路与极简现代交互规范（参考 `handleTrendingApply` 和 commit `4e671d0dc`），输入框本身已通过 FLIP 平滑动画吸底停靠，且已自动装载提示词草稿与光标聚焦，输入框和附件本身即是最佳直观回执，中央弹出的 Toast 浮层纯属冗余视觉干扰。

## 二、改造方案
1. **彻底移除模板复刻弹窗**：
   - 在 `handleExploreTemplateApply` 中删除 `showToast('已装配【...】提示词')`；
   - 删除 `showToast('已为您打开【...】')`；
2. **彻底移除热门视频复刻弹窗**：
   - 在 `handleExploreTrendingApply` 中删除 `showToast('已挂载灵感文件 ... 分镜上下文')`；
3. **保持纯粹丝滑体验**：
   - 用户点击「复刻」或「使用」时，输入框静默吸底、静默填入草稿并自动聚焦，页面中央绝不再弹出任何 Toast 气泡遮挡视线。

## 三、验收标准
1. 点击模板卡片「复刻」，草稿正常预填，输入框正常吸底，页面中央绝不弹出「已装配」Toast 提示；
2. 点击 TikTok 热门视频卡片「复刻」，草稿正常预填，输入框正常吸底，页面中央绝不弹出「已挂载」Toast 提示；
3. 自动化测试 100% 绿灯。
