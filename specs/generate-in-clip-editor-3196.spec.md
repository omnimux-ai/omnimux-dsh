# 生成能力并入视频剪辑窗口（Issue #3196）

## 1. 问题与用户旅程

**问题**：生成能力（创建／动画／修改／延续）目前挂在一个**独立产品页面**上，靠「抢占产品舞台」显示。真机实证两类缺陷：
1. 从「探索」点击后页面**空白**——页面内与生成相关的节点只剩一段样式，舞台根节点根本不存在；
2. 入口调用「唯一活动主面板」选择器后，右栏被折叠为 **0 宽**（实测 640×713 → 0×713），刚挂载的剪辑工作台被卸载，「新建工程」事件因此无人监听而失效。

成因是两套互斥主张各改一半：一侧按「普通页面」登记，另一侧按「同屏工作台」接管，结果两边都不成立。

**用户旅程（目标态）**
1. 用户从「探索」点击生成入口 → 打开**视频剪辑窗口**（不再新开独立页），左列即为生成面板。
2. 用户在左列选模式、写提示词、按需点开右侧素材工作台挑选虚拟形象／素材／图片／视频，选完回填为可删除标签。
3. 用户点「生成」→ 左列显示任务进度；生成期间可切页签、可编辑时间线，任务不中断。
4. 生成完成 → 成片自动登记为剪辑素材并**追加到时间线**，片段高亮，用户可直接剪辑。
5. 用户需要调整画面时，右侧「素材／属性」页签里就是官方原有配置面板（媒体／文字／图形／效果／转场／调整）。

## 2. 根因

- 生成界面被实现为**独立产品舞台**（需要入口先接管舞台、再显示内容），而产品舞台与「同屏工作台」两种承载方式互斥。
- 入口同时保留两套承载动作，导致舞台未被正确接管、右栏又被折叠 → 中间空白。

## 3. 行为契约

| 编号 | 契约 |
| --- | --- |
| C1 | 生成入口不再注册／接管任何产品舞台；点击后打开剪辑窗口并聚焦生成面板。 |
| C2 | 剪辑外壳布局为四区：左＝生成插槽，中＝官方播放器，右＝官方素材／属性页签，下＝官方多轨时间线。 |
| C3 | 官方组件（资源库／属性面板／播放器／时间线／导出）**一律保留原实现**，仅调整列序与列位，不替换、不自研替代。 |
| C4 | 生成面板由视频插件提供、经**具名插槽**注入；剪辑插件只声明插槽与消费，不导入视频插件内部；视频插件不触碰剪辑内部状态。 |
| C5 | 插槽不可用（剪辑插件缺失或未声明）时，入口给出明确提示并提供「打开剪辑」路径，**不得出现空白页**。 |
| C6 | 生成请求链路不变：面板 → 视频插件自身接口 → 中枢生成缝 → 本机通道；四模式映射 `text_to_video / first_frame / video_edit / video_extend` 不变。 |
| C7 | 任务状态以服务端任务存储为真源；切换页签或关闭窗口不丢任务，重进后按任务号恢复展示。 |
| C8 | 成片落地复用剪辑既有素材登记与轨道写入通道，不新造写入路径；引用上游取片地址，不落本地临时文件。 |
| C9 | 输入项（虚拟形象／素材／图片／视频）的文件类型与数量上限严格按中枢契约校验；超限给出可读拒绝原因。 |
| C10 | 三列在窄窗口下按最小宽度与折叠规则降级，优先保留播放器；**不得出现零宽列**。 |
| C11 | 主题沿用官方设计变量，不引入第二套配色；空态使用 ui-kit，禁止裸选择器与表情图标。 |

## 4. 验收用例

| 编号 | 用例 | 判据 |
| --- | --- | --- |
| AC-1 | 从探索进入生成入口 | 打开的是剪辑窗口；左列存在生成面板；页面无空白区 |
| AC-2 | 官方配置面板位置 | 媒体／文字／图形／效果／转场／调整出现在**右侧**，组件与官方实现一致（非重写） |
| AC-3 | 播放器与时间线 | 官方播放器与多轨时间线原样可用（播放、切片、撤销） |
| AC-4 | 输入项经右侧工作台选择 | 点击任一输入项打开右侧素材工作台；选中后回填为可删除标签；超限被拒且有原因 |
| AC-5 | 提交生成 | 面板提交后任务受理；四模式各自映射到约定的操作类型，参数字段逐项透传（时长／分辨率／比例） |
| AC-6 | 成片落地 | 任务到达终态后，成片登记为剪辑素材并出现在时间线 |
| AC-7 | 任务不丢 | 生成中切页签再回来，任务进度按任务号恢复 |
| AC-8 | 插槽缺失回退 | 未声明插槽时入口给出提示且不空白 |
| AC-9 | 窄窗口 | 三列降级后无零宽列、无破版 |
| AC-10 | 真机证据 | 工作树内真实浏览器四区截图随 PR 提交，逐张人眼确认 |

## 5. 边界

- 生成失败：面板显示失败原因与重试入口，不静默吞错。
- 成片落地失败：保留成片地址并给出可重试入口，不丢结果。
- 剪辑窗口在生成中被关闭：任务继续；重开后恢复。
- 首次打开剪辑（无工程）：沿用官方空态与「新建工程」路径。

## 6. 非目标

- 不重写官方编辑器组件；不替换官方时间线／播放／导出实现；不自研第二套界面壳。
- 不动生产环境；不重启桌面应用。
- 不做参考图的像素级视觉打磨（另单进行）。

## 7. 契约影响

`docs/contracts/openreel-vendor-contract.md` 现有「官方 GUI：映射 CSS 变量，不重排、不换组件」。本单授权范围（用户已确认）：**允许调整官方外壳的列序与列位；必须保留全部官方组件、不得替换其实现、不得自研替代界面**。契约文本随本单同步修订并在 PR 说明。
