# 本机 CLI 模型配置升级：支持模型列表自动获取与下拉手动选择规格说明（Issue #2617）

## 背景与问题陈述
在设置界面的「对话与媒体生成模型」卡片中，选中「本机 CLI」后，各个已安装的命令行工具（Claude Code、Codex CLI、Kimi CLI、Qwen Code）下方的「模型」配置原本为普通单行输入框，用户必须自行记忆各工具支持的模型名称并手工输入，缺乏直观引导且容易拼写错误。

## 改造目标
1. **自动获取并附带支持的模型列表**：
   - 扫描或获取各个已知 CLI 工具时，附带其官方常用模型列表（如 `claude-3-7-sonnet`、`gpt-4o`、`moonshot`、`qwen-max` 等）；
   - 在前端各 CLI 卡片展开后，直接读取该 CLI 对应的模型列表。
2. **升级为标准下拉选择框 (DropdownSelect)**：
   - 将原单行文本输入框升级为标准 `DropdownSelect` 组件；
   - 下拉首选项（默认项）为「CLI 默认设置」（value 对应空字符串 `""`），展示文案为 `t('runtime.cliDefaultSetting', 'CLI 默认设置')`；
   - 点击下拉框可列出所有自动获取到的官方模型选项，点击即可选中；若当前已保存有值，也能保持高亮选中。
3. **执行链路模型参数注入**：
   - 在 `agentTextCommand` 与 `runAgentText` 中支持可选的 `model` 参数；若用户选定了指定模型，自动向 CLI 命令行追加 `-m <model>` 或 `--model <model>`；若为「CLI 默认设置」则不附加参数，遵循 CLI 本地预设。
4. **测试与质量保障**：
   - 包含端到端自动化测试断言下拉框挂载、默认项“CLI 默认设置”以及切换选中的行为。

## 验收断言标准 (Spec Criteria)
- **S1 (CLI 模型列表元数据)**：各个已知本地 agent 实体均提供 `models` 列表字段，包含官方推荐的常用模型名称。
- **S2 (下拉框组件挂载)**：展开已选中的 CLI 卡片后，模型配置项呈现为 `DropdownSelect`（拥有选择框结构，而非仅是普通输入框）。
- **S3 (默认选项契约)**：下拉选项列表第一项的文本严格为「CLI 默认设置」，初始未设置时默认处于此项。
- **S4 (可交互选择与保存)**：用户切换选择候选模型后，自动触发更新并保存；切回「CLI 默认设置」时正常生效。
- **S5 (全套测试回归)**：单元测试与 E2E 测试全部通过。
