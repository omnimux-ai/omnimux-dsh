# 4051 发布列表选中后自动显示批量操作栏

Issue: #4051 · 分支 `agent/publish-batch-bar-issue-4051` · 风险等级 **R2**（列表交互）

## 背景

发布列表勾选记录后没有批量操作入口；只有先点顶部「批量管理」进入批量模式才会显示。产品内其他列表（商品、资产）的约定是：**勾选任意一项即出现选择栏**（已选 N 项 + 取消选择 + 批量操作），不需要额外进入模式。

## 方案

1. `PublishViewport`：批量栏显示条件由 `isBatchMode` 改为 `isBatchMode || selectedIds.size > 0`，抽成 `shouldShowBatchBar()` 便于测试。
2. `PublishBatchBar`：
   - 计数改用本地化文案 `action.selectedCount`；
   - 未选中时批量重试/批量删除禁用；
   - 非批量模式下右侧显示「取消选择」，批量模式下显示「退出批量」。
3. `PublishStage` 的 `onExitBatch` 同时清空选择，避免退出后残留勾选。
4. 新增中英文文案。

## 假设

- 勾选行为本身已经维护 `selectedIds`，不需要改表格与卡片的选择逻辑。
- 「批量管理」按钮继续保留，用于全选/退出批量；勾选也能直接唤起同一栏。
- 批量操作仍只作用于已选记录，不变更现有批量重试/批量删草稿的语义。

## 证伪方式

- 单测：`shouldShowBatchBar(false, 1) === true`、`(false, 0) === false`、`(true, 0) === true`；批量栏在计数 0 时批量按钮 disabled。
- 浏览器实测：未选中时无批量栏；勾选一行后出现「已选 1 项」与批量按钮；点「取消选择」后消失。
- 现有 310+ 单测保持通过。

## 新用户基线

无新增配置；默认未选中不显示，勾选即出现，与其他列表一致。

## 文档影响

无。
