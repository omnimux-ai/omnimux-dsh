# 规格：浏览器伴侣插件精灵助手消息排队坞（QueueDock）对齐原生规范

## 1. 目标与背景
浏览器伴侣扩展（精灵助手侧边栏）当前的消息排队框存在三大缺陷：
1. 宽度与下方输入框生硬齐平，缺乏官方原生队列的台阶咬合结构（dock-inset）；
2. 缺失「立即发送 / 插话发送（Steer）」功能，用户在多消息排队时无法插队优先调度；
3. 操作按钮常显刺眼，缺乏官方原生「默认隐藏、鼠标悬停时平滑浮现」的极简微交互。

本任务在保持精灵助手现有输入框结构（20px 圆角大卡片、回形针附件、自动模型胶囊、纯圆白色发送按钮）100% 不变的前提下，将消息排队框（QueueDock）按官方原生标准彻底对齐升级，做到所见即所得。

## 2. 验收标准
1. **排队框比例与结构咬合**：
   - 排队框位于输入框正上方，左右各自内缩 12px ~ 14px（width: calc(100% - 24px); margin: 0 auto -1px auto;），比输入框明显窄一圈，形成优雅的台阶式咬合；
   - 顶部圆角 12px，磨砂毛玻璃半透明深灰底色，0.5px 微浅边框。
2. **操作按钮显隐交互**：
   - 默认状态下操作按钮组完全隐藏（opacity: 0; pointer-events: none;），保持纯净；
   - 当鼠标悬停（Hover）在排队框上时，操作按钮组平滑浮现（opacity: 1; pointer-events: auto;）。
3. **三大图标操作齐备**：
   - **立即发送（插话发送 / Steer）**：点击立即通过 RPC 调用 session.updateQueue（action 为 { kind: 'steer' }），将该条排队指令抢占优先注入执行流；
   - **编辑（Edit）**：行内展开自适应多行文本框修改文本，支持回车保存与 Esc 取消；
   - **删除（Remove）**：点击移出队列，清空后排队框自动隐退。
4. **杜绝 Emoji 表情**：
   - 彻底禁用系统 Emoji，一律采用高清矢量 SVG 图标（MessageSquare、ZapIcon 向上插话箭头、EditPencilIcon、TrashIcon）。
5. **输入框保持精灵助手原有体系**：
   - 不修改精灵助手自身的输入卡片结构（保留回形针、自动模型选择胶囊、白色圆形发送按钮）。
