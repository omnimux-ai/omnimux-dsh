# 规格文档：顶栏会话按钮文案与图标修正及搜索框内框线消除 (#1642)

## 一、背景与问题定义
1. **顶栏会话触发按钮文案不准确**：左上角会话菜单触发器目前默认文案为「新建项目」（英文 New Project），但该入口实际管理的是历史会话列表，新建时也是创建新会话，导致业务表达与即时对话直觉脱节。
2. **顶栏会话触发按钮图标辨识度不足**：目前采用望远镜图标（BinocularsIcon），在 16px/17px 小尺寸渲染下视觉呈白色团块状，与即时聊天会话心智不符。
3. **会话搜索框存在突兀内边框线**：在会话历史浮层中，内部 input 元素带有浏览器原生或继承的矩形边框与聚焦外框，与外层圆角胶囊容器叠加形成双层线，视觉杂乱割裂。

## 二、验收标准（Acceptance Criteria）
1. **文案变更**：
   - 默认会话标题由「新建项目」修改为「新会话」。
   - 英文本地化由「New Project」修改为「New Chat」。
2. **图标修正**：
   - 顶栏触发器图标由 `BinocularsIcon`（望远镜）替换为现代极简的双向气泡对话图标 `MessageSquareIcon`。
   - 统一尺寸（16px）与居中对齐，与右侧的「＋」和「···」保持一致视觉节奏。
3. **搜索框内边框消除**：
   - `.session-search-input` 强制声明 `border: none !important; outline: none !important; box-shadow: none !important;`。
   - 搜索框内文字与放大镜图标自然融入外层圆角容器，仅由外层胶囊在聚焦时呈现柔和微光，彻底杜绝双层框。

## 三、用户交互关键旅程（Critical User Journey）
1. 用户打开侧边栏扩展，顶栏左侧直观呈现 `💬 新会话 ▾`，无边框设计，悬停呈现轻量高光。
2. 用户点击该按钮展开历史会话面板，顶部搜索栏中光标聚焦，输入框平滑自然，无任何生硬的矩形内边框。
