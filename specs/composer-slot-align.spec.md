# 素材缩略图与输入框左右对齐

## 目标

首页已加入的素材缩略图，无论输入框停在页面中部还是吸到底部，都要和输入框左边缘对齐、宽度相同。缩略图不能贴在整栏最左边。没有素材时不出现空条。

新用户不依赖本机私有服务。没有素材时不显示、不报错。

## 用户操作旅程

1. 打开首页，输入框在页面中部。
2. 加入一张图片或视频。
3. 缩略图出现在输入框正上方，左边缘与输入框相同，右边缘不超过输入框。
4. 选用会把输入框吸到底部的入口，再向下浏览。
5. 缩略图仍贴在吸底输入框正上方，左右继续对齐。

## 验收用例

- 用例一：未吸底时，素材条最大宽度与输入框相同，并且水平居中。
- 用例二：吸底时，素材条左边缘、宽度与输入框相同。
- 用例三：没有素材时不渲染素材条。

## 边界

- 只改素材条的宽度和对齐，不改上传、删除、预览、提交。
- 不改输入框自己的宽度。
