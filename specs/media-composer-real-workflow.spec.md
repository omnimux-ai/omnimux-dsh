# 图像与视频生成输入面板真实中枢集成与全流程闭环规格 (Issue #2419)

## 1. 目标与背景
此前版本输入面板存在写死的假数据（写死的外国人示例参考图、写死的英文 Prompt、写死的死模型列表），且生成中状态未在主画布中央呈现，导致实机体验脱节。
本任务对图像生成页输入面板与执行闭环进行彻底的真实业务工程化改造：
1. **彻底清除所有写死假数据**：
   - 移除写死的人物/建筑参考图卡片，无真实素材时不占位，支持主动上传/附加素材；
   - 移除写死的英文 Prompt 文本，输入框默认初始化为空字符串 `''`；
   - 默认模式从图像生成页出发，初始化为 `image`（图像生成）；
2. **动态接入中枢真实模型目录 (`/omnimux/model-catalog`)**：
   - 动态拉取中枢真源目录，支持 `image` 与 `video` 双模态模型与参数提取；
   - 级联模型面板（三级）动态由中枢模型数据推导：
     - 第一列【品牌】：由模型的 `family` 归一化提取（OpenAI, ByteDance, MiniMax 等）；
     - 第二列【型号】：该品牌下的真实模型（如 `gpt-image-2.5`, `gpt-image-2.5-flare`, `seedance-2-0` 等）；
     - 第三列【版本渠道】：由模型的 `channelGroups` 动态渲染（旗舰版、官方版、优选版等，带真实积分、折扣与计费模式）；
3. **真实参数配置与动态摘要**：
   - 图像模式：提供生成方式（文生图/图生图/多图参考）、比例网格、清晰度（1K/2K/4K）、生成张数；
   - 视频模式：提供生成模式（文生视频/首帧/首尾帧/全能参考）、比例网格、清晰度（480p/720p/1080p/4k）、有声开关、时长滑块（4s~15s）；
   - 胶囊摘要条实时呈现当前选定参数组合；
4. **画布中央生成态与产物无缝落地闭环**：
   - 用户点击发送或按 Enter 时清空输入框，直连后端 `POST /omnimux/api/media/generate`；
   - 画布中央大舞台立即展示复刻自画布节点的 `Organic Shimmer` 炫彩流光执行卡片与实时秒表计时；
   - 后端自动解析系统 API Key 凭据，真正调用多模态模型渲染生成；
   - 渲染完成后，产物通过 `store.addMedia` 自动入库，大图在画布中央呈现，缩略图推入导轨，炫彩卡片平滑淡出。

## 2. 验收契约
- [ ] 输入框默认内容为空，无任何写死假参考图与英文 Prompt；
- [ ] 模型与版本数据 100% 动态对齐中枢真源；
- [ ] 提交瞬间画布中央立即升起带有流体波纹扫光的炫彩执行卡片；
- [ ] 真实生成请求成功，产物自动在画布大图呈现。
