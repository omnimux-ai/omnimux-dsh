# 规格说明：视频网址弹窗示例卡片苹果极简风格升级

## 1. 业务目标与背景
用户反馈在「视频网址」全屏创建弹窗中，左侧轮播示例卡片底部存在生硬的黑色实底信息栏，导致两行长文本（如【视觉前置反差 & 痛点唤醒】）拥挤堆砌，将素材画面硬性截断并产生明显的上下黑边与割裂感。
本任务旨在将卡片重构为对标苹果现代极简设计规范（Apple HIG Poster / Card Design）的全画幅沉浸式卡片。

## 2. 核心设计变更与验收标准
1. **彻底消除底部黑边与硬分割**：
   - 废除原有的独立深黑底色信息栏（移除实底背景与上边框）；
   - 示例素材（图片/视频封面）100% 满版铺满卡片全画幅（object-fit: cover），卡片圆角设为 16px，无任何上下黑底色块截断。
2. **文字精简收敛**：
   - 彻底移除描述字段（`desc`）的展示，全卡片仅保留单行精简标题（`title`），单行截断省略。
3. **悬浮纯白标题与立体柔和文本阴影**：
   - 标题绝对定位悬浮于卡片底部上方，采用纯白字色（`#ffffff`）；
   - 底层配备由透明至微暗色的超柔和平滑渐变微蒙层，保证浅色与深色背景下均极具可读性；
   - 标题应用符合苹果规范的层次微阴影（`text-shadow: 0 1px 2px rgba(0,0,0,0.85), 0 2px 8px rgba(0,0,0,0.5)`），清晰立体、通透不晕散。
4. **磨砂毛玻璃标签徽标**：
   - 左上角「示例」徽标升级为高斯模糊半透明磨砂玻璃微胶囊（`backdrop-filter: blur(16px)`，半透明白边）。
5. **中心聚焦卡片微质感**：
   - 当前选中卡片具备微发光外框与适度阴影，左右侧卡片保留 3D 透视层级。
