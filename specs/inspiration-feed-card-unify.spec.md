# 灵感库根层卡片与合集统一（P0，Issue #3477）

## 授权与范围

用户要求把「合集内」与「合集外」的单个卡片收敛为一套 UI，并明确：卡片按内容形态（视频 / 图片 / 轮播 / 帖子）区分信息位、弹窗应统一、账号监控卡保持独立但弹窗共用。本任务只做 P0：**根层卡片与合集卡统一卡壳**，仅保留媒体比例差异（根层按数据、合集固定 4:5）。交付含实现、最小充分检查、隔离工作树真实浏览器证据、独立评审、常规 PR/Merge Queue、主干同步、Dev 物化与工作树清理。不改 HTTP、存储、schema，不动账号监控卡与弹窗（P1）、不动类型细化（P2）。

## 新用户基线

已安装并登录的新用户无需额外配置即可浏览本地灵感库与云端爆款；根层卡片只消费既有列表响应与本地媒体路由。空库保持现有空态，封面缺失/损坏走既有封面兜底，不伪造成功。

## 确定行为

- 根层媒体卡（短视频/长视频/图片/图文媒体）与合集成员卡同构：封面优先、标题 13/18 最多 2 行、元信息行（平台 · 播放量（有数据才显示）· 加入时间）+ 状态胶囊；角标为「类型左下、时长/图数右下」；悬停为封面底部 28px 工具条（详情 / 立即复刻），不再有居中播放钮与 footer；不再有右上平台/本地角标。
- 根层帖子卡与合集成员中的纯文本条目共用同一形态：文本摘要最多 3 行 + 同一元信息行（高度公式按 `max(144, 24 + 行数×20 + 24 + 2)`，与渲染逐像素一致）；导入失败/拆解失败等状态仍以正文承载原因，不重复加胶囊；复选框移到右上，不再压标题首行。
- 状态胶囊三态与合集一致：导入失败（红）、已入库但 AI 拆解失败（黄）、导入中（中性阶段文案）；完整原因仍可达（title / aria-label / 详情弹窗）。
- 媒体比例：根层按数据比例（短视频 9:16、长视频 16:9、图片区间），合集固定 4:5。这是两处唯一的视觉差异。
- 高度估算与渲染逐像素一致：根层媒体卡 `(列宽−2)/比例 + 82 + 2`；帖子卡 `24 + 行数(≤3)×20 + 24 + 2`；合集卡与账号监控卡公式不变。
- 账号监控卡、账号监控弹窗、合集卡、拖拽合并、选择模式、落地高亮与「加入会话」行为不变。

## 实施边界与文档影响
