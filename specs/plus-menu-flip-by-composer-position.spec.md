# 任务规格 · 加号菜单跟随输入框位置展开

## 目标

新对话页里，输入框停在页面顶部。点左下角加号后，菜单目前固定出现在输入框上方，顶部空间不够时会被顶出可视区域。

本任务只改这一处方向：

- 输入框在页面顶部时，加号菜单出现在输入框下方。
- 输入框在页面底部时，加号菜单保持出现在输入框上方。
- 在输入框里输入斜杠唤出的技能联想，方向不变，仍在输入框上方。

新用户不依赖本机私有模型、密钥或开发目录。菜单打不开时，页面保持原样，不额外报错。

## 用户操作旅程

1. 打开新对话，输入框停在页面顶部。
2. 点输入框左下角加号。
3. 期望：菜单贴在输入框下方展开，四项「上传媒体或文件、从灵感库选择、从资产库选择、从商品库选择」完整可见，不被顶栏挡住。
4. 进入已有对话，输入框停在页面底部。
5. 再点加号。
6. 期望：菜单仍贴在输入框上方展开，与现在一致。
7. 在任一位置的输入框里输入斜杠。
8. 期望：技能联想仍在输入框上方，不改到下方。

## 验收用例

- 用例一：输入框靠近页面顶部，且加号处于展开状态时，菜单在输入框下方。
- 用例二：输入框靠近页面底部，且加号处于展开状态时，菜单在输入框上方。
- 用例三：斜杠技能联想在顶部和底部都仍在输入框上方。
- 用例四：菜单打开后，选项可以点到，不被旁边的页面层挡住。

## 不做

- 不改菜单里有哪些选项。
- 不改输入框停在顶部还是底部的规则。
- 不改官方宿主程序。
