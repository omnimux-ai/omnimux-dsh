# 加号选素材改为整页浏览

## 目标

新对话里，点输入框加号中的「从资产库选择」「从商品库选择」「从灵感库选择」后，不再弹出小窗。分类钉在会话内容顶部，素材铺满中间，输入框固定在页面底部。点一张卡片，素材进入输入框，并写入对应提示词，不自动发送。

「上传」仍只打开系统文件选择，不改变页面布局。

用户是在空白新对话里挑参考素材的人。成功是：点「从灵感库选择」后，能在几乎整页的区域里浏览本地灵感，点一张卡片后，输入框里同时出现这张素材和一句提示词。

## 命令

在本任务工作区执行：

node --test plugins/omnimux/src/client/composer-add/library-stage-model.test.js plugins/omnimux/src/client/composer-add/controller.test.js plugins/omnimux/src/client/session-guide/library-stage.test.js

## 行为

加号三个素材入口打开整页，并选中对应分类：

| 菜单 | 打开后的分类 |
| --- | --- |
| 从资产库选择 | 资产库 |
| 从灵感库选择 | 灵感库 |
| 从商品库选择 | 产品库 |

顶部分类从左到右固定为：精选、资产库、灵感库、产品库、爆款趋势。滚动时分类留在内容区顶部，输入框留在页面底部。

数据：

- 精选：资产、本地灵感、产品、云端爆款各取一批，混在同一页。某一类失败或为空时，其余仍显示。
- 资产库：本机资产。
- 灵感库：只读灵感社区本地数据。
- 产品库：本机产品。
- 爆款趋势：只读灵感社区云端数据。未登录时说明需要登录，不编造卡片。

卡片沿用各库现有卡片，不新画一套：

- 资产用资产选择卡片
- 产品用产品选择卡片
- 本地灵感用灵感选择卡片
- 爆款用首页爆款视频卡片

点卡片：

1. 素材进入当前对话的输入框素材区。重复点同一张不新增第二条。
2. 输入框写入一句提示词。已有文字时接在后面，不覆盖。同一句不重复追加。
3. 不自动发送。整页保持打开，方便继续挑。

输入框上的「技能」按钮和它弹出的技能列表面板保持可用，本次布局不得把它藏起来。

没有可用对话时，仍提示先进入对话，不打开整页。

## 测试

- 三个菜单分别对应资产库、灵感库、产品库。
- 灵感库请求只打本地接口；爆款趋势只打云端接口；精选四类都请求。
- 提示词合并：空输入框写入、已有文字追加、相同句子不重复。
- 打开整页时不渲染原来的选择弹窗。
- 点卡片走原有素材入库，不发送。
- 整页样式不得隐藏技能按钮。

## 边界

总是做：只改加号三个素材入口的打开方式和选中后的写入；上传保持系统文件选择；卡片复用现有组件；不跨插件引用私有模块。

先问：若要把菜单文案「从商品库选择」改成「从产品库选择」，或点卡片后自动发送。

绝不做：改官方输入框源码；合入其他未完成工作区；在用户确认前合入正式版；把开发版真机点验收当作完成条件。

新用户不依赖本机私有目录、本地模型或开发端口。素材来自本机资产库、本机产品库和灵感社区接口。接口不可用时显示失败或空态，可重试，不回落到样例卡片。

## 成功标准

- 点三个素材菜单之一后，看不见选择弹窗，顶上是五个分类，输入框在页面底部。
- 灵感库里没有云端卡片；爆款趋势里没有本地卡片。
- 点一张卡片后，输入框里有该素材，并且有对应提示词，消息没有发出。
- 上传仍是系统文件选择。
- 技能按钮还在输入框上，点开仍是原来的技能列表面板。
