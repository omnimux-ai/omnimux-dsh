# Issue #2655 规格说明书：首页输入框位置状态机、滚动防抖与交互收敛

## 一、用户操作旅程与行为规格

### 1. 用户旅程 A：新会话页面默认加载与浏览
- **前置条件**：打开 OmniMux 进入新对话（空会话）。
- **用户行为**：页面默认未滚动（`scrollTop = 0`）。
- **期望反馈**：输入框稳定渲染在 Hero 原生文档流顶部（TOP / Inline），宿主无 `data-omnimux-dock-open` 标记，收起按钮不可见。

### 2. 用户旅程 B：长列表向下滚动至不可见
- **用户行为**：向下滚动页面查看模板、Skills 货架或热门视频。
- **期望反馈**：
  - 当顶部输入框原位槽位底边滚出视口顶端（`bandRect.bottom < 0` 且超过迟滞阈值）时，输入框自动平滑固定迁移至视口底部（`position: fixed; bottom: 20px; z-index: 45`）。
  - 宿主被打上 `data-omnimux-dock-open`，输入框右上方浮现收起按钮（`.omnimux-trending-undock`）。
  - **防抖核心**：原位槽位尺寸锁定恒定，无论滚动快慢绝不触发 380ms 跨屏位移动画，触控板滚动全程平顺无撕裂、无页面几何突变震荡。

### 3. 用户旅程 C：长列表向上滚动至重新可见
- **用户行为**：向上滑回页面顶部方向。
- **期望反馈**：
  - 一旦顶部原位槽位露入视口顶端（`bandRect.bottom > 0`），输入框自动平滑归还原生文档流位置。
  - 宿主移除 `data-omnimux-dock-open`，收起按钮消失。

### 4. 用户旅程 D：点击任意功能按钮激活输入框
- **用户行为**：
  - 点击 Skills 卡片内「使用」按钮；
  - 点击模板卡片/热门视频内「复刻」按钮；
  - 点击顶部快捷入口（复刻/拆解/带货/反推）。
- **期望反馈**：
  - 输入框立即固定停靠在视口底部；
  - 自动预填对应 Prompt 意图文本；
  - 输入框获得焦点且携带 `{ preventScroll: true }`，页面视口保持当前滚动位置不动，绝不跳顶；
  - 浮现收起按钮。

### 5. 用户旅程 E：收起与反悔归位
- **用户行为**：
  - 点击收起按钮（`.omnimux-trending-undock`）；
  - 或再次点击已激活的同一张卡片反悔。
- **期望反馈**：解除吸底状态，清空对应预填与技能，输入框归位回顶部。

## 二、验收测试用例设计

1. **Test 1（默认状态）**：验证初始状态下宿主无 `data-omnimux-dock-open`，输入框为 inline，无收起按钮；
2. **Test 2（向下滚动吸底）**：无 item 纯滚动场景，模拟 `scrollTop > leaveThreshold`，输入框变为 `docked`，宿主打上标记；
3. **Test 3（向上滚动归位）**：模拟从底部滚回 `scrollTop <= revealThreshold`，输入框恢复 `inline`，宿主标记清除；
4. **Test 4（功能按钮吸底防跳顶）**：偏下位置点击使用/复刻按钮，输入框立即吸底且视口保持原位 0 偏移；
5. **Test 5（收起按钮与反悔）**：点击收起按钮或再次点击卡片解除吸底；
6. **Test 6（CDP 端到端验证）**：在 Dev App 真实环境中连续下滚与上滚，验证页面无抖动、无几何死循环震荡。
