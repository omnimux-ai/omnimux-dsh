# #2997 组合锁定的卡槽直接不显示

## 背景
#2987 以「半透明 + 不可点击（is-locked）」呈现被组合规则锁定的卡槽。用户反馈：不支持的直接不显示，不要出现不可点击的灰槽。

## 目标
组合规则锁定的卡槽整体不渲染（与「满上限不再出现空卡槽」同一心智）；解锁条件满足后照常出现。

## 用户旅程
1. H3/Seedance 2.0「参考」空态 → 只显示「图片、视频」两个卡槽，看不到音频槽。
2. 放入一张图片或一段视频 → 音频卡槽出现并可正常使用。
3. 音频在组内的模型（Seedance 2.5）→ 音频槽照常显示。
4. 粘贴音频时无图/视频 → 后台仍拒并回显契约提示（行为不变，只是不可见槽也可粘贴）。

## 规则
- 仅隐藏「被锁且该卡槽自身为空」的卡槽；锁中但已有素材的卡槽保留显示（避免丢素材）。
- is-locked 样式与文案仍可服务「有素材时被锁」的边缘态，不删。
- 后台校验（rejectionOf/groupLockOf）不变。

## 验收
- 渲染：`slots` 过滤掉 `groupLockOf 非空 && items.length===0` 的卡槽。
- 浏览器：H3 空态 2 卡槽 → 放图后 3 卡槽。
- media-slot.test/e2e 断言渲染过滤条件存在。
