# 视频拆解错误规范化引导与 DSH 原生决策选项规格说明书 (Spec)

## 1. 业务背景与问题定义
在视频视听拆解工具（`video_breakdown_analyze`）处理长视频（如播客访谈、会议实录等长视频，或模型服务异常）时，多模态模型无法按短视频转化逻辑解析出有效分镜。
在此前实现中存在以下关键缺陷：
1. **报错生硬且缺乏行动指引**：仅抛出单行错误 `视频视听拆解失败：多模态模型未解析出有效分镜，请检查模型服务可用性或视频内容。`，缺少可操作的恢复上下文。
2. **Agent 擅作主张与盲目降级**：Agent 捕获报错后，缺少规范约束，往往会擅自猜测，直接调用读取工具读取长达数千行的字幕文件（如 7,605 行超长 .srt），造成对话上下文被严重撑爆、Token 剧烈消耗，且未经过用户知情与授权。
3. **用户决策权缺失**：用户无法自主选择是要“基于字幕做文本速览”还是“截取前 1~3 分钟片段做短视频视觉拉片”。

## 2. 目标与验收标准 (Acceptance Criteria)
1. **环境与伴生资源感知**：
   - 拆解失败时，工具主动探测目标视频同级路径下是否存在同名或关联的字幕文件（`.srt` / `.vtt`）。
   - 若存在字幕文件，统计其基本信息（如文件名、行数/大小），并记录在错误上下文中。
2. **错误结果注入强约束 Agent 行动指南**：
   - 错误信息明确解释根本原因（长视频/访谈超出短视频逐镜头拉片规格）。
   - 错误信息中**显式下达禁令**：严禁 Agent 私自读取大文件，严禁擅自做降级决策。
   - 错误信息中**显式下达操作指令**：强制 Agent 必须调用 DSH 原生提问工具（`ask_user_question`）向用户展示标准选项芯片，由用户拍板决策。
3. **DSH 原生选项契约定义**：
   - 选项 1（推荐）：`使用字幕快速提炼 (Recommended)`，说明为“跳过逐镜头视觉拆解，直接根据全片对话字幕提炼核心内容与大纲”。
   - 选项 2：`截取前 2 分钟切片拆解`，说明为“提取片头精华短视频切片，重新发起逐镜头画面拉片与分镜分析”。
   - 选项 3：`检查模型服务后重试`，说明为“若原片本身即为短视频，请确认视觉大模型服务连通性后重试”。
4. **零破坏性兼容**：
   - 不影响正常短视频且模型解析成功时的执行链路与工件落盘。
   - 所有已有测试用例平滑兼容或按新错误格式更新断言。

## 3. 关键场景验证用例
1. **无字幕且模型解析失败**：
   - 抛出的错误信息中包含规格超限说明与强制调用 `ask_user_question` 指引，提示未检测到配套字幕。
2. **存在配套字幕且模型解析失败**：
   - 抛出的错误信息中准确识别出伴生字幕文件名与信息，指示 Agent 推荐方案 1 并调用 `ask_user_question`。
3. **正常解析成功场景**：
   - 依然产出有效分镜，流程与工件保存不受任何影响。
