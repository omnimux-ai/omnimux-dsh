# #1786 工作树测试环境自动准备

## 目标与已批准设计
用户于 2026-09-14 明确批准：普通界面测试不使用真实密钥；明确启用真实模型测试时只读复用开发版必要 DeepSeek 配置。统一测试启动入口与 Agent 指引，不在工作树创建时复制密钥。默认打开即可进行不依赖模型的真实界面验收；首次配置流程另行测试。

## 成功标准
- 默认模式不读取 Dev/Prod 凭据，使用清楚标注的测试配置与模拟模型响应；不把模拟响应称为真实模型执行证据。
- 临时环境仅属于本任务工作树，动态回环端口，隔离 HOME/DSH_HOME/配置缓存与数据目录；不复制或修改共享 profile。
- 显式真实模型模式只读 Dev 必要 DeepSeek 配置，秘密仅进入当前测试子进程；不写入仓库、日志、截图、命令行或报告。允许使用已授权进程环境；不默认发起模型请求。
- 配置缺失、格式不支持、授权缺失等在启动前返回可操作的脱敏状态，不让 Agent 反复尝试网页填写或自行搜密钥。
- 并行运行不相互污染；启动失败、正常结束及可捕获中断清理任务自有进程和临时数据，保留脱敏证据。
- 原生完整应用入口的验证须观察真实首次进入及刷新，不以现有轻量 Stage 夹具的占位页面冒充应用验收。

## 命令与项目结构
复用 scripts/worktree.sh 管理任务工作树；复用已安装正式 CLI 与插件安装机制，不修改官方源码或分发包。
拟在 scripts/ 增加或扩展共享测试准备模块与对应 *.test.mjs；准确命名在入口调查完成后固定。
验证：`node --test scripts/*test-env*.test.mjs`（实现后以准确文件名替换）、`pnpm test:gates`、`git diff --check`，以及本工作树真实浏览器证据。
文档更新 owning contracts：docs/contracts/plugin-qa.md、docs/contracts/dev-pipeline.md 及 AGENTS.md 的薄入口指针；具体说明只保留一处真源。

## 测试策略与执行计划
1. 核对入口调查与凭据契约报告，记录现有重复启动流程及首次配置触发条件，固定最小集成路径。
2. 先写失败单元测试：默认不读秘密、显式配置白名单、缺失/坏配置脱敏、子进程环境隔离与清理。
3. 只写使测试通过的最小共享准备入口；不重造宿主或路由器，不改变普通工作树创建行为。
4. 在独立临时环境预先观察真实 DOM 与首次配置状态，保留真实截图、服务身份与清理结果；再固化 E2E。
5. 独立规格符合与安全代码评审，相关测试及门禁通过后按仓库流程 PR/Merge Queue；纯脚本无需 Dev 物化。

## 边界
始终：先失败测试后实现；只修改任务树；使用公开受支持配置/插件机制；脱敏及任务归属检查；明确 fixture 与 live 证据。
先确认：扩张至其它提供商、生产配置、跨仓写入、额外付费请求或长期运行服务。
绝不：复制整个 Dev profile、写回 Dev、读取 Prod、提交/打印密钥、伪造登录 Cookie、绕过安全检查、修改官方源码或替换当前 GUI 服务。
