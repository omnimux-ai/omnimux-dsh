核心业务契约
1. 初始无事件交互：下滑时输入框随页面滚出视口，底部不出现。
2. 一旦事件交互（如点复刻）：输入框激活，在页面下滑时始终保持在底部显示。
3. 滑回顶部：平滑切换回顶部内联显示。
4. 再次下滑：交互状态保持有效，底部再次自动显示，绝不消失！
5. 点击收起：解除激活，底部消失；再点复刻时重新激活。
