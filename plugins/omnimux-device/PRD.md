# OmniMux Device - 移动真机矩阵与设备智能体中枢 PRD

## 一、 产品愿景与战略定位

### 1.1 愿景
将传统的“按键精灵式”机械化手机群控，升级为**“自主感知、极速决策、自愈抗风控的 AI 移动智能体集群”**。
连接物理世界的真实 iPhone 阵列，让创作者与运营者在 OmniMux 对话中，仅凭一句自然语言，即可驱动多台手机自主完成素材导入、短视频发布、账号矩阵互动与状态监控。

### 1.2 解决的核心行业痛点
1. **传统群控极其脆弱**：基于固定坐标和死板脚本，App 一旦更新改版、出现弹窗或做 AB 测试，整个脚本瞬间卡死失效；
2. **大模型操控手机过慢、过贵**：传统纯视觉多模态大模型每一步操作思考 3~5 秒，发布一条视频耗时数分钟，且容易发生幻觉导致误操作；
3. **多机管理门槛极高**：USB 接口断连、WDA 闪退、手机自动锁屏等硬件问题频发，缺乏自愈保活机制。

## 四、 功能模块详细规格

### 1. 设备池化与硬件中控模块
* **自动握手与保活**：检测 USB 接入的 iPhone，自动完成端口映射（8100+），维持 WDA 进程常驻；
* **防休眠与自动解锁**：支持配置设备锁屏密码，任务到来前自动点亮并解锁屏幕；
* **实时推流面板**：低延迟 MJPEG 流直通 DSH 侧边栏，支持多机平铺监控与人工直接鼠标接管。

### 2. 双脑分层决策引擎（TypeSafe 赋能）
* **快慢大脑解耦**：
  - 通用大模型（如 DeepSeek/Claude）负责全局策略规划与文案理解（只调用 1 次）；
  - TypeSafe Jev 决策模型负责单步 Action 微操（100~200ms 快速闭环）；
* **类型安全（Type-Safe）控制**：输出严格受限于枚举操作集（tap / scroll / type / wait），绝不发生解析溢出；
* **置信度硬门禁**：对每个操作校验置信度分值（阈值 0.85），低置信度时自动挂起并报警，杜绝不可逆误操作。

### 3. 多模态语义感知与容错模块
* **无障碍树提取（AXe）**：优先按控件名称和身份 ID 操作，彻底告别写死像素坐标；
* **原生 Vision OCR 兜底**：当无障碍属性失效时，调用本地编译的 Vision 引擎进行毫秒级文字找点；
* **干扰弹窗智能自愈**：自动检测常见干扰层（系统权限授权、App 评分、版本升级提示），自主点选“稍后再说”或“关闭”。

### 4. 社交媒体发布流水线（以 TikTok 为基准）
* **相册安全注入**：将目标视频/图片安全导入 iOS 系统相册；
* **防重发审计日志**：基于任务指纹实现幂等锁，严格杜绝同一条视频重复投递；
* **矩阵账号隔离**：单机单号严格绑定，隔离代理网络与登录会话。

## 五、 非功能需求与成功指标 (KPI)

1. **执行效率**：单步 UI 识别与决策平均耗时 **≤ 300ms**（比纯通用视觉模型提升 10 倍以上）；
2. **发布成功率**：在目标 App 正常运行的前提下，端到端发布任务成功率 **≥ 98%**；
3. **断网与崩溃自愈**：WDA 异常闪退时，底层需在 **5 秒内** 自动完成重启并恢复执行现场；
4. **资源占用**：单机常驻代理内存占用 **≤ 80MB**，CPU 待机占用率接近于 0。
