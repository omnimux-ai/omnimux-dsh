# 浏览器图片加入资产库 · 文字原型

产品负责人：许清楚（Xu）。基线：`d95764912e36da01d879ab65d6340469b48a4625`。

此为最小交互原型，不是新页面设计，不执行保存，不代表已完成浏览器验收。逐字文案和图形真源为 [UI-Spec](<UI-Spec.md>)。下列方括号表示既有图标槽，不是产品中显示的文字或字符图标。

## 1. 作品角标工具栏

### 收起

作品卡片未悬停时入口隐藏。悬停作品卡片时，只显示原有品牌幽灵角标。继续悬停/聚焦角标后在既有横向工具栏位置展开。

### 图片作品展开

作品卡片 → 品牌角标 → 横向工具栏：

`[资产矢量] [复制双页] [对话气泡]`

- 第一项 hover/focus：`加入资产库`。
- 第二项原 title/aria：`复制`。
- 第三项原 title/aria：`加入对话`。
- 不显示“图片”“资产库”组标题，不显示按钮下副标题，不显示新增徽章。

### 视频作品展开，包括 TikTok img 封面

`[原灯泡] [复制双页] [对话气泡]`

第一项：`加入灵感库`。`/@作者/video/作品编号` 决定这是视频作品，即便卡片只渲染封面 `img`，不得把第一图标切为资产图标，也不得保存封面进资产库。

### 点击图片第一项后的反馈

保持同一个第一动作槽：

`[既有忙态] [原复制] [原对话]` → 单条原位提示 `正在加入资产库`。

只有宿主真实完成图片保存后：

`[既有勾形] [原复制] [原对话]` → 单条原位提示 `已加入资产库`。

角标基线没有可见动作结果，允许复用现有媒体提示组件在第一项上呈现此结果；不得点击后立即折叠而吞掉结果，也不得再加一份 toast。用户移出入口时仍按既有离开/隐藏规则处理，不长期占屏。

## 2. 媒体悬浮胶囊

合格媒体命中后立即显示原 24×24 品牌圆钮；悬停/聚焦品牌圆钮后保持既有 128×24 横向胶囊，不调整宽度、命中区、材质或动画。

### 图片展开

`[资产矢量] [复制双页] [对话气泡]`

第一项提示 `加入资产库`；第二项提示仍为 `复制素材链接`；第三项仍为 `加入对话`。idle title/aria、busy、done 及错误严格采用 [UI-Spec：第一动作](<UI-Spec.md#3-第一动作逐字中英文文案>)。

### 视频展开

`[原灯泡] [复制双页] [对话气泡]`

第一项 `加入灵感库`；视频已有保存星形状态保留。视频 poster 或当前帧是视频预览，不按图片入资产库。TikTok 现有禁止悬浮胶囊的规则继续保留，本任务不在 TikTok 网格同时显示两个入口。

## 3. 最小异常反馈

异常提示均替换第一按钮上原有提示，只有一条，不增按钮、横条、连接弹窗或“本地兜底成功”。

| 现场 | 中文原位反馈 | 交互 |
|---|---|---|
| 新用户没有可用目标宿主 | `宿主未连接，请打开 OmniMux 后重试` | 第一项恢复可用；用户自行打开宿主，再点击原按钮 |
| 宿主明确无法下载图片 | `图片下载失败，请重试` | 不亮勾、不写灵感库；再点原按钮重试 |
| 宿主明确无法保存资产 | `资产保存失败，请重试` | 不亮勾；不把拒绝谎称成未连接 |
| 请求已发但回执未确认 | `未确认保存结果，请稍后查看资产库` | 不亮勾、不自动补写；用户先查看宿主资产库 |
| 类型无法核定 | `无法确认素材类型，请刷新后重试` | 保留三个位置；第一项不发起写入 |
| 来源不支持安全保存 | `该图片无法保存` | 不用页面链接或视频截图假装成功 |

英文原型只替换 [UI-Spec](<UI-Spec.md>) 指定的字符串，组件树完全相同。视频的英文仍是原有 `Add to library`；复制/对话不另创英文。

## 4. 用户可见闭环

图片第一按钮点击 → 同一按钮忙态 → 真实保存回执 → 同一按钮完成反馈 → 用户自行打开已连接宿主资产库 → 本地找到并预览该图片。

不能把最后的“本地找到并预览”省略为消息已派发，也不能把第一按钮成功后的跳转/自动打开资产库作为本轮新增功能。

## 5. 状态切换与键盘

- 切换到 B 图片时，第一项重新呈现 B 图片 idle，A 请求晚到不把 B 置为已保存。
- 复制/加入对话不会因本次图片保存失败被永久禁用，不修改它们既有投递逻辑。
- 保留原 Tab、Enter、focus-visible 与离开行为；任何状态文案都有对应 aria，不靠颜色或图形独自传达结果。
- “已保存”不是删除开关，重复点击不能取消保存或生成未授权的删除动作。

## 6. 不渲染的区域

没有新增页面、标题、分类器、徽章、功能说明、成功弹窗、资产数量、网络状态条、第四动作、原始服务端错误正文。新增可见变化仅图片第一动作图形、对应提示及必要结果反馈。
