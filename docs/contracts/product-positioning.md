# 产品定位：属于你的内容电商团队

本文件是本仓现行产品定位与对外描述的唯一归属。它记录产品方向，不证明功能已经实现；实际能力需核对当前源码、配置和具版本身份的验收证据。[MVP 范围](mvp-scope.md)继续约束任务准入与授权，不因落地页展示或既有插件存在而跳过确认。

## 产品主线

**OmniMux 定位于「属于你的内容电商团队」（Your Content Commerce Team）：一套内容电商系统，让商品卖点贯穿每一次出片。用你熟悉的 Agent，一站式搞定广告、电商与种草视频。** 本仓（`omnimux-dsh`）是 OmniMux 桌面端（本地工作台）基于 DeepSeek Harness 构建的核心插件工程。

官网首页（`omnimux.ai`）展示桌面端「发现/对标 → 拆解 → 制作 → 发布 → 复盘」完整内容电商工作台，`/ai-influencer-studio` 承载角色生成与参考视频复刻专线。在桌面端工作台中：

- **执行中枢（`omnimux`）**：统一身份、模型路由与多模态执行（生图、生视频、文本理解与语音）；
- **内容电商核心工作台插件**：商品库（`omnimux-products`，管理商品卖点、受众与素材）、资产库（`omnimux-assets`，管理可复用 AI 角色、多角度设定图、场景、风格与道具）、灵感库（`omnimux-inspiration`，爆款收藏与结构拆解）、无限画布（`omnimux-workflow`，可视化节点编排）、剪辑工坊（`omnimux-clip`，基于 OpenReel 的时间轴剪辑）、账号与发布中心（`omnimux-accounts` / `omnimux-publish`，海外平台 TikTok / Instagram / Facebook / YouTube 排期与发布跟踪）、数据复盘（`omnimux-analytics`）与技能市场（`omnimux-market`）；
- **角色生成与参考视频复刻**是其中的核心创作能力主线之一，与商品带货视频生产、画布编排、排期发布协同构成完整的内容电商工作流。

保留已有插件及技术合同不等于承诺所有延伸功能均已全量交付，也不授权未经确认删除、隐藏或停用它们。

## 产品体验要求与内部执行分开

| 层面 | 现行方向 | 不可推导的结论 |
| --- | --- | --- |
| 普通用户创作 | 面向内容电商与角色视频创作，不强制暴露底层渠道分组，生成与发布前须由用户确认参数与积分消耗 | 插件现有选择器、工具参数已经全部改造完成 |
| 内部模型与渠道 | 系统按任务和素材匹配能力；每次模型请求携带明确分组，与上游分组及能力对齐；同组可有多个渠道容错，按低价优先路由 | 可以发裸模型请求，或因用户不选组而删除分组契约 |
| 模型收敛 | 核心创作围绕生图与生视频入口，文本理解与语音作为脚本拆解、卖点提炼、编排与配音支撑 | 所有历史模型、音频、编辑或扩展用途应立即删除 |
| 价格 | 对外价格与内部采购成本分开；用户已要求统一价格口径，实际金额、套餐、折扣与结算须读取当前定价来源 | 低价优先就等于按采购原价出售，或能够承诺固定降本比例 |

上述内容是产品要求。本次文档同步不变更模型、路由、计费、运行时技能或既有用途。技术入口见[模型列表归属](model-list-ownership.md)、[中枢合同](hub.md)与[新用户基线](product-baseline.md)。

## 对外表述边界

- 统一使用「属于你的内容电商团队 / 内容电商系统」作为主定位；禁止使用脱离商品与视频出片闭环的泛化夸大口径。技术文档保留各插件真实接口职责，并区分目标愿景与已验证交付。
- 不承诺“保证爆款”“保证销量”“零抽成”“降本 70%~90%”“素材百分之百留在本地”“防封号”“永久 100% 角色一致”或“任意视频完全复刻”，也不以代码存在标记全量正式可用。缺少同版本证据的能力不得宣传为已交付。
- 真实可用性仍以[能力记录](../capabilities.md)、[插件生命周期清单](../../plugins/omnimux/src/plugin-lifecycle.json)与当前版本证据为准；大陆平台（抖音/小红书/视频号/快手/B站）自动发布、实时趋势抓取、独立封面生成、发布前自动预检等未实现能力不得写成已交付。
- 软件许可、官网生成收费和企业定制服务是不同事项。许可依据根目录 LICENSE，生成与套餐价格依据官网当前结算来源；不得把免费使用源码写成免费生成、无订阅或所有服务免费。
- 演示作品只说明展示内容，不证明支持所有输入、时长、分辨率或生成成功率。使用真人照片、参考视频和作品须核对授权与适用平台规则。

## 桌面端首页与表面收敛（omnimux.ai）

2026-10-27 起，桌面端落地页已正式成为 `omnimux.ai` 主站首页，原角色落地页保留在 `/ai-influencer-studio`，`d.omnimux.ai` 已退役并 301 跳转至 `omnimux.ai`。三端公开源码仓已按 AGPL-3.0 独立发布：插件仓 `omnimux-ai/omnimux-dsh`、桌面端 `omnimux-ai/omnimux-desktop`、云端路由与计费服务仓 `omnimux-ai/omnimux-gateway`（以及汇总快照仓 `omnimux-ai/omnimux-ai`）。

对外描述桌面端与插件能力时必须遵守：

- 明确区分桌面端本地工作台与 Web 端边界，不得将桌面端插件能力推导为 Web 端在线工作台已同步提供；
- 已交付插件能力（执行中枢、商品库、角色/资产库、灵感收藏与拆解、无限画布、OpenReel 时间轴剪辑、海外四平台 TikTok / Instagram / Facebook / YouTube 排期发布跟踪）按实际验收证据表述；未实现边界（大陆平台抖音/小红书/视频号/快手/B站发布、实时趋势抓取、独立封面生成、发布前自动预检）不得写成已交付；
- 不改变 [MVP 范围](mvp-scope.md) 的准入、授权规则，不承诺自动矩阵防封、保证爆款或保证销量；
- 模型 ID、基准价与 Web 端分组不变；桌面端专属分组请求继续遵循既有上游与执行中枢契约（如 `desktop-480p` / `desktop-720p`）。
