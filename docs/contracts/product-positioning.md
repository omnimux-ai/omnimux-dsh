# 产品定位：角色生成与视频复刻

本文件是本仓现行产品定位与对外描述的唯一归属。它记录产品方向，不证明功能已经实现；实际能力需核对当前源码、配置和具版本身份的验收证据。[MVP 范围](mvp-scope.md)继续约束任务准入与授权，不因落地页展示或既有插件存在而扩大。

## 产品主线

**OmniMux 聚焦角色生成与视频复刻：用文字描述或有权使用的照片建立角色，结合参考视频制作角色视频。** 核心创作能力为生图与生视频；灵感选择、素材复用、必要剪辑和可播放、可导出的成片为这条主线服务。

落地页以“创建你的角色”为主标题，展示“角色图片 + 参考视频 = 角色视频”。用户旅程是建立角色、调整形象与多角度细节、选择参考动作、生成和导出视频。导出后由用户按平台规则发布，不把展示中的“发布”解释为本仓已实现多账号自动分发。

社媒矩阵运营、自动排期、独立数据分析、通用创意平台和短剧平台不属于默认产品主线。保留已有插件及技术合同不等于承诺这些功能，也不授权删除、隐藏或停用它们。

## 产品体验要求与内部执行分开

| 层面 | 现行方向 | 不可推导的结论 |
| --- | --- | --- |
| 普通用户创作 | 面向角色生图和生视频，不暴露模型 ID，不要求用户选择渠道分组 | 插件现有选择器、工具参数已经改造完成 |
| 内部模型与渠道 | 系统按任务和素材匹配能力；每次模型请求携带明确分组，与上游分组及能力对齐；同组可有多个渠道容错，按低价优先路由 | 可以发裸模型请求，或因用户不选组而删除分组契约 |
| 模型收敛 | 用户确认的方向为一个生图入口、一个生视频入口；文本仅作为理解与编排支撑，保留 Gemini 3.8 Flash | 所有历史模型、音频、编辑或扩展用途应立即删除 |
| 价格 | 对外价格与内部采购成本分开；用户已要求统一价格口径，实际金额、套餐、折扣与结算须读取当前定价来源 | 低价优先就等于按采购原价出售，或能够承诺固定降本比例 |

上述内容是产品要求。本次文档同步不变更模型、路由、计费、运行时技能或既有用途。技术入口见[模型列表归属](model-list-ownership.md)、[中枢合同](hub.md)与[新用户基线](product-baseline.md)。

## 对外表述边界

- 禁止把“企业级社媒营销 Agent”“社交媒体全链路 API”“内容制作到矩阵获客”继续用作当前主定位。技术文档可保留已有接口职责，但须区分产品范围。
- 不承诺“零抽水”“降本 70%~90%”“素材百分之百留在本地”“防封号”“永久完全一致”“任意视频完全复刻”，也不以代码存在标记全量正式可用。缺少同版本证据的能力不得宣传为已交付。
- 软件许可、官网生成收费和企业定制服务是不同事项。许可依据根目录 LICENSE，生成与套餐价格依据官网当前结算来源；不得把免费使用源码写成免费生成、无订阅或所有服务免费。
- 演示作品只说明展示内容，不证明支持所有输入、时长、分辨率或生成成功率。使用真人照片、参考视频和作品须核对授权与适用平台规则。
