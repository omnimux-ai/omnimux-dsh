# 项目与创作页封面

本方案由 OmniMux 的持久化画布数据派生，参考截图仅规定文件夹视觉；不声称复现了参考产品未公开的选图算法。

## 状态与选择

- 页面摘要为 `empty / document / image / audio / video`，`unavailable` 独立表达读取或源文件失败。加载中与失败使用状态标记，不假扮文档。
- 页面按首次观察到的持久化节点顺序选择首个带可用 URL 的媒体节点，文档仅在没有媒体时兜底；项目按 pages 顺序取首个媒体页面。图片不优先于音频/视频。节点移动、布局、分组、切换活动页不影响排名。
- 文件夹始终包含固定底板、两张插页和前袋；图片填满插页，音频使用静态类型波形（非真实振幅分析），视频优先 poster，否则抽帧。列表从不自动播放。
- 生成中、失败或取消保留已有输出；成功替换视频时清除旧视频 poster，优先使用新资产携带的 thumbnail。删除首来源后选择下一可用媒体。

## 数据与失效

`ProjectCoverService` 通过 `WorkspaceStore.canvasFileOf/get` 读取绑定项目或独立工作区的真实画布。摘要缓存独立于业务 JSON，不修改项目/画布的业务更新时间。canvas 路径、mtime、size 变化后重算；缓存损坏重建，缓存写入失败不阻止读取。

返回摘要每次重新检查所选本地源的 mtime、ctime、size。同路径覆盖无需改节点 URL；受保护的 project-file（含别名）、local-file 和 media 路径支持此校验。远程 HTTP URL 无服务器文件 stat，依赖输出元数据版本与缩略图缓存有效期，不保证即时发现同 URL 的远程替换。

## 浏览器缩略图

进入视口附近才加载。图片或视频帧编码为最长边不超过 640px 的 WebP；缓存 key 由类型与源版本计算 SHA-256，CacheStorage 最多 128 项，有效期一小时，访问时过期重建。坏缓存解码失败后删除并重建。坏 poster 可回退视频抽帧；坏远程 poster 恢复后在缓存过期后的下一次加载重新尝试。

缩略图为浏览器派生产物，首次访问仍可能下载原始素材；这不是服务端缩放，也没有承诺原始下载字节数上限。跨域源若不能导出 canvas，图片或现有 poster 降级为普通 img；无法跨域抽帧且没有 poster 的视频保留类型占位。源本身不能加载时显示失败状态。

同键请求复用，一次一个解码器，队列上限 32，单次解码超时 10 秒。失败冷却 30 秒，挂载卡片最多再试两次；卸载清理观察器、重试定时器和对象 URL。队列满可能延后封面显示，不阻塞打开项目或菜单。

## 验收

静态/单测覆盖稳定顺序、缓存损坏、源替换、路径边界、缩略图去重/尺寸、poster 回退。合并后 Dev 的 ego-browser 验收还须覆盖：五类封面、空项目双插页、返回页面刷新、删除来源后返回顶层、同路径覆盖、失败占位、菜单键盘操作及窄屏。构建与单测通过不等同于该运行验收通过。
