- 本阶段只有前端 Mock：不新增后端、HTTP/WS/SSE、真实生成、provider 客户端、密钥存储、付款、真实扣费或入库。
- 本轮只修改本目录 PRD、system_design 和两张 Mermaid；`index.html` 与 `architecture-audit.md` 保留原样。审计结论仍为实现 FAIL，文档整改不关闭实现缺陷。
- 裁决顺序：当前用户边界 > 本修订的明确整改 > 原型中未冲突的布局/菜单/交互意图。旧 PRD 的顶栏、localStorage 强制、生产级能力与进度日期不再有效。
- 原型是 4,442 行视觉/交互参考，不是官方 API 规范；其中“真实数据源、实时渲染、100%极稳”等文字和脚本缺陷不得照搬为产品事实。
- 工程规范及 F01–F14 验收表见 [system_design.md](system_design.md)。只读证据见 [architecture-audit.md](architecture-audit.md)。

## 2. 必交交互

### 2.1 工作台与详情

保留 Agent / 视频 / 图片三模式、局部输入卡片、视频参考/首尾帧/编辑槽位、图片单参考槽、历史/示例与详情底部 dock。主区和详情 dock 必须编辑同一个 scope 的同一份模态草稿；切换页面或模式不得复制一份本地 prompt。返回和再次进入保持内存草稿。

只有内部 `dashboard / video / image` view 状态，不实现 `/app/...` 深链接、浏览器 history 或刷新恢复。可见文案为“本页内存草稿，刷新或关闭工作台后清空”。Tab 临时隐藏与会话来回切换可保留；明确关闭 Tab、插件/依赖卸载清理，详见生命周期表。

### 2.2 Agent 行内输入

使用有序结构化文档 `text | url-token`，允许“文字A → 商品Token → 文字B → 视频Token → 文字C”，不能用 textarea + 底部 token 列表冒充行内。展示、复制、提交序列化均保持该顺序；不从 innerHTML 反推业务状态。

| 推荐 Chip | 技能（演示） | Token / 可追加槽 | 默认模型、规格 |
|---|---|---|---|
| 一键创作带货视频 | 创作带货视频 | 商品；可追加商品/视频 | Veo 3.1 Fast (体验)，720P、9:16、8s |
| 复刻爆款视频 | 复刻爆款视频 | 视频及商品；可追加商品/视频 | Seedance 2，720P、9:16、15s |
| 拆解爆款视频 | 视频分析 | 视频 | model/spec=null，隐藏选择器 |
| 反推视频提示词 | 视频分析 | 视频 | model/spec=null，隐藏选择器 |

重置原子清空文本、Token、技能、选择器状态和校验；不清任务或扣点。卸载技能不暗中删除文本与 Token；分析模式不得沿用隐藏的生成参数。

键盘规则：Token 内 Enter（包括 Ctrl/Cmd+Enter）只校验当前值；有效后焦点移到后续文字，无提交；无效/空值留在 Token。正文 Enter 换行、Ctrl/Cmd+Enter 提交，Shift+Enter 换行。`isComposing`、组合输入期间或 keyCode=229 时不校验、不跳焦点、不提交。Token 内非空 Backspace 正常删字；空 Token 内 Backspace 删除该节点并聚焦前一文字末尾；正文在 Token 后的边界 Backspace 首次选择 Token，第二次删除。删除按钮只删指定节点并恢复邻近焦点。

URL 状态为 empty/invalid/valid（仅语法有效，不代表可访问/已解析）。仅 http/https URL 或商品 ID 分支；URL 不得携带 userinfo，拒绝 localhost、环回/私网字面 IP、明显凭据/签名查询参数。商品 ID 限 1–64 位 ASCII 字母、数字、下划线、连字符；不含协议时才走 ID 分支。URL 最长 2048 字符；不做 DNS/网络解析。纯文本粘贴，不接受 HTML；非法 Token 禁止提交。Agent/视频序列化正文最多 8000 字符，图片最多 2000。

### 2.3 Mock、任务与虚拟点数

在 Tab 内容内持续显示“前端演示 · 不调用模型 · 不扣真实点数”，不是新增全局 banner。每张任务/示例/结果和下载入口带 Mock/样例标识。按钮显示“模拟提交”，状态为“模拟处理中 / 模拟完成 / 模拟失败 / 已取消”。分析 Chip 返回明确的样例分析文本，不伪造视频成片。

提交先校验并冻结完整请求快照：scope、模态、技能/预置、有序正文、槽位与本地引用、模型 id/label、分辨率、比例、时长模式和值、批量数、虚拟单价/总价、版本。卡片与重做读取快照，不能从当前草稿补参数；1:1、15s、Auto 不得被改写为默认值。

- 一次图片提交是一个 batch 任务，`batchCount=1..4`，完成结果数量必须等于 batchCount，各结果独立 ID；视频和分析为 1。部分结果不支持，缺结果即整批模拟失败。
- 初始演示余额 3463；总价=fixture 单价×batchCount。余额不足时无任务、无定时器、无扣点；同一次接受提交原子扣减，无负数。取消或模拟失败退回原总价且仅一次，成功后删除不退款；不是金融账本。
- UUID 标识请求、任务、结果及节点；禁止 Date.now 作为唯一 ID。按钮处理同步加锁至接受/拒绝，防同一事件重复提交。
- pending 可以取消；删除 pending 先取消再移除。取消/删除/销毁后的迟到回调不得更新状态或 toast。重做仅回填完整草稿，用户再点击模拟提交才产生新任务与点数变化。
- 超分/去水印/重绘/裁剪/收藏入库尚无真实能力：禁用并解释“演示未实现”，不得只改参数即报成功。参考槽可加载明确样例，或本地文件仅预览（不上传）。下载只允许已就绪样例，文案“下载样例”，不能宣称生成/增强文件已保存。
- 播放/加载失败独立显示“样例媒体不可用”；不可用时禁下载。请求规格与样例实际尺寸/时长分别展示，不能把 fixture 媒体声称为所请求输出。

## 4. 视觉与可访问性

- 无全局顶栏；详情标题与返回留在内容内。三模式和输入卡片保留原型层次，组件基础几何遵循仓库 UI 合同（32px 控件、8px 基础圆角）；原型胶囊/24px 主卡片仅为参考，不把冲突几何称为官方硬要求。
- 消费宿主语义 Token，不重写 `:root --dsw-*`。`#111113` 的 RGB 为 17/17/19，并非零饱和度纯灰；它只可作为参考，不能据此禁止宿主品牌蓝或语义状态色。颜色/对比度以已安装主题与语义用途验收。
- 操作图标用经核实的宿主图标导出或 SVG，遵守原图 viewBox（16/20/24 等均可能正确），不强制所有图标重设为 24×24，也不把图标数当质量证据。禁止 Emoji 代操作图标不等于禁止用户正文 Emoji。
- CSS/浮层只在 `[data-omnimux-studio]` 子树；独立滚动包含块、局部 sticky dock、局部 modal portal，不覆盖宿主。窄宽度横向滚动参数栏，不遮发送键。focus-visible、键盘 Tab、Esc、对比度和焦点恢复必须实测。

## 5. 验收与未纳入项

F01–F14 的可执行 QA 与工程顺序以系统设计第 7–9 节为准。文档静态通过只证明规范一致；实现合格必须有离线回归及已授权隔离 Host 的 ego-browser 证据。无后端和真实生成是本阶段预期，不是 QA 豁免 Mock 诚实性、scope 隔离或任务一致性的理由。

未来真实接入须独立授权和 Hub seam 设计（鉴权、请求映射、回执、进度、取消、失败、资产寿命），不能承诺“替换 submit 一个函数即可”。本修订不授予插件外部工作树写入、部署、Git 切换、远程操作权限。
