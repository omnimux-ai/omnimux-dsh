## 宿主适配与范围边界

- 官网动作预设的第三方视频及趋势数据不随插件镜像分发；插件复用现有受管公共视频目录，以最近/播放量组织，保留预览、下载、选用、说明和手动上传的业务路径。它不是官网分类、时间窗或素材集合的等价镜像；使用前仍须确认授权。
- 官网游客登录前草稿改为宿主本地会话草稿；宿主连接鉴权控制读写，生成渠道缺失明确报错。没有独立网站游客账号，也不读取其他账号的历史缓存。
- 官网管理员发布/下架、会员支付及公共素材永久托管属于网站账户运营，不迁入角色插件；角色结果继续使用现有本地资产归档，选用灵感不会自动生成或付款。
- 官网云端五槽排队与短链到期改为中枢持久意图和本地受管素材；不承诺同样的云并发数。原生成功记录只有真实文件存在时提供预览入口；丢失文件明确不可用，不以重新提交生成来伪恢复。

## 同步中的优化，不照搬源站问题

- 任务原生格式统一；旧来源 properties.input 只兼容读取。
- 第一份文件保留旧布局，后续任务专属路径，历史不会被下一次生成覆盖。
- 多视角严格来自选定父记录，不借最新图片/当前设定替代。
- 真实浏览器发现第二次生成使旧卡消失，已通过刷新历史修复；两次成功任务有独立文件与参数。
- 官网动作模式按钮存在显式画幅可能被参考画幅覆盖的冲突；插件应尊重显式选择并由真实能力拒绝，而非静默改画幅。
- 生成受理和媒体取回分开；加载失败不是新付费意图。已受理鉴权失败保留原引用，同步缓存续取无需再提交。

### 本轮已证伪并修正的假设

初稿打算用 `videoProcess` 的 `video_scene_detect`（`extractFrames: true`）抽帧。真实 ffmpeg 实测证伪：该能力靠 `gt(scene,0.4)` 选帧，无剪切点的长镜头返回 0 帧（5 秒连续片段 `pts_time` 计数 0，两段拼接片段仅 1 帧），而数字人参考视频大量是长镜头。改为按真实时长等距抽帧（`video_thumbnail_extract`，512 长边、约 1.2 秒一帧、6–12 帧），与源仓实际参数一致（`FrameMinCount=6` / `MaxCount=12` / `SecondsPer=1.2` / `FrameBox=512`）。同一无剪切片段改后稳定产出全部帧。
