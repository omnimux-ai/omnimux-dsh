## 验收发现并修掉的两个缺陷

1. **可见性坐标系（真缺陷）**：`isComfyCardVisible` 把 React Flow 的 `viewport.x/y`（屏幕平移量）当成画布坐标，可见区算成 `[x, x+W/zoom]`。后果：卡片整块在屏幕上（未选中）也判不可见 → 只显示「页面已暂停」且不再重挂。改为 `[-x/zoom, (-x+W)/zoom]`，并把验收方四组复现数据写成用例；复验：原来判错的三个位置现在都挂上，真·移出视口仍卸载。
2. **全屏署名压住卡片**：不隐藏（xyflow 要求保留署名，`hideAttribution` 属付费项），改为全屏时 `position: fixed` 到右下角、层级 3000，署名保持可见；实测该点命中的正是署名链接，且不压内容中心。
