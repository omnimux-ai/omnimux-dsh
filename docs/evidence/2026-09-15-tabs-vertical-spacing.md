# 技能市场与全库双层 Tab 纵向净空实测预演证据

## 1. 验证目标
消除第一层 Tab 与第二层分类胶囊之间的贴脸挤压感，落实 14px ~ 16px 标准舒适呼吸间距。

## 2. CDP 实机实测数据 (Live Dev App)
- 第一层 Tab 底部 (tabBottom): 236px
- 第二层胶囊顶部 (catTop): 252px
- 纵向呼吸间距 (verticalGap): **16px** (完全处于 14px ~ 16px 黄金呼吸间距区间)
- 导航外边距 (navBarMarginBottom): `14px`

## 3. 视觉效果与结论
- 彻底消除了原先仅 2px 的紧贴压迫感，第一层下划线与下方药丸胶囊疏密得当，视觉层级舒展通透。
