# 资产中心卡片按钮双态自适应实机预演验证报告

## 1. 验证目标
验证在调整阈值（max-width: 220px）后：
- 卡片单列宽度 >= 220px（如常规 260px、280px）下，按钮展示「图标 + 名称」，文字不隐藏、不截断；
- 卡片单列宽度 <= 220px（如极窄紧凑 200px）下，按钮自适应收缩为 32px 方形「纯图标」，文字优雅退出布局。
