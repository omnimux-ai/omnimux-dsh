# 技能市场分类胶囊暗灰底白字加粗方案预演证据

## 1. 验证目标
验证分类筛选胶囊对齐业务决策（方案 B）：半透明暗灰底色（`rgba(255,255,255,.16)`）+ 纯白文字（`#ffffff`）+ 加粗字重（`font-weight: 700`），彻底消除纯白实心大药丸的刺眼高反差感。

## 2. DOM 计算属性实测
- `backgroundColor`: `rgba(255, 255, 255, 0.16)`
- `color`: `rgb(255, 255, 255)`
- `borderColor`: `rgba(255, 255, 255, 0.28)`
- `fontWeight`: `700`
- `borderRadius`: `999px`
- 视觉呈现：低调沉浸、暗黑模式下一体化质感极佳，高亮明确且完全不刺眼。
