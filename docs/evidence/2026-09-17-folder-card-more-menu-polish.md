# 验证证据报告：项目卡片「更多操作」菜单对齐 design.md 规范

## 1. 验证目标
解决项目卡片右下角「更多操作」展开的 Popover 菜单样式不合规问题：
- 浮层背景具备 elevated 提升层底色与 16px 毛玻璃高质感微透；
- 「解散项目」作为破坏性操作具备语义危险警示红（文字与图标标红，悬停浅红微光衬底）；
- 菜单面板与子项圆角收敛为 10px 外框与 6px 内切圆角，控件高度统一为 32px 基准；
- 展开进场微动效与按压缩放反馈跟手灵动。
