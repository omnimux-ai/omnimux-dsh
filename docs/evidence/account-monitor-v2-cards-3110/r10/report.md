## 行首禁则：按码位分语义（QA 收口复验 FAIL 主修项）

R9 按**前驱类型**分：前驱 CJK 字 → 拉回；前驱不可断词原子 → 标点留行尾。
QA 以逐行内容测量（@40px，非行数差）证 Chrome 行为**逐码位异质**：

| 码位语义 | 码位 | @40px `中文中文中文X` | Chrome 逐行 |
|---|---|---|---|
| 拉回 | `，。、：；？！﹖﹗`（FF0C/3002/3001/FF1A/FF1B/FF1F/FF01/FE56/FE57） | 4 行 | `中文`/`中文`/`中`/`文X` |
| 悬挂 | `｡､･〉】〕）］｝》」』〞〟`（FF61/64/65/3009/11/15/FF09/3D/5D/300B/0D/0F/301E/1F） | 3 行 | `中文`/`中文`/`中文X` |
| 拉回（本表外补充） | `％`（FF05） | 4 行 | 同拉回组 |

落地语义（`rival-masonry.js`，`LINE_START_PULLBACK` / `LINE_START_HANG` /
`LINE_START_HALFWIDTH_HANG` 三个集合）：

1. 恰宽即放下——Chrome 装入边界是行宽本身；R8–R9 的 −0.5 容差在恰宽时
   多折一行（`中中，`@42 Chrome 2 行、旧模型 3 行；`中中中中中･`@28
   Chrome 3 行、旧模型 4 行），已移除；
2. 悬挂组——ink（约半 advance）不越行宽就挂行尾；挂不下时同样把
   「最近非禁则原子 + 尾部禁则 run」整体带下行（`中中中中））`@63
   Chrome 3 行：首 `）` 挂下、第二个挂不下 → `中）+run` 落下一行）；
3. 拉回组——行尾最近的**非禁则**原子（CJK 字或不可断词原子）连同尾部
   禁则 run 一起下行；行内只剩 head 一个原子时拉不动、挂行尾
   （`中，`@26 → `中，`/`ab`；`aa bb cc，word`@60 → `cc，` 下行）；
4. 前驱本身是禁则标点 → 挂在 run 尾，不链式拉回
   （`中文中文中文。、`@40 = 4 行非 5 行）；
5. 半角悬挂组（`｡､･`）行中即半 advance（`中･ab`@40 单行）。
