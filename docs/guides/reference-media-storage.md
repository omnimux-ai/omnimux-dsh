# 参考素材云存储

在插件页打开“参考素材云存储”，填写兼容 S3 的上传地址、存储空间、区域、公开读取地址及访问凭据，保存一次。未开启时保持原上传方式；开启后，图片或视频生成需要在线参考媒体时使用你指定的存储。

## 保存和生成

保存配置本身不上传素材或调用模型。配置修改作用于后续任务，已提交任务继续按原任务身份收取，不重新生成。更换访问凭据时同时填写标识和密钥；两项留空沿用已配置值。设置页只显示是否已配置，不回显访问值。

生成前先按已有任务规则核对素材，再准备受控副本、上传并匿名读回核对类型、大小和内容摘要。素材不一致、上传失败或公开地址不可读取时，生成不会提交，也不悄悄改传官方存储。重复引用同一份一致媒体可共用一次准备；同来源的内容身份冲突则拒绝。

已有公开媒体链接会检查本次可读内容，不额外镜像到你的存储空间。原有公共文档和网页准入不改成媒体上传，不因开启此设置开放尚未验证的生成操作。原生文件上传渠道仍使用其原文件交付方式。

## 隐私与费用

公开读取地址必须允许生成服务直接读取。它不是私密云备份；拥有公开链接的人可能读取媒体。云存储空间与流量由你的云服务收取，应用不会替你购买服务。

原文件不被搬动。上传后检查失败可能已经留下云端副本，此功能不自动删除云对象，不承诺链接永久有效或第三方内容永久不变。请按你的云服务规则管理副本和权限，给异步生成任务留足取料时间。

## 明确不做

不迁移本地素材库，不同步项目，不提供完整备份或多设备协作。本功能代码和合成测试不等于所有 S3 服务商已实测互通；真实存储账户和生成费用需在你明确授权的验收中确认。
