# 工作台平滑展开设计（#1765）

## 获批目标
左侧导航保持原样，右侧工作台直接平滑铺满剩余区域；进入、退出同节奏，不经过整页全屏中间态。先独立真实原生组件测试页面复现、修正、演示，不改当前页面，不合入正式代码。

## 方案与取舍
采用单一原生布局节奏：保留原生面板和按钮，以插件现有布局接缝消除重复几何写入和方向不对称。复用原生缓动参数。拒绝额外 timeout 掩盖状态竞争；拒绝手造 CSS 页面替代真实应用组件。是否保留原生 fullscreen 模式取决于实际逐帧证据，不把源码嫌疑作为实证。

## 视觉与状态不变量
- 左导航展开/折叠状态不被工作台动作改变；展开宽度及右边界全过程稳定（容差 1 CSS px）。
- 工作台右边界贴视口，左边界在原分栏边界与导航右边界之间直接移动，不能越过导航；离开时恢复原分栏宽度（容差 1 px）。
- 进入和退出相同属性集合、原生时长和缓动。动画可反向接续；减少动态效果时不执行非必要运动。
- 面板内容节点不重建，不刷新页面，不增设第二个全屏按钮，不出现空黑区。

## 实现边界
本任务树插件源码及任务测试/证据可改；主目录只读；官方源码、桌面 fork、#1761 工作树只读且不得修改。与 #1761 可能重叠 sidebar-toggle-topbar.js，仅记录冲突。可本地提交；不 push、merge、物化，不操作共享 Dev 或当前 GUI。

## 调查事实与待证
先前报告确认捕获监听先写 collapsed/width，原生随后写 mode，fullscreen CSS 覆盖 transition，桌面 fullscreen 取消 grid 动画。是否形成可见帧尚待真实原生装配验证。左导航窄屏当前基于 window 宽，不能归因为旧 auto-collapse。
