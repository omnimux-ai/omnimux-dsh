# OmniMux 全域技能检索与会话临时装配 PRD 原型与 UI 元素/文案白名单规格

## 1. 业务目标与价值定位
在 OmniMux 桌面端会话中，解决当前 Agent 专属预设（如 `omni-agent`）过度限制技能面板检索范围的断层，建立“**预设聚焦推荐 + 全局自由穿透 + 单轮临时装配**”的四级技能生命周期：
1. **用户级（全局）**：用户在公共环境（`~/.omnimux-dev/skills`）已安装的全部技能，在任何 Agent 会话均可被检索。
2. **项目级（工作区）**：当前工作区目录下的专属技能，当前工作区内所有 Agent 可见。
3. **Agent 预设级（绑定推荐）**：打开面板无搜索词时，默认展示当前 Agent 角色的精选分类与推荐技能，强化专业心智。
4. **临时检索调用（会话药丸）**：用户通过面板搜索或输入框 `/` 选中的任何外部技能，作为当前轮次的临时附带技能（Ad-hoc Attached Pill）挂载于输入框底栏，随消息发送临时生效，**绝不永久修改 Agent 预设配置文件**。

---

## 2. 用户旅程（User Journey）

### 旅程 A：技能面板全局搜索与临时装配
1. **浏览推荐**：用户在「社媒操盘手」会话中点击输入框底栏「技能」按钮，面板默认展示该预设的推荐分类（如 `全部 | 创作视频 | 创作图片 | 矩阵策略 | 文案改写`）与 5 款专属预设技能。
2. **穿透搜索**：用户在搜索框键入 `skill-creator`。系统感知到 `query` 非空，立即穿透预设沙盒限制，向宿主发起跨渠道（已安装 + 推荐 + 广场）全量模糊匹配。
3. **精准呈现**：列表中实时展示匹配到的 `skill-creator`，若来自非本预设的外部技能，清晰归类展示，无多余装饰性小图标。
4. **即时装配**：用户点击该技能，面板自动收起，输入框底栏即时点亮技能药丸 `[= skill-creator ×]`。
5. **单轮生效与卸下**：用户输入业务提示词并发送，技能作为临时上下文随当轮发出；若用户在发送前点击药丸上的 `×`，立刻安全卸下并还原。

### 旅程 B：输入框 `/` 快捷键入与智能吸附
1. **全量补全**：用户在空输入框中键入 `/`，下拉补全菜单聚合展示当前 Agent 预设技能以及用户级全局安装的所有技能。
2. **直接吸附**：用户键入 `/skill-creator` 并选中或按下回车，输入框内的 `/skill-creator` 文本自动清空，焦点保持在输入框，底栏自动吸附并点亮 `[= skill-creator ×]` 药丸。

## 3. 界面与交互状态机

| 状态 | 触发条件 | 面板表现 | 输入框底栏表现 |
| :--- | :--- | :--- | :--- |
| **S0: 默认推荐态** | 打开面板，搜索框为空 (`query === ''`) | 展示当前 Agent 绑定的分类 Tabs 与预设推荐技能列表 | 无药丸（若之前未选） |
| **S1: 穿透检索态** | 搜索框输入字符 (`query.trim() !== ''`) | 穿透预设限制，调用全域搜索。列表显示全局已安装与公共库匹配项 | 保持当前状态 |
| **S2: 搜索空态** | 搜索词无任何全域匹配 | 显示简约空态提示：`未找到「{query}」相关技能`，底部保留「探索更多」与「+ 创建」 | 保持当前状态 |
| **S3: 临时装配态** | 点击任何匹配的技能卡片 | 面板自动关闭，焦点回到输入框编辑器 | 点亮底栏胶囊药丸：`[= {skill_title} ×]` |
| **S4: 临时卸下态** | 点击药丸的 `×` 按钮，或换片/清除 | 保持当前状态 | 药丸平滑移除，发送 `omnimux:skill:changed` 广播 |

## 4. UI 组件与文案白名单字典（SaaS 科技极简规范）

根据现代 SaaS 科技产品准则（严禁无意义装饰图标，严禁同义重复，严禁营销口号）：

### 4.1 可见组件与文案白名单

| 组件标识 | 出现位置 | 允许文案（逐字定稿） | 禁用反模式（严禁出现） |
| :--- | :--- | :--- | :--- |
| `SearchField` | 技能面板顶部搜索栏 | 占位符：`搜索技能...` | 严禁写 `输入技能名称或关键词试试` |
| `EmptyNotice` | 搜索无结果时 | `未找到「{q}」相关技能` | 严禁堆砌 `换个词试试看`、`去广场逛逛吧` |
| `ExploreButton` | 技能面板底部左侧 | `探索更多` | 严禁带火箭、放大镜等装饰小图标 |
| `CreateButton` | 技能面板底部右侧 | `+ 创建` | 严禁写 `点我创建超级Skill` 等花哨文案 |
| `SkillPill` | 输入框底部工具栏 | 技能标准中文名（或英文 slug），后置 `×` 按钮 | 严禁在药丸旁边追加 `[临时]`、`[会话]`、`[新]` 等冗余徽章 |
| `RemovePillBtn`| 技能药丸右侧关闭按钮 | `aria-label="移除技能"`，`title="移除技能"` | 严禁无无障碍标签 |

## 5. 终验准则（PM Sign-off 检验清单）

- [ ] **预设与穿透双模并存**：在绑定了特定 Agent 预设的会话中，面板打开时展示其预设分类；搜索框输入字符时 100% 能够检索出非预设的全局技能（如 `skill-creator`）。
- [ ] **底栏药丸临时性（零预设污染）**：选中技能后底栏点亮药丸，但 `~/.omnimux-dev/.agent-presets/<preset>/skills.json` 绝不发生任何持久变更。
- [ ] **文案 100% 合规**：无任何未核准的营销形容词、多余徽章和无交互图标。
- [ ] **卸下与自愈**：点击药丸 `×` 能即时卸下；清空或换片时能够联动重置。
