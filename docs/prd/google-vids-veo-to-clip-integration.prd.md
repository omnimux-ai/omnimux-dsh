## 一、项目概述与业务背景

### 1.1 业务痛点与行业背景
在现有的 AI 视频创作流程中，创作者面临着严重的**跨工具流转壁垒与割裂感**：
1. **界面频繁切换**：用户需要脱离本地工作台，在网页版生成平台（如 Google Vids）进行提示词编写与生成；
2. **下载导入耗时费力**：生成完毕后需手动下载庞大的 MP4 视频文件，再重新打开剪辑软件通过文件选择器逐个导入媒体库；
3. **时间轴拼装打断心流**：用户需手动将片段拖拽至时间轴，对齐前序切片，调整黑场空隙，操作繁琐且重复；
4. **弹窗打扰严重**：传统自动化工具在后台执行抓取时频繁弹出操作系统级浏览器窗口，极度干扰用户当前工作。

### 1.2 产品定位与核心目标
本项目旨在打造 **OmniMux 桌面端智能创作中枢**，深度集成谷歌顶尖的 **Veo 视频大模型**能力，并与右侧现有的 **OmniMux Clip 视频剪辑工作台**（基于 OpenReel 工业级时间轴内核）实现原生级无缝协同：
- **后台静默沙箱执行**：借助 **OpenCLI** 命令行引擎配合 **ego 独立任务空间（TaskSpace）**，实现 100% 后台无头静默调度，**零弹窗打扰用户**；
- **非侧边栏常驻中间页**：该生成中枢**不注册到左侧/右侧常驻插件列表**，保持工作台外壳极简，作为创作主舞台的二级中间生成页呈现；
- **项目状态硬门禁自愈**：未建工程前安全锁定生成栏并给予明确指引，进入项目后秒级解锁；
- **生成即进入时间轴**：成片完成后支持**一键无缝 0 间距追加至右侧时间轴主视频轨道**，播放器自动加载播放，彻底消灭手动下载与拖拽断层。

## 三、用户操作流程与状态机规范

### 3.1 项目准入状态硬门禁（Gate Mechanism）
1. **未进入项目状态（初始态）**：
   - 右侧剪辑工作台展示欢迎与新建卡片（“开启剪辑工程”、“新建空白项目并进入”）；
   - 中栏生成工作台顶部常驻黄色醒目门禁条：“⚠️ **请新建或打开项目，进入编辑器页面后方可提交生成**”；
   - 底部提示词输入框置灰禁用，占位符提示“请先进入剪辑项目”，素材卡槽置灰不可点击，右下角向上箭头生成按钮彻底禁用（Disabled）。
2. **进入项目状态（解锁态）**：
   - 用户在右侧点击“新建空白项目并进入”，右侧平滑切换为专业 NLE 多轨道编辑器；
   - 中栏生成工作台顶部黄色门禁条瞬时变为绿色成功状态并于 1.8 秒后平滑向上收起隐藏；
   - 底部提示词框、素材卡槽、参数配置器全面点亮激活，创作者可立即输入指令并派发任务。

### 3.2 任务生成与时间线卡片流（Timeline Stream）
1. **任务派发中（Generating State）**：
   - 用户点击底部「↑ 生成」按钮后，输入抽屉平滑收折，时间线顶部即刻插入一张浅蓝渐变背景的任务卡片（对应截图 1）；
   - **左上角**：以大字号呈现平滑递增的**实时百分比进度**（如 `3%`、`18%`、`45%`、`89%`）；
   - **中间**：呈现平滑推进的进度指示条与“正在通过 ego 独立沙箱调用 Veo 大模型渲染...”文案；
   - **右下角**：提供蓝色的“**取消**”文本按钮，点击后立即向后台发出任务中断指令并优雅移除该卡片。
2. **生成完毕成片态（Completed State）**：
   - 任务渲染完毕后，卡片无缝就地转变为成片卡片（对应截图 2）；
   - **视口预览**：内嵌渲染完成的高清视频，鼠标悬停时自动循环播放微动，移开后暂停；
   - **规格徽标**：右下角悬浮半透明磨砂徽标（如 `720p • 0:10`）；
   - **右上角微标**：展示“👍 建议不错”与“👎 建议没用”轻量反馈按钮。

### 3.3 成片卡片高阶动作栏全链路联动（Action Bar Matrix）

成片卡片底部常驻一排高阶创作工具栏，其与右侧时间轴及底部输入框的联动机制严格对齐截图如下：

| 操作按钮 | 图标与文案 | 核心联动行为与时序响应 (Interaction Effect) |
| :--- | :--- | :--- |
| **插入** | `← 插入` | **直通右侧时间轴**：系统自动调用原子操作将该视频切片追加至 `V1 视频主轨` 末尾，严格执行 **0 间距无缝拼接**；时间轴总时长自动延长，播放指针平滑吸附到新切片起始点，监看播放器即刻加载该视频。 |
| **延续** | `⧉ 延续` | **联动扩展模式（对应截图 3）**：底部输入抽屉自动平滑切换至 **【扩展】** Tab；当前生成的视频缩略图自动挂载到左下方原视频卡槽，右侧显示“清除”文字按钮；输入框占位符自动更新为：“添加您的视频，然后描述接下来会发生什么。” |
| **编辑** | `✎ 编辑` | **联动修改模式（对应截图 4）**：底部输入抽屉自动切换至 **【修改】** Tab；当前视频作为基底载入左侧卡槽，右侧浮现大虚线框 `+ 添加` 卡槽（支持追加辅助参考素材）；输入框占位符更新为：“请描述您想进行的更改”。 |
| **升频** | `⛶ 升频` | **超分增强状态流转**：当前卡片立即切换为进行中状态（显示进度条、实时百分比数值与高保真流光动效）；后台调用 4K 超分辨率与帧率增强管道；完成后卡片徽标升级为 `1080p • 0:10 (已升频)`。 |
| **重新创建** | `⟲ 重新创建` | **快捷复用重投**：系统自动提取本条记录的原始提示词与参数配置，在时间线顶部重新派发一条并行的生成中任务。 |
| **更多菜单** | `⋮` -> `🗑 移除` | **安全清理（对应截图 5）**：点击三个点弹出极简悬浮菜单，点击“移除”，该卡片伴随优雅的缩小与淡出动效从时间线生成流中平滑删除，任务计数同步刷新。 |

### 3.4 首次使用环境就绪向导（Onboarding Wizard）与自愈机制
为了彻底解耦对客户端打包发版周期的依赖，插件采用“**开箱自检向导（Pre-flight Checklist）**”设计：
1. **触发时机**：当用户首次安装并打开该插件时，若本地持久化未记录 `gvids_onboarding_completed: true`，则主动阻断主工作台进入，居中呈现四步引导卡片；
2. **四步检查与一键自愈清单**：
   - **步骤 1：OpenCLI 驱动探测**（检测 `which opencli`，未通过时提供「一键自动安装配置」按钮，后台静默下载安装）；
   - **步骤 2：浏览器安全桥接**（检测 `opencli doctor` 扩展连接状态，未通过时提供「安装 Chrome 扩展」按钮一键唤起应用商店）；
   - **步骤 3：Google 账号登录态**（检测 Google Vids 鉴权会话，未登录时提供「登录 Google 账号」一键引导浏览器登录）；
   - **步骤 4：剪辑工程初始化**（检测右侧 Clip 工程就绪态，未激活时提供「新建空白工程并进入」一键创建）。
3. **完成与持久化**：
   - 当四项指标全绿（4/4 完成）后，向导卡片平滑淡出，永久解锁双栏创作工作台；
   - 本地写入标记，后续再次进入直接秒开工作台，彻底免除用户任何繁琐的终端命令配置。

## 四、四大生成模式功能、卡槽与参数规格拆解

基于用户提供的 4 组基础界面截图，底部收纳型创作抽屉（Collapsible Prompt Box）支持 4 种独立子模式平滑切换：

### 4.1【创建】模式 (Create) — 对应截图 1
- **业务场景**：纯文生视频、多参考图生视频、虚拟形象口播短片。
- **输入区域与卡槽**：
  - **提示词框**：占位符为“描述您的视频。您可以添加品牌图片、角色等素材。”，字符上限 10,000 字符；
  - **虚拟形象卡槽**：左侧独立卡片，点击可从预设数字人库中挑选角色形象；
  - **素材卡槽**：右侧横向虚线卡槽，支持点击或拖拽上传最多 **3 张参考图片**（PNG/JPEG），上传后转化为胶囊徽标内联绑定在提示词下方。
- **参数控制**：底栏胶囊控制器支持设定：
  - 模型：`Omni`（谷歌 Veo 视频大模型）；
  - 画质：`720p`（标清） / `1080p`（全高清）；
  - 比例：`横屏 16:9` / `竖屏 9:16`；
  - 时长：`3 秒 ~ 10 秒`（滑块可调，步长 1s，默认 10s）。

### 4.2【修改】模式 (Modify) — 对应截图 2
- **业务场景**：已有短视频指令级局部重绘或风格迁移（如更替人物服饰、背景光影变换）。
- **输入区域与卡槽**：
  - **提示词框**：占位符为“添加您的视频，然后描述您想做出的更改”；
  - **主卡槽**：中间大面积虚线框提示“**添加视频 (10 秒或更短)**”，支持从本地文件选取或从右侧剪辑轨道当前选中切片一键导入。
- **参数控制**：保持原视频比例，支持设定重绘强度与风格描述。

### 4.3【添加动画】模式 (Animate) — 对应截图 3
- **业务场景**：单张静态图片（摄影作品、商品海报、角色插画）首帧运镜驱动。
- **输入区域与卡槽**：
  - **提示词框**：占位符为“添加您的图片，然后描述视频中应展现的情节。”；
  - **主卡槽**：中间独立虚线框提示“**添加图片**”，支持单张超清主体图上传。
- **参数控制**：自适应图片宽高比，支持设置 3s ~ 10s 动态时长。

### 4.4【扩展】模式 (Extend) — 对应截图 4
- **业务场景**：长镜头分镜自然延伸、前后剧情平滑递进。
- **输入区域与卡槽**：
  - **提示词框**：占位符为“添加您的视频，然后描述接下来会发生什么。”；
  - **主卡槽**：挂载前置基底视频片段。
- **参数控制**：严格继承前序片段的色彩科学、角色外貌与分辨率画幅。

## 五、系统架构与技术实施方案

### 5.1 整体技术拓扑与数据流图

```
[ 用户操作界面 (双栏工作台) ]
       │
       ├─ [中栏：Veo 视频生成工作台] ──(提交任务)──┐
       │                                         │
       └─ [右栏：OmniMux Clip 剪辑工作台] <──┐    │
                                            │    │
                               (自动追加主视频轨)  │
                                            │    v
[ 业务中枢桥接层 (Seam / Store) ] ──────────┼── [ OpenCLI 驱动引擎 ]
                                            │            │
                                            │   (分配独立 TaskSpace, 后台无头运行)
                                            │            v
                                            │   [ ego-browser 独立空间 ]
                                            │   - 复用本地 Google 账号安全 Cookies
                                            │   - 零弹窗打开 Google Vids 会话
                                            │   - 执行提示词/参考图注入并派发 374/376 指令
                                            │            │
                                            │            v
                                            │   [ 谷歌云端 Veo 大模型集群 ]
                                            │   - 执行扩散生成渲染
                                            │   - 通过双向管道下发成片 MP4 直链
                                            │            │
                                            └─(带凭证下载至本地工作区 .workbuddy/media/)
```

### 5.2 核心技术机制与落地约束

#### 1. ego-browser 独立空间后台无头静默机制（零弹窗原则）
- **TaskSpace 隔离运行**：系统调用 `ego-browser` 的独立空间 API，启动后台 Chromium 实例，携带关键配置参数：
  `opencli browser gvids open "..." --window background`；
- **杜绝操作系统弹窗**：通过无头守护进程模式运行，严禁在用户桌面上拉起任何可见的操作系统独立浏览器窗口，绝不打扰用户正在进行的打字或剪辑操作；
- **凭据桥接与安全透传**：直接复用本地 Chrome 浏览器已经登录的 Google 账号安全会话（提取 `SAPISID` 等核心 Cookies 计算带时间戳签名哈希），免密无感建立安全通信；
- **资源安全回收**：每次生成任务结算后，自动清理临时流对象并释放无头浏览器租约，杜绝内存堆积与僵尸进程。

#### 2. 中间页呈现形态（非侧边栏插件设计）
- **空间纯净性**：不向宿主外壳注册任何常驻侧边栏图标或侧边菜单选项，坚决防止侧边栏视觉杂乱；
- **沉浸式主舞台呈现**：以创作工作台的“中间生成主页”形态挂载在视图中栏，与右侧剪辑时间轴形成自然分屏，随时可通过顶部把手调节宽度占比。

#### 3. 结果秒级自动追加时间轴（流水线核心闭环）
- **本地化安全落盘**：从谷歌直链拉取视频流后，直接带凭证写入工作区内部安全目录 `.workbuddy/demo/media/`（坚决杜绝写入 `/tmp/` 导致触发沙箱跨区拦截报错）；
- **时间轴原子操作调用**：
  1. 调用 `omnimux-clip` 的 `projectStore` 注册新媒体项元数据；
  2. 检索当前工程的视频主轨道（`track_video_main`）；
  3. 计算主轨道末尾时间点 `lastEndTimeMs`；
  4. 执行 `clip_edit` 的 `add_clip` 原子指令：
     ```json
     {
       "type": "add_clip",
       "trackId": "track_video_main",
       "mediaId": "media_veo_generated_xxx",
       "startTimeMs": lastEndTimeMs,
       "durationMs": 10000
     }
     ```
  5. 播放头对齐新片段起点，时间轴视图平滑滚动居中，右下角弹出轻量成功吐司通知。

## 六、异常防御与边缘体验保障

1. **未建项目强拦截与引导**：
   - 用户尝试在未建项目状态下强制点击生成按钮时，界面触发轻微晃动反馈，并高亮右侧“新建空白项目”按钮，清晰引导用户完成准入；
2. **云端渲染超时与阶梯重试**：
   - 谷歌 Veo 云端排队偶发延长时，任务卡片进度条以平滑减速算法推进至 `95%`，并提示“云端排队中，正在加速渲染”；若超过 5 分钟未返回，卡片转为“已超时，支持一键重试”；
3. **内容安全策略合规拦截（Safety Filter）**：
   - 若输入的提示词触发谷歌敏感词过滤，精准捕获后台拦截反馈，前端弹出温和提示“提示词包含受限主题，已为您保留文本，请微调后重试”，**100% 保护用户已输入的文字，绝不清空输入框**；
4. **视频主轨锁定保护**：
   - 若用户在剪辑端锁定了 `V1 视频主轨`，系统检测到锁定标志后，自动在上方新建 `V2 视频辅轨` 进行无缝插入，绝不强行覆写被锁定的轨道资产。
