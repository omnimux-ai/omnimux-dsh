# 灵感库分页刷新约束

Issue: #637（父任务 #630）

灵感库把筛选条件变化与分页追加视为两种独立触发：

- 激活页面、授权就绪或筛选变化时加载第一页，并把分页游标复位到 `1`；命中第一页缓存时也必须复位。
- 滚动哨兵只在当前列表可继续加载且没有进行中的加载时追加下一页。
- 追加结果必须保留已有卡片；追加引起的页码或卡片数变化不得再次触发第一页刷新。
- 末页返回 `hasMore: false` 后停止观察和请求。
- 页面未激活时，筛选变化不主动加载；重新激活后按当前筛选加载第一页。

回归测试必须挂载真实 React Hook，至少证明 `20 + 10` 条结果稳定为 `30` 条、末页不再请求，以及筛选变化从第一页重新开始。
