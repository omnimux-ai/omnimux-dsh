# 任务表单与会话草稿

Issue #851。表单负责把用户输入转成可检查的 Prompt 和素材引用，最终发送由现有会话输入框完成。模板配置及校验真源为 `packages/form-contract`。

## 页面

`omnimux-forms:tasks` 是工作台 Tab，提供参考视频拆解、保留结构复刻、替换人物或产品复刻。宽屏案例在左、字段在右，窄屏上下排列。固定操作区不遮挡字段和错误，媒体保持比例。Chakra UI 3 仅在表单子树生效并消费官方主题 Token。

七种字段使用契约原有语义。无效模板不得部分显示；文字不得解释为 HTML。案例是说明素材，不能自动替代用户选择的参考视频。

## 责任与数据

表单插件拥有工作区、模板、版本作用域的填写草稿。恢复时重新校验引用；版本不匹配保留原稿并要求重新填写。重置是显式操作，成功交接不自动清空。

Hub 拥有实际附件导入、字节验证及官方会话草稿接入。领域插件只消费公开 seam，不读取其他插件内部模块，不新建模型路由。Prompt 生成仍调用共享契约。

交接先完成输入与素材验证，再绑定新会话。只有目标输入框确认接受 Prompt 和全部附件才返回成功。请求标识约束重试，已有文本禁止覆盖，过期交接不得写入另一个会话。失败保留填写内容；只能撤回本次交接新增的状态。

## 验收

静态与单测覆盖七种字段、保存/恢复、失效素材、版本不兼容、重复点击、超时、部分失败和会话切换。灵感库使用通用接入后须回归原行为。

合并前以隔离 L2、ego-browser 和 `verify:live forms` 验证模板选择、填写、真实附件导入、草稿恢复及 Prompt/附件交接。合并后用官方入口物化 Dev，再在 45120 重复验证；磁盘同步不替代浏览器验收。模型生成和自动发送不是本插件职责，测试不以付费请求为前提。

本规格不表示运行时已验收。当前 revision、环境身份、测试和浏览器结果保存在任务证据中。
